# Plunge Roughing for Deep Narrow Pockets

Vertical drilling motions, 60-70% step-over. For L/D>4, >45 HRC, weak spindles. Axial forces (strongest direction). Slower MRR but dramatically safer. Tebis generates efficient plunge patterns with minimized repositioning. Use when lateral roughing produces unacceptable vibration.
