# Workplane from SolidWorks Coordinate Systems

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:solidcam-docs`

## Tip

SolidCAM inherits SolidWorks coordinate systems as workplanes. Name descriptively in SolidWorks: OP10-Top, OP20-Front. Active per operation. Probe at setup. This SolidWorks→SolidCAM integration eliminates manual workplane definition — design intent carries through.

- Operation types: `setup`
