# Pocketing Spiral vs Zigzag Tool Path Style Selection

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:catia-docs`

## Tip

In CATIA Prismatic Machining, select Spiral tool path style for closed pockets with rounded corners to maintain constant cutter engagement and reduce shock loading. Use Zigzag (back-and-forth) only for rectangular pockets where sharp directional changes are acceptable. Spiral paths reduce cycle time by 10-15% on average because the tool stays in the cut continuously rather than lifting and repositioning.
