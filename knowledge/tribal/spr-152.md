# Composite CFRP Trimming

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.83` · **Source:** `web:sprutcam-docs`

## Tip

PCD/diamond compression routers, 200-400 m/min, 0.02-0.05mm fz. 5-axis tool normal. Vacuum fixturing. Zig only. Dust extraction mandatory. Delamination-free = sharp tools + controlled feed. SprutCAM programs trim curves with automatic approach/retract for clean edges.

- Material groups: `N`
- Operation types: `specialty`
