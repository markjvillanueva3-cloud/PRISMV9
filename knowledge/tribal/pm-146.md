# Robot Polishing with Force Control

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.81` · **Source:** `web:powermill-docs`

## Tip

PowerMill Robot programs force-controlled polishing with compliant tools. Define target force (5-30N), tool RPM (500-3000), and polishing pattern. The robot's force/torque sensor maintains constant contact pressure across curved surfaces. Use orbital or random motion patterns for uniform material removal. Cycle through grit sequences: 120→240→400→800 for mirror finish.
