# Turbomachinery Milling for Blisks and Impellers

**Category:** `cam_strategy` · **Subcategory:** `scallop` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:siemens-nx-docs`

## Tip

NX's turbomachinery module handles blisks, impellers, and shrouded blades. Define hub, shroud, blade, and splitter surfaces. Roughing uses plunge or slot milling between blades; finishing uses flowline or Z-level on blade surfaces. Use barrel cutters for blade finishing — 3-5× wider step-over for the same scallop height. Check for 5-axis singularities at blade leading/trailing edges.
