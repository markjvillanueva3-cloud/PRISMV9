# Tool Tracking and Usage Reporting Across Programs

SURFCAM tool tracking maintains a log of which tools are used in each program, their total cutting time, and accumulated distance. Use this data to schedule tool replacement before failure. Export tool usage reports for tool crib management. For production environments, link the tool tracking data to the tool preset system so the operator knows which tools to load before running the program.
