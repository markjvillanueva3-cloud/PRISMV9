# Feature Recognition for Hole Automation

Recognize through/blind/countersink/counterbore/tapped holes. Batch assign canned cycles: G81 through, G83 peck, G84 tap. Sort by diameter for tool changes. Tolerance 0.01mm. Review — filleted pockets occasionally misidentified. Tebis batch hole processing saves significant time on fixture plates.
