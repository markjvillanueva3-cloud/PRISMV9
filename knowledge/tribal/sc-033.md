# iMachining Database — Configure Machine and Material Files

**Category:** `speeds_feeds` · **Subcategory:** `cutting_parameters` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:solidcam-docs`

## Tip

Access the iMachining Database via Tools > SolidCAM > iMachining Database to manage machine and material definitions. Each machine entry defines spindle power, torque curves, max RPM, and rigidity class. Each material entry defines hardness, machinability factor, and recommended cutting parameters. Accurate machine data is critical — the wizard's output is only as good as its input.

## Applies to

- Operation types: `roughing`, `pocket_milling`
