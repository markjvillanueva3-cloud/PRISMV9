# Tool Deflection Compensation δ = FL³/3EI

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:cimatron-forum`

## Tip

Cantilever deflection: δ = FL³/(3EI) where F = cutting force, L = overhang, E = 580 GPa (carbide), I = πd⁴/64. For 6mm ball at 40mm overhang, 50N: δ = 0.009mm. Cimatron can apply deflection compensation by offsetting tool position. Critical for finishing deep cavities with long-reach tools where 0.01mm deflection causes visible finish degradation.
