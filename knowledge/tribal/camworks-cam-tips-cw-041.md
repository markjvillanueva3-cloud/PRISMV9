# Offset Finishing — Outward-Spiral Toolpath for Contoured Surfaces

Offset finishing generates concentric toolpath loops that follow the contour shape, spiraling outward from the center. This is ideal for circular or near-circular features (bosses, domes, fillets) where raster patterns would create direction-change marks. Offset maintains consistent tool engagement direction around the feature. Use offset finishing for cosmetic surfaces where any directional pattern would be visible on the finished part.
