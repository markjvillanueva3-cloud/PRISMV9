# Cross-Drilling on Swiss-Type Lathes

Cross-drilling uses live tools mounted perpendicular to the spindle axis. In SprutCAM, define the cross-drill position relative to the spindle centerline. Set C-axis indexing for angular positioning of holes around the part. For deep cross-holes (>3D), use peck drilling with chip clearing. Program the guide bushing position to support the workpiece at the drill location to minimize deflection.
