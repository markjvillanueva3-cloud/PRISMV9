# Cpk Prediction for Mold Cavity Dimensions

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:cimatron-forum`

## Tip

Predict Cpk for critical mold dimensions by combining: machining tolerance (from machine capability), tool wear drift (systematic), thermal expansion uncertainty, and measurement uncertainty. For a target Cpk ≥ 1.33 on a ±0.01mm tolerance: machine capability must contribute ≤0.005mm, thermal drift ≤0.003mm, and measurement uncertainty ≤0.002mm. Use Cimatron's tolerance analysis to identify which dimensions need tighter process control.
