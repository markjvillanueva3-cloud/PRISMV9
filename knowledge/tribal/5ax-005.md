# M140 retracts tool along current tool vector on Hurco 5-axis

**Category:** `cnc_programming` · **Domain:** `document_learned`

**Confidence:** `93` · **Source:** `document:hurco-5axis-post`

## Tip

Hurco M140 retracts tool along current tool vector to machine limit position. Add L parameter for specific retract distance: M140 L3.0 retracts 3 inches. Use M140 instead of G28 Z0 after 5-axis moves to avoid collision during retract when tool is tilted. For Z-home in program header, prefer G53 Z0 (machine coordinates) over G91 G28 Z0 to avoid G90/G91 mode confusion.

## Applies to

- Operation types: `5axis`, `multiaxis`
