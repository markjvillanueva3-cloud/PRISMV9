# Harvey and Helical tool libraries provide pre-configured Mastercam tool definitions

## Tip

Harvey Performance Company (Harvey Tool + Helical Solutions) provides a free Mastercam tool library plugin with full geometry definitions and recommended cutting parameters for their entire catalog. Import tools directly by part number — geometry, corner radius, helix angle, flute count, and material-specific feeds/speeds are pre-populated. Similar plugins exist for Kennametal, OSG, and other major manufacturers. Using vendor-provided libraries eliminates manual data entry errors that cause 15-20% of first-article failures.
