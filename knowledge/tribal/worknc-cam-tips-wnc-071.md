# Robot Path Planning Uses Full WorkNC Toolpath Strategies

WorkNC Robot leverages the full range of WorkNC toolpath strategies (3, 3+2, and 5-axis) for robot machining. The system converts CNC-style toolpaths into robot joint coordinates with automatic collision avoidance. Supports 4-axis to 7-axis robots plus supplementary axes (rotary tables, linear rails, gantries). The robot library includes 250+ models from 22+ suppliers.
