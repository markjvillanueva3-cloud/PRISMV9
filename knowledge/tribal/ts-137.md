# TopSolid PDM Vault — Version-Controlled CAD/CAM Data Management

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `91` · **Source:** `web:topsolid-docs`

## Tip

TopSolid's integrated PDM vault manages all design and manufacturing data: part models, assemblies, CAM projects, tool definitions, post processors, and setup sheets. Every modification creates a new revision with full audit trail. Multiple users can work on the same project with check-out/check-in locking. The PDM prevents the critical error of machining an obsolete part revision. Set up automatic notifications so CAM programmers receive alerts when design revisions are published that affect their active projects.
