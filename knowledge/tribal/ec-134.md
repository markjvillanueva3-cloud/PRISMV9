# Edgecam Designer Split Face for Selective Machining

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:edgecam-forum`

## Tip

Use Designer's 'Split Face' to divide large surfaces into regions with different machining requirements. Project a sketch onto a face to create split lines, then assign different surface finish requirements to each region. This enables selective strategy application — e.g., fine finishing only on sealing surfaces while leaving non-critical areas at roughing finish. Reduces cycle time by 15-25% on parts with mixed surface requirements.
