# Z-Level Finishing for Steep Walls Over 30°

**Category:** `cam_strategy` · **Subcategory:** `scallop` · **Domain:** `cam_software`

**Confidence:** `92` · **Source:** `web:surfcam-3axis-zlevel`

## Tip

SURFCAM Z-level (waterline) finishing produces the best surface finish on steep walls (>30° from horizontal). Set the Z-step based on target scallop height, not a fixed value — use the scallop height calculator with target Ra. For a 10mm ball nose with 0.005mm scallop height target, the Z-step is approximately 0.45mm. Enable 'Smooth connect' between levels to eliminate witness marks at Z-transitions. Always climb mill for best finish on hardened steel.
