# Workplane Naming Convention for Mold Shops

Name descriptively: OP10-CavitySide, OP20-CoreSide, OP30-SlideAccess. Active Workplane per operation. Index workplanes for 3+2. Probe at each setup start. Standard naming across the shop enables any operator to set up any mold without programmer assistance.
