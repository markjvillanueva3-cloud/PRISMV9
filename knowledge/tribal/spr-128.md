# Taper Ball Nose for Deep Cavity Walls

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.83` · **Source:** `web:sprutcam-docs`

## Tip

Ball tip + tapered shank = 30-50% stiffer than straight ball-end. Define ball radius and taper half-angle precisely. Taper must match wall draft. Use for Z-level finishing on draft walls in deep mold cavities. SprutCAM tool definition supports custom taper geometry for accurate simulation.
