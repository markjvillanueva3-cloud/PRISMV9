# Multi-Machine Post for Flexible Scheduling

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:sprutcam-docs`

## Tip

Post same SprutCAM program for Mazak, DMG, Okuma by switching configs. Each applies machine-specific G-codes, axis names, canned cycles. For robot: post for ABB, KUKA, Fanuc from same path. Enables flexible job scheduling across shop floor.
