# Cloud CAM on 3DEXPERIENCE Enables Browser-Based NC Programming

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:catia-docs`

## Tip

The 3DEXPERIENCE platform provides cloud-based CAM through DELMIA roles (NC Milling Machine Programmer, NC Turning Machine Programmer). Programming is done in a web browser with the same core algorithms as desktop CATIA V5 machining. The key advantage is zero local installation and automatic updates. However, cloud computation can be slower for complex multi-axis tool path calculations. For large programs (>100 operations), consider using the desktop Connected Client mode which runs computations locally while storing data on the cloud.
