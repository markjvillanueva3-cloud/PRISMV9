# ERP Integration via Edgecam Workflow Connector

**Category:** `automation` · **Subcategory:** `part_catcher` · **Domain:** `cam_software`

**Confidence:** `0.79` · **Source:** `web:edgecam-forum`

## Tip

Connect Edgecam to ERP/MES systems using the Workflow Connector API. Import work orders containing part number, material, quantity, and due date. Edgecam automatically loads the part file, applies the saved machining template, generates NC code, and writes the estimated cycle time back to the ERP. Configure the connector to poll the ERP database at regular intervals (1-5 minutes) or trigger on new work order creation via webhook notification.
