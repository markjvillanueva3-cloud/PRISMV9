# Steep-Shallow Automatic Strategy Assignment

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.88` · **Source:** `web:sprutcam-docs`

## Tip

SprutCAM detects steep (>65°) and shallow (<65°) regions automatically. Z-level for steep, raster/3D-offset for shallow. Set threshold angle. Overlap 1-2mm at boundaries to eliminate witness lines. Same tool for both passes avoids tool-change marks. Automation reduces programming time 30-40%.
