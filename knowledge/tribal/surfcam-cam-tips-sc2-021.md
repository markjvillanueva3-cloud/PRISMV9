# Closed Pocket with Helical Plunge and Island Avoidance

Closed pockets (no open sides) require the tool to enter from the top. SURFCAM uses helical interpolation plunge with configurable helix diameter (2-3x tool diameter) and ramp angle (2-5°). For pockets with islands, the helix center is automatically placed in the largest open area. Set minimum pocket width to 2x tool diameter — narrower pockets should use a smaller tool for roughing then finish with the target-size tool.
