# hyperMILL Automation Center scripts automate repetitive CAM workflows

**Category:** `automation` · **Subcategory:** `lights_out` · **Domain:** `document_learned`

**Confidence:** `92` · **Source:** `document:hypermill-automation-center`

## Tip

hyperMILL AUTOMATION Center provides scripting for automating repetitive CAM tasks: model preparation, colouring, feature recognition, toolpath generation. Scripts can be saved as toolbar buttons or menu items for one-click execution. Server controller mode runs scripts across multiple parts without user interaction. Critical for production environments processing many similar parts.
