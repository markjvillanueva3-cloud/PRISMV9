# CAD Surface Repair Before Programming

Imported STEP/IGES: gaps, overlaps, tangency breaks. Close gaps to 0.1mm, extend surfaces, rebuild degenerate faces. Fix before programming — machining amplifies defects. SprutCAM surface analysis identifies problems. Clean geometry = prerequisite for accurate toolpath generation, especially 5-axis.
