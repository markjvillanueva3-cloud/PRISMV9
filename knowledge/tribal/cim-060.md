# Lollipop Cutter for Undercut Features

**Category:** `cam_strategy` · **Domain:** `process_engineering`

**Confidence:** `0.82` · **Source:** `web:cimatron-tutorials`

## Tip

Lollipop (undercutting) tools access features behind overhanging geometry. In Cimatron, define the lollipop geometry: ball diameter, neck diameter, neck length. Use 3+2 positioning for undercut access. Verify clearance between neck and surrounding geometry. Set cutting speed based on ball diameter. For mold cores with undercut features, lollipop cutters eliminate the need for EDM in many cases.
