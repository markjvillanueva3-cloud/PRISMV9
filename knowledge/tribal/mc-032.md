# FBM auto-programs prismatic features from solid models

**Category:** `automation` · **Subcategory:** `lights_out` · **Domain:** `cam_software`

**Confidence:** `83` · **Source:** `web:mastercam-docs`

## Tip

Feature Based Machining (FBM) in Mastercam automatically identifies prismatic features (holes, pockets, bosses, slots) on solid models and generates appropriate toolpaths without manual chaining. FBM analyzes feature type, size, and location to select tools and create drilling/milling operations. Best for plate work and fixture plates with many similar features. Not suitable for freeform surfaces or complex 3D geometry.

- Operation types: `drilling`, `pocketing`, `automation`
