# Composite Machining with Diamond Tools

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.83` · **Source:** `web:sprutcam-tutorials`

## Tip

For CFRP/GFRP composite machining in SprutCAM: use PCD (polycrystalline diamond) or diamond-coated tools. Set cutting speed to 200-400 m/min with low feed (0.02-0.05mm/tooth) to prevent delamination. Use 'Compression Router' geometry (up-cut bottom + down-cut top) for clean edges on both faces. Program vacuum clamping as fixture — composites can't handle mechanical clamp pressure without deformation.
