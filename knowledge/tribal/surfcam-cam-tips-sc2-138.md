# SURFCAM Traditional Macro System for Batch Processing

SURFCAM Traditional includes a macro recording system that captures operation sequences for batch processing of part families. Record a macro on the first part, then replay it on subsequent parts with different geometry. The macro system uses relative geometry references, so parts must share the same feature topology. For families with varying hole patterns, use parameterized macros with user-input prompts for hole count and spacing. SURFCAM 2023 replaces this with operation templates and the API.
