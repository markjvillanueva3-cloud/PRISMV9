# Setup Sheet Generation with Tebis

Generate setup sheets from Tebis including: fixture diagram, tool list with dimensions, WCS origin location, program sequence, estimated cycle time, and critical notes. Tebis HTML setup sheet generator exports all operation details automatically. Customize templates to match shop format. Include photos of the physical setup for operator reference. Distribute via network share or MES.
