# Surface Extension for Clean Exit

Extend 2-5mm beyond edges for clean tool exit without deceleration marks. Create extension surfaces in model or use boundary extension. Tool completes stroke on extension before retract. Critical for visible surfaces where exit marks need extra polishing. SprutCAM supports automatic boundary extension.
