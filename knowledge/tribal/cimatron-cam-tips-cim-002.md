# Electrode Extraction from Mold Cavity

Use Cimatron's Electrode Design module to automatically extract electrodes from mold cavities. Set 'Extension Surface' to 2mm beyond the cavity edge for proper spark gap. Group electrodes by burn depth: roughing electrodes with 0.3mm undersize, finishing electrodes with 0.05mm undersize. The electrode blank optimization feature minimizes graphite waste by nesting multiple electrodes.
