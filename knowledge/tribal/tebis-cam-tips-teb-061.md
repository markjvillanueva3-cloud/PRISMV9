# Multi-Axis Deburring and Edge Breaking

Tebis programs automated deburring along detected edges using chamfer or ball tools. Define the edge to deburr, set engagement depth and feed rate. The system generates a 5-axis toolpath following the edge while maintaining consistent contact depth. Use 'Edge Detection' to automatically find edges from the model. Sort edges by region to minimize rapid moves between deburring passes.
