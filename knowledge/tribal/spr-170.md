# Electrode Machining for EDM Precision

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `process_engineering`

**Confidence:** `0.86` · **Source:** `web:sprutcam-docs`

## Tip

Graphite: uncoated 2-flute, 15-24K RPM, vacuum. Copper: sharp tools, flood. SprutCAM tracks undersizing (rough 0.3mm, finish 0.05mm). Program datum pads for CMM on EROWA/3R pallets. Burn position data output for sinker EDM.
