# TopSolid Digital Twin — Virtual Commissioning for New Machines

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:topsolid-docs`

## Tip

When installing a new CNC machine, create the digital twin first in TopSolid: full kinematic model, axis limits, spindle specifications, tool magazine capacity, and turret positions. Run existing jobs through the virtual machine to verify compatibility before the physical machine arrives. This virtual commissioning identifies: required post processor modifications, tool magazine capacity issues, axis travel limitations, and cycle time estimates on the new platform. The twin reduces new machine ramp-up time from weeks to days by having verified programs ready on day one.
