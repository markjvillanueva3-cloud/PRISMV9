# Cloud Post Editor for Browser-Based Customization

**Category:** `post_processor` · **Subcategory:** `tool_change` · **Domain:** `cam_software`

**Confidence:** `84` · **Source:** `web:fusion360-docs`

## Tip

Fusion's Cloud Post Editor (introduced 2025) lets you edit post processors directly in the browser without VS Code. It provides a side-by-side view of the post code and the resulting G-code output, updating in real time as you modify the JavaScript. Use it for quick property adjustments and to test the effect of code changes immediately. For complex modifications, still export to VS Code where you get full debugging and Git integration.
