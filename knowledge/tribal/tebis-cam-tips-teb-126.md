# Multi-Setup Coordinate System Alignment

For multi-setup parts, define master coordinate system shared across all setups. Each setup workplane references the master datum. Use probing routines at start of each setup to verify alignment. When machining both sides, use precision dowel pins or 3-2-1 locating to ensure Setup 2 aligns with Setup 1 features. Tebis setup sheets include datum locations for each workplane.
