# Code Wizard Tool List and Setup Sheet Generation

Configure Code Wizard to output tool lists and setup sheets as secondary output files. Use the FileOutput event to create CSV/HTML/PDF tool lists containing tool number, description, diameter, length, holder, offset number, and estimated life remaining. Include setup information: work offsets, stock dimensions, first-tool Z-height, and total cycle time. Output to a shared folder for operator access via shop floor tablets.
