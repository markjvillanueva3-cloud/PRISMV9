# Rotary Axis Wrapping for Round Mold Components

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.83` · **Source:** `web:cimatron-docs`

## Tip

Wrap 2D patterns onto cylinders via rotary substitution. Verify diameter matches actual part. For engraving text, logos on round components. X converts to rotary. Cimatron generates rotary G-code automatically. Circumferential scale distortion if diameter wrong.
