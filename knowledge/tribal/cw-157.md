# CAMWorks API for SOLIDWORKS — Custom Automation via VBA/C#

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:camworks-docs`

## Tip

CAMWorks exposes an API accessible from SOLIDWORKS VBA macros and C# add-ins. Automate repetitive tasks: batch-generate operations for part families, extract cycle time estimates for ERP integration, modify tool parameters programmatically, and create custom setup sheet templates. The API documentation is in the CAMWorks installation folder under API/. Common uses: automated first-article setup for new jobs, custom report generation, and integration with shop scheduling systems.
