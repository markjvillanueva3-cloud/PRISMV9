# Machine Definition vs Control Definition vs Post Processor — know the layers

**Category:** `post_processor` · **Subcategory:** `formatting` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:mastercam-docs`

## Tip

Mastercam separates machine setup into three layers: Machine Definition (physical machine kinematics, axis travel, spindle), Control Definition (how arcs, canned cycles, and G-codes are output), and Post Processor (exact format and ordering of the NC output). Most shop customizations only need Control Definition changes. Only edit the post (.pst) file when you need to change output formatting or add custom M-codes.
