# hyperMILL collision check requires pre-defined stock model and tool holder definition

**Category:** `cam_strategy` · **Domain:** `document_learned`

**Confidence:** `93` · **Source:** `document:hypermill-manual`

## Tip

hyperMILL collision checking analyzes tool holder against current stock model (tracked stock) and turning model. Preparation: 1) Define accurate tool holder geometry in Tool Management, 2) Create initial stock model before first operation, 3) Enable 'Generate resulting stock' on each operation so stock updates progressively. Without proper stock tracking, collision check reports false positives or misses real collisions.

- Operation types: `setup`, `simulation`
