# Closed Pocket Island Detection and Machining Strategy

When machining closed pockets with islands, CATIA automatically detects island geometry if you select the pocket bottom and island tops as guide elements. Enable 'Island Detection' in the strategy parameters and set the island offset to match your finishing allowance (typically 0.2-0.5mm). Use the Spiral-from-outside style to approach islands progressively rather than plunging near them, which reduces deflection risk on thin island walls.
