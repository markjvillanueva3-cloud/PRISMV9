# Feature Recognition for Automated Hole Programming

Cimatron recognizes holes (through, blind, countersink, counterbore, tapped) from the 3D model. Assign drilling strategies in batch after recognition. Set recognition tolerance to 0.01mm. Sort by diameter for optimal tool changes. Assign canned cycles: G81 through, G83 peck deep, G84 tapping. Review the feature list — filleted pockets occasionally misidentified as holes.
