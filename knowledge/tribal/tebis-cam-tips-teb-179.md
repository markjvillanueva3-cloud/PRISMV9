# Collision Avoidance with Safety Margin

Set collision detection to include full tool assembly plus 0.5mm safety margin. Shrink-fit holders for minimum profile. Extended tools: 50% feed at 7:1 L/D. Tebis gouge check after every finish operation. Machine simulation catches holder/machine interference that toolpath-only checking misses.
