# In-Process Inspection for Critical Dimensions

BobCAD in-process inspection inserts probing cycles between operations to verify dimensions before proceeding. Probe bore diameter after semi-finish — if out of tolerance, adjust offset or alert operator. Program conditional logic with macro variables for go/no-go decisions. This prevents scrap from propagating through operations. BobCAD integrates probing as a standard operation type in the CAM Tree, positioned between machining operations.
