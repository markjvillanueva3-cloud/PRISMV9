# Sinker EDM Orbital Motion for Improved Flushing

**Category:** `cam_strategy` · **Domain:** `process_engineering`

**Confidence:** `87` · **Source:** `web:esprit-sinker-edm`

## Tip

Orbital sinker EDM in ESPRIT moves the electrode in a circular or elliptical orbit while plunging, improving dielectric flushing and debris evacuation. Set the orbital radius to the electrode undersize amount (0.05-0.2mm for roughing, 0.01-0.05mm for finishing). Orbital motion produces more uniform surface finish than static plunging and allows using fewer electrodes. It is especially effective for deep cavities (depth > 3x width) where flushing is critical.
