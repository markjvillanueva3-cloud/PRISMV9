# Canned Cycle Output for Standard and Custom Cycles

**Category:** `post_processor` · **Subcategory:** `controller_quirk` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:bobcad-canned-cycles`

## Tip

BobCAD posts map drilling operations to controller canned cycles: G81 spot, G83 peck, G73 chip-break, G84 tap, G85 bore, G76 fine bore. V37 added native peck tapping support for Fanuc, Siemens, Heidenhain, and Haas — eliminating the need for custom scripts. Configure cycle output per controller brand. For custom cycles, the post editor supports user-defined G-code sequences that can be triggered from specific operation types.

## Applies to

- Operation types: `posting`, `drilling`
