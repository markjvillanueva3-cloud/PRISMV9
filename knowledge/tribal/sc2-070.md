# S-POST with Factory Interface Language for Complex Logic

**Category:** `post_processor` · **Subcategory:** `macro_call` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:surfcam-spost-fil`

## Tip

SURFCAM S-POST uses the Factory Interface Language (FIL) for advanced post-processor customization with conditional logic, variable manipulation, and mathematical operations. Use FIL when M-POST templates cannot handle the required logic — for example, automatic tool length measurement macros, adaptive feed rate calculation, or conditional sub-program generation. S-POST has 50+ pre-built post processors for major machine brands.
