# NXOpen Journal Automation for Batch Operations

**Category:** `automation` · **Subcategory:** `part_catcher` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:siemens-nx-docs`

## Tip

Record NXOpen journals (Python, C#, VB.NET, Java) to automate repetitive CAM tasks. Common automations include: batch-regenerating all toolpaths after a design change, exporting tool lists for all setups in a part file, posting multiple operations to separate NC files, and generating shop documentation. Journals run inside NX with full access to the CAM API. Schedule journal execution via command line (run_journal.exe) for overnight batch processing. A single journal can process an entire folder of part files unattended.
