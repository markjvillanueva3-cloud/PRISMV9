# LHS for Efficient Parameter Space Screening

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.77` · **Source:** `web:powermill-forum`

## Tip

Latin Hypercube Sampling: 5 factors at 3 levels → factorial=243 runs, LHS=30-50 with comparable coverage. Each level sampled equally while exploring full space. Use for initial PowerMill parameter screening before targeted RSM. Essential when physical trials are expensive — large aerospace parts, exotic materials, limited machine time.
