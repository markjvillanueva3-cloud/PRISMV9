# Probing for In-Process Verification

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:sprutcam-docs`

## Tip

Program probe cycles: verify stock, check WCS, measure between operations. Output for Renishaw/Heidenhain/Blum. Store for SPC. Verify rough allowance before semi-finish to prevent overload. SprutCAM post processor generates probe macros in machine-specific format automatically.
