# M128/M129 control TCPM for simultaneous 5-axis on Hurco

**Category:** `cnc_programming` · **Domain:** `document_learned`

**Confidence:** `94` · **Source:** `document:hurco-5axis-post`

## Tip

Hurco M128 enables Tool Center Point Management (TCPM) for simultaneous 5-axis machining. M129 cancels TCPM. With M128 active, all XYZ coordinates reference the un-rotated workpiece system while the machine compensates for rotary axis position. Position XY and Z to initial point BEFORE M128 to avoid travel limit errors. TCPM is essential for smooth 5-axis surface machining with IJK tool vectors.

- Operation types: `5axis`, `multiaxis`
