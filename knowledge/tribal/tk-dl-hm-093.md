# Create bounding box for stock model definition

**Category:** `setup` · **Domain:** `document_learned`

**Confidence:** `90` · **Source:** `document:hypercad-s-v33@p173`

## Tip

Use Analysis → Create bounding box to generate a cuboid or cylinder enclosing selected geometry. Enable 'Minimize volume' for optimal XY rotation fit. Output as Lines, Faces, or Solid. Enable 'Points' to generate center points on each face — useful for positioning CAM reference systems. Offset distributes evenly on both sides. Align to current workplane or select a planar face as reference.
