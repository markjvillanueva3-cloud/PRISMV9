# Tebis Blade Module for Turbine Components

Tebis blade module handles blisks, impellers, and individual blades. Define hub, shroud, blade surfaces, splitter blades. Generate roughing (plunge between blades), semi-finishing, and hub finishing toolpaths. Use barrel cutters for blade finishing — 3-5× wider step-over for same scallop height. Check 5-axis singularities at blade leading/trailing edges.
