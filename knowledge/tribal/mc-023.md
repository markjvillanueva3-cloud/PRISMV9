# Control Definition handles canned cycle and arc output format

**Category:** `post_processor` · **Subcategory:** `tool_change` · **Domain:** `cam_software`

**Confidence:** `84` · **Source:** `web:community`

## Tip

The Control Definition in Mastercam determines how drilling canned cycles are output (G81/G82/G83 vs. expanded code), arc output format (IJK incremental vs. R-word), and plane selection codes (G17/G18/G19). To change a drill cycle from G73 chip-break to G83 deep-peck, edit the Control Definition — not the post. This is the most common customization need and does not require post-processor editing skills.
