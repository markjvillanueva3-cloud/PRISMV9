# PCI Macro Language for Custom Automation

**Category:** `automation` · **Subcategory:** `robot_loading` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:edgecam-pci`

## Tip

Edgecam's PCI (Programmable Command Interface) macro language provides full programmatic access to all CAM functions. Write PCI macros to automate repetitive tasks: batch tool loading, standard operation creation, report generation, and custom workflows. PCI uses a Basic-like syntax with access to Edgecam's object model. Start with the macro recorder to capture manual operations, then edit the recorded code to add logic and parameters.
