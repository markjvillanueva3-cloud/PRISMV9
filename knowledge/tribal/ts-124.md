# TopSolid'Cam 7 Contextual Machining — Feature-Driven Operation Proposals

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `91` · **Source:** `web:topsolid-docs`

## Tip

TopSolid'Cam 7's contextual machining analyzes selected features and proposes appropriate operations based on the feature type, material, and tolerance. Select a bore and the system proposes drill → ream or drill → bore based on the tolerance annotation. Select a pocket and it proposes roughing → finishing with appropriate tool sizes. The proposals are based on rules stored in the machining knowledge base, which can be customized per shop. Accept, modify, or reject each proposal — the system learns from your choices to improve future proposals.

## Applies to

- Operation types: `milling`, `drilling`
