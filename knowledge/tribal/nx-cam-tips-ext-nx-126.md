# Machine Tool Builder for Custom Kinematics

NX's Machine Tool Builder creates custom machine kinematic models for simulation. Define: axis types (linear/rotary), travel limits, home positions, and collision bodies. Import machine CAD geometry and assign to kinematic components. The resulting model enables accurate ISV (Integrated Simulation and Verification) for custom or modified machines. Critical for 5-axis machines with non-standard head/table configurations.
