# Dynamic Mill region types control material engagement precisely

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:community`

## Tip

Dynamic Mill supports four chain region types: Containment (limits tool motion boundary), Avoidance (areas the tool must not enter), Air (regions with no material — tool can traverse freely), and Entry (forced entry points). Combining these regions in a single toolpath gives precise control over where the tool cuts without needing multiple operations. Always define avoidance regions for clamps and fixtures.

## Applies to

- Operation types: `roughing`, `2d_pocket`
