# Automatic Tool Selection — Let TechDB Choose the Best Tool

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:camworks-docs`

## Tip

Configure TechDB tool selection rules to automatically choose tools based on feature type, size, and material. Rules specify: minimum and maximum tool diameters per feature dimension, preferred tool types (solid carbide vs. indexable), and tool material (HSS, carbide, ceramic, CBN) per workpiece material. Test automatic selection against manually programmed benchmark parts — if the automatic selection consistently produces comparable results, trust it for routine parts and reserve manual selection for critical features.

## Applies to

- Operation types: `milling`, `drilling`
