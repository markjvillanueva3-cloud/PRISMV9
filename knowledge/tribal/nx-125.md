# Teamcenter Integration for Manufacturing PLM

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:siemens-community`

## Tip

NX CAM integrates with Teamcenter for full PLM: version-controlled NC programs, tool libraries shared across sites, approved cutting parameter databases, and manufacturing BOMs. Use 'Release to Shop Floor' workflow to push approved programs to DNC. When the design revision changes in Teamcenter, NX flags affected manufacturing operations for re-verification. This prevents obsolete programs from reaching the machine.
