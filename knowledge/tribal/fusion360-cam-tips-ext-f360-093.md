# Geometry Inspection with Tolerance Bands

Probe Geometry lets you measure bores, bosses, webs, and faces in-process and compare against nominal dimensions with configurable tolerance bands. Set the Upper and Lower tolerance for each feature to match the drawing callout (e.g., +0.025/-0.000 for an H7 bore). When the measurement falls outside tolerance, the controller can trigger a tool offset update, alarm, or conditional branch to a rework operation. This converts your CNC into a closed-loop manufacturing cell.
