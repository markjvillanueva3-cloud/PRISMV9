# NC Template Automation for Repeat Jobs

Create NC Templates in Cimatron that capture the full machining sequence (roughing → semi-finish → finish → pencil → drilling) with relative tool selections and parameterized stock allowances. Apply templates to similar parts using 'Apply Template' — Cimatron automatically maps geometry features. Update templates when process improvements are validated to propagate best practices.
