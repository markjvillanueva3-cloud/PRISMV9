# Machine Tool Kit Posts for Turnkey Deployment

**Category:** `post_processor` · **Subcategory:** `controller_quirk` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:siemens-nx-docs`

## Tip

NX Machine Tool Kits provide complete post + machine model + simulation packages for specific machine/controller combinations. Install the kit and receive a validated post processor, accurate machine kinematics model for ISV, and controller-specific cycle definitions. Kits are available for major manufacturers (DMG MORI, Mazak, Okuma, Haas). Using a kit instead of building from scratch saves 2-4 weeks of post development and catches machine-specific quirks like non-standard canned cycle formats and rotary axis unwinding behavior.
