# Pareto Front for Quality vs Cycle Time Trade-Off

**Category:** `optimization` · **Subcategory:** `cycle_time` · **Domain:** `cam_software`

**Confidence:** `79` · **Source:** `web:tebis-forum`

## Tip

Build Pareto front by varying step-over (0.1-0.5mm) and feed (0.03-0.10mm/tooth) in Tebis. Plot surface finish vs cycle time. The Pareto-optimal set shows best achievable quality at each cycle time. Tight-tolerance molds favor quality end; production dies favor speed end. The Pareto front is specific to each tool-material-machine combination.
