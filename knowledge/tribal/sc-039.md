# Machine Simulation Collision Tolerance — Set Appropriate Clearance

**Category:** `safety` · **Domain:** `safety`

**Confidence:** `86` · **Source:** `web:solidcam-docs`

## Tip

SolidCAM's collision control includes a tolerance parameter that filters out near-miss detections below a specified value. Set collision tolerance to 0.5–1.0 mm for roughing verification and tighten to 0.1–0.2 mm for finishing and 5-axis operations. Too tight a tolerance on roughing generates false positives; too loose on 5-axis risks real collisions going undetected.

## Applies to

- Operation types: `all`, `5axis_finishing`
