# Spiral Finishing for Flat Pocket Floors

**Category:** `finishing` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:tebis-docs`

## Tip

For flat or near-flat pocket floors, spiral finishing produces superior surface quality vs raster. Continuous spiral motion eliminates direction changes that leave witness marks. Set step-over for target scallop height. Use climb milling direction. Tebis spiral auto-computes the center start point and expands outward to the boundary. Best for visible flat surfaces.
