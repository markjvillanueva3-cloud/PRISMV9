## Tip

OEE = Availability × Performance × Quality. Availability: uptime/scheduled. Performance: estimated vs actual feeds. Quality: CMM pass/fail per program version. Typical: 75-85%. Gap analysis: slow rapids (Performance), excess tool changes (Availability), parameter drift (Quality). Target 85%+.
