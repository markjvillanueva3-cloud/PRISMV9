# Full Machine Simulation with Kinematic Model

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `91` · **Source:** `web:edgecam-simulation`

## Tip

Edgecam's machine simulation uses a full kinematic model of the CNC machine including all axes, spindles, turrets, tailstocks, and sub-spindles. The simulation displays all machining action in real time, providing a highly accurate animated view of the process. Always run full machine simulation before first-article production, verifying tool changes, work offsets, and all rapid moves. This provides peace of mind that the program is correct.
