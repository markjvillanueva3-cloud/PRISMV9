# Wire EDM Integration for Hybrid Workflows

**Category:** `setup` · **Domain:** `process_engineering`

**Confidence:** `82` · **Source:** `web:tebis-docs`

## Tip

Export Tebis geometry to wire EDM for features better suited to wire: thin slots, sharp corners, hardened inserts. Define start holes in Tebis, drill during milling setup. Coordinate WCS between programs. Wire for thin/sharp, milling for 3D surfaces. This hybrid approach uses each process optimally.
