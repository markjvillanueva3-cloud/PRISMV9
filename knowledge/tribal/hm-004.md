# hyperMILL turning model must be closed planar contour in X-Z plane of turning frame

**Category:** `setup` · **Domain:** `document_learned`

**Confidence:** `92` · **Source:** `document:hypermill-manual`

## Tip

A hyperMILL turning model requires a closed, planar contour located exactly in the X-Z plane of the defined turning frame. Select surfaces or solid → hyperMILL auto-generates the 2D turning contour. Resolution parameter controls contour fineness for complex surfaces. The turning contour creates a Contour feature in the feature browser. For multi-setup parts, define separate turning models per setup/frame.
