# SPC Control Charts for Critical Dimensions

After establishing a stable PowerMill program, implement SPC on critical dimensions. Set control limits from the first 25 parts (X-bar and R charts). Monitor for: trends (7 consecutive points on one side of CL = tool wear), shifts (sudden jump = fixture or WCS issue), and increasing range (tool breakage or vibration onset). Re-qualify the program when any out-of-control signal is detected.
