# FMEA for NC Program Risk Management

Link Process FMEA to PowerMill operations. Per operation: failure modes (tool break, drift, defects), effects (scrap, rework), RPN = Severity×Occurrence×Detection. High-RPN: add probing, reduce tool life limits, add redundant passes. Aerospace/automotive OEMs require FMEA traceability. PowerMill operation notes can store FMEA linkage data.
