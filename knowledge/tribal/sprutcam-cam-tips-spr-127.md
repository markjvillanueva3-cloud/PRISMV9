# Plunge Roughing for Deep Narrow Features

Vertical drilling motions, 60-70% step-over. For L/D>4 slots, >45 HRC materials, weak spindles. Axial forces (strongest direction). Slower MRR but dramatically safer. SprutCAM generates efficient plunge patterns with minimized repositioning distance between plunges.
