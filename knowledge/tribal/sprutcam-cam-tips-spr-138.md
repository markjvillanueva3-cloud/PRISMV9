# Workplane Management for Multi-Setup

Define workplanes per setup. Active Workplane per operation. Index workplanes for 3+2. Name descriptively: OP10-Top, OP20-Front. Probe at each setup start. Precision pins or 3-2-1 for cross-setup alignment. SprutCAM generates rotary positioning commands per workplane automatically.
