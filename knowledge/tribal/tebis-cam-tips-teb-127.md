# Disc Cutter for Slot and Groove Machining

Define disc (slitting/slotting) cutters in Tebis with correct geometry: disc diameter, thickness, bore size, number of teeth. Use 3+2 axis positioning to orient the disc for each slot. Set cutting speed based on disc outer diameter. Feed per tooth must account for large tooth count (20-60). Enable flood coolant for chip evacuation from the slot.
