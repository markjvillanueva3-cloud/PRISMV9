# Probing Integration for In-Process Verification

**Category:** `setup` · **Subcategory:** `probing` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:tebis-docs`

## Tip

Tebis programs probing cycles for in-process verification: measure stock dimensions before machining, verify WCS after setup, check critical dimensions between operations. Output probing routines in the NC program using machine-specific probe macro formats (Renishaw, Heidenhain, Blum). Store measured data for SPC analysis and trend monitoring.
