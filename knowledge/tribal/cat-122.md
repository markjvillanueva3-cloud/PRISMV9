# 3DEXPERIENCE Collaborative Manufacturing vs V5 Standalone Workflow

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:dassault-forum`

## Tip

3DEXPERIENCE manufacturing apps (NC Milling Programmer, NC Turning Programmer) store all machining data as PLM objects with revision control, enabling multi-user concurrent NC programming. In V5, CATProcess files are monolithic — only one user can edit at a time. For large aerospace programs, split manufacturing programs by setup/fixture in 3DEXPERIENCE so multiple programmers work on different setups simultaneously. Use the 'Manufacturing Review' role to give shop-floor users read-only access to the latest machining program without CAM licenses.
