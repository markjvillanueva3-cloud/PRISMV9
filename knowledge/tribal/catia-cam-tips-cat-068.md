# User Defined Features Package Complex Machining Sequences

CATIA User Defined Features (UDFs) in the machining context package a complete machining sequence (multiple operations with tools and parameters) into a single reusable object. Unlike PowerCopy, a UDF includes input/output specifications and can validate applicability before instantiation. Create UDFs for complex multi-step processes like 'bore finishing sequence' (rough bore → semi-finish → finish bore → chamfer) and deploy them across multiple Manufacturing Programs.
