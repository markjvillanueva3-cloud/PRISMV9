# Cooling Channel Drilling Sequences

**Category:** `cam_strategy` · **Subcategory:** `drilling` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:cimatron-forum`

## Tip

For mold cooling channels, program gun drilling with through-coolant at 70+ bar. Plan drilling sequences to avoid intersecting existing channels under pressure. Use Cimatron's cooling channel design view to verify intersection angles (target 90°±5° for cross-drilled channels). Plug drill entry points with pipe plugs — add M00 program stops before each plug location for operator verification.
