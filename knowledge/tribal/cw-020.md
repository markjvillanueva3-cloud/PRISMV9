# Custom TechDB Parameters — Store Shop-Specific Variables

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:camworks-docs`

## Tip

Extend TechDB with custom parameters for shop-specific requirements. Examples: coolant type (flood/mist/through-tool), clamping force limits for thin-wall parts, minimum tool life expectation (minutes), chip breaker preference. These custom fields can be referenced in post processor output — e.g., embedding coolant codes or tool life monitoring commands in G-code automatically based on TechDB settings.

## Applies to

- Operation types: `milling`, `turning`
