# Mold Base Standard Component Integration

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:cimatron-docs`

## Tip

Cimatron's Mold Design module includes standard mold base catalogs (HASCO, DME, Meusburger, FUTABA). Select the base, auto-position guide pins, ejector pins, and cooling channels. The NC Setup inherits these components as collision bodies — no separate definition needed. Machine around standard components with automatic avoidance zones defined from the mold base geometry.
