# Feature Recognition for Automated Hole Machining

PowerMill's feature recognition identifies holes (through, blind, countersink, counterbore, tapped) from the 3D model. After recognition, assign drilling strategies to each feature type in batch. Set recognition tolerance to 0.01mm. Review the feature list — occasionally, filleted pockets are misidentified as holes. Sort features by diameter to optimize tool change sequences.
