# CAMWorks for Solid Edge — Same Engine, Different Host CAD

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:camworks-docs`

## Tip

CAMWorks for Solid Edge provides the same machining engine (AFR, TechDB, VoluMill) as CAMWorks for SOLIDWORKS, but runs inside Siemens Solid Edge. The TechDB is identical and portable between platforms — export your SOLIDWORKS TechDB and import it into the Solid Edge version. Feature recognition works on Solid Edge's Synchronous Technology models (direct editing) as well as traditional Ordered models. This enables shops using both CAD systems to standardize on one CAM knowledge base.
