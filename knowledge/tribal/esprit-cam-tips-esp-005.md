# ProfitMilling Multi-Level Roughing with Variable Depths

For deep pockets, ProfitMilling multi-level roughing supports variable axial step-downs. Use aggressive depths (1.5-2x diameter) in the upper levels where the tool is well-supported, then reduce to 0.5-1x diameter near the bottom where chip evacuation is challenging. Enable the 'progressive depth' option to have ESPRIT automatically taper the step-down based on pocket depth and aspect ratio.
