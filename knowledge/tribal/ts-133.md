# TopSolid'Cam 7 Batch Processing — Multiple Parts in One Session

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:topsolid-docs`

## Tip

TopSolid'Cam 7 supports batch processing: apply the same machining template to multiple similar parts automatically. Load a folder of part files, assign each to a template, and TopSolid generates toolpaths for all parts in sequence. Review results for each part before posting. This is ideal for job shops with families of similar parts (e.g., mold inserts of varying sizes). Batch processing with automatic tool assignment can generate programs for 10-50 similar parts in the time it takes to manually program 2-3.
