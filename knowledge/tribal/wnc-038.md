# Draft Angle Machining for Textured Mold Surfaces

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:worknc-draft`

## Tip

WorkNC accounts for draft angle requirements when machining mold surfaces destined for texturing. The minimum draft must be 1 degree per 0.01 mm of texture depth (VDI 3400 standard). Verify draft angles using the surface analysis tool before machining. For textured surfaces, leave 0.02-0.05 mm extra stock for the texturing process (etching removes material). Program these surfaces with consistent tool-mark direction.
