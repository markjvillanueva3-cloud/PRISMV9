# Local vs Cloud Post Storage for Shop Consistency

Store your customized post processors in the Local library on a shared network drive so all programmers use the same version. Cloud posts auto-update from Autodesk, which can break your customizations without warning. After customizing a post, save it locally and version-control it with Git. Only pull updates from the cloud library to a test location first.
