# OptiRest uses stock model for targeted 3D rest roughing

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `84` · **Source:** `web:community`

## Tip

OptiRest (OptiRough using Stock) targets only the material left by a previous roughing operation. Feed it the stock model from the prior OptiRough or Area Rough pass and it generates Dynamic Motion toolpaths only where material remains. This is far more efficient than running a second full-coverage roughing pass. Cycle time savings of 40-60% are typical on complex 3D parts versus re-running OptiRough with a smaller tool.
