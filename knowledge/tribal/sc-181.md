# Feature Recognition for Drilling Automation

**Category:** `cam_strategy` · **Subcategory:** `drilling` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:solidcam-docs`

## Tip

Recognize holes from SolidWorks model. Batch assign: G81 through, G83 peck, G84 tap. Sort by diameter. Tolerance 0.01mm. SolidCAM inherits SolidWorks feature data directly — no separate recognition needed. Saves programming time on complex parts with 50+ holes.
