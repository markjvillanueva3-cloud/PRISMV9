# TopSolid Swiss-Type Synchronization — Gang Tool Overlapping

**Category:** `cam_strategy` · **Subcategory:** `drilling` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:topsolid-docs`

## Tip

TopSolid's synchronization editor for Swiss-type machines enables overlapping operations on different tool posts. While the main turret performs OD turning, the cross slide can simultaneously drill or mill. The editor shows a timeline with each tool post as a lane, and sync points coordinate critical moments (part-off, sub-spindle pickup). TopSolid checks for physical interference between simultaneous operations and alerts if two tools would occupy the same zone. Optimize overlap to reduce cycle time by 20-40% compared to sequential operation.

## Applies to

- Operation types: `turning`, `milling`
