## Tip

hyperMILL AUTOMATION Center basic workflow: (1) Create script in Manage mode, (2) add template commands in Template mode (Start → NCS → Stock → Fixture → Feature Recognition → Pocket Recognition → Basic Programming → Optimize → Calculate → NC File), (3) define parameters in Parameter mode. Use 'Stop for input' on interactive steps (job list name, machine, material, fixture selection). Copy parameters between functions by double-clicking to avoid duplicate naming. Execute with 'Run until next stop' for step-by-step verification.
