# Manufacturing Templates with Material-Specific Presets

**Category:** `automation` · **Subcategory:** `part_catcher` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:fusion360-docs`

## Tip

Build separate manufacturing templates for each material group: aluminum alloys, mild steel, stainless steel, hardened steel, titanium, and plastics. Each template should include proven feeds/speeds, stepover/stepdown, stock-to-leave, and coolant settings. When deploying a template to a new part, Fusion auto-matches tool diameters from the document library. Maintain templates with version dates in the name (e.g., 'Aluminum-Roughing-v2026-03') so operators know they are using the latest validated settings.

## Applies to

- Material groups: `P`, `M`, `N`, `S`, `H`
- Operation types: `general`
