# ESPRIT Edge CAD Model Revision Tracking

**Category:** `workflow` · **Domain:** `cam_software`

**Confidence:** `0.83` · **Source:** `web:esprit-docs`

## Tip

When a customer sends a revised STEP or Parasolid file, ESPRIT Edge's Model Compare automatically identifies changed faces, added features, and modified tolerances. Access via Edge → Model Compare → Load Revision. Changed regions are highlighted in red, new geometry in green, and unchanged in gray. The system suggests which operations need regeneration (typically only those touching changed faces), preserving unchanged toolpaths. This reduces reprogramming time from hours to minutes on complex parts.
