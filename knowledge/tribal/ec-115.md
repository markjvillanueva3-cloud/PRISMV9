# Batch Operations for Multi-Part Processing

**Category:** `automation` · **Subcategory:** `part_catcher` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:edgecam-automation`

## Tip

Automate multi-part processing in Edgecam by combining Strategy Manager with batch operations. Queue multiple CAD files, assign strategy sets, and process all parts sequentially. Batch operations support automatic feature recognition, tool assignment, and G-code generation. Review batch logs for failed parts that need manual attention. Ideal for contract shops with diverse part mixes — process simple parts automatically, reserve programmer time for complex work.
