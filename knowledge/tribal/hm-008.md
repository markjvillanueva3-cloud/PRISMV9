# hyperMILL Probing cycles auto-measure workpiece alignment before machining

**Category:** `automation` · **Subcategory:** `robot_loading` · **Domain:** `document_learned`

**Confidence:** `91` · **Source:** `document:hypermill-manual`

## Tip

hyperMILL Probing module includes: 3D Point Probing, Workpiece Alignment (edge/holes), Rectangular Probing, Slot-Rib Probing, Circular Probing, Axis-dependent Probing. Cycles output probe results to controller variables for automatic WCS adjustment. Run probing after fixture loading, before machining. Critical for production automation where manual touch-off is eliminated. Requires Renishaw or compatible touch probe.
