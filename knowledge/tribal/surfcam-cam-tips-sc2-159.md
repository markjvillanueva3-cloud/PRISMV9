# SURFCAM Swiss-Type Polygon Turning for Hex and Square Features

Polygon turning in SURFCAM creates hex, square, or other polygonal features on Swiss-type parts using synchronized spindle-to-tool rotation. The polygon cutter has N cutting edges, and the spindle-to-cutter speed ratio determines the number of flats. For a hexagon: 3-edge cutter at 2:3 speed ratio. Program the polygon turning depth, length, and angular orientation in SURFCAM's turning module. Verify the speed ratio produces an integer number of flats — non-integer ratios create irregular polygons.
