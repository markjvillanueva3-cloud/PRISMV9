# Surface Analysis with Deviation Color Mapping

**Category:** `quality` · **Subcategory:** `inspection` · **Domain:** `cam_software`

**Confidence:** `83` · **Source:** `web:siemens-nx-docs`

## Tip

After machining, use NX's Surface Analysis tools to compare scanned point cloud data against the nominal CAD model. Import CMM or structured light scan data (STL/point cloud) and NX generates a deviation color map showing areas outside tolerance. Set the tolerance bands to match your drawing requirements (e.g., green = +/- 0.025 mm, yellow = +/- 0.05 mm, red = beyond 0.05 mm). Export the deviation report as a PDF with GD&T callouts for quality records. This closes the loop between programming, machining, and inspection.
