# Centralized Tool Library with Assembly Management

**Category:** `tooling` · **Subcategory:** `tool_selection` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:esprit-tool-management`

## Tip

ESPRIT's tool library stores complete tool assemblies: cutter + holder + collet/adapter + extension. Define each component separately and combine them into assemblies. This allows mixing and matching — the same 10mm end mill can be assembled with different holders for different machines. Store manufacturer-specific parameters (grade, coating, max RPM, recommended feeds) with each tool. Import tool data from manufacturer catalogs (ISO 13399 format) to build the library quickly.
