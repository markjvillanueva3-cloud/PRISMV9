# Steep/Shallow Boundary Detection for Hybrid Finishing

**Category:** `cam_strategy` · **Subcategory:** `spiral` · **Domain:** `cam_software`

**Confidence:** `0.88` · **Source:** `web:cimatron-docs`

## Tip

Use Cimatron's automatic steep/shallow angle detection to split finishing into optimal strategies. Set the threshold angle to 65-70°. Steep regions (>threshold) use Z-level finishing for uniform step-down; shallow regions (<threshold) use raster or spiral for uniform step-over. Enable 'Overlap Band' (1-2mm) at the boundary to eliminate the visible transition line.
