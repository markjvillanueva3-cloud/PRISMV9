# Boundary Boolean for Selective Rework

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:sprutcam-docs`

## Tip

Create from edges, silhouettes, sketches. Boolean union/intersection/subtraction. 0.5mm extension prevents marks. Named sets for reuse. Selective machining reduces cycle 20-40% when reworking regions. SprutCAM supports complex boundary chains for targeted finishing.

- Operation types: `roughing`, `finishing`
