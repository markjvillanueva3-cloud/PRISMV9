# Tool Library with Presetter Synchronization

**Category:** `setup` · **Subcategory:** `zero_setting` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:tebis-docs`

## Tip

Store geometry, holders, parameters per material. Sync with presetter (Zoller/Haimer). Actual vs nominal diameter differences of 0.01mm affect finish. Update after presetting. Shared libraries ensure consistency across shifts. Export tool data to setup sheets automatically.
