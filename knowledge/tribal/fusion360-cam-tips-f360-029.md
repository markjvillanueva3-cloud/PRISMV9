# Threading with Standard Definition Mode

Use the Standard Definition mode for thread turning to simplify thread programming. Instead of manually calculating pitch diameters and minor diameters, select from standard thread definitions (M, UNC, UNF, NPT, etc.) and Fusion calculates the correct parameters automatically. Always verify thread profile with a thread gauge on the first part — post processor rounding can cause pitch diameter drift.
