# Multi-Surface 5-Axis — Machine Multiple Faces in a Single Operation

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:camworks-docs`

## Tip

CAMWorks multi-surface 5-axis allows selecting multiple drive surfaces and check surfaces for a single operation. The tool follows the drive surface while avoiding check surfaces (clamps, fixtures, adjacent features). This is more efficient than creating separate operations per surface. Set surface transition smoothing to avoid abrupt axis movements when the tool crosses from one drive surface to the next — abrupt rotary axis changes cause surface marks.

- Operation types: `5_axis`
