# GPP Arc Output — VMID Settings for Multi-Plane Arcs

**Category:** `post_processor` · **Subcategory:** `controller_quirk` · **Domain:** `cam_software`

**Confidence:** `83` · **Source:** `web:solidcam-community`

## Tip

To enable arc output in all planes (not just XY), set 'Pos to Machine = Yes' and 'Arcs in ZX,YZ plane = Yes' in the Controller Definition section of your VMID file. Without these settings, SolidCAM linearizes arcs in the ZX and YZ planes into short line segments, bloating file size and causing jerky motion on older controllers.
