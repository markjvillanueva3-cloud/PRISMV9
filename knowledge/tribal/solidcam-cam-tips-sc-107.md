# Operation Templates — Save Proven Process Sequences for Reuse

Save complete multi-operation machining sequences as SolidCAM Templates (.sldcamt). A template captures tool selections, cutting parameters, strategies, and operation order. For recurring part families (e.g., hydraulic manifolds), a template can set up 80% of the programming in seconds. Store templates on a network share with naming conventions like 'POCKET_STEEL_3FLUTE_iM2D-HSM.sldcamt'. Templates adapt to new geometry automatically — the toolpaths regenerate for the new part shapes while retaining all strategy and parameter settings.
