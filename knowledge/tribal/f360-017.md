# Cloud Post Library for Machine-Specific Posts

**Category:** `post_processor` · **Subcategory:** `safe_start` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:fusion360-docs`

## Tip

Access the Autodesk Post Library from the Manage menu in the Manufacture workspace. It contains hundreds of free, machine-specific post processors maintained by Autodesk. Install posts to your Personal Cloud library so they sync across all your devices and team members. Always start from the closest matching post rather than writing one from scratch.
