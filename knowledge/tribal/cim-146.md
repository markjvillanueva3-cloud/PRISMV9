# Additive/Hybrid Manufacturing for Mold Repair

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.8` · **Source:** `web:cimatron-docs`

## Tip

Cimatron supports DED for hybrid mold manufacturing: repair worn areas by depositing material, then machine back to spec. Define deposition paths, bead width, layer height. After deposition, run finishing passes to restore dimensional accuracy. Use for: worn parting surfaces, damaged cavity edges, and adding conformal cooling channels to existing molds.
