# ESPRIT Edge Automatic Post Processor Updates

**Category:** `post_processing` · **Domain:** `cam_software`

**Confidence:** `0.81` · **Source:** `web:esprit-docs`

## Tip

ESPRIT Edge delivers post processor updates automatically through the cloud channel. When Hexagon releases a fix for a specific controller (e.g., Fanuc 31i-B5 canned cycle output), the updated post is pushed to Edge subscribers and flagged in the Post Manager. Review changes in the diff viewer before accepting. Pin production-critical posts to a specific version to prevent unreviewed updates from reaching the shop floor. Rollback any update within 90 days.
