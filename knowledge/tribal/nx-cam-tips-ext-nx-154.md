# Multi-Objective Optimization: Quality vs Throughput

Build a Pareto front by varying step-over (0.1-0.5mm) and feed (0.03-0.10mm/tooth) in NX. Plot surface finish vs cycle time for each combination. The Pareto-optimal set shows the best achievable finish at each cycle time. For aerospace: select points favoring quality (tight Ra specs). For automotive production: select points favoring throughput. The Pareto front is specific to each tool-material-machine combination.
