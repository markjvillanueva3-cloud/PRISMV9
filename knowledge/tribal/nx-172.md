# Turbine Disk Slot Point Milling

**Category:** `cam_strategy` · **Subcategory:** `contour` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:siemens-nx-docs`

## Tip

5-axis point milling as alternative to broaching for prototype fir-tree slots. Lower tooling cost (standard ball/flat end) vs broach. NX programs each slot profile with 5-axis contour. Slower than broaching but no $50K broach tool investment for small quantities.
