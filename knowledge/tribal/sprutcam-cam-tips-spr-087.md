# SPC Control Charts for Production Monitoring

After establishing stable SprutCAM programs, implement X-bar/R charts on critical dimensions. First 25 parts establish control limits. Monitor for: trends (7 consecutive points on one side = tool wear), shifts (sudden jump = fixture shift), increasing range (chatter onset or tool breakage). When out-of-control signals appear, stop production and diagnose before continuing.
