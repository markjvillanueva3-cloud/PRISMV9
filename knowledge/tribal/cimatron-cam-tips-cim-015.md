# Graphite Electrode Machining Parameters

For graphite electrodes, use uncoated carbide tools with 2-flute geometry. Set spindle speed to 15,000-24,000 RPM with feed per tooth 0.05-0.08mm. Use vacuum dust extraction — graphite dust is abrasive and conductive. No coolant required. Finishing step-over: 0.05mm for EDM roughing electrodes, 0.02mm for finishing electrodes. Expect 20-30% faster cycle times than copper.
