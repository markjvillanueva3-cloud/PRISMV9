# Additive/Hybrid Manufacturing with PowerMill

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:autodesk-university`

## Tip

PowerMill Additive supports DED (Directed Energy Deposition) for hybrid manufacturing: alternate between additive deposition and subtractive machining in the same program. Define layer height, bead width, overlap percentage, and deposition parameters. After each additive layer block, run a machining pass to maintain dimensional accuracy. Use for: repair, feature addition, and near-net-shape production.
