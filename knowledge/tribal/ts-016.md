# Core Roughing Efficiently Machines Around Bosses

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:topsolid-core`

## Tip

TopSolid's core roughing strategy is optimized for machining material around protruding features (cores, bosses, ribs). The toolpath spirals outward from the core perimeter, maintaining constant engagement and avoiding the plunge-into-corners problem of conventional contouring. Set the approach to tangential arc entry and use climb milling for best surface quality on the core walls. This is essential for mold core machining where wall accuracy drives part quality.
