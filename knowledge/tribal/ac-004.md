# Automation Center layer management organizes model data for CAM processing

**Category:** `automation` · **Subcategory:** `tool_presetter` · **Domain:** `document_learned`

**Confidence:** `88` · **Source:** `document:hypermill-automation-center`

## Tip

hyperMILL Automation Center layer functions: Create layer, Delete layer, Set layer visible/invisible, Set layer current, Layer description. Use layers to organize: raw stock, finished model, fixtures, toolpath boundaries, construction geometry. Check layer collision validates that programmed operations do not intersect restricted layers. Delete unused hyperMILL data cleans up orphaned CAM data from failed calculations.
