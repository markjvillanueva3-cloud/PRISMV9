# Parallel Finishing with Optimized Cut Angle

WorkNC's parallel (raster) finishing generates linear passes at a user-defined angle. Choose the angle to align with the longest surface dimension to minimize retracts. Enable zigzag mode for bidirectional cutting (halves cycle time) but use unidirectional climb milling for critical surface quality. Set the stepover to achieve the target scallop height based on tool radius and local curvature.
