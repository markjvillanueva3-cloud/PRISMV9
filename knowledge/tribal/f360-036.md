# Setup Sheets for Shop Floor Communication

**Category:** `setup` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:fusion360-docs`

## Tip

Generate Setup Sheets from the Actions menu in the Manufacture workspace to create printable documents showing tool lists, WCS origins, stock dimensions, and operation sequences. Customize the setup sheet template to include your shop-specific information like fixture callouts and inspection notes. For quick reference, export the tool list as CSV and print it as a laminated tool card for the machine operator.
