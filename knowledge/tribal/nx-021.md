# AI Make Machining Suggestion for Intelligent FBM

## Tip

NX 2512+ includes AI Make Machining Suggestion which builds on FBM with AI-driven intelligence. Select a face or feature and NX presents multiple machining approaches with operations, tools, and parameters pre-defined. The system learns from your programming history over time so suggestions align with your shop standards. Rate suggestions with thumbs up/down to improve future accuracy.
