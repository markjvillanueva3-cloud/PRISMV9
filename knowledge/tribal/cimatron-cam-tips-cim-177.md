# Bayesian Model Averaging for Robust Prediction

Instead of one model (Taylor, Archard, empirical), BMA weights multiple by posterior probability. P(y|data) = ΣP(y|M_k)P(M_k|data). More robust to model misspecification. For Cimatron tool life when no single model fits all mold materials and operations.
