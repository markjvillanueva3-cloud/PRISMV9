# Multi-Machine Post-Processing Flexibility

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:powermill-docs`

## Tip

Post the same PowerMill toolpath for different machines by switching post configs. Program once, post for DMG/Hermle/Makino. Each config applies machine-specific axis naming, RTCP format, retract strategy. Enables flexible scheduling — if one machine is busy, quickly re-post for available machine. Store machine-specific configs as named post profiles.
