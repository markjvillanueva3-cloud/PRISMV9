# Gouge Check Prevents Surface Damage Before Cutting

WorkNC's gouge check analyzes toolpaths for any condition where the tool would cut below the intended surface. Gouges can occur from: incorrect tool compensation, tolerance approximation, holder interference, and tool deflection. The gouge check reports the location, depth, and cause of each potential gouge. Fix gouge conditions before posting by adjusting stock allowance or tool selection.
