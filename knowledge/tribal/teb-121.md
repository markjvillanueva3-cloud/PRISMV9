# Tebis Turning Module for Mill-Turn Centers

**Category:** `cam_strategy` · **Subcategory:** `drilling` · **Domain:** `cam_software`

**Confidence:** `83` · **Source:** `web:tebis-docs`

## Tip

Tebis turning module programs OD/ID profiling, grooving, threading, and drilling on mill-turn centers. Define turret layout with tool positions. Program CSS (constant surface speed) for profiling. Synchronize turning and milling operations via the operation timeline. For complex parts, alternate turning and milling passes to maintain workpiece rigidity throughout the sequence.
