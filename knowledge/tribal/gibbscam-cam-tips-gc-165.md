# GibbsCAM keyboard shortcut customization accelerates power-user workflows

Map frequently used GibbsCAM commands to keyboard shortcuts via Preferences > Keyboard Shortcuts. Essential mappings for power users: F5=Simulate, F6=Post, Ctrl+R=Regenerate Toolpath, Ctrl+Shift+S=Save As. For view manipulation: Ctrl+1=Isometric, Ctrl+2=Top, Ctrl+3=Front, Ctrl+4=Right. Map the 'Copy Operation with Transform' command to a shortcut for pattern operations. Export your shortcut set as a .gccfg file and share it with the team. On average, keyboard-driven programmers complete tasks 25-35% faster than mouse-only users, especially for repetitive sequences like creating, parameterizing, and regenerating operations.
