# Batch Processing Runs Multiple Parts Overnight

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:topsolid-batch`

## Tip

TopSolid's batch processing queues multiple CAM programs for unattended toolpath calculation, simulation, and NC code generation. Set up the batch queue with all parts that need processing, define the output folder for NC files, and run overnight. Each program's status (calculated, verified, posted) is tracked in the batch manager. This is invaluable for shops processing large numbers of similar parts—set up the batch and let it run while the shop is closed.
