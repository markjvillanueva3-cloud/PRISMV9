# CAD Repair for Import Quality

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:powermill-docs`

## Tip

STEP/IGES: close gaps to 0.1mm, extend surfaces, rebuild degenerate. Run surface analysis first. Fix before programming — defects amplify. UV direction continuity affects toolpath. Parting surfaces need G2 minimum. PowerMill geometry repair tools handle common import issues.
