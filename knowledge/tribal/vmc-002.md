# Best Fit calculates optimal part placement within machine workspace

**Category:** `setup` · **Domain:** `document_learned`

**Confidence:** `92` · **Source:** `document:hypermill-vmc`

## Tip

hyperMILL VIRTUAL Machining Best Fit function automatically calculates the optimal placement of a part within available machine workspace. This prevents time-consuming manual setup adjustments when part orientation causes axis travel limit issues. Run Best Fit before posting to ensure all toolpaths execute within machine limits. Critical for large parts on smaller machines or parts with extreme orientations.
