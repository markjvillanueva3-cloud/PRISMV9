# Machine Setup Origin Alignment with Part Datum

In CATIA Manufacturing Program setup, align the machining origin (Part Operation reference) with the part's primary datum features — typically the three mutually perpendicular datum planes (A, B, C). Use CATIA's axis system tool to define the machining origin at the intersection of the datum planes, with Z-axis normal to the primary datum, X-axis along the secondary datum. This alignment ensures that the G54/G55 work offset on the CNC machine corresponds directly to the part datum structure, simplifying setup and inspection.
