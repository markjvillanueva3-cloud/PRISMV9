# GibbsCAM 14 supports direct PDF-based setup sheet generation with embedded screenshots

GibbsCAM 14's built-in Setup Sheet Generator exports professional PDF documents with embedded 3D viewport screenshots, tool lists, coordinate system tables, and cycle time estimates. Configure the template under Preferences > Documentation to include your company logo and custom fields. Each operation is listed with its tool, speeds/feeds, and a cropped isometric view showing the toolpath in context. For shops running ISO 9001, the auto-generated sheets provide traceable documentation linking the CAM program revision to the specific setup parameters used.
