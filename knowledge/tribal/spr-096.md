# Virtual Commissioning with SprutCAM Simulation

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:sprutcam-docs`

## Tip

Use SprutCAM's machine simulation for virtual commissioning of new machines. Load the machine kinematic model, define tools and fixtures, then run existing programs to verify: (1) axis travel limits are not exceeded, (2) no collisions with machine structure, (3) tool change positions are clear, (4) safe retract heights are adequate. This identifies issues before the physical machine is delivered to the shop.
