# Wire EDM Integration for Hybrid Workflows

Export PowerMill geometry to wire EDM CAM for features better suited to wire: thin slots, sharp internal corners, hardened inserts. Define wire EDM start holes in PowerMill and drill them during milling setup. This hybrid approach uses each process where it excels — wire for thin/sharp features, milling for 3D surfaces. Coordinate WCS between both programs.
