# SPC Control Charts for Mold Dimensions

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:cimatron-forum`

## Tip

After stable Cimatron programs, implement X-bar/R charts on critical dims. First 25 parts establish control limits. Trends (7 same-side points) = tool wear. Shifts = fixture/WCS issue. Increasing range = vibration. Re-qualify program on out-of-control signals. SPC evidence increasingly required by automotive OEMs for injection mold tool qualification.
