# Flowline Finishing for Aerofoil Surfaces

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.83` · **Source:** `web:sprutcam-tutorials`

## Tip

Flowline finishing follows user-defined flow curves across the surface. Define start and end boundary curves. SprutCAM interpolates intermediate toolpath lines between them. Ideal for aerofoil surfaces where the tool should follow the aerodynamic flow direction. Step-over is measured perpendicular to the flow direction. Produces directional surface patterns that aid aerodynamic performance.
