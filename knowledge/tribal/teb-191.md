# CAD Surface Repair Best Practices

**Category:** `setup` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:tebis-docs`

## Tip

Imported STEP/IGES: close gaps to 0.1mm, extend surfaces, rebuild degenerate faces. Tebis surface analysis identifies problems. Fix before programming — machining amplifies defects. Clean geometry prerequisite for 5-axis. Pay special attention to UV direction continuity — affects toolpath direction.
