# AC NCS orientation: two-face method for automatic part alignment

**Category:** `setup` · **Subcategory:** `alignment` · **Domain:** `video_learned`

**Confidence:** `88` · **Source:** `video:hypermill-AC-basic-tutorial@5-7min`

## Tip

AUTOMATION Center NCS function 'Two faces' method: select one surface for Z orientation (typically top face) and another for Y-plus orientation (a side face). The system automatically aligns the part coordinate system. If the result is wrong, click Refresh to re-select. This eliminates manual coordinate system setup and works reliably for prismatic parts with clear reference faces.
