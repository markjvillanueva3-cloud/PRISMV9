# Multi-Level Roughing Processes All Depths in One Operation

WorkNC's multi-level roughing processes all depth zones within a single operation, automatically transitioning between levels. The system optimizes tool movements between levels to minimize retracts and air cutting. Enable 'Level linking optimization' to allow the tool to spiral between adjacent levels rather than retracting. This can reduce roughing cycle time by 15-25% on multi-level cavity parts.
