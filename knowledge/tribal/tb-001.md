# TOOL Builder prepares 3D tool models from manufacturers for CAM collision checking

**Category:** `setup` · **Domain:** `document_learned`

**Confidence:** `90` · **Source:** `document:hypermill-tool-builder`

## Tip

hyperMILL TOOL Builder interactively prepares 3D tool models from tool suppliers for use in calculation, collision checking, and simulation. Import 3D data (STEP, IGES), run toolbar steps to label entities (spindle, holder, extension, tool), auto-create appropriate layers. Required for accurate collision detection on tools with non-standard holder geometry. Tool holders with rotationally symmetrical support in spindle are supported.
