# Additive Deposition Path Planning

PowerMill Additive DED path planning: contour+fill scan patterns, overlap 30-50% of bead width, layer height 60-80% of bead height. Interleave subtractive passes every 3-5 additive layers for accuracy. Define deposition speed based on wire/powder feed rate. Near-net-shape builds reduce machining time by 60-80% on large aerospace forgings.
