# WorkNC Dental — Automated Crown and Bridge Machining

WorkNC Dental automates CAM programming for dental restorations: crowns, bridges, inlays, onlays, and veneers. Import STL files from dental scanners (3Shape, Exocad, Planmeca), and WorkNC Dental automatically generates 5-axis toolpaths optimized for dental materials (zirconia, PMMA, wax, CoCr, titanium). The system handles: margin line detection, insertion axis calculation, and nesting of multiple restorations in a single blank. Typical cycle: 6-8 minutes per crown in pre-sintered zirconia using 1mm and 0.5mm ball-nose tools.
