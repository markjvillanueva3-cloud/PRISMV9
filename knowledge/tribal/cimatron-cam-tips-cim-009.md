# Rest Machining with Multiple Reference Tools

Cimatron's rest machining can reference multiple previous tools, not just one. Add all prior roughing and semi-finishing tools to the 'Reference Tool List' to calculate the true remaining stock. This prevents re-cutting already-machined areas and targets only the actual rest material. Critical for complex mold cavities with deep ribs.
