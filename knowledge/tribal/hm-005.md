# hyperMILL Feature Based Machining auto-recognizes holes, pockets, slots from solid models

**Category:** `automation` · **Subcategory:** `part_catcher` · **Domain:** `document_learned`

**Confidence:** `90` · **Source:** `document:hypermill-manual`

## Tip

hyperMILL Feature technology automatically identifies prismatic features (holes, pockets, slots, threads) on solid models and generates appropriate machining cycles. Feature catalogue contains standard templates for common feature types. Generate feature → hyperMILL analyzes geometry and proposes machining operations. Best for: plate work, fixture components, parts with many similar features. Manual intervention still needed for complex 3D surfaces.
