# Pareto Front for Quality-Throughput Trade-Off

Vary step-over (0.1-0.5mm) and feed (0.03-0.10mm/tooth) in SolidCAM finishing. Plot Ra vs cycle time. Pareto-optimal set = best quality at each throughput. iMachining Pareto front for roughing is built into the material-level slider — level 1 = conservative, level 8 = aggressive. The Pareto concept applies to both roughing and finishing.
