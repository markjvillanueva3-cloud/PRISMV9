# Flow-Line Finishing Aligns Toolpath with Part Aesthetics

**Category:** `finishing` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:tebis-docs`

## Tip

Tebis flow-line finishing lets you define guide curves that control toolpath direction. The tool follows paths parallel to the guide curves, producing machining marks aligned with the intended visual flow of the part. Essential for automotive exterior panels, consumer products, and any part where machining marks are visible. Define guide curves along the primary viewing direction. Step-over is perpendicular to the flow direction with constant scallop height.
