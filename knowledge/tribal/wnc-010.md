# Undercut Machining with Auto 5 Lollipop Cutters

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `process_engineering`

**Confidence:** `89` · **Source:** `web:worknc-undercut`

## Tip

WorkNC Auto 5 supports undercut machining using lollipop (ball on stick) and T-slot cutters. The Auto 5 module tilts the tool to reach undercut regions that are hidden from the spindle axis, using the full tool assembly collision model. Set the undercut detection to automatic and specify the minimum undercut depth to process. This eliminates the need for EDM in many undercut situations, reducing lead time.
