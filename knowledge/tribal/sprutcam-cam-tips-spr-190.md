# Workplane Convention for Multi-Setup Turning

OP10-MainSpindle, OP20-SubSpindle, OP30-LiveToolFront. Active per operation. Probe at setup. Standard naming enables any operator to set up any job. SprutCAM generates rotary positioning per workplane. Include datum locations in setup sheets.
