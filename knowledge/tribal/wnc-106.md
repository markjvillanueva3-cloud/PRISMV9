# Batch Processing Runs Multiple Jobs Unattended

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:worknc-batch`

## Tip

WorkNC's batch processing queues multiple parts for unattended toolpath calculation, simulation, and posting. Set up the queue, define output folders, and run overnight. Each program's status is tracked in the batch manager. For shops processing many similar parts, this maximizes programmer productivity. Include simulation verification in the batch to catch errors automatically.
