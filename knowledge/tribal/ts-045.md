# Grooving with Peck Cycles for Deep Grooves

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:topsolid-grooving`

## Tip

TopSolid's grooving operation supports peck cycles for deep grooves that exceed 2-3x the insert width. The peck cycle alternates between plunging to depth and retracting for chip clearance. Set the peck increment to 1-2x insert width and the retract amount to 0.5-1 mm. For face grooves, use the radial grooving variant with appropriate approach angles. Enable coolant-through inserts for grooves deeper than 5x insert width.
