# Volumetric Accuracy Compensation

**Category:** `optimization` · **Domain:** `cam_software`

**Confidence:** `82` · **Source:** `web:tebis-docs`

## Tip

Import machine 21-error map, Tebis adjusts coordinates to pre-compensate. Valuable for large die parts (1m+). Improves from ±0.03mm to ±0.01mm. Requires periodic calibration (laser interferometer or ball-bar). Tebis virtual machine stores the compensation data alongside kinematic model.
