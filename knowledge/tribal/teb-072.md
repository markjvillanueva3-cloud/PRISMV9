# Surface Extension for Clean Tool Exit

**Category:** `finishing` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:tebis-docs`

## Tip

Extend machining surfaces 2-5mm beyond part edges to ensure clean tool exit without deceleration marks. In Tebis, create extension surfaces automatically or manually. The tool completes its cutting stroke on the extension surface before retracting. Critical for visible surfaces on automotive exterior dies and consumer product molds where tool exit marks would require extra polishing.
