# Wall Finishing With Spring Pass for Tolerance Control

**Category:** `cam_strategy` · **Subcategory:** `contour` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:catia-docs`

## Tip

After roughing prismatic pockets in CATIA, add a dedicated Profile Contouring operation for wall finishing with zero stock allowance and a spring pass. The spring pass re-traces the contour without additional depth, allowing the tool to deflect back to true position and remove residual material left by deflection during the first pass. This is critical for H7 tolerance bores and tight-tolerance pocket walls.

- Operation types: `profile_contouring`
