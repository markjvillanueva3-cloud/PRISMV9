# Renewal Theory for Optimal Replacement

Minimize C(T) = (Cp + Cf×F(T)) / (T×R(T) + M×F(T)). For Swiss-type medical parts: Cf >> Cp (scrapped implant + FDA documentation). Replace early. For production bolts: Cf ≈ Cp, replace later. SprutCAM tool notes should track economic analysis per job type.
