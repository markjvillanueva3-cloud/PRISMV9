# Automation Center variables store and reuse values across script functions

**Category:** `automation` · **Subcategory:** `tool_presetter` · **Domain:** `document_learned`

**Confidence:** `89` · **Source:** `document:hypermill-automation-center`

## Tip

hyperMILL Automation Center Set Variable/Get Variable functions enable data persistence within scripts. Variable from spreadsheet reads values from Excel files for batch processing. Use variables to store: tool numbers, feed rates, stock allowances, feature counts, iteration indices. Variables scope to the current script execution — use external files for cross-session persistence. Helper functions manipulate strings, numbers, and lists.
