# MultiBlade module automates impeller and blisk programming workflow

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:gibbscam-docs`

## Tip

GibbsCAM 5-Axis MultiBlade provides task-oriented dialogs for impeller/blisk programming: floor roughing, blade finishing, and fillet machining. Select the hub surface, blade surfaces, and splitter blades (if present), and the system generates optimized toolpaths for each zone. Floor roughing uses plunge or Z-level strategy between blades. Blade finishing follows the blade surface with controlled lean angle. Fillet machining targets the blade-to-hub transition with a ball nose. This integrated workflow reduces programming time for impellers from hours to 30-45 minutes.

- Operation types: `roughing`, `finishing`, `plunge_milling`, `5_axis`
