# Tool Library with Insert Tracking

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:sprutcam-docs`

## Tip

Store geometry, holders, parameters per material. Track insert edges used (CNMG has 4 edges). Sync with presetter. Actual vs nominal 0.01mm affects finish. SprutCAM tool notes track edge usage count for Weibull calibration per insert type.
