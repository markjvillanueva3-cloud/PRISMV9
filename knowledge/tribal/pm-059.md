# Disc Cutter for Slot and Groove Machining

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:powermill-tutorials`

## Tip

Define disc (slitting/slotting) cutters in PowerMill with the correct geometry: disc diameter, thickness, bore size, and number of teeth. Use '3+2 axis' positioning to orient the disc for each slot. Set cutting speed based on the disc outer diameter. Feed per tooth should account for the large number of teeth (typically 20-60). Enable flood coolant for chip evacuation from the slot.
