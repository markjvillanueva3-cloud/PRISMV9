# Multi-contour selection: per-contour Plus, Rev, Over columns

**Category:** `setup` · **Domain:** `video_learned`

**Confidence:** `80` · **Source:** `video:HyperMILL-5axis-Lesson1@70-80s`

## Tip

The hyperMILL 'Contour Milling on 3D Model' dialog supports multiple contours with per-contour control columns: Nr, Start, End, Plus (additive offset), Rev (reverse direction), Over (overlap). Each contour row can be individually configured. Use 'Sort contours' checkbox to optimize machining order and minimize tool travel.

- Operation types: `profiling`, `milling`
