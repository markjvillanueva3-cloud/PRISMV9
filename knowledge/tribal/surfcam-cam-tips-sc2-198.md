# SURFCAM Template-Based Programming for Standardized Features

Create SURFCAM operation templates for standardized features (bolt circles, key slots, O-ring grooves) with parameterized dimensions. Save the template with placeholder geometry, then apply it to new parts by selecting the target geometry. Templates store all operation parameters: tool selection, speeds/feeds, depth control, lead-in/out, and stock allowances. Maintain a library of 20-50 templates for common features to reduce programming time by 60-80%. Name templates with a prefix indicating the feature type: BH_ for bolt holes, KS_ for key slots, OR_ for O-ring grooves.
