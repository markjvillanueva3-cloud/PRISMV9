# Tool Catalog Organization by Operation Type and Material

**Category:** `cam_strategy` · **Subcategory:** `drilling` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:catia-docs`

## Tip

Organize CATIA tool catalogs by operation type (roughing, finishing, drilling) and material group (steel, aluminum, titanium). Create catalog families using the Tool Catalog workbench with parameterized tool templates. This allows operators to query tools using filters (e.g., 'end mill, diameter 10-12mm, for titanium roughing') rather than scrolling through hundreds of entries. Store catalogs on a shared network location and reference them in all Manufacturing Programs for consistency across programmers.

## Applies to

- Material groups: `P`, `N`, `S`
- Operation types: `tool_management`
