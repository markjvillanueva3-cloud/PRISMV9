# Default initial plane is G17 — change in post for lathe or rotary work

**Category:** `post_processor` · **Subcategory:** `tool_change` · **Domain:** `cam_software`

**Confidence:** `82` · **Source:** `web:community`

## Tip

Mastercam's default initial work plane is G17 (XY). For lathe operations or certain rotary-axis configurations, you may need G18 (XZ) or G19 (YZ) as the initial plane. This is set in the post processor via the plane parameter (e.g., plane=sg18). Getting this wrong causes arcs to interpolate in the wrong plane, producing scrap or crashes on the first arc move.

## Applies to

- Operation types: `post_processing`, `turning`
