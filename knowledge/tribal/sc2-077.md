# Automatic Cut Data Population from Material Database

**Category:** `speeds_feeds` · **Subcategory:** `cutting_parameters` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:surfcam-cutdata`

## Tip

SURFCAM stores recommended cutting data (surface speed, feed per tooth, axial/radial depth) per tool-material combination in the tool library. When you select a tool and specify the workpiece material, the system auto-populates the cutting parameters. Customize these defaults based on your shop's experience — the factory values are conservative starting points. For new materials, use the closest existing material as a baseline and adjust based on test cuts.
