# 3DEXPERIENCE Manufacturing Change Management Workflow

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:catia-docs`

## Tip

On the 3DEXPERIENCE platform, manufacturing changes follow a formal change management workflow: (1) Engineering Change Request (ECR) triggered by design modification, (2) Manufacturing Impact Analysis — CATIA identifies affected machining operations and estimates re-programming effort, (3) Manufacturing Change Order (MCO) approved by manufacturing engineering, (4) NC Program update with revision increment, (5) Verification (re-simulation, first article), (6) Release to production. Configure the workflow in ENOVIA (Change Management role) and link it to CATIA manufacturing data. Each NC program revision is immutably stored, enabling rollback if the change causes production issues.
