# Chamfer and Edge Break with Controlled Depth

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:edgecam-milling`

## Tip

Program chamfering in Edgecam using a chamfer mill or ball end mill with controlled Z-depth. Set the chamfer width by controlling the tool's Z position relative to the edge — for a 45-degree chamfer mill, Z-depth equals chamfer width. Use 3D edge detection to automatically identify all edges requiring chamfering. For non-uniform chamfers, use the 3D profiling cycle with the tool tilted to the chamfer angle.
