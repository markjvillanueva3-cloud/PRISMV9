# Code Wizard for Custom Post Processor Creation

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:edgecam-post`

## Tip

Edgecam's Code Wizard provides a graphical interface for creating and customizing post processors without manual coding. Define output format, block structure, G/M-code assignments, and machine-specific parameters through dialog boxes. Code Wizard generates the post processor files automatically. Start with the closest matching standard post and modify incrementally rather than building from scratch. Test each change against a reference program.
