# Parametric Programming for Family-of-Parts

Use ESPRIT's parametric programming to create master programs that adapt to different part sizes within a family. Define key dimensions as parameters (OD, length, bore depth, thread size) and link them to operation parameters. When a new part variant arrives, update the parameter table and regenerate — no reprogramming needed. This works best for turned parts (shafts, bushings, fittings) and prismatic parts (plates, brackets) with consistent feature layouts.
