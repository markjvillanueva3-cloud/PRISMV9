# TopSolid'ShopFloor Tool Management — Tracking Life Across Jobs

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:topsolid-docs`

## Tip

TopSolid'ShopFloor tracks tool life across multiple jobs and machines. Each tool assembly has a cumulative cutting time counter that decrements from the expected life. When remaining life drops below the threshold for the next job, the system warns the operator to replace the tool before starting. This prevents mid-job tool failures that cause scrap and machine downtime. The tool management system also maintains a tool crib inventory, tracking which tools are in the crib, on which machines, and in what condition.
