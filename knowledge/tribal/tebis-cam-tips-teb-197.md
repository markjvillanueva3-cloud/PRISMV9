# Optimal Replacement via Renewal Theory

Renewal theory: minimize long-run cost rate C(T) = (Cp + Cf×F(T)) / (T×R(T) + M×F(T)) where Cp = preventive cost, Cf = failure cost, F(T) = failure CDF, R(T) = reliability, M = mean repair time. For Tebis tool management: balance preventive replacement cost against catastrophic failure cost (scrapped mold component).
