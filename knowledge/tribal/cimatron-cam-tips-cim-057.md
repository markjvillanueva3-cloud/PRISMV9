# Machine Simulation with Full Kinematic Model

Cimatron machine simulation uses the complete kinematic chain for collision detection. Import machine models or create custom machines in the Machine Builder. Define: spindle nose, tool holder, rotary table, fixtures. Run simulation at 'Full Machine' mode for 5-axis — catches head/table interference that geometric simulation misses. Mandatory for first-article 5-axis programs.
