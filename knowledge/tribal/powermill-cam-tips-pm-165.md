# Mutual Information for SPC Feature Selection

I(X;Y) quantifies dependence between feature and quality outcome. Top-k features with highest MI for monitoring. Reduces false alarms. For PowerMill production: 3-5 features capture 90% of quality information. Focus monitoring resources on these.
