# Probing for In-Process Verification

Program probing cycles: verify stock before machining, check WCS after setup, measure critical dims between operations. Output probe macros for Renishaw/Heidenhain/Blum. Store data for SPC. Use probing to verify rough stock allowance before semi-finish — prevents tool overload from excessive remaining material. PowerMill macros automate probe-measure-correct loops.
