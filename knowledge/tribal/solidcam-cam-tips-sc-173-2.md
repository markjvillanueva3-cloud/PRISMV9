# Steep-Shallow Automatic Assignment

SolidCAM auto-detects steep (>65°) and shallow (<65°) regions. Z-level for steep, raster/3D-offset for shallow. Overlap 1-2mm at boundaries. Same tool for both. Automation saves 30-40% programming time. Combine with iMachining for roughing — the complete workflow.
