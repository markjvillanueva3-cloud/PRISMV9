# SolidCAM inside SolidWorks Integration

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:solidcam-docs`

## Tip

SolidCAM runs inside SolidWorks — full associativity. Design changes automatically propagate to machining operations. No export/import step. This is SolidCAM's unique advantage: single-window CAD/CAM with native feature recognition. Reduces design-to-machining iteration time by 50%.
