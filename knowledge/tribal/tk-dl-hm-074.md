# Redefine workplane type without recreating

**Category:** `setup` · **Domain:** `document_learned`

**Confidence:** `88` · **Source:** `document:hypercad-s-v33@p208`

## Tip

Right-click a saved workplane → Redefine as → select new command (On face, On curve, Through 3 points, etc.) to change how a workplane is defined without deleting and recreating it. Example: convert a free non-associative workplane into an associative one on a face. The name is reset during redefinition — reselect it from the name list to keep the same name.
