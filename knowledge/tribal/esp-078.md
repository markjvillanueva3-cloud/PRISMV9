# Spot Drilling for Accurate Hole Location

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:esprit-drilling`

## Tip

Always program a spot drill cycle before twist drilling in ESPRIT. Use a 90° spot drill for standard drilling or a 120° for carbide drills (matching the drill point angle prevents wandering). Set the spot drill depth to create a cone slightly larger than the drill web thickness — typically 10-20% of the drill diameter deep. ESPRIT's feature recognition automatically adds spot drilling when the 'require spot' option is enabled in the machining template.
