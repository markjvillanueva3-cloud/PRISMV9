# Post Processor Property Overrides per Operation

Many Fusion post processors expose properties (like useRadius, safeRetractDistance, useFilesForSubprograms) that can be toggled in the Post Process dialog without editing code. Check the Properties section when posting — you may find your machine-specific need (like outputting radius arcs vs IJK, or enabling subprogram calls) is already built in as a togglable property.
