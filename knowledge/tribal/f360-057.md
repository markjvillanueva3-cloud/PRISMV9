# Projected Toolpath for Engraving and Surface Patterns

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `84` · **Source:** `web:fusion360-docs`

## Tip

Use Projected toolpath to machine 2D geometry (text, logos, patterns) onto 3D curved surfaces. The 2D sketch is projected normal to the surface, and the tool follows the resulting 3D intersection curve. Set the projection direction to match the tool axis (typically Z-down) for consistent depth. For engraving on compound-curved surfaces, use a tapered ball nose cutter (15-30 degree taper) to maintain rigidity while reaching into narrow character strokes.
