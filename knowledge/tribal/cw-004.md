# Multi-Axis Feature Recognition — Detect Features Across Index Angles

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:camworks-docs`

## Tip

Enable multi-axis AFR to let CAMWorks analyze the part from multiple orientations simultaneously. The system identifies which features are machinable from each setup or index angle and automatically assigns them to the correct orientation in the feature tree. For parts requiring 3+2 indexing, this eliminates manual feature-to-setup assignment and ensures no features are overlooked due to accessibility constraints.

## Applies to

- Operation types: `milling`, `5_axis`
