# Volumetric Accuracy Compensation

Import machine 21-error map, hyperMILL adjusts coordinates. For large dies (1m+) where errors compound. ±0.03mm → ±0.01mm. Requires calibration. VIRTUAL Machining stores compensation data in the virtual machine model for accurate simulation.
