# Copula for Dependent Failure Modes

Flank/crater/chipping correlated. Gaussian copula models joint: P(fail) = C(P(flank), P(crater), P(chip); ρ). Ignoring dependence underestimates 15-25%. For PowerMill tool change intervals on critical aerospace components where any failure mode is catastrophic.
