# M31 rotary axis encoder reset prevents unwinding to zero on Hurco 5-axis

**Category:** `cnc_programming` · **Domain:** `document_learned`

**Confidence:** `95` · **Source:** `document:hurco-5axis-post`

## Tip

On Hurco 5-axis machines, output M31 early in program header to reset rotary axis encoder to current machine position. Without M31, commanding rotary axes to return to zero degrees can cause 'unwinding' — the axis takes the long way around instead of staying put. Place M31 before any rotary positioning commands. Critical for programs that use rotary indexing or A0 C0 retract positions.

## Applies to

- Operation types: `5axis`, `multiaxis`
