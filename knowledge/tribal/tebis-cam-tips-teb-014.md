# Cooling Channel Drilling Uses Deep-Hole Templates

Program cooling channel drilling operations in Tebis using the drilling module with deep-hole cycle support. Define peck depths based on diameter (3-5xD per peck for gun drills, 1-2xD for twist drills). Use the collision check to verify drill clearance against the mold geometry. For angled cooling channels, use 5-axis positioning to orient the spindle along the hole axis. Generate a separate setup sheet showing all hole positions, depths, and diameters.
