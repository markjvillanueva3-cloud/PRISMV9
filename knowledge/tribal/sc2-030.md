# Steep/Shallow Boundary Detection for Hybrid Finishing

**Category:** `cam_strategy` · **Subcategory:** `scallop` · **Domain:** `cam_software`

**Confidence:** `91` · **Source:** `web:surfcam-3axis-steep-shallow`

## Tip

SURFCAM automatically detects steep and shallow regions based on a user-defined threshold angle (typically 30-45°). Steep regions use Z-level (waterline) finishing for optimal wall quality, shallow regions use planar (raster/scallop) finishing for optimal floor quality. Set a 5° overlap band between steep and shallow regions to ensure seamless blending. This hybrid approach typically reduces polishing time by 40-60% compared to using a single strategy across the entire part.
