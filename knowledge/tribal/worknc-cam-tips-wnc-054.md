# Collision Detection Covers Full Tool Assembly

WorkNC's collision detection checks the complete tool assembly including cutter, holder, collet, spindle nose, and extensions against workpiece, fixtures, and machine structure. Define tool assemblies with accurate 3D models. The system reports interference (overlap), near-miss (within threshold), and axis limit violations. Set near-miss threshold to 2 mm for initial checks and 0.5 mm for final verification.
