# Tool Library Management with Physical Measurements

**Category:** `setup` · **Subcategory:** `zero_setting` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:tebis-docs`

## Tip

Tebis tool library stores: geometric parameters (diameter, flute length, overall length), holder assembly (shrink-fit, collet, hydraulic), and cutting parameters per material. After tool presetting, update the library with actual measured dimensions — nominal vs actual diameter differences of 0.01mm affect finish quality. Sync tool data with presetter software (Zoller, Haimer) via data exchange interface.
