# Tool Deflection δ = FL³/3EI

Cantilever: δ = FL³/(3EI), E=580 GPa carbide, I=πd⁴/64. Halving overhang reduces deflection 8×. Doubling diameter reduces 16×. For SprutCAM finishing with long tools: compensate by offsetting tool position or use shorter, larger tools. Calculate deflection for every finishing operation exceeding 4:1 L/D ratio.
