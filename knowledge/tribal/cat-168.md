# DMU Ergonomic Analysis of Operator Access During Setup

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.78` · **Source:** `web:dassault-forum`

## Tip

Use CATIA DMU Fitting to simulate operator access during machine setup, part loading, and inspection. Define the machine enclosure, door openings, and fixture in the DMU product. Insert a CATIA human model (manikin) and simulate the reaching, loading, and clamping motions. This identifies: (1) parts too heavy for manual loading (need crane/robot), (2) clamp locations requiring uncomfortable reaching, (3) probe access limitations for in-process inspection. Especially critical for large 5-axis machines with limited door clearance — a machining program that is technically perfect but produces a part the operator cannot safely load is still a failed program.
