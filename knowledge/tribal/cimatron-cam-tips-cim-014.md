# Parting Line Surface Matching for Mold Halves

When machining mold parting surfaces, use 'Match Machining' to ensure core and cavity parting surfaces match within 0.005mm. Machine both sides with the same tool, same step-over, and same cutting direction. Apply identical stock allowance (0.02mm) to both halves. This prevents parting line mismatch that causes flash in molded parts.
