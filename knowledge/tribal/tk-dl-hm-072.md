# Workplane through 3 points axis control

**Category:** `setup` · **Subcategory:** `alignment` · **Domain:** `document_learned`

**Confidence:** `90` · **Source:** `document:hypercad-s-v33@p196`

## Tip

Workplane → Through three points: Point 1 = origin, direction 1→2 = positive X axis, point 3 completes XY plane. Use the Z axis Invert option to flip Z direction (Y adjusts automatically, X stays). Use Offset to shift the WP along Z. For multi-axis setups requiring precise X-axis alignment, use the XY axis direction option to constrain an axis to a specific edge or line.
