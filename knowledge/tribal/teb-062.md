# Lollipop Cutter for Undercut Features

**Category:** `multi_axis` · **Subcategory:** `tool_axis` · **Domain:** `cam_software`

**Confidence:** `82` · **Source:** `web:tebis-tutorials`

## Tip

Lollipop (undercutting) tools access features behind overhanging geometry. In Tebis, define the lollipop geometry: ball diameter, neck diameter, and neck length. Use 3+2 axis positioning to orient the tool for undercut access. Verify clearance between the neck and surrounding geometry. Set cutting speed based on the ball diameter, not the neck diameter.
