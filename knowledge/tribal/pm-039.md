# Tool Axis Strategies: To/From Point vs Lead/Lean

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.88` · **Source:** `web:powermill-docs`

## Tip

PowerMill offers multiple tool axis strategies: 'To Point' tilts the tool toward a fixed point (good for concave cavities), 'From Point' tilts away (convex surfaces), 'Lead/Lean' tilts forward and sideways relative to feed direction (best for 5-axis finishing with ball-end mills — set lead=10-15°, lean=0-5°). 'Automatic' mode selects the best tilt to avoid collisions but may produce jerky motion.
