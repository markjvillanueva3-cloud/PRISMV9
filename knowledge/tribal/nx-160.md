# OEE Optimization Using NX Manufacturing Data

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.8` · **Source:** `web:siemens-community`

## Tip

Calculate OEE (Overall Equipment Effectiveness) using NX's cycle time estimates vs actual machine run times. Availability: track machine uptime vs scheduled time. Performance: compare NX estimated feed rates vs actual achieved rates. Quality: link CMM pass/fail to NX program versions. Typical NX-programmed cells achieve 75-85% OEE. Gap analysis between NX's theoretical and actual performance reveals optimization opportunities.
