# Contour Finishing with Wall Profiling

**Category:** `cam_strategy` · **Subcategory:** `contour` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:sprutcam-tutorials`

## Tip

Contour finishing profiles vertical and near-vertical walls at a specified Z-depth. Use for slot walls, pocket walls, and boss sides where Z-level would produce too many passes. Set 'Wall Offset' to the finish stock allowance (typically 0mm for final pass). Multiple depth levels can be programmed in a single operation with automatic lead-in/out per level.
