# Tool Axis Control for 3+2 Positioning

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:cimatron-tutorials`

## Tip

In 3+2 axis machining, lock the tool axis to a fixed orientation for each setup. Use Cimatron's 'Tilt' function to orient the tool perpendicular to the target surface region. Set 'Indexing Angle' increments matching your machine's rotary table resolution (typically 0.001° for modern machines). Create separate operations for each tilt position with appropriate WCS offset numbers.
