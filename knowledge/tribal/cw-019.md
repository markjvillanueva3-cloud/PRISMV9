# TechDB Synchronization — Share Across Networked Workstations

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:camworks-docs`

## Tip

Place the TechDB database file (TechDB.mdb or SQL Server instance) on a network share so all CAMWorks seats use identical machining knowledge. Assign a TechDB administrator who validates and approves changes before they propagate. Use the TechDB export/import function to merge improvements from individual programmers into the master database. Back up the TechDB weekly — it represents thousands of hours of accumulated machining intelligence.

## Applies to

- Operation types: `milling`, `turning`, `drilling`
