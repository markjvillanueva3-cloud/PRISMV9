# Multi-Cavity Copy with Verification

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.87` · **Source:** `web:cimatron-docs`

## Tip

Program one cavity, copy to all positions. Cimatron adjusts WCS and rapids per instance. Verify each copy in simulation — different orientations may need modified approach/retract. For identical cavities: 1/N programming effort. For 16-cavity molds this saves 15× the single-cavity programming time.
