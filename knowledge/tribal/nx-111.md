# CMM Inspection Programming with DMIS Output

**Category:** `quality` · **Subcategory:** `inspection` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:siemens-nx-docs`

## Tip

NX CMM Inspection Programming generates measurement routines in DMIS (Dimensional Measuring Interface Standard) format that run on any DMIS-compliant CMM (Zeiss, Hexagon, Mitutoyo). Select measurement features directly from the 3D model with PMI annotations and NX generates probe paths with appropriate approach vectors, clearance moves, and measurement point distributions. Use the Measurement Planning assistant to define the number of points per feature: 4 points minimum for planes, 6 for cylinders, 8 for complex profiles.
