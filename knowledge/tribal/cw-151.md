# ShopFloor DNC Integration — Program Transfer and Version Control

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:camworks-docs`

## Tip

ShopFloor integrates with DNC (Direct Numerical Control) systems to manage NC program transfer to CNC machines. Programs are version-controlled — only the latest approved revision is available for download. Lock programs after approval to prevent unauthorized edits at the machine. The system logs every program download with timestamp, operator ID, and machine. This creates a complete audit trail required for aerospace (AS9100) and medical (ISO 13485) quality systems.
