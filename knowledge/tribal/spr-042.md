# Polygon Turning for Hex and Square Profiles

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.8` · **Source:** `web:sprutcam-tutorials`

## Tip

Polygon turning machines non-circular profiles (hex, square) by synchronizing the spindle and polygon attachment rotation speeds. In SprutCAM, define the polygon sides and set the speed ratio (e.g., 2:3 for hex). The tool orbits at a specific ratio to the workpiece rotation, creating flat faces. Verify the setup in simulation — incorrect ratios produce incorrect polygon geometry.
