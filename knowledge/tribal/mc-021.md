# Never run unverified post output directly on the machine

**Category:** `safety` · **Subcategory:** `coolant_safety` · **Domain:** `safety`

**Confidence:** `90` · **Source:** `web:community`

## Tip

After any post processor edit, always run the output through simulation or a dry run before cutting metal. Wrong arc direction (G02/G03 swap), incorrect G90/G91 logic, or reversed axis signs can cause immediate crashes. Compare the new output line-by-line against a known-good program for the same part. Post processor bugs are the most dangerous because they silently produce valid-looking but incorrect G-code.
