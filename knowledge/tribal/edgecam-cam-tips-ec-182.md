# Edgecam Workflow VBA Macro Automation

Edgecam supports VBA macros for workflow automation. Common automations: auto-load part files from a folder, apply standard machining template based on material/size, generate NC code, export setup sheet, and log to database. Access the VBA editor from Tools → Macro Editor. Key objects: Application (top-level), Document (active file), Operations (machining tree), Toolpath (geometry data). Schedule macros to run on file-open or post-process events.
