# Rest machining with smaller tool requires accurate previous-tool stock model

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:community`

## Tip

Rest machining (remachining) in Mastercam identifies areas the previous larger tool could not reach and targets them with a smaller tool. The accuracy depends entirely on the stock model from the prior operation. If the previous tool or stepover changed, regenerate the stock model before computing the rest toolpath. Stale stock models cause the rest tool to either miss material or plunge into already-machined surfaces.

- Operation types: `rest_machining`, `finishing`
