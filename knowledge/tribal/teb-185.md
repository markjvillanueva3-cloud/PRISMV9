# Pocket Machining with Progressive Level Cutting

**Category:** `roughing` · **Subcategory:** `stock_removal` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:tebis-docs`

## Tip

Tebis auto-detects islands in pockets. Progressive level cutting machines all pockets per Z-level before stepping down. Prevents excessive rapids between disconnected regions. Saves 15-25%. Set island offset = finish stock. Review detection — thin ribs occasionally missed by automatic detection.
