# Automatic Tilting Accesses Deep Cavities with Short Tools

WorkNC Auto 5 tilts the tool to reach deep cavity regions that would otherwise require long tool assemblies in 3-axis mode. By tilting 15-30 degrees, the effective tool reach increases by 15-30%, allowing use of shorter, more rigid tools. This reduces tool deflection and vibration, improving surface finish. Set the maximum tilt angle based on the machine's rotary axis limits and the cavity geometry. Typical savings: 40-60% shorter tools and 30-50% less vibration.
