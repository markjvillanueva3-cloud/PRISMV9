# TopSolid Wire EDM — Integrated Profile and Technology Management

TopSolid'Cam Wire EDM combines profile programming with technology databases from major machine manufacturers (Agie Charmilles, Sodick, Mitsubishi, Makino). Select the wire material, diameter, and workpiece material, and TopSolid loads the optimal cutting parameters (generator settings, wire tension, flushing pressure) from the technology database. This eliminates manual technology lookup and ensures the machine runs at manufacturer-recommended parameters. For each machine brand, install the corresponding technology package from TopSolid's partner program.
