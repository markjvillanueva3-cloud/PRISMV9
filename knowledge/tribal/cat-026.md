# Multi-Axis Curve Machining for Edge Trimming and Deburring

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:catia-docs`

## Tip

CATIA Multi-Axis Curve machining drives the tool along a guide curve while maintaining a specified orientation relative to the surface normal. Use it for edge trimming, deburring, and chamfering operations where the tool must follow a 3D edge with consistent engagement. Define the tool axis using 'Normal to Surface' mode and add a small offset (0.5-1mm) from the edge to prevent gouging. Set the angular limit to ±30 degrees to prevent excessive axis rotation.
