# Workplane Management for Multi-Setup Molds

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.87` · **Source:** `web:cimatron-docs`

## Tip

Define workplanes for each setup orientation. Use 'Active Workplane' per operation. For 5-axis indexed work, create workplanes at each angle. Name descriptively: 'OP10-CavitySide', 'OP20-CoreSide'. When machining both halves, use precision dowel pins or 3-2-1 locating for setup alignment. Include datum locations in setup sheets for operator reference.

## Applies to

- Operation types: `setup`
