# Live Connection Probing for Real-Time Results

**Category:** `quality` · **Subcategory:** `inspection` · **Domain:** `cam_software`

**Confidence:** `83` · **Source:** `web:fusion360-docs`

## Tip

Use Fusion's Live Connection feature to stream probing results from the CNC machine directly into Fusion over a network connection. This enables real-time inspection visualization — probe points appear on the CAD model as they are measured, with deviation arrows showing the direction and magnitude of each error. Live Connection works with Renishaw probes via the OMI receiver and requires the machine to have a network connection. This eliminates the manual export-import step and catches issues before the part leaves the machine.
