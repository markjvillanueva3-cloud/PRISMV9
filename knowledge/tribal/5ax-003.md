# G68.2 Transform Plane enables tilted workplane machining on Hurco with TCPM

**Category:** `cnc_programming` · **Domain:** `document_learned`

**Confidence:** `93` · **Source:** `document:hurco-5axis-post`

## Tip

Hurco G68.2 activates Transform Plane (tilted workplane) and enables Tool Center Point Management. Format: G68.2 X Y Z A C where XYZ repositions origin and AC defines tilt angles using ISO rotation conventions. G68.2 does NOT command axis motion — output rotary position separately or use G08.2 (ASR). Cancel with G69. Transform planes can stack; each G69 cancels one in reverse order.

## Applies to

- Operation types: `5axis`, `multiaxis`, `3plus2`
