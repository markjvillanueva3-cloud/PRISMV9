# Multi-Cavity Copy and Verify

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.87` · **Source:** `web:sprutcam-docs`

## Tip

Program one cavity, copy to all positions. Adjust WCS and rapids per instance. Verify each in simulation. For identical cavities: 1/N effort. SprutCAM supports pattern-based copying with automatic verification of all instances.
