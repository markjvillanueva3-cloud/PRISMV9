# Workplane Naming Convention for Shops

OP10-Top, OP20-FrontFace, OP30-SlideAccess. Active Workplane per operation. Probe at each setup start. Standard naming enables any operator to set up any job without programmer. PowerMill setup sheets auto-include WCS data, fixture diagrams, and critical notes.
