# CONNECTED Machining synchronizes CAM workstation with machine controller bidirectionally

**Category:** `automation` · **Subcategory:** `lights_out` · **Domain:** `document_learned`

**Confidence:** `93` · **Source:** `document:hypermill-vmc`

## Tip

hyperMILL CONNECTED Machining enables real-time bidirectional communication with the machine controller. Before running: zero-point definitions, tool data, and machine parameters are read from controller and validated against CAM data. Machine run only starts if data matches and collision check passes. NC programs load directly to controller memory, preventing mixup and unauthorized access. Use for lights-out production.
