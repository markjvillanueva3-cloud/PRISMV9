# Configuration Management Tracks All CAM Versions

TopSolid's integrated PDM system tracks every revision of both CAD models and CAM programs. Each configuration stores the complete machining context including tool lists, stock definitions, and post-processor settings. Use the 'Compare Configurations' tool to visualize differences between program revisions. This is essential for AS9100/ISO 13485 environments requiring full traceability of manufacturing process changes.
