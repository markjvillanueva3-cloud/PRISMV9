# ERP/MES Integration via PowerMill API

PowerMill COM API automates: project creation, model import, template application, post-processing, file export. Common integration: pull job from ERP → create project → apply template → simulate → post → upload to DNC. Batch processing overnight for design changes. API also enables custom tool management synchronization with shop tool crib systems.
