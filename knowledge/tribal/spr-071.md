# Swarf Cutting for Draft Walls

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:sprutcam-docs`

## Tip

Swarf cutting uses the tool's side (flute length) to machine ruled surfaces in a single pass. In SprutCAM, define the 'Drive Surface' (wall) and set tool axis perpendicular to the wall. Swarf cutting is 5-10× faster than Z-level for draft walls. Verify the surface is truly ruled — swarf on doubly-curved surfaces causes gouging. Limit tool tilt variation to ±3° per pass for smooth surface quality.
