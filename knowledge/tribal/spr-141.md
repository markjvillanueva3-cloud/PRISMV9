# Wire EDM Programming for Inserts

**Category:** `cam_strategy` · **Domain:** `process_engineering`

**Confidence:** `0.82` · **Source:** `web:sprutcam-docs`

## Tip

2-axis and 4-axis taper. Define profile, taper angles, skim passes. Wire type, flushing, power per cut. Independent top/bottom profiles for taper. Tabs for slug retention. SprutCAM outputs Fanuc, Sodick, Mitsubishi formats. Wire EDM preferred for thin inserts where milling forces cause deflection.
