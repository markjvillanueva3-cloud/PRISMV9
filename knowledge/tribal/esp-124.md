# ESPRIT Edge Analytics Dashboard for Cycle Time Trends

**Category:** `workflow` · **Domain:** `cam_software`

**Confidence:** `0.79` · **Source:** `web:esprit-docs`

## Tip

The Edge Analytics dashboard aggregates cycle time, tool usage, and machine utilization data across all connected machines. Access via Edge → Analytics → Dashboard. Track KPIs like spindle utilization percentage, average setup time, tool cost per part, and program revision frequency. Historical trend analysis identifies which operations consistently exceed estimated cycle times, enabling targeted optimization. Export reports in PDF/CSV for management review or feed data into ERP systems via REST API.
