# Volume Milling Stock-Aware Roughing Strategy

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.91` · **Source:** `web:cimatron-docs`

## Tip

Cimatron's Volume Milling uses a stock-aware approach that tracks remaining material between passes. Set 'Stock Allowance' to 0.5mm for semi-finish and use 'Rest Roughing' mode to target only unmachined pockets. The IPW (In-Process Workpiece) updates automatically, preventing air cutting on subsequent operations.
