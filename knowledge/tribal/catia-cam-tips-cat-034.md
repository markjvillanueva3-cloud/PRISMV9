# Geodesic 5-Axis Machining for Deep Narrow Cavities

CATIA Multi-Axis Geodesic machining is specialized for deep, narrow cavities where conventional 3-axis tool paths cannot reach without excessive tool stick-out. The tool follows geodesic curves on the surface while CATIA automatically orients the tool axis for maximum rigidity and minimum overhang. Use lollipop or barrel cutters to further extend reach. Set the geodesic direction to follow the longest cavity dimension to minimize the number of passes and linking moves.
