# Collision with SolidWorks Assembly Context

SolidCAM checks collision against the full SolidWorks assembly: fixture, clamps, vise, machine table. Include tool holder assembly. Gouge check every finish. iMachining's constant engagement avoids sudden force spikes that cause tool pull-in gouging.
