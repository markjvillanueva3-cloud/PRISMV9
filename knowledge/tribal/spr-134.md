# Tool Library with Presetter Sync

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:sprutcam-docs`

## Tip

Store geometry, holders, parameters per material. Sync with presetter (Zoller/Haimer). Actual vs nominal diameter differences of 0.01mm affect finish. Update after presetting. Shared libraries ensure consistency across programmers. SprutCAM exports tool data to setup sheets automatically.
