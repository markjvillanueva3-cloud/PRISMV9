# Spiral Machining for Circular Cavity and Dome Features

Use CATIA Spiral machining for rotationally symmetric features like cavities, domes, and lens molds. The spiral path eliminates the retract-reposition moves found in Sweeping, keeping the tool in continuous contact. Set the spiral center point at the feature axis and define the start/end radii to match the feature extents. For concave features, start from the center outward; for convex, start from the perimeter inward to maintain climb milling.
