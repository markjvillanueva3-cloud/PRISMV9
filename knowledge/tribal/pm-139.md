# Multi-Setup Alignment with Probing

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.87` · **Source:** `web:powermill-docs`

## Tip

Multi-setup parts: master coordinate system shared across setups. Probe at each setup start to verify alignment. Precision dowel pins or 3-2-1 locating for Setup 2→Setup 1 feature alignment. PowerMill setup sheets include datum locations. When machining both sides of a mold, alignment accuracy between setups determines parting line quality.
