# Cusp Analysis Visualizes Surface Quality Before Cutting

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:topsolid-cusp-analysis`

## Tip

TopSolid's cusp analysis tool displays a color-coded map of the theoretical cusp height across the finished surface before any cutting occurs. Areas exceeding the target cusp height are highlighted in red, allowing you to adjust strategy or tool selection before committing to a cut. Use this to identify regions where a smaller tool or tighter stepover is needed. The analysis accounts for tool geometry (ball-nose radius), surface curvature, and local stepover.
