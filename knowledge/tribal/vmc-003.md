# Axis diagrams reveal unusual traverse movements before machine execution

**Category:** `simulation` · **Subcategory:** `machine_simulation` · **Domain:** `document_learned`

**Confidence:** `91` · **Source:** `document:hypermill-vmc`

## Tip

hyperMILL VIRTUAL Machining axis diagrams display detailed traversing movements of each individual axis over time. Use to identify: unexpected rapid movements, axis reversals, near-limit conditions, excessive rotary unwinding. Unusual patterns often indicate post-processor issues or suboptimal toolpath planning. Correct before transferring program to machine to avoid crashes and premature axis wear.
