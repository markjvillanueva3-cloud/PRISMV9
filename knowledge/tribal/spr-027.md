# Macro Programming for Automated Workflows

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.83` · **Source:** `web:sprutcam-docs`

## Tip

SprutCAM's macro system allows automated workflows: load model → apply template → generate toolpaths → simulate → post-process. Write macros in JavaScript to control the full CAM pipeline. Use macros for batch processing of part families — loop through a folder of models and generate NC code for each. Store reusable macro libraries for common operations.
