# Macro Automation for Mold Base Programming

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.86` · **Source:** `web:cimatron-docs`

## Tip

Cimatron macros record and parameterize standard mold base sequences. Pocket machining for A/B plates, guide pins, sprue bores, clamp slots. Replay for similar bases. Saves 4-6 hours. Store in shared folders. Enforce shop standards across programmers.
