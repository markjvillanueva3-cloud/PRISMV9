# Workplane Management for Multi-Setup Parts

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.88` · **Source:** `web:powermill-docs`

## Tip

Define workplanes for each setup orientation. Use 'Active Workplane' to control which coordinate system applies to each operation. For 5-axis indexed work, create workplanes at each indexed angle. Name workplanes descriptively (e.g., 'OP10-Top', 'OP20-FrontFace'). When transferring stock between setups, ensure the workplane origin matches the physical datum point used on the machine.

- Operation types: `setup`
