# Tool Library with 3D Holder Assemblies

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `93` · **Source:** `web:topsolid-tools`

## Tip

TopSolid's tool library stores complete 3D tool assemblies including cutter, holder, collet, extension, and adapters. Each component is a separate 3D model that can be combined into assemblies. Maintain accurate holder models to ensure collision detection works correctly—a 1 mm error in holder diameter can mean the difference between a safe and crashed program. Import holder models from manufacturer catalogs (Sandvik Coromant, Kennametal, BIG DAISHOWA) in STEP format.
