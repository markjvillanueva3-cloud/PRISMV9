# Electrode Design Wizard for EDM Electrodes

Cimatron Electrode Wizard automates: extract electrode geometry from cavity, define blank and holder (EROWA/3R/System 3R), create extension surfaces, apply spark gap offsets. Generates roughing and finishing NC programs automatically. Supports both graphite and copper electrodes. Output burn position data for the EDM machine. Track electrode status (new/used/worn) in project.
