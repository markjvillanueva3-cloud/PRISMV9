# TopSolid EROWA/System 3R Holder Integration — Pallet Reference Systems

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `process_engineering`

**Confidence:** `91` · **Source:** `web:topsolid-docs`

## Tip

TopSolid integrates with precision pallet reference systems (EROWA ITS, System 3R Macro/Mini) for electrode and workpiece handling. The CAD library includes 3D models of all standard holders, chucks, and pallets. When designing electrodes, the holder geometry is included in the tool assembly for reach checking and collision avoidance. The holder reference datum transfers between the milling machine (electrode machining) and the EDM sinker — ensuring the electrode position in the sinker matches the programmed position without additional setup alignment.
