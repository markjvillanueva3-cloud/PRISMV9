# ISV Mandatory Before First Article

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.88` · **Source:** `web:siemens-nx-docs`

## Tip

Full assembly collision check: shank, holder, taper, spindle + 0.5mm margin. Gouge check every finish op. 5-axis aerospace parts: ISV is mandatory, not optional. Run at full machine mode to catch head/table interference. Shrink-fit holders for minimum collision profile.
