# Stock Setup defines raw billet — Stock Model defines in-process shape

**Category:** `setup` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:community`

## Tip

Stock Setup and Stock Model serve different purposes in Mastercam. Stock Setup defines the raw material shape (rectangular, cylindrical, or STL) before any machining. Stock Model represents material remaining after specific operations. Use Stock Setup for the first roughing operation and Stock Model for all subsequent operations. Confusing these causes either air cutting (stock too large) or missed material (stock too small).
