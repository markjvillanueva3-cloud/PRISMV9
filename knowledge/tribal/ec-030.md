# 5-Axis Blade and Impeller Machining

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:edgecam-5axis`

## Tip

Edgecam's blade/impeller cycle machines hub surfaces, blades, and splitter blades in coordinated sequences. Start with hub roughing using a bull-nose cutter, then blade finishing with a tapered ball-nose. Set blade extension to 3-5% beyond the blade edge. For splitter blades, use thinner tools and enable secondary blade offset. Always simulate with full holder geometry — splitter channels are the most common collision zone.
