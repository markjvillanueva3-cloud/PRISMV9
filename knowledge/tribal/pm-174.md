# Surface Quality Analysis Before Programming

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:powermill-docs`

## Tip

Curvature maps, zebra stripes, deviation analysis on imported models. Identify tangency breaks, faceting, waviness before machining. Fix in CAD first. Parting surfaces need G2 minimum. PowerMill's surface analysis tools highlight problem areas. Run before any toolpath generation.
