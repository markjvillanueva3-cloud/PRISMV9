# Centralized Tool Library with Assemblies

Edgecam's tool library stores complete tool assemblies: cutter + holder + adapters. Define each component separately and combine into assemblies for different machines. Import manufacturer data in ISO 13399 format for rapid library building. Store cutting data per tool-material combination so speed/feed values are automatically applied when the tool is selected. A well-maintained library of 300-500 assemblies covers most shops.
