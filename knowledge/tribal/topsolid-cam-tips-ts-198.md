# TopSolid'ShopFloor Scheduling — Visual Job Queue per Machine

TopSolid'ShopFloor provides a visual scheduling board showing the job queue for each machine. Jobs are displayed with: estimated cycle time (from TopSolid'Cam), required tools (with availability status), material requirements, and due date. Drag and drop jobs between machines when one machine is overloaded. The system checks tool availability — if a required tool is in use on another machine, it flags the conflict. Integration with ERP systems (SAP, Oracle) synchronizes production orders and priorities.
