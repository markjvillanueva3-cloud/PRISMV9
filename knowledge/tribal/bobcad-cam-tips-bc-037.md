# 5-Axis Trimming for Composite and Sheet Parts

BobCAD 5-axis trimming machines the edge profile of composites, thermoformed parts, and sheet metal. Tool axis is controlled relative to the edge surface normal (0° for flush trim, 45° for chamfer). Use compression router bits for CFRP to prevent delamination. Set feed rate based on material stack thickness and cutter engagement. BobCAD's multi-surface definition allows the trim path to follow complex compound curves across multiple surface patches.
