# Shop Documentation with NX Manufacturing

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.87` · **Source:** `web:siemens-nx-docs`

## Tip

Generate shop documentation directly from NX: setup sheets, tool lists, operation sequences, and estimated cycle times. Use 'Manufacturing Documentation' template to create HTML or PDF output. Include fixture diagrams, WCS origin locations, and critical dimension callouts. Customize templates to match your shop format. Distribute via Teamcenter for revision-controlled shop floor access.
