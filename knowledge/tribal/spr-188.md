# Surface Analysis Before Programming

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:sprutcam-docs`

## Tip

Curvature maps, zebra stripes, deviation analysis on imported models. Identify tangency breaks, faceting. Fix in CAD first. UV continuity affects toolpath direction. SprutCAM surface analysis tools highlight problems. Run before any toolpath generation on mold/die work.
