# hyperMILL VIRTUAL Machining simulates NC code post-postprocessor for collision detection

**Category:** `simulation` · **Subcategory:** `nc_simulation` · **Domain:** `document_learned`

**Confidence:** `94` · **Source:** `document:hypermill-vmc`

## Tip

hyperMILL VIRTUAL Machining Center simulates actual NC code AFTER postprocessor output, not just toolpaths. This catches collision issues that only appear in posted code (tool changes, rapid moves, retract heights). Simulation includes holder, fixtures, clamps, and tracked stock. Each machining operation is collision-checked before machine movement. Essential for 5-axis work where complex motions create hidden collision risks.
