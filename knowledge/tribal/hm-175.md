# Disc Cutter for Slots

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `82` · **Source:** `web:hypermill-docs`

## Tip

Define disc geometry precisely. 3+2 per slot. Speed on outer diameter. High tooth count = low fpt. Flood for evacuation. More consistent width than end mills. hyperMILL VIRTUAL Machining simulates disc operations with full machine model.
