# Zone-Based Rapid Heights

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.85` · **Source:** `web:siemens-nx-docs`

## Tip

Different safe heights per region based on fixture clamp locations. 5-15% savings vs single global height. NX supports zone-based rapids. Configure per-operation. Verify in ISV that all rapids clear fixturing across all zones.
