# Setup Sheet Generation

Generate from SprutCAM: fixture diagram, tool list, WCS origin, program sequence, cycle time, notes. HTML/PDF export. Customize template to shop format. Include fixture photos. Distribute via network or MES. Setup sheets reduce operator errors and setup time by 30-50% vs verbal instructions.
