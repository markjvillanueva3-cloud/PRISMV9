# Tool Assembly Stacking — Build Modular Tool/Holder/Extension Combinations

Use SolidCAM's tool assembly feature to stack cutting tool + extension + holder as a single assembly. This enables you to maintain a library of standard holder configurations and simply swap the cutting tool. When a tool requires extra reach, add an extension component between the tool and holder rather than creating a new holder entry. The stacked assembly propagates to collision checking and simulation, ensuring the full physical tool assembly is verified against the workpiece and machine.
