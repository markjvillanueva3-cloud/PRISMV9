# Contour Milling with Advanced Clearance Areas

**Category:** `cam_strategy` · **Subcategory:** `contour` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:bobcad-contour-advanced`

## Tip

BobCAD V36 Advanced UI provides custom clearance areas for contour operations. Define how the tool transitions from clearance zones — shortest path or horizontal/vertical approach/exit with specified entry/exit feed distances. This prevents uncontrolled tool motions between features. Set distinct clearance areas per operation to account for different fixture heights and part features. The Advanced UI is for experienced users who need absolute control over tool motion.

- Operation types: `profiling`, `finishing`
