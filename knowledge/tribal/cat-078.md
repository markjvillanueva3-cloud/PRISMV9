# Collaborative Machining Enables Multi-User NC Programming

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `83` · **Source:** `web:catia-docs`

## Tip

On the 3DEXPERIENCE platform, multiple NC programmers can work on the same Manufacturing Program simultaneously. Each programmer locks the operations they are editing, preventing conflicts. Use the 'Collaborative Machining' role to assign different programmers to different setup orientations or operation groups. Changes are merged automatically when locks are released. This can reduce lead time for complex parts from weeks to days by parallelizing the programming effort.
