# CMM Output for Quality Documentation

ESPRIT can generate CMM (Coordinate Measuring Machine) inspection programs in DMIS format alongside the machining program. Define inspection points on critical features — bore centers, face positions, hole patterns, profile tolerances — and ESPRIT creates both the on-machine probing routine and the corresponding CMM program. This ensures the same datum scheme is used for both in-process and final inspection, eliminating discrepancies between on-machine and CMM results.
