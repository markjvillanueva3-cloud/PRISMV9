# Additive/Hybrid Manufacturing Integration

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `81` · **Source:** `web:tebis-docs`

## Tip

Tebis supports DED (Directed Energy Deposition) for hybrid manufacturing: alternate additive deposition and subtractive machining. Define layer height, bead width, overlap percentage. After each additive layer block, run a machining pass for dimensional accuracy. Use for: component repair, feature addition, and near-net-shape production of expensive aerospace materials.
