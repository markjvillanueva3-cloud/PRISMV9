# Automatic Feature Recognition identifies holes with minimal user input

GibbsCAM's Automatic Feature Recognition (AFR) scans imported solid models and identifies machinable features—primarily holes and hole-like features. AFR detects simple through-holes, blind holes, counterbores, countersinks, and threaded holes from the solid geometry. Select holes by face, coordinate system, or feature group. For parts with hundreds of holes, AFR programs them with as few as 3 clicks: select the face, confirm the hole groups, and apply the drilling template. AFR accuracy depends on clean solid model import—repair any missing faces or slivers before running feature recognition.
