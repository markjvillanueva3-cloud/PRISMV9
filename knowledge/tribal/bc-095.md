# Cutting Data per Material for Auto-Population

**Category:** `speeds_feeds` · **Subcategory:** `cutting_parameters` · **Domain:** `cam_software`

**Confidence:** `88` · **Source:** `web:bobcad-cutting-data`

## Tip

BobCAD stores recommended cutting data (speed, feed, depth) per tool-material combination. When tool and workpiece material are selected, parameters auto-populate. Customize defaults based on shop experience — factory values are conservative starting points. V37's improved tool management allows copying cutting data across similar tools, so updating the data for one 10mm end mill automatically applies to all 10mm end mills of the same type and coating.
