# SPC Integration for Aerospace Production

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:siemens-community`

## Tip

Implement SPC on critical aerospace dimensions machined with NX programs. X-bar/R charts from first 25 parts establish control limits. Monitor for: trends (tool wear), shifts (fixture or WCS drift), and stratification (material batch variation). NX's Teamcenter integration can link SPC data to specific program versions and tool setups for full traceability. NADCAP auditors require SPC evidence for critical features.
