# Wire EDM No-Core Pocketing Eliminates Slug Handling

**Category:** `cam_strategy` · **Subcategory:** `spiral` · **Domain:** `process_engineering`

**Confidence:** `88` · **Source:** `web:esprit-wire-edm`

## Tip

ESPRIT's no-core (coreless) pocketing removes material without creating a slug by using a spiral or raster pattern that progressively erodes the cavity. This is ideal for small features where slug removal is difficult or risky, or for blind cavities where the slug cannot fall through. No-core is 30-50% slower than conventional profile cutting, so use it only when slug management is problematic. Set the erosion stepover to 60-80% of wire diameter + overburn.
