# WorkNC Cloud Collaboration — Multi-Site Program Sharing

WorkNC supports cloud-based collaboration for multi-site manufacturing operations. Share CAM projects, tool libraries, machining templates, and post processors through cloud storage with version control. Benefits: (1) a program developed at site A can be immediately run at site B using the shared post processor, (2) tool library updates propagate to all sites simultaneously, (3) best-practice templates developed by experienced programmers are available to all sites. Ensure network security: use VPN or encrypted connections, and implement access controls per user role (viewer, programmer, administrator).
