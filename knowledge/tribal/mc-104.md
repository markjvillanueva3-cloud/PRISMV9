# NET-Hook (.NET) bridges the gap between VBScript simplicity and C-Hook power

**Category:** `automation` · **Subcategory:** `tool_presetter` · **Domain:** `cam_software`

**Confidence:** `84` · **Source:** `web:community`

## Tip

NET-Hook allows C# or VB.NET applications to interact with Mastercam through a managed API. NET-Hooks can create geometry, modify toolpath parameters, access the tool library, and automate workflows — all with modern .NET debugging and IntelliSense support. They are easier to develop than C-Hooks (no manual memory management) and more powerful than VBScript (full .NET framework access). NET-Hook DLLs deploy to Mastercam's Plugins folder and appear in the Mastercam menu. Ideal for shop-specific automation tools and MES integration.
