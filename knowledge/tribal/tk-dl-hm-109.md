# 3+2 part setup: dimension overlay verification in 3D viewport

**Category:** `setup` · **Domain:** `video_learned`

**Confidence:** `75` · **Source:** `video:Hypermill-3plus2-tutorial@0-10s`

## Tip

For 3+2 axis machining in hyperMILL, the part setup shows dimensions annotated directly in the 3D viewport (e.g. 75x25mm with 75mm height via green arrows). The simulation highlights the cutting zone in yellow against the workpiece, confirming tool engagement before running the full operation. Use this visual check before committing to calculation.
