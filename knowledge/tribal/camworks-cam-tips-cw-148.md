# CAMWorks ShopFloor — 3D Work Instructions at the Machine

CAMWorks ShopFloor provides interactive 3D work instructions on the shop floor without requiring a SOLIDWORKS license. Operators can rotate, zoom, and section the model, view operation sequences with toolpath overlays, and access setup sheets. Deploy ShopFloor on touchscreen stations at each CNC machine. The system reads the CAMWorks project file directly, so any changes made by the programmer are immediately available to the operator after a file refresh.
