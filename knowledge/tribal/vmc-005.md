# VIRTUAL Machining Optimizer calculates best tool positions for multi-axis machining

**Category:** `multiaxis` · **Domain:** `document_learned`

**Confidence:** `92` · **Source:** `document:hypermill-vmc`

## Tip

hyperMILL VIRTUAL Machining Optimizer module calculates technically optimal tool positions that enable efficient traverse movements during 5-axis machining. All selected tool positions are collision-checked, guaranteeing safe machine run. This eliminates programming errors that would require machine-side correction. Use Optimizer when standard indexing produces suboptimal results or near-collision conditions.
