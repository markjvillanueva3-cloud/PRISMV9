# Disc Cutter for Slot and Groove Machining

Define disc geometry: diameter, thickness, bore, teeth. 3+2 per slot. Speed on outer diameter. Feed accounts for high tooth count (20-60). Flood coolant for evacuation. More consistent slot width than end mills. Tebis supports full disc cutter simulation and collision detection with machine model.
