# Engraving with V-Bit and Drag Knife Support

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:surfcam-engraving`

## Tip

SURFCAM engraving uses V-bit tools (30°, 60°, 90°) with depth-controlled paths for text and logos. The cut depth determines character line width — deeper cuts produce wider lines. For crisp text in aluminum, use a 60° V-bit at 0.3mm depth, 18000 RPM, and 800 mm/min feed. Enable 'Retract between characters' to prevent drag marks. For curved surfaces, use the 3D engraving option which projects the text onto the surface model.
