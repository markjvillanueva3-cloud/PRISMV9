# Pareto Front for Quality-Throughput Trade-Off

Build a Pareto front by varying step-over (0.1-0.5mm) and feed rate (0.03-0.10mm/tooth) in SprutCAM. Plot surface finish vs cycle time for each combination. The Pareto-optimal set shows the best achievable finish at each throughput level. Select operating points based on job priority: tight-tolerance mold work favors quality, high-volume production favors speed.
