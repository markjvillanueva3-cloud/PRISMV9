# Machine Simulation with Full Kinematic Model

Tebis machine simulation uses the complete kinematic chain for collision detection. Import machine models from Tebis library or create custom machines. Define: spindle nose, tool holder, rotary table, fixtures, tailstock. Run simulation at 'Full Machine' mode for 5-axis operations — catches collisions that geometric simulation alone misses (head/table interference, cable wrap limits).
