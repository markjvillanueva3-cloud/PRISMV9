# Boundary Boolean for Selective Machining

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

## Tip

Create from edges, silhouettes, sketches, steep/shallow detection. Boolean union/intersection/subtraction. 0.5mm extension prevents marks. Named sets for reuse. Selective machining reduces cycle 20-40% when reworking specific regions. PowerMill supports complex boundary chains.
