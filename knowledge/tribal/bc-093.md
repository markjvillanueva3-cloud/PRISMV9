# Multiple Tool Libraries for Organized Tool Management

**Category:** `setup` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:bobcad-multiple-tool-libraries`

## Tip

BobCAD V37 introduces Multiple Tool Libraries — organize tools by machine, manufacturer, or location. Import, merge, clone, and copy tools across libraries. This eliminates the single-library bottleneck where all tools were in one list. Create libraries per machine (e.g., 'Haas VF-4 Tools', 'Mazak QTN Tools') with only the tools actually available in each machine's magazine. Link operations to the machine-specific library for faster tool selection.
