# Mill-Turn MCO Cycles — Use Pre-Built Machine Control Operations

**Category:** `automation` · **Subcategory:** `bar_feeder` · **Domain:** `cam_software`

**Confidence:** `82` · **Source:** `web:solidcam-docs`

## Tip

Mill-Turn post-processors include pre-built Machine Control Operation (MCO) cycles for common tasks like part catch, bar feed, spindle transfer, and tailstock control. These cycles require minimal user input and save significant programming time. Check your machine's MCO library before manually coding M-functions — most standard operations are already templated.
