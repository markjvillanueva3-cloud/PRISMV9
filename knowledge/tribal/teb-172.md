# Multi-Machine Post Flexibility

**Category:** `setup` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:tebis-docs`

## Tip

Post same Tebis toolpath for different machines by switching virtual machine configs. Program once, post for DMG, Hermle, Makino. Each applies machine-specific axis naming, RTCP format, retract strategy. Enables flexible scheduling — if one machine is busy, quickly re-post for available machine.
