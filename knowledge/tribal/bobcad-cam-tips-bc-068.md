# Wizard-Driven Programming Reduces Learning Curve

BobCAD's wizard interface guides programmers through operation setup step-by-step: geometry selection → tool selection → cut parameters → lead-in/out → linking → simulation. Each wizard page has context-sensitive defaults based on the selected tool and material. For experienced programmers, the V36 Advanced UI provides all parameters on a single page with full control. Toggle between Wizard and Advanced modes per operation as needed — both produce the same toolpath output.
