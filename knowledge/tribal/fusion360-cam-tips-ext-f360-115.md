# Feature Recognition for Automated Hole Programming

Fusion's Feature Recognition scans the model and groups holes by type (through, blind, threaded, countersunk, counterbored) and diameter. Each hole group can be assigned a machining template that defines the full drill cycle: center drill, pilot drill, final drill, chamfer, tap. Use the Hole Table in the Setup Sheet to verify all holes are accounted for. Feature recognition catches holes that manual selection misses — on parts with 50+ holes of varying sizes, it reduces programming time from hours to minutes.
