# Robot Drilling for Large Structures

**Category:** `cam_strategy` · **Subcategory:** `drilling` · **Domain:** `cam_software`

**Confidence:** `0.82` · **Source:** `web:powermill-docs`

## Tip

PowerMill Robot programs automated drilling on large aerospace structures (fuselage panels, wing skins). Define hole patterns from CAD. 6-axis robot positions and drills at each location. Use peck cycle for composites, orbital drilling for metals. Verify reachability at all positions.
