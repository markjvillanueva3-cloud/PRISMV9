# Lollipop Cutter for Undercuts

**Category:** `cam_strategy` · **Domain:** `process_engineering`

**Confidence:** `82` · **Source:** `web:hypermill-docs`

## Tip

Lollipop tools access behind overhangs. Define ball diameter, neck diameter/length. 3+2 positioning for access. Verify neck clearance. Speed based on ball diameter. hyperMILL checks the complete tool assembly during simulation. Eliminates EDM for many undercut features in mold cores.
