# Morphing Between Depths for Smooth Adaptive Transitions

**Category:** `cam_strategy` · **Subcategory:** `adaptive` · **Domain:** `cam_software`

**Confidence:** `84` · **Source:** `web:fusion360-docs`

## Tip

Enable the Both Ways option in 3D Adaptive Clearing to allow the tool to cut in both climb and conventional directions during depth transitions. Combined with Smoothing enabled, this eliminates the retract-reposition-plunge cycle between Z-levels, reducing cycle time by 15-25% on deep cavities. Monitor surface finish on conventional-cut walls — if unacceptable, switch back to one-way climb cutting and accept the longer cycle.
