# Mutual Information for SPC Feature Selection

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.76` · **Source:** `web:cimatron-forum`

## Tip

I(X;Y) quantifies statistical dependence between process feature X and quality outcome Y. Select top-k features with highest MI. Reduces false alarms from irrelevant features. For mold production: 3-5 features capture 90% of quality information. Focus monitoring on these.
