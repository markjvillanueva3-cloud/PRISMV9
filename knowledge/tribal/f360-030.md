# Manufacturing Extension Unlocks Advanced Strategies

**Category:** `cam_strategy` · **Subcategory:** `contour` · **Domain:** `cam_software`

**Confidence:** `86` · **Source:** `web:fusion360-docs`

## Tip

The Fusion Manufacturing Extension adds Steep and Shallow finishing, Swarf cutting, Multi-Axis Contour, Multi-Axis Flow, 4-axis Rotary, Surface Inspection, Part Alignment, and Geometry Probing. If you machine complex 3D parts or run 4/5-axis machines, the extension pays for itself by eliminating the need to manually split operations and reducing programming time for freeform surfaces.
