# Rotary Axis Wrapping for 4-Axis Engraving

**Category:** `multi_axis` · **Subcategory:** `tool_axis` · **Domain:** `cam_software`

**Confidence:** `84` · **Source:** `web:tebis-docs`

## Tip

Wrap 2D patterns onto cylinders via rotary substitution. Verify diameter matches actual part — errors cause circumferential scale distortion. For text, logos, patterns on round mold components. Tebis generates rotary-substituted G-code automatically. X-axis motion converts to A/B-axis rotation.
