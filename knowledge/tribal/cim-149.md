# Wire EDM Programming for Mold Inserts

**Category:** `cam_strategy` · **Domain:** `process_engineering`

**Confidence:** `0.82` · **Source:** `web:cimatron-docs`

## Tip

Cimatron wire EDM supports 2-axis and 4-axis taper cutting for mold inserts. Define profile geometry, taper angles, skim cut passes. Set technology: wire type, flushing, power per cut. For mold inserts with draft: specify independent top/bottom profiles. Add tabs for slug retention. Wire EDM is preferred for thin inserts where milling forces would cause deflection.
