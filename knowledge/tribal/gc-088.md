# GibbsCAM macros automate repetitive geometry creation and tool selection

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `87` · **Source:** `web:gibbscam-docs`

## Tip

GibbsCAM macros are text-based scripts (similar to Basic) that automate repetitive tasks: geometry creation, tool loading, operation parameter setting, and process execution. Write macros for standardized setups like: loading a company tool library, creating common fixture geometries, or generating hole patterns. Macros execute at runtime and can access most GibbsCAM API functions. Store macros in a shared network folder so all programmers use the same standardized scripts. For complex automation, macros can read external data files (CSV, text) to drive parametric geometry creation for part families.
