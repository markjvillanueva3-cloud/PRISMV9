# Post-Machining Verification Generates Quality Reports

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:topsolid-verification`

## Tip

TopSolid's post-machining verification probing cycle measures final part dimensions and generates a quality report comparing measured values against nominal dimensions and tolerances. The report can be output as a text file on the controller, transmitted to a PC via DNC, or stored in the TopSolid'Inspection system. This provides traceability documentation for aerospace (AS9102 FAI) and medical (ISO 13485) quality requirements without removing the part from the machine.
