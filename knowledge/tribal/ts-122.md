# TopSolid'Cam 7 Unified Architecture — Single Environment for All Operations

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `process_engineering`

**Confidence:** `93` · **Source:** `web:topsolid-docs`

## Tip

TopSolid'Cam 7 merges milling, turning, mill-turn, and wire EDM into a single unified environment. Unlike earlier versions where each machining type was a separate module, v7 uses one document type with operation-aware context menus. This means a mill-turn part can be programmed in a single project file with seamless transitions between turning and milling operations. The unified architecture also shares tool libraries, stock models, and simulation across all operation types, eliminating duplicate tool definitions.
