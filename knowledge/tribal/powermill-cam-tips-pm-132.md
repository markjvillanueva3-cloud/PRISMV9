# Pocket with Island Detection

PowerMill auto-detects islands in pockets. Progressive level cutting machines all pockets per Z-level. Prevents excessive rapids. Saves 15-25% cycle time. Review detection results — thin ribs occasionally missed. Set island offset = finish stock allowance. For multi-level pockets, IPW tracking ensures each level starts with accurate stock representation.
