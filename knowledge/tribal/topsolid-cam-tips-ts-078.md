# Tool Magazine Setup Sheet Generation

TopSolid generates tool magazine setup sheets listing all tools required for a program in magazine pocket order. The setup sheet includes: pocket number, tool ID, assembly drawing, gauge length, gauge diameter, minimum and maximum projection lengths, and any special notes. Export the setup sheet as a PDF or directly to the tool presetter (Zoller, Haimer, etc.) for automated tool measurement. Consistent setup sheets reduce setup errors and machine downtime.
