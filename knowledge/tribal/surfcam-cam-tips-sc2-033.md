# Parallel Lace Cuts for Large Flat-Bottomed Cavities

For cavities with large flat floors, SURFCAM parallel lace cuts provide efficient area coverage with minimal retracts. Use a flat-bottom end mill (rather than ball-nose) with 60-70% stepover for roughing and 40% for finishing. The lace pattern alternates direction on each pass for continuous cutting. Set the boundary offset to -0.5mm (inward) to leave stock for a dedicated wall finishing pass. Enable 'Optimize linking' to minimize rapid traverse distance between passes.
