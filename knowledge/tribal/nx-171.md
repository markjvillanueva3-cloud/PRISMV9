# Wall Thickness Monitoring via Probing

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `0.84` · **Source:** `web:siemens-nx-docs`

## Tip

Probe wall thickness between rough and finish. If under min + finish allowance, adjust strategy. Teamcenter stores thickness data for NADCAP. Prevents scrapping thin-wall components at final inspection. Program automatic probing in NX operation sequence.
