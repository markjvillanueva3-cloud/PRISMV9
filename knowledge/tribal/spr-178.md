# Steady Rest for Long Shaft Support

**Category:** `cam_strategy` · **Subcategory:** `rest_machining` · **Domain:** `cam_software`

**Confidence:** `0.84` · **Source:** `web:sprutcam-docs`

## Tip

L/D > 6: program steady rest. Machine contact diameter first, then engage rest. M10/M11 for open/close. Cutting forces push INTO rest jaws. Verify turret-rest clearance in simulation. SprutCAM timeline synchronizes rest engagement with machining operations.
