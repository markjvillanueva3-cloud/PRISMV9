# Holder Definition for Accurate Collision Checking

**Category:** `setup` · **Domain:** `cam_software`

**Confidence:** `89` · **Source:** `web:surfcam-holder-def`

## Tip

SURFCAM holder definition uses a profile-of-revolution to define the holder shape. Input the holder profile as a series of diameter/length segments from the cutter shoulder to the spindle taper. Include the retention knob, pull stud, and any adapter elements. For ER collet holders, model the collet nut as the largest-diameter component. Holder inaccuracy is the leading cause of false collision clearances — measure actual holders with calipers and input exact dimensions.
