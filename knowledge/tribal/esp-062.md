# Sinker EDM Linear Path for Rib and Slot Features

**Category:** `cam_strategy` · **Domain:** `process_engineering`

**Confidence:** `85` · **Source:** `web:esprit-sinker-edm`

## Tip

For narrow ribs and slots in mold cavities, use ESPRIT's linear sinker EDM path. The electrode plunges to depth then moves linearly along the rib/slot centerline. Set the linear feed rate based on the gap flushing capability — typically 0.5-2mm/min for roughing and 0.1-0.5mm/min for finishing. Monitor the gap voltage to detect flushing problems — if voltage drops below 70% of normal, reduce feed rate or add retract cycles for chip clearing.
