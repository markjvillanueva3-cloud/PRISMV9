# Pocket Island Detection Validation

**Category:** `cam_strategy` · **Subcategory:** `pocket` · **Domain:** `cam_software`

**Confidence:** `0.87` · **Source:** `web:powermill-docs`

## Tip

PowerMill auto-detects islands. Review results: thin ribs occasionally missed, spurious islands from model artifacts. Progressive level cutting machines all pockets per Z-level. Set island offset = finish stock. For multi-level pockets, IPW tracking ensures accurate stock per level.
