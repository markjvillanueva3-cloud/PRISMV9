# Impeller Machining with Dedicated Multi-Blade Operations

TopSolid provides specialized multi-blade operations for impeller and blisk machining. The system automatically identifies blade, hub, and splitter surfaces, then generates roughing, blade finishing, hub finishing, and fillet finishing passes optimized for the turbomachinery geometry. The blade finishing operation uses ruled-surface projection for precise airfoil profiles, while hub finishing employs flowline passes that respect the inter-blade channel geometry.
