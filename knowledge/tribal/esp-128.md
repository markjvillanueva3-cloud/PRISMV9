# ESPRIT Edge Secure Job Package Distribution

**Category:** `workflow` · **Domain:** `cam_software`

**Confidence:** `0.8` · **Source:** `web:esprit-docs`

## Tip

ESPRIT Edge packages G-code, setup sheets, tool lists, and simulation videos into encrypted job packages (.espkg) for distribution to shop floor tablets. Operators scan a QR code to access the package — no ESPRIT license needed on the shop floor device. Packages auto-expire after configurable time (default 90 days) and log every access for AS9100/IATF-16949 compliance. Include revision-controlled work instructions and inspection plans alongside the NC program.
