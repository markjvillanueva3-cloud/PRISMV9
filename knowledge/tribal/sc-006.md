# iMachining 2D Arc Feed Correction — Fine-Tune for Your Machine

**Category:** `speeds_feeds` · **Subcategory:** `chip_load` · **Domain:** `cam_software`

**Confidence:** `80` · **Source:** `web:solidcam-community`

## Tip

In the Technology Wizard, the Arc Feed Correction parameter adjusts feed rate on curved segments to compensate for machine dynamics. Set it to 0% on high-end machines with fast servo response (Mazak, DMG MORI). On older or less rigid machines, leave the default correction active to prevent tool overload on tight radii.

## Applies to

- Operation types: `pocket_milling`, `roughing`
