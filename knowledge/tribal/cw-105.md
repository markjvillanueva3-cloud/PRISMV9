# Tool Library — Maintain Accurate Tool Assemblies with Holders

**Category:** `cam_strategy` · **Subcategory:** `pocket` · **Domain:** `cam_software`

**Confidence:** `90` · **Source:** `web:camworks-docs`

## Tip

Build tool assemblies in the CAMWorks tool library that include the cutting tool, holder, and collet/adapter. Accurate holder geometry is essential for collision detection in deep pockets and 5-axis work. Measure actual tool dimensions (not catalog values) for frequently used tools — catalog overall lengths may differ from actual assembled length by 2-5mm. Include tool overhang (stick-out from holder face) as this determines maximum reach and deflection characteristics.
