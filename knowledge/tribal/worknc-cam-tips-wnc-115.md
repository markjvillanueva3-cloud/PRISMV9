# Level Rest Machining Targets Specific Z-Ranges

WorkNC's level rest machining limits rest material detection to specific Z-height ranges, allowing targeted cleanup at particular depths. This is useful when only certain depth zones have remaining material (e.g., a shelf or step in the cavity). Set the Z-range to encompass the problem area plus 2-3 mm overlap above and below for smooth transitions.
