# In-Process Inspection Catches Errors Mid-Program

WorkNC programs in-process probing between operations to verify critical dimensions before proceeding. If out of tolerance, the program can apply tool offset correction, alert the operator, or abort to prevent scrap. Define inspection points on critical bores, faces, and depths. Set tolerance band to drawing tolerance minus 25% safety margin for reliable pass/fail decisions.
