# AMSAA Reliability Growth for Program Maturity Tracking

Track Tebis program maturity using AMSAA model. Plot cumulative failures (scraps, rework, tool breaks) vs cumulative production hours. Failure rate should follow power law decrease. If trend stalls or reverses, investigate: tool vendor change, material batch shift, or undocumented machine maintenance. Mature programs achieve <0.5% scrap rate after 50+ production cycles.
