# Tool Life Tracking Across Manufacturing Programs

**Category:** `cam_strategy` · **Domain:** `cam_software`

**Confidence:** `85` · **Source:** `web:catia-docs`

## Tip

CATIA can track cumulative tool engagement time across multiple operations and Manufacturing Programs. Enable Tool Life management in the Resource Management module to set maximum cutting time or length per tool. When a tool exceeds its life limit, CATIA flags the operation and suggests a tool change. This prevents unexpected tool failure on the machine. Set conservative life values (70-80% of manufacturer's rating) for critical aerospace parts where tool breakage is catastrophic.
