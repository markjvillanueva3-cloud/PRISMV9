# Plot the path · track every movement · wire proven paths into autonomous+learning · propagate fleet-wide

**RULE (fleet-wide — applies to EVERY galaxy/slot, every goal).** Operator directive 2026-05-31.

1. **PLOT THE PATH first.** Before acting on a goal, name the goal, decompose it into discrete tracked steps, state the measurable success criterion. No "just start" — plot, then move.
2. **TRACK EVERY MOVEMENT.** Record each step's action / why / measured result as you go (R10 checkpoint discipline). No untracked moves; never continue from a state you cannot describe back. The movement log IS the working-path candidate.
3. **WIRE THE PROVEN PATH into the autonomous AI.** Once a tracked path actually achieves the goal, encode it as an autonomous-execution recipe wired into the PRISM AI system so it re-runs without re-deriving. For CAD that means **autonomous CAD work that continues to learn** (delta domain); each domain wires its own.
4. **ADD IT TO THE LEARNING SYSTEM.** Feed the proven path + its run outcomes into the closed-loop learning backbone (per-domain self-improving AI, outcome ledger, GNN/RAG) so each run makes the system better — not a static recipe, a learning one.
5. **PROPAGATE THE RULE + PATTERN TO ALL GALAXIES.** Pass this rule and every proven-path recipe across the galaxy network so learning **COMPOUNDS** — every domain reuses every other domain's proven paths; the whole fleet gets smarter per goal achieved, not just one slot.
