## What it is
```
ProveOutPromotionEngine — Promote prove-out programs to production

Takes a prove-out G-code program (generated by ProveOutModeEngine) and strips
all prove-out modifications to produce a production-ready program:
  - Removes PROVE-OUT comment lines
  - Removes M01 optional stops added during prove-out
  - Removes single-block header comments
  - Restores original feed rates (by reversing the derating)
  - Restores original RPM values (by reversing the cap)
  - Generates A/B comparison between prove-out and production
  - Includes operator sign-off block

References:
  - Peter Smid, "CNC Programming Handbook" 3rd ed., Ch. 28 (First Article)
  - PRISM ProveOutModeEngine (upstream engine)
```
