## Next-layer knowledge (Hermes-drafted)
**Next Layer: Formal Verification, Real-Time Middleware, and Predictable Distributed Architectures for Shop-Floor Control Systems**

A world-leading expert next masters formal methods for compositional verification of distributed real-time control, predictable middleware for time-sensitive networking, and architectural patterns for mixed-criticality cyber-physical systems deployed at the edge.

Key areas include:
- Timed automata and UPPAAL-based model checking for schedulability and timing verification of IEC 61499 function-block networks (Behrmann et al., 2004).
- Real-time CORBA and Data Distribution Service (DDS) middleware with end-to-end predictability guarantees (Schmidt et al., 2002; OMG DDS 1.4, 2015).
- Mixed-criticality scheduling theory on multiprocessor platforms, including Vestal’s model and its extensions to partitioned and global scheduling (Baruah et al., 2015).
- Formal specification and verification of time-triggered Ethernet (TTEthernet) and TSN traffic shaping using TLA+ and model checkers beyond SPIN (Steiner et al., 2011; IEEE 802.1Qbv-2015).
- Software architecture patterns for predictable integration of control loops with enterprise IT using the “4+1” view adapted for real-time CPS (Kruchten, 1995; Feiler et al., 2012 – SEI AADL).

These build directly on already-covered scheduling theory, TLA+, SPIN, IEC 61499, and IEEE 802.1AS by adding scalable compositional verification, standardized real-time middleware, and industrial-grade mixed-criticality architectures suitable for shop-floor deployment.
