Stability Lobe Diagram — SDOF Chatter Prediction Algorithm

Implements simplified single-degree-of-freedom (SDOF) stability lobe diagram:
  b_lim = -1 / (2 × Ks × Re[G(jω_c)])

  - ω_c: Chatter frequency [rad/s]
