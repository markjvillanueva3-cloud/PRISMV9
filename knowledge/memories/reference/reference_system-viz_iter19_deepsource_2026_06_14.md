## Next-layer knowledge (Hermes-drafted)
The next layer in system-viz centers on prescriptive methodologies for designing cognitively effective visual notations for software architectures and runtime behavior. This includes Moody's nine principles (perceptual discriminability, semantic transparency, complexity management, cognitive integration) that operationalize empirical perception research into repeatable notation engineering. It extends to multi-view architectural documentation frameworks that treat visualizations as first-class artifacts for system comprehension, stakeholder alignment, and evolution tracing in large-scale distributed software.

Additional depth covers survey-derived layout and interaction taxonomies for automatically rendering massive dependency graphs and dynamic traces, plus standardized metamodels (UML) that enforce consistent diagrammatic semantics across tools. Evaluation shifts toward controlled empirical protocols measuring comprehension speed and error rates in realistic SE maintenance tasks.

These elements form the bridge from descriptive cognitive theories to engineering-grade system-viz construction and maintenance.
