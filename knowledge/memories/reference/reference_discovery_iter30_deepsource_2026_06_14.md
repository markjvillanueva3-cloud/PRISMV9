## Next-layer knowledge (Hermes-drafted)
**Next layer: statistical relational learning, probabilistic graphical models for uncertain KG construction, and principled data integration architectures for automated discovery pipelines.**

A world-leading expert advances beyond covered embedding models (TransE/ComplEx/GCN), rule mining (AMIE), link discovery (LIMES), ontology learning, and basic KG surveys by mastering **statistical relational learning (SRL)** to handle uncertainty, incompleteness, and noisy web-scale sources. This includes lifted inference, probabilistic soft logic, and Markov logic networks that combine first-order logic with probabilistic graphical models for joint inference over relational data. 

Theory depth draws from probabilistic graphical models for relational domains, enabling discovery systems to perform collective entity resolution, link prediction under uncertainty, and ontology population with calibrated confidence. On the engineering side, this layer requires data integration methodologies for schema matching, entity linking, and instance matching across heterogeneous sources—foundational for scalable KB construction pipelines that feed semantic web and graph ML systems. These integrate with existing SPARQL, R2RML, and big-data reference architectures (NIST 2019/ISO 20547) but add explicit handling of provenance, trust, and incremental discovery.

Institutional depth comes from MIT Press SRL textbooks, Springer relational learning monographs, and Morgan Kaufmann data integration treatises used in graduate AI and database curricula. This layer equips experts to design production discovery galaxies that move from static KG refinement (Paulheim 2017) to adaptive, uncertainty-aware construction.
