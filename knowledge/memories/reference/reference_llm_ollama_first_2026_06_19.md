# U-LLM-OLLAMA-FIRST (slot:india, 2026-06-19) — free-AI-at-launch keystone

**Operator goal:** product CAD/CAM drawing + print-to-CNC AI generation must run on **local Ollama (free)** instead of the paid Claude API, so the products cost $0 at launch; backend "robust, streamlined, reasoned, intelligent, adaptive to any situation."

## What shipped (the runtime chokepoint)
`mcp-server/src/engines/LLMEngine.ts` `query()` was **Claude-only** (hardcoded `api.anthropic.com`, model `claude-sonnet-4-6`). 6 engines consume it (AIExtractionReasoner, ColdHeadingToolConfigurator, ElectrodeAIReasoning, LocalModelOrchestrator, PRISMIntelligenceLayer, TrilobeElectrodeGeometry) → every call was **paid**. Migrated all 6 to **free-by-default in ONE chokepoint change**:
- **Provider loop** Ollama (free, via existing `ollamaClientEngine.generate`) → Claude (paid) → deterministic offline. Policy `config.prefer` = auto|ollama|claude (env `PRISM_LLM_PREFER`); `config.ollama_model` default `qwen2.5-coder:32b` (env `PRISM_LLM_OLLAMA_MODEL`). `"ollama"` = strict-free (never pays).
- **Adaptive (robust to any situation):** bounded Ollama timeout (`_withTimeout` race, `config.ollama_timeout_ms` / env `PRISM_LLM_OLLAMA_TIMEOUT_MS` default 60s) + failure cooldown (`PRISM_LLM_OLLAMA_RETRY_MS` default 60s). A cold/hung daemon degrades to Claude/offline, never hangs. **Graceful degradation = ZERO regression** (Ollama down + key behaves exactly like the old Claude-only path).
- **R12 honesty:** `ElectrodeAIReasoningEngine.model_used` now reports the REAL provider (`step3Response.model`) — was hardcoded false `"claude-sonnet-4-6"`.
- **cache key** includes `prefer`; **offline fallback NOT cached** (transient failures re-probe a recovered provider).
