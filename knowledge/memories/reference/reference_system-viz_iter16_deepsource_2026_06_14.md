**NEXT LAYER: Cognitive and Semiotic Foundations for System Visualization in Software Architecture**

A world-leading expert in system-viz next masters the **formal semiotic and algebraic foundations** that treat visual notations as rigorously engineered sign systems, moving beyond perceptual psychology and cognitive dimensions into mathematically-grounded visual languages suitable for complex software architecture descriptions.

Key uncovered layer includes:

- **Algebraic semiotics** as a formal theory for mapping between semantic domains and visual representations, including sign systems, semiotic morphisms, and blending (Goguen already cited at introductory level; next is the deeper formal apparatus).
- **Formal visual language theory** using attributed graph grammars, spatial relations, and constraint-based parsing for diagram syntax (beyond CD and physics of notations).
- **Computational models of diagram understanding** that integrate logic, abstraction, and visual inference (extending Stenning & Oberlander and Narayanan into operational systems).
- **ISO/IEC/IEEE 42010:2022** viewpoint specification mechanics, model kinds, and correspondence rules treated as an engineering standard for visual stakeholder languages (moving past 1471-2000’s recommendations into concrete architecture description language (ADL) visualization design).

**Core next sources to master:**

- **Shimojima (2004)** – “The Inferential and the Cognitive Bases of Diagrams” – formal theory of diagrammatic inference and free rides.
- **Goguen (2000)** – “An Introduction to Algebraic Semiotics” (extended version) and subsequent papers on semiotic morphisms for UI and architecture.
- **Bardohl et al. (2002)** – “Visual Language Techniques for Software Development” – graph transformation and visual language parsing (Springer LNCS).
- **Marriott & Meyer (1998)** – “Visual Language Theory” – foundational textbook on constraint-based diagrammatic languages and parsing (Springer).
- **IEEE Std 42010-2022** – explicit requirements for viewpoint languages, model kinds, and visual correspondence frameworks.
- **MIT 6.5840 Distributed Systems (2022 OCW)** – diagrammatic reasoning modules on visualizing consistency and state machines.
- **Purchase et al. (2018)** – “On the Cognitive Effectiveness of Diagrams in Software Engineering” – empirical extension beyond Moody and CD (Empirical Software Engineering).

These provide the institutional, formal, and standards-based depth required for designing system-viz notations that are semantically sound, visually parsable, and compliant with modern architecture description standards.
