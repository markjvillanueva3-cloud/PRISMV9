## Lesson (the reusable one)
**A generator that confirms endpoints against a VOLATILE/rotating source silently loses coverage when that source rotates.** Confirm against the STABLE, ADD-only merged-graph oracle (node-card-offsets, 336K ids, cheap parse, no 548MB load) instead. The test must also degrade gracefully when the gitignored oracle is absent (CI): full endpoint confirmation when present, structural+provenance checks otherwise (proven by hiding the oracle + re-running -> 7/7).
