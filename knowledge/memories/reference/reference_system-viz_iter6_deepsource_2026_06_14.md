## Next-layer knowledge (Hermes-drafted)
**Next Layer: System Visualization as Architectural Abstraction and View Synthesis**

A world-leading expert in system-viz must master **viewpoint-driven architectural visualization**, formal visualization of runtime behavior through model-driven engineering, and the rigorous evaluation of visual notations against cognitive and architectural quality attributes. This layer focuses on how multiple architectural views are synthesized, validated, and presented as coherent system visualizations, grounded in software architecture theory rather than general infovis.

Key next-tier knowledge includes:

- **Viewpoint and View Models** for software-intensive systems (IEEE 42010 conceptual foundations, viewpoint specification, model correspondences).
- **Model-Driven Visualization** techniques that derive interactive system visualizations directly from architectural description languages (ADLs) and metamodels.
- **Cognitive evaluation of software architecture diagrams** using formal notation analysis frameworks beyond basic Cognitive Dimensions.
- **Runtime architecture visualization** and dynamic trace visualization mapped to static architectural models.
- **Architectural decision visualization** and rationale capture linked to view synthesis.

**Concrete sources for this layer:**

- Kruchten P (1995) The 4+1 View Model of Architecture / IEEE Software 12(6)
- ISO/IEC/IEEE 42010:2022 Systems and software engineering — Architecture description

- van Deursen A, Kuipers T (1999) Building Documentation Generators / ICSM 1999
