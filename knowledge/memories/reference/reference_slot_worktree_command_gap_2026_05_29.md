2026-05-29 (slot:bravo): operator reported "all checkin slash commands missing, only getting some chat slots." NOT a client glitch, NOT the MCP server.

**Root cause:** `.claude/commands/*.md` is **gitignored**. A `slot/<nato>` worktree (`H:/prism-slot-<nato>`) does NOT receive gitignored files on `git worktree add`, so its `.claude/commands/` is sparse and frozen at whatever was physically placed there. Commands added to main `H:/prism/.claude/commands` afterward (e.g. the `checkin-mike..zulu` wrappers generated by the 13→26 [[reference_slot_reclaim_2026_05_19|SLOT-RECLAIM]] expansion, which `scripts/generate-per-slot-wrappers.mjs` writes ONLY to `OUT_DIR=H:/prism/.claude/commands`) never reach the worktree. Measured: bravo worktree had 52 command files / 12 checkin wrappers (alpha..lima); main had 375 / 27 (alpha..zulu). Claude Code reads project commands from `<cwd>/.claude/commands` = the worktree → user sees only the 12.

**Diagnostic:** compare `readdirSync` counts of `H:/prism-slot-<slot>/.claude/commands` vs `H:/prism/.claude/commands`; the gap is the missing commands.

**Fix (additive, safe):** copy files present in main but missing in the worktree (recursive; skip existing so worktree-local files like `stub-hunt-bravo.md` are preserved). Writing into the worktree is allowed (not main tree); these are gitignored runtime files so no commit/lane concern. Result: 324 files restored, 52→376, all 27 checkin wrappers present. Harness re-enumerates immediately; client `/` palette refreshes on next open (restart not strictly required).

**Systemic (golf/launcher follow-up):** EVERY slot worktree on this PC likely has this gap. Permanent fix = the worktree-creation / launcher step should sync (or junction) `.claude/commands` from main into each new slot worktree, and `generate-per-slot-wrappers.mjs` should fan out to active worktrees (or worktrees should symlink the command dir).
