## Next-layer knowledge (Hermes-drafted)
The next layer in system-viz mastery centers on **standardized architecture description frameworks** that formalize viewpoints, model kinds, correspondence rules, and decision capture beyond 4+1, RM-ODP, and viewpoint catalogs in Rozanski/Woods or Clements. This includes rigorous engineering of architecture description languages (ADLs) and their visual notations for static structure, dynamic behavior, and evolutionary analysis of large-scale software systems. It adds depth via dedicated software visualization textbooks that integrate reverse-engineering graphs, dynamic trace visualization, and metric-driven views, plus pedagogy from university curricula emphasizing empirical evaluation of diagrammatic reasoning in maintenance and comprehension tasks.

Key advancements: ISO/IEC/IEEE 42010 defines required metamodel elements for consistent, stakeholder-oriented visualizations; Stasko’s multimedia approach and Diehl’s text supply concrete techniques for algorithm animation, polymetric extensions, and evolution views grounded in CS reverse-engineering practice. These layers supply institutional methodology (standards conformance, viewpoint validation) and theory (notation semantics, cognitive fit in SE contexts) absent from the listed perceptual/cognitive foundations or UML 2.5.1 surface syntax.
