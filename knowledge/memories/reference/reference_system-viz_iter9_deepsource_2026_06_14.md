**NEXT LAYER: Cognitive and Perceptual Foundations for Software Architecture Visualization**

A world-leading system-viz expert masters the integration of perceptual psychology, graph drawing aesthetics, and cognitive load theory into architectural view design, moving beyond Munzner’s nested model and the 4+1 views to formal evaluation of diagram effectiveness using established cognitive dimensions and perceptual laws.

Key areas include:

- **Cognitive Dimensions of Notations** framework applied to architectural diagrams (Green & Petre extended by Purchase).
- **Graph drawing aesthetics and perceptual organization** (Gestalt principles, edge-crossing minimization, hierarchical layout cognition).
- **Working memory constraints** in diagram comprehension beyond Cowan’s “magical number 4”, including Baddeley’s multicomponent model applied to visual notation.
- **The Physics of Notations** (Moody’s theory of visual syntax) for evaluating and designing software architecture diagrams.
- **Task-specific perceptual benchmarks** from software comprehension literature (e.g., eye-tracking studies of UML and architectural views).

**Concrete next sources to master:**
