## Key decisions + rationale  
- **Slot worktrees & path‑spec commits** – eliminate `.git/index.lock` storms, prevent peer absorption.  
- **R12 “fail‑loud” doctrine** – any test or lint failure aborts commit; 3‑of‑3 scrutiny (2 Claude reviewers + optional Codex) required before merge.  
- **Hybrid RAG default fleet‑wide** – single generic bridge per galaxy reduces duplication; dense fallback only on embed failures.  
- **Native Ollama only, NIM containers disabled** – avoids GPU contention and OOM; keep‑alive 30 min, maxLoaded 4.  
- **Global JSON route‑savings state** – atomic `writeBandState` replaces per‑slot churn.  
- **Token‑budget & compact guards** – auto‑compact at 80 % of token limit; injection‑knob ≤ 3 KB enforced.  
- **Atomic file writes (`flag:"wx"`)** – prevents EPERM rename races in index generation, outcome bus, roadmap files.  
- **GPU offload thresholds** – enable when `offload‑stats` ≥ 30 %; after threshold, > 30 % of calls use GPU, reducing idle time > 90 %.  
- **System‑viz sidecar vs full graph** – sidecar caps memory at 512 MB; full graph regenerated only on envelope flips.  
- **Priority ordering: dev‑tools/backend → revenue units** – ensures reproducibility and drift control before UI/CAM features.  
- **Cron vs YOLO loops** – `/loop [5m]` for autonomous progress; CronCreate used only for ≥60 min tasks (fleet‑reaper, NN retrain).
