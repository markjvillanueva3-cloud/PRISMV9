## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Hierarchical Bayesian Models, Cognitive Architectures Integration, and Structured Knowledge Representation for Adaptive Curricula**

A world-leading expert in mit-curriculum next masters **hierarchical extensions of Bayesian Knowledge Tracing (BKT)** that incorporate student-specific priors, multi-skill conjunctive models, and deep integration with cognitive architectures beyond ACT-R. This includes formal treatment of **individual difference modeling**, **transfer between skills via production-rule overlap**, and **curriculum sequencing as approximate POMDP planning** under partial observability of cognitive state.

Key uncovered competencies:
- **Additive Factors Model (AFM)** and **Performance Factors Analysis (PFA)** as logistic extensions that replace or augment BKT when skills are not binary (Cen et al., 2006; Pavlik et al., 2009).
- **Bayesian hierarchical modeling of student proficiencies** using full posterior inference over population-level hyperparameters (Rasch-style with item-response theory fused to KT).
- **Deep Knowledge Tracing (DKT)** limitations and successors: **Dynamic Key-Value Memory Networks (DKVMN)** and **Graph-based KT** that explicitly model prerequisite graphs as relational inductive bias (Abdelrahman & Wang, 2019; Nakagawa et al., 2019 – already partially covered; next is integration with **relational DBNs**).
- **Cognitive Tutor Authoring Tools (CTAT)** and **Cognitive Task Analysis** methodologies for extracting production rules that feed into model-tracing tutors (Aleven et al., 2016).
- **POMDP-based instructional planning** with factored state spaces representing declarative/procedural/automatic stages (Rafferty et al., 2016; Lindner, 2022).
- Formal **learning progressions** and **learning maps** as defined in educational measurement standards (Wilson, 2018; Scalise et al., 2018).

These build directly on Pearl’s causality, Anderson’s ACT-R, and MIT’s computational cognitive science thread by adding rigorous psychometric, hierarchical-Bayesian, and planning-layer depth suitable for PRISM’s adaptive curriculum engine.
