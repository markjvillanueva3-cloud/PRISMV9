- **Refinement calculus for distributed systems**, including vertical and horizontal refinement with liveness (beyond basic TLA+ refinement mappings).
- **Certified compilation stacks** that preserve correctness from high-level specs to executable code (e.g., CompCert-style guarantees for systems infrastructure).
