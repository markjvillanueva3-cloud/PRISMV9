## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Database Expansion in Distributed Systems & Scalable Data Management**

A world-leading expert in database-expansion must next master the theory and mechanisms of elastic horizontal scaling, sharding strategies, consistent query routing, and automated data repartitioning within modern distributed database architectures.

Key topics include:
- Consistent hashing and dynamic shard splitting/merging (Karger et al., 1997)
- Paxos/Raft-based metadata management for elastic rebalancing
- Online schema evolution and zero-downtime data migration techniques
- Adaptive partitioning and learned indexing for workload-driven expansion
- Formal models of data locality, hot-spot mitigation, and load balancing in expanding clusters

This layer draws from distributed systems theory rather than application-specific manufacturing data models.
