Key uncovered competencies:
- Probabilistic layout models and graph-based reading order inference beyond heuristic approaches (Monte Carlo sampling of layout hypotheses, constraint satisfaction formulations).

- Post-OCR correction pipelines using language-model rescoring and document-specific statistical language models.
- Corpus deduplication and provenance tracking at petabyte scale using minhash/LSH techniques adapted for structured documents.
