## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Advanced Compiler Optimization, Register Allocation, and Polyhedral Optimization Theory**

A world-leading token-optimization expert next masters the formal theory and algorithms that underpin modern JIT, AOT, and interpreter-level token/stream optimization. This includes advanced register allocation via graph coloring and SSA-based techniques, instruction scheduling under resource constraints, loop nest optimization using the polyhedral model, and the mathematical foundations of cost models for token throughput and latency.

Key uncovered topics at this depth:

- **Iterated Register Allocation and Coalescing** (Appel & George, 2001): Briggs-style optimistic coloring, iterated coalescing, and the impact of SSA form on allocation quality.
- **Polyhedral Model and Affine Transformations**: Integer linear programming formulations for loop tiling, fusion, and skewing to minimize token movement and maximize pipeline throughput (Feautrier 1992, Bastoul 2004).
- **Exact Dependence Analysis** via Presburger arithmetic and the Omega test (Pugh 1992).
- **Global Code Scheduling and Software Pipelining** using modulo scheduling and swing modulo scheduling (Lam 1988, Rau 1994).
- **Trace Scheduling and Superblock Optimization** (Fisher 1981, Hwu et al.).
- **Static Single Assignment (SSA) construction and destruction** semantics, including minimal, pruned, and semi-pruned variants, plus out-of-SSA translation challenges (Cytron et al. 1991, Rastello et al.).

These are drawn from graduate-level compiler construction sequences that treat token optimization as a constrained combinatorial optimization problem over directed acyclic graphs and integer lattices.
