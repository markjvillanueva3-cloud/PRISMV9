This layer focuses on verifiable timing contracts that survive timing faults, mixed-criticality interference, and stochastic disturbances while preserving end-to-end predictability.

Key topics include:
- Stochastic assume-guarantee contracts with quantitative refinement
- Probabilistic timed game automata for synthesis of adaptive schedulers
- Compositional verification of stochastic hybrid systems using PRISM extensions
