## Lessons (generalizable)
- **A single hardcoded model in a latency-bounded path is a single point of failure.** The route-gist model broke the offloader TWICE the same way (deletion → cascade-miss; slow reasoner → timeout), both ending in 0 offloads. Resolve dynamically against live `/api/tags` with a fast-tier fallback (R16: enumerate ALL re-trigger paths). → [[feedback_enumerate_all_retrigger_paths]]
- **A mechanical sub-task (log/dump gist) belongs on the TRIVIAL model tier, not the reasoner.** Putting a 32B on an in-Read-path gist is both slow AND wasteful; 1.5b gives an adequate gist in <8s cold.
- **`homedir()` is wrong when the host process runs as SYSTEM** — it returns the systemprofile, not the interactive user. Any per-user resource (Hermes/.claude/AppData) resolved from `homedir()` in a SYSTEM-launched MCP server / scheduled task must scan the real user profile. Sibling of the `CLAUDE_CODE_SESSION_ID` env-anchor lesson and the windowsHide SYSTEM-principal class.
