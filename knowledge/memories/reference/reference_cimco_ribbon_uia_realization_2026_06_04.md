**2. Driver `.ps1` host-invariants (each proven by a failed run this session):**
- **STA apartment** — UIA descendant enumeration needs `powershell.exe -STA`. pwsh-7 (MTA) finds top-level windows but mis-reads descendants (returned 0 tabs where 5.1-STA is the working host).
- **Pure ASCII source** — PS 5.1 reads a non-BOM `.ps1` as ANSI/CP-1252 and mis-decodes UTF-8 multibyte chars (em-dash), corrupting the parse into a bogus `"Try statement is missing its Catch or Finally block"`. pwsh-7 masks it (reads UTF-8 default). Strip non-ASCII: `t.replace(/[‒-―]/g,'-')...replace(/[^\x00-\x7F]/g,'')`.
- **No parse-time UIA param types** — `function f([System.Windows.Automation.ControlType]$x)` fails to parse under 5.1 (type unloaded until `Add-Type` runs mid-script). Use untyped params + runtime casts.
