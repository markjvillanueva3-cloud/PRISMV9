**NEXT LAYER: Cognitive and Perceptual Foundations for System Visualization**

A world-leading system-viz expert masters the integration of perceptual psychology, graph-theoretic aesthetics, and formal software architecture description theory to design cognitively effective visualizations of large-scale software systems.

Key uncovered depth includes:

- **Perception-based visual encoding models** grounded in pre-attentive processing and Gestalt principles specifically applied to software diagrams (Ware, 2012).
- **Algorithmic graph drawing aesthetics** beyond basic force-directed methods: orthogonal, layered, and symmetric layouts optimized for software dependency graphs, including multi-level crossing minimization and edge bundling (Sugiyama, 2002; Tamassia, 2013).
- **Viewpoint and abstraction formalisms** extending ISO/IEC/IEEE 42010 with explicit correspondence rules, model-view consistency, and architectural viewpoint languages (Rozanski & Woods, 2011; ISO/IEC/IEEE 42010:2022 revision).
- **Cognitive effectiveness metrics** using controlled experiments on notation usability, extending beyond Purchase (2014) with eye-tracking and working-memory load analysis for software architecture diagrams (Petre, 2014; Green & Petre, 1996 revisited in software context).
- **Visualization of dynamic and evolving architectures** via runtime trace visualization, software evolution maps, and polymetric views (Lanza & Ducasse, 2003; Wettel & Lanza, 2008).

This layer moves from notation physics and basic graph drawing into rigorous perceptual science, formal correspondence theory, and empirical evaluation methods drawn from HCI, software architecture, and information visualization literature.
