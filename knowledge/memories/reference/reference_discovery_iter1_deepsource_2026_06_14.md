## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Advanced Discovery in Software & Data Systems**

A world-leading expert in the “discovery” galaxy (PRISM’s internal software-engineering domain of intelligent search, data exploration, and insight extraction) masters formal methods and architectures for scalable, semantics-aware discovery beyond basic search and visualization.

Core next-layer topics include:

- **Formal Knowledge Discovery and Concept Lattices**: Formal Concept Analysis (FCA) as a mathematical framework for discovering conceptual hierarchies from data contexts (Ganter & Wille, 1999).
- **Distributed Metadata and Semantic Discovery**: Use of ontology-based data access (OBDA), semantic web discovery protocols, and linked-data traversal algorithms (Hitzler et al., 2010).
- **Automated Discovery in Large-Scale Software Repositories**: Mining software repositories (MSR) techniques, including API and feature discovery at scale using static and dynamic analysis (Zimmermann et al., 2005; Kagdi et al., 2007).
- **Information Retrieval Theory for Discovery Systems**: Probabilistic retrieval models, latent semantic indexing (LSI), and modern neural IR for relevance-driven discovery (Manning et al., 2008; Mitra & Craswell, 2018).
- **Standards for Discovery Metadata and Interoperability**: ISO 11179 (metadata registries), Dublin Core, and IEEE 1484.12.1 (Learning Object Metadata) applied to discovery services.
- **Architectural Patterns for Discovery Platforms**: Event-driven discovery, polyglot persistence discovery layers, and microservice-based discovery using service meshes (Newman, 2021).

These layers are typically taught in graduate-level courses such as MIT 6.830/6.814 Database Systems, CMU 15-721 Database Systems, and University of Washington CSE 544 Principles of Database Systems (advanced modules on data exploration and discovery).
