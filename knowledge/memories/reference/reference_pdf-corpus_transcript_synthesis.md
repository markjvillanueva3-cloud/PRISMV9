## Key decisions + rationale
- **Slot‑worktrees** for every chat → eliminates index lock contention; atomic commits via tmp+rename.  
- **Ollama as primary LLM backend**, NIM containers disabled by default – lower latency, avoids OOM.  
- **Deterministic AI‑synergy gate** must meet AUROC ≥ 0.78 before any model pull (quality baseline).  
- **GPU‑tier detection** (`catalog-gpu-profile.mjs`) unlocks ×3 concurrent VLM workers; prevents stale “overnight GPU” gating.  
- **ASCII‑guard & EM‑DASH enforcement** stop punctuation regression in generated docs.  
- **Two‑pass cost cascade** adopted for budget control (≤144 API calls → `/compact`).  
- **Last‑wins dedup guard** on `prism_ai` registration prevents duplicate crashes (SDK 1.29).  
- **R8 dedup‑win / R12 fail‑loud doctrines** abort silent failures early, enforce per‑file scrutiny.  
- **Sidecar graph index (~105 MB)** used instead of raising `PRISM_GRAPH_MAX_BYTES`; avoids OOM.
