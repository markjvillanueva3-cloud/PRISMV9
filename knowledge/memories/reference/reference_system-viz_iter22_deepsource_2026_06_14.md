## Next-layer knowledge (Hermes-drafted)
The next layer in system-viz mastery centers on the Cognitive Dimensions of Notations (CDs) framework for systematic evaluation and design of visual languages, ISO-standardized architecture description practices that mandate explicit viewpoint specifications for visualizations, foundational software architecture theory linking views to stakeholder concerns, and classic empirical studies extending diagrammatic reasoning into notation usability metrics. These provide methodological rigor for constructing cognitively effective system diagrams, formal semantics for multiview consistency, and theory-driven assessment beyond ad-hoc diagram creation.

This layer equips experts to measure and refine notations using dimensions such as viscosity, hidden dependencies, and premature commitment, while grounding system visualizations in standardized architecture practices that treat views as first-class artifacts.
