## Reusable lesson 1 — streamPopulateQdrant (OOM-proof, fleet-wide)
The non-streaming `populateQdrant` in `scripts/populate-qdrant.mjs` loads the whole input via `loadImpl -> records[]`, which **OOMs the default ~400MB heap** on a 137MB / 53.9K plain-int8-array corpus (confirmed crash at 382MB). Added an ADDITIVE shared export `streamPopulateQdrant({inputPath,...,validate,lineIter,sendImpl})` that reads line-by-line and holds **<=1 batch in memory** -> OOM-proof at any corpus size. Reuses `buildBatch` so points are byte-identical across all collections. Same streaming fix class as the tribal heap ceiling ([[reference_wiki_tribal_coverage_69pct_qdrant_gate_2026_06_10]]). Use it for any large corpus -> Qdrant; the non-streaming path is fine only for small/base64-packed inputs (e.g. the 17K memory sidecar).

## Reusable lesson 2 — meta.count torn-corpus integrity guard (R12, scrutiny P1)
A streaming populate that swallows malformed JSON lines silently will report `ok:true` on a **partially-populated** collection when the input is torn/truncated (the wiki jsonl is regenerated by a separate embedder = real torn-write risk; PRISM's regression log is full of this silent-data-loss class). Fix: count `malformed` lines, and on a FULL read (not `--limit`) cross-check `scanned + malformed === meta.count` -> else `ok:false` `corpus-incomplete`. A present-but-corrupt line (count matches) is a benign `warning`, not a fail. The data to detect it (`meta.count`) is already in the __meta header.

## Reusable lesson 3 — cosine is scale-invariant -> dequant q/127 is correct
Qdrant Cosine distance normalizes server-side, so dequantizing int8 by `/127` (vs the per-entry `s` scale) preserves direction and yields identical cosine. The same SEM_MIN_COSINE (0.62) floor applies via `score_threshold` -> the ANN path and the linear path can't silently diverge on the threshold.
