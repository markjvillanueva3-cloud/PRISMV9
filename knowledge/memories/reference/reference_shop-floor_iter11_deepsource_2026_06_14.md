A world-leading shop-floor expert masters **compositional assume-guarantee reasoning for timed and hybrid automata**, **stochastic timed games with quantitative objectives**, and **contract-based predictable execution models** on multicore platforms that integrate mixed-criticality scheduling with formal timing contracts. This layer extends beyond single-system PRISM verification and basic real-time calculus into scalable, modular analysis of large-scale cyber-physical shop-floor systems using interface theories, game-theoretic controller synthesis, and WCET-aware partitioning under probabilistic guarantees.

Key topics include:
- Assume-guarantee compositional verification of real-time systems using timed I/O automata interfaces
- Stochastic games with continuous time for quantitative verification of schedulers under uncertainty
- Contract-based design for predictable execution models (PREM) on multicore with mixed-criticality and memory contention
- Symbolic controller synthesis for timed systems with safety, liveness, and optimality objectives
- Statistical model checking with guarantees for rare-event properties in real-time stochastic systems
