## Next-layer knowledge (Hermes-drafted)
The next layer masters integration of educational data mining (EDM) with hierarchical Bayesian inference for skill discovery from log data, contextual bandit algorithms for efficient exploration-exploitation in curriculum sequencing, and performance factors analysis (PFA) as a logistic alternative to KT that directly models learning rates per knowledge component. Emphasis is placed on interpretability of latent student states, reward design based on learning gains versus accuracy, and scaling via learning analytics frameworks that fuse cognitive models with self-regulated learning traces. Institutional depth includes Carnegie Mellon’s LearnLab methods for cognitive task analysis at scale and extensions beyond listed IEEE/ISO competency metadata toward analytics interoperability.
