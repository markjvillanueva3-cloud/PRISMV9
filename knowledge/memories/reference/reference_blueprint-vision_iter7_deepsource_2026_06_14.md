Core topics include:
- **Triple Graph Grammars (TGGs)** with application conditions and static analysis for bidirectional model synchronization between raster/vector views and feature-based CAD models.
- **Constraint-based feature recognition** using constructive geometric constraint solvers that exploit **global rigidity** and **scene analysis** to decompose under-constrained engineering drawings.
- **And-Or Graph Grammars** extended with **compositional hierarchical models** that combine perceptual grouping, stochastic parsing, and semantic mapping via Common Logic (CL) to produce ISO-compliant product definitions.
- **Algebraic approaches to incremental view maintenance** in model-driven engineering, leveraging adhesive HLR systems with NACs for conflict-free propagation of changes from drawing edits to the model repository.
- Formal verification of transformation confluence and termination using critical pair analysis on attributed typed graphs.

These layers build directly on the covered Ehrig/Schürr TGG foundation, Hoffmann/Sitharam constraint solving, MIT rigidity lectures, Han/Zhu And-Or grammars, ISO/IEC 24707 CL, and NIST model-based enterprise integration.
