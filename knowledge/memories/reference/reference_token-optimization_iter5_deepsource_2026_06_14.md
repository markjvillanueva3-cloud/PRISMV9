**Next Layer: Advanced Token-Optimization Knowledge**

A world-leading expert in token-optimization next masters the interaction between register allocation, instruction scheduling, and polyhedral code transformation under strict latency and throughput constraints, with particular focus on **rematerialization**, **partitioned register banks**, **software pipelining with modulo scheduling**, and **constraint programming formulations** that integrate ILP and SAT/SMT solvers for exact solutions at basic-block and loop-nest granularity.

Key uncovered areas include:

- **Integer Linear Programming (ILP) and Constraint Programming (CP) formulations** for simultaneous register allocation and instruction scheduling that model register pressure as an exact resource-constraint problem rather than graph coloring (Goodwin & Wilken already covered; next is the full CP/SAT encoding lineage).
- **Optimal register allocation via tree scanning and dynamic programming** on SSA trees with explicit live-range splitting and coalescing costs (beyond Wilson et al.).
- **Modulo scheduling with register pressure control** using kernel-unrolling and rotating register files, including the impact of IEEE 754-2019 extended precision on pressure in floating-point pipelines.
- **Polyhedral code generation with affine scheduling under register-file and cache-capacity constraints**, extending Feautrier/Bondhugula with explicit memory-port and register-file resource models.
- **Exact methods using SMT solvers and PBQP extensions** that incorporate rematerialization profitability and multi-file register architectures.

**Institutional depth**: Carnegie Mellon’s advanced compiler courses (15-745, 15-746), Rice University’s SSA and polyhedral seminars, and LLVM’s internal “GlobalISel + RegAlloc” development papers (post-2018).

**Theory depth**: Lagrangian relaxation techniques for register-pressure-aware scheduling, fixed-point algorithms for lifetime analysis under loop unrolling, and the connection between static single assignment, continuation-passing style, and linear logic resource tracking.

**Standards depth**: IEEE Std 1800-2023 (SystemVerilog) register semantics for verification, and ISO/IEC 14882:2023 (C++) memory model implications on compiler-inserted register spills.
