## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Visual System Modeling & Architecture Visualization Theory**

A world-leading system-viz expert next masters formal visual languages for software architecture, runtime behavior visualization, and model-driven system comprehension. This layer focuses on diagrammatic reasoning, graph-based system abstraction, hierarchical visualization semantics, and cognitive effectiveness of notations.

Key areas include:
- **Visual notations and cognitive dimensions**: Theory of visual languages, perceptual pop-out, dual coding, and notation design principles.
- **Architectural description languages (ADLs)** with visual counterparts and automated layout algorithms.
- **Dynamic system visualization**: Execution trace visualization, dependency graphs, state-space visualization, and temporal visual metaphors.
- **Graph drawing aesthetics and automated layout**: Force-directed methods, layered drawings, orthogonal layouts, and semantic-preserving clustering.
- **Model visualization in MDE**: Concrete syntax mapping, view consistency, and transformation-driven visualization.

**Institutional depth**:
- MIT 6.170 Laboratory in Software Engineering (older versions) and 6.005 Software Construction – visualization modules on abstracting complex state.
- Carnegie Mellon’s 15-313 Foundations of Software Engineering and 17-214 Principles of Software Construction.
- IEEE Std 1471-2000 / ISO/IEC 42010: Systems and Software Engineering — Architecture Description (visual model requirements).
- Graph Drawing literature (GD conference series) and cognitive dimensions framework.

**Theory depth**:
- Moody’s “Physics of Notations” (2009) provides the seminal evaluation framework still used for designing effective system-viz languages.
- Graph visualization algorithms from Battista et al. (1999) remain the canonical reference for producing readable system diagrams at scale.
