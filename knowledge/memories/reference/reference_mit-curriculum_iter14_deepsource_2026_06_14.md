**Next Layer: Hierarchical Task Networks, Cognitive Skill Decomposition, and Formal Curriculum Theory in Intelligent Tutoring Systems**

A world-leading expert in mit-curriculum next masters **hierarchical skill modeling** through Cognitive Task Analysis extensions that produce reusable, machine-interpretable skill hierarchies, combined with formal curriculum sequencing grounded in computational cognitive architectures and learning technology standards.

Key uncovered areas include:

- **Hierarchical Task Network (HTN) planning** applied to curriculum generation and skill decomposition (Erol et al., 1994; Nau et al., 2003).
- **ACT-R/Constraint-Based Modeling** integration for atomic skill production rules and constraint-based tutors that automatically generate domain models from expert traces (Ohlsson, 1994; Mitrovic et al., 2007).
- **Q-Matrix and Skill Matrix** formalisms for mapping items to latent skills, extending beyond simple KT (Tatsuoka, 1983; Barnes, 2005).
- **Formal learning design languages** and competency frameworks that support adaptive sequencing at the curriculum level, including IEEE and IMS extensions (IEEE 1484.12.1-2002; IMS RDCEO v1.0, 2002).
- **Curriculum reinforcement learning** that treats sequencing as a partially observable Markov decision process with hierarchical abstraction (Bisson et al., 2015; Narasimhan et al., 2015).

These build directly on already-covered Bayesian models, cognitive tutors, and deep RL curriculum work by adding rigorous **hierarchical planning**, **expert-derived skill ontologies**, and **standards-based competency interchange** necessary for scalable, reusable intelligent curriculum systems.
