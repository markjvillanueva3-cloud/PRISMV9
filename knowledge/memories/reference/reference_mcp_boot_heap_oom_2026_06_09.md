**2026-06-09 (slot golf, synergy /goal) — THE recurring MCP outage root cause, found + fixed.**

**CONFIRMED root cause (the recurring :3100 crash, 4 outages this session at consolidate-graph counters 1,10,4,4):** the MCP server **OOMs on its cold boot** — `H:/prism/.claude/cache/mcp-daemon.log`: `FATAL ERROR: Reached heap limit Allocation failed - JavaScript heap out of memory`, then `WARNING: Daemon started but health check failed`. The server loads 4000+ tribal tips + registries + graph during its ~40-50s boot, needing well over **384MB** — but the `node` shim (`H:/.claude/bin/node` → `portable-node`) sets `NODE_OPTIONS=--max-old-space-size=384` (fleet commit-budgeting, set-if-unset), and **child spawns INHERIT it** via `process.env.NODE_OPTIONS`. So any MCP server spawn launched from a capped context (e.g. `singleton-service-guard --fix` run through the shim) crashes the server on boot. **PROVEN:** a manual boot with `--max-old-space-size=4096` (raw node, bypassing the cap) brought :3100 up in **~3s**; the inherited-384 spawn OOMed. (Connected to [[reference_systemviz_find_heap_oom_2026_06_09]] — same 384 cap, different victim.)

**The bug = a SPAWN-PATH DIVERGENCE (06-04 plan FIX-7 "unify spawn paths"):** the **supervisor** (`scripts/mcp-server-supervisor.mjs` spawnChild) already floored its spawn heap to 4096 (kilo 2026-05-23 MCP-OOM-FIX) — so supervisor-spawned daemons boot. But the **daemon-helper** (`.claude/helpers/mcp-server-daemon.mjs` start) spawned with bare `{...process.env}` — **NO heap override** — so a shim-context spawn OOMed. Worse, the supervisor's own logic was latently fragile: `existingNodeOpts.includes("--max-old-space-size") ? keep : append` would **KEEP the 384 shim cap** (mistaking the fleet cap for an operator override) if it were ever shim-invoked.

**FIX (build-once, ALL spawn paths — R15, commit `6ca2f6afd2` U-MCP-BOOT-HEAP-FLOOR):** shared pure `scripts/lib/ensure-heap-floor.mjs` → `ensureHeapFloor(nodeOptions, floorMb=4096)`: floor to ≥4096, **OVERRIDE a too-small cap** (the 384→4096 fix), **RESPECT a larger one** (8192 stays), preserve other flags. 7 tests. Wired into: (1) `mcp-server-daemon.mjs` spawn env [`NODE_OPTIONS: ensureHeapFloor(process.env.NODE_OPTIONS)` — was missing entirely]; (2) `mcp-server-supervisor.mjs` [replaces the keep-if-present logic — now overrides 384, keeps ≥4096]. The 3rd path `mcp-daemon-autostart.mjs:53` spawns `[DAEMON_HELPER,"start"]` → covered transitively by (1).
