- **Model routing matrix** – primary Claude for high‑value tasks, fleet‑standard `gpt‑oss:20b`, fallback to Ollama models; avoids 400 errors and respects extra‑usage billing limits.  
- **Zero‑drop streaming ingest** for side‑car JSON (`JMDiePartLibraryEngine`); guarantees no data loss on failures.  
- **Single capability‑probe oracle** for all Octopus branches – simplifies model selection, reduces wiring bugs.  
- **Auto‑advance precedence**: `--resume` → handoff‑resume → unit pick → fleet fallback; ensures loop never stalls.  
- **Resumable cursor loops** (OCR, LoRA) to survive reaper kills and keep GPU usage bounded.  
- **Slot‑binding before `/checkin`** (`/checkin‑sierra`) – enforces resource accounting across agents.  
- **W​SL memory guard** (`wsl --shutdown`) after Docker stop; caps balloon at 16 GB, prevents >90% commit pressure.  
- **Offload coverage target ~30 %** (current ≈8 %) – expand pattern list before scaling OCR/LoRA workloads.  
- **Avoid speculative LoRA builds** (P0‑6) until H2GCN integration proven; focus on stable engines.  
- **Keep Qdrant Dockerized** and start container before MCP restart to guarantee vector search availability.

## How to build it (patterns/sequence)
- **Zero‑drop ingest → streaming commit**: use `writeWithRetry` + atomic rename for all file writes.  
- **Slot‑binding → `/checkin‑sierra`** before any agent work; ensures resource accounting.  
- **Resumable loops with cursor** (`processed-cursor.jsonl`) for OCR, LoRA, transcript mining; wrap in `try/catch` and persist progress on each batch.  
- **Auto‑advance loop precedence**: encode in `loop-state.mjs`; use `--resume` flag to pick up from last successful unit.  
- **Ultracode multi‑agent fan‑out**: define `resumeFromRunId`, checkpoint state, and aggregate results via MCP dispatcher.  
- **Three‑of‑three scrutiny gate** after each commit (unit, integration, system); enforce with `scrutiny-3way.mjs`.  
- **Hook heap cap management**: set `PRISM_HOOK_HEAP_CAP=384MB`; monitor via `/metrics` and shrink balloon with `wsl --shutdown`.  
- **Warming‑up & offload hooks**: `PRISM_OLLAMA_OFFLOAD_ENFORCE` toggles hard vs advisory offload; schedule warm‑up daemon (`ollama‑prewarm.mjs`).  
- **Graph edge prediction pipeline**: generate candidates → score with sigmoid(dot) → filter by heterophily hops (default 3) → write to `predicted-edges.json`.  
- **Embedding regeneration**: run `generate-predicted-edges-features.mjs` after each major graph update; re‑index Qdrant.
