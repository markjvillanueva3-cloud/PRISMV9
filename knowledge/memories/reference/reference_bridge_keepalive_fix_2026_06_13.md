## The fix (commit, slot:bravo, U-BRIDGE-KEEPALIVE)
`scripts/lib/galaxy-reasoning-bridge.mjs`:
- `resolveKeepAlive(env)` + `buildOllamaRequestBody(prompt,model,env)` PURE exported helpers; body now carries `keep_alive: OLLAMA_KEEP_ALIVE||"30m"` so one load warms the model for the whole 34-galaxy sweep (cold-load ONCE, not per-galaxy).
