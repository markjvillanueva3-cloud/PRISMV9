**NEXT LAYER: Perceptual Psychology Foundations for System Visualization Design**

A world-leading system-viz expert masters the integration of low-level **visual perception science** with notation engineering, moving beyond cognitive dimensions and Physics of Notations (PoN) to rigorously apply pre-attentive processing, Gestalt principles in diagrammatic reasoning, and dual-coding theory calibrated specifically for software architecture and complex system visualizations.

Key uncovered layer includes:

- **Ware’s perceptual foundations** for how visual variables (position, length, angle, area, color, motion) interact with working memory and attention when rendering multi-view system models.
- Quantitative models of **visual search asymmetry** and **pop-out effects** applied to UML/SysML viewpoint design and correspondence visualization.
- **Dual-coding theory** extensions (Paivio updated by Scaife & Rogers) measuring when text+diagram combinations reduce extraneous cognitive load in architecture description languages.
- **Graph drawing aesthetics** validated through eye-tracking metrics rather than solely preference rankings, including edge-crossing tolerance thresholds for system dependency diagrams.
- Application of **Marr’s computational theory of vision** (1982) stages to the design of abstraction hierarchies in system-viz tools.

This layer supplies the psychophysical “why” that Moody’s PoN principles build upon, enabling predictive rather than purely empirical notation design for PRISM’s system-viz galaxy.
