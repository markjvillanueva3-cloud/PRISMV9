**Method/Theory:**  
- Formal synthesis of correct-by-construction post-processors using temporal logic specifications and supervisory control of discrete-event systems for NC code generation.  
- Application of model-checking and automated theorem proving (Coq/Isabelle) to certify that generated G-code satisfies both kinematic reachability and real-time safety invariants under bounded computational resources.  
- Use of differential dynamic logic (dL) for verifying hybrid systems behavior of post-processor + machine tool + material removal loop.
