**Next Layer: Cognitive and Semiotic Foundations for System Visualization**

A world-leading system-viz expert next masters the theory of **notational systems** as external cognitive artifacts, focusing on how visual syntax, semantics, and pragmatics interact with human inference mechanisms in complex software architecture models. This layer moves beyond perceptual psychology and basic cognitive dimensions into formal semiotic analysis, diagrammatic reasoning, and empirically validated principles of visual language design drawn from software engineering and HCI.

Key uncovered areas include:
- **Visual language theory** and the role of **secondary notation** in program comprehension.
- **Cognitive integration** of multiple coordinated views using **correspondence and consistency rules** at the notational level.
- **Semantic transparency** and **perceptual discriminability** as measurable properties of software visualization notations.
- **Distributed cognition** models applied to collaborative system-viz artifacts.

- **Moody (2009)** “The ‘Physics’ of Notations: Toward a Scientific Basis for Constructing Visual Notations in Software Engineering” (IEEE Transactions on Software Engineering, 35(6)).
