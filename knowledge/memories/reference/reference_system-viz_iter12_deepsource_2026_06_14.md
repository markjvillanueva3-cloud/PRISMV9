## Next-layer knowledge (Hermes-drafted)
**Next Layer: Advanced Cognitive and Semiotic Foundations for System Visualization**

A world-leading expert in system-viz must next master the integration of **semiotic engineering**, **graph drawing aesthetics with cognitive load metrics**, and **formal correspondence theories** between multiple architectural views. This layer moves beyond perceptual psychology and basic cognitive dimensions into rigorous theories of how visual notations function as computational artifacts and how consistency across views can be formally verified.

Key uncovered areas include:

- **Semiotic Engineering of Visual Languages** (de Souza, 2017 framework extending earlier work): treats diagrams as designer-to-user metacommunication, providing methods to evaluate pragmatic qualities of system visualizations.
- **Aesthetic Graph Drawing Algorithms and Cognitive Validation** (Purchase, 2014): extends beyond Moody’s Physics of Notations with empirical measures of layout algorithms (minimizing edge crossings, bend minimization, symmetry) and their measurable impact on working-memory load.
- **Viewpoint Consistency and Correspondence Rules** (ISO/IEC/IEEE 42010:2022 Annex E – Formalizing Correspondence): formal methods for specifying and verifying consistency between multiple architectural viewpoints in complex software-intensive systems.
- **Distributed Cognition and External Representations** (Kirsh, 2010; Hutchins-style analysis applied to software diagrams): models how system visualizations function as cognitive artifacts in collaborative engineering environments.
- **Cognitive Complexity Metrics for Visual Notations** (Störrle, 2014–2017 series): quantitative models combining graph-theoretic complexity with eye-tracking validated cognitive effectiveness specifically for UML and architecture diagrams.

These sources provide the institutional, standards-based, and theoretical depth required for the next iteration of PRISM’s system-viz galaxy.
