## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Software Quality Engineering & Assurance (post-foundational)**

A world-leading expert in PRISM’s quality galaxy next masters rigorous software quality models, measurement frameworks, and assurance techniques drawn from software engineering curricula and standards. This includes formal quality attribute specification and evaluation (ISO/IEC 25010/25012), defect classification taxonomies (Orthogonal Defect Classification), statistical software process control adapted to code and CI/CD pipelines, and model-based quality assessment using Bayesian networks or Markov models for reliability prediction.

Key depth areas:
- **Quality attribute workshops and scenario-based architecture evaluation** (Bass et al., 2012 methodology)
- **IEEE Std 730-2014 Software Quality Assurance Plans** and its integration with ISO/IEC/IEEE 12207 lifecycle processes
- **NIST SP 800-218 Secure Software Development Framework** (SSDF) and its mapping to quality gates
- **Orthogonal Defect Classification (Chillarege et al., 1992)** for causal analysis in large-scale software systems
- **Software reliability growth models** (Musa, 2004; Goel-Okumoto, Jelinski-Moranda) and their use in release decisioning
- **Goal-Question-Metric (GQM) paradigm** and its extension to GQM+Strategies (Basili et al., 2010)
- **Static analysis quality models** and technical debt quantification (Seacord et al., Carnegie Mellon SEI curricula)

These topics represent the layer beyond basic testing or simple metrics — focusing on predictive, quantitative, and standards-driven software quality management suitable for a manufacturing-intelligence platform.
