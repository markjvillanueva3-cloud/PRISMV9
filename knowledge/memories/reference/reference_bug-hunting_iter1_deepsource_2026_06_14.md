## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Systematic Bug Hunting via Formal Methods, Model Checking, and Advanced Static Analysis**

A world-leading bug-hunting expert moves beyond ad-hoc testing and basic static analysis into mathematically grounded defect detection. This layer centers on **symbolic execution**, **bounded model checking**, **abstract interpretation**, and **property-based verification** applied at scale in large software systems.

Core competencies include:
- Using SMT solvers and constraint solving to explore exponential path spaces that concrete testing cannot reach.
- Applying temporal logic (LTL, CTL) and Hoare-style reasoning to prove absence of classes of bugs (use-after-free, data races, integer overflows).
- Mastering soundy static analyzers that trade completeness for precision at industrial scale.
- Understanding how compiler IR-level bug hunting (LLVM, MLIR) uncovers defects invisible at source level.

**Key next-layer topics:**
- Bounded Model Checking with SAT/SMT (Biere et al.)
- Abstract Interpretation frameworks (Cousot & Cousot)
- Symbolic Execution engines (King 1976 → KLEE, angr)
- Formal verification of concurrent systems and memory models
- Advanced fuzzing hybridized with concolic execution

This layer shifts bug hunting from “find crashes” to “prove properties” or “exhaustively search under abstractions.”
