## Next-layer knowledge (Hermes-drafted)
**NEXT LAYER: Post-Processor Domain for SAFETY-CRITICAL Cutting (Iteration 2)**

World-leading post-processor expertise next requires mastery of **kinematic transformation integrity under dynamic load**, **real-time trajectory smoothing with error-bounded contouring**, and **compensated inverse kinematics for 5-axis tool-tip control** while preserving volumetric error budgets defined by ISO and ASME.

Core theory layer: homogeneous transformation matrices with **screw theory** for exact modeling of rotary-table and tilting-head kinematics, including non-orthogonal axes and rotary axis compensation under thermal growth. This extends beyond static ISO 6983 parsing into **real-time position command generation with lookahead-based feed scheduling** that respects servo bandwidth and structural dynamics.

Critical methods:  
- **Generalized NURBS interpolation** with chord-error and centripetal-acceleration limiting for safe high-speed contouring.  
- **Inverse-time feed mode (G93)** combined with **tool-vector smoothing** to prevent rotary-axis overspeed or singularity crossing.  
- **Dynamic machine model integration** into the post-processor (modal parameters, stiffness matrix) for predictive velocity limiting before NC output.  
- **Volumetric error mapping** compensation using rigid-body + non-rigid error synthesis per ASME B5.54 and ISO 230-6.

Standards depth:  
- ISO 230-6:2002 – Test code for machine tools – Part 6: Determination of positioning accuracy on body and face diagonals (volumetric performance).  
- ISO 14649-1:2003 and ISO 14649-10:2004 (STEP-NC) – for feature-based, tolerance-aware toolpath data that post-processors must interpret for safety-critical work.  
- ASME B5.64-2014 – Methods for the Performance Evaluation of CNC Rotary Tables.

Textbook/course layer:  
- Suh, S.-H., et al. (2008). *Theory and Design of CNC Systems* (Springer). Chapters on post-processing algorithms, inverse kinematics, and look-ahead interpolation.
