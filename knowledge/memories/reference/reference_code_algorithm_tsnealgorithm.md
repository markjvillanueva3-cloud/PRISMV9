Algorithm:

  2. For each i, binary-search precision beta_i s.t. H(P_i) = log(perplexity)
  3. Symmetrize: P_ij = (P_j|i + P_i|j) / (2n)

  5. Repeat:

     - Compute gradient ∂C/∂y_i = 4·Σ_j (p_ij - q_ij)·(y_i - y_j)/(1+|y_i-y_j|²)
