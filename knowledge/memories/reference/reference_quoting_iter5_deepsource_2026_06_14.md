## Next-layer knowledge (Hermes-drafted)
**Next Layer: Advanced Quoting Theory and Methodology (Iteration 5)**

A world-leading expert in software quoting next masters formal **measurement theory**, **Bayesian model calibration under epistemic uncertainty**, **value-driven decision analysis**, and **parametric model uncertainty quantification** applied specifically to software cost and schedule estimation.

Key uncovered areas include:

- **Representational Measurement Theory** and scale types (nominal, ordinal, interval, ratio) as they constrain valid statistical operations on software metrics for quoting (Fenton & Bieman extensions).
- **Bayesian inference frameworks** for COCOMO-style model recalibration using informative priors derived from organizational baselines, explicitly separating aleatory and epistemic uncertainty (post-2010 USC-CSE Bayesian work).
- **Multi-attribute value theory (MAVT)** and **multi-attribute utility theory (MAUT)** for constructing additive and multiplicative value functions that support quoting trade-offs across cost, schedule, quality, and reuse dimensions under uncertainty.
- **Parametric model uncertainty propagation** techniques including Monte Carlo filtering, global sensitivity analysis (Sobol indices), and empirical Bayes methods tailored to software estimation models.
- **Information quality (InfoQ)** framework for assessing the utility of measurement products used in quoting (Kenett & Shmueli).
- **Probability encoding** methods and **calibration of expert judgment** for eliciting quoting inputs when historical data are sparse.

These layers move quoting from heuristic parametric application toward rigorous, auditable, decision-theoretic foundations suitable for high-stakes software acquisition and internal portfolio forecasting.
