# Multi-Pass Tool Life Model (OSCAR)

**Galaxy:** OSCAR (Speed & Feed Calculator)
**Status:** Advanced Topic - Master Level

## Description
Tool life when multiple passes are taken with the same tool (roughing + semi-finishing + finishing).

## Model
Total tool life is not simply additive. Wear accumulates differently on each pass.

## PRISM Approach
- Cumulative wear tracking across operations
- Different wear rates applied per pass type
- Remaining life prediction for tool management

## Tribal Notes
- JM Die sometimes re-sharpens or re-coats tools for secondary operations
- Roughing pass usually consumes 60-70% of total tool life
