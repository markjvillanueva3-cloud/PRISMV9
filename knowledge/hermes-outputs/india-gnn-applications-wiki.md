# Graph Neural Networks (GNN) Applications (INDIA)

**Galaxy:** INDIA (AI/NN/GNN/LoRA/RAG Training)
**Status:** Core Technique - Master Level

## Description
Graph Neural Networks model relationships between entities as graphs, making them powerful for structured data like toolpath dependencies, feature relationships in CAD, process flows, and knowledge graphs.

## Key Architectures
- GCN (Graph Convolutional Networks)
- GAT (Graph Attention Networks)
- GraphSAGE
- GNN + Transformer hybrids

## PRISM Implementation
- Potential use in system-viz, process dependency graphs, and feature relationship modeling
- Can enhance RAG by modeling relationships between wiki/tribal entries

## Edge Cases
- Graph construction quality is critical
- Scalability on very large graphs
