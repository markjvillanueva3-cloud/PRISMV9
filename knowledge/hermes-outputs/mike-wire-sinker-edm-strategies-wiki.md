# Sinker EDM Strategies (MIKE)

**Galaxy:** MIKE (Wire)
**Status:** Core Strategy - Master Level

## Description
Sinker EDM (die-sinking) operations using graphite or copper electrodes to create complex cavities.

## Key Strategies
- Roughing, semi-finishing, and finishing passes
- Multiple electrode strategy for deep or complex cavities
- Orbital and vector machining
- Wear compensation techniques

## PRISM Implementation
- EDMProgramAssemblerEngine supports sinker operations
- Electrode design integration with DELTA (CAD)

## JM Die Notes
- Multiple electrode strategy is standard for cavities deeper than 20mm
- Rule: Design at least 3 electrodes (rough, semi-finish, finish) for deep cavities
