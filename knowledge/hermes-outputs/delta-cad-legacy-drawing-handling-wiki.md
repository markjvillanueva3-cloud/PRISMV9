# Legacy Drawing Handling (DELTA)

**Galaxy:** DELTA (CAD)
**Status:** Practical Capability - Master Level

## Description
Processing and interpretation of old, non-standard, or poorly scanned engineering drawings.

## Key Challenges
- Mixed units and standards
- Hand-drawn or poorly reproduced drawings
- Incomplete dimensioning
- Non-standard symbols and abbreviations

## PRISM Implementation
- Robust OCR and layout analysis tuned for legacy drawings
- Manual validation workflow for low-confidence extractions
- Symbol library for common legacy notations

## JM Die Notes
- A large portion of the existing job library consists of legacy drawings
- Rule: Always allocate extra time for legacy drawing interpretation and validation
