# /dedup — Duplication Guard Check

**MANDATORY** before creating ANY new asset in PRISM. Checks for existing similar engines, hooks, skills, actions, formulas, and algorithms.

## Usage

```
/dedup <asset-type> <name> [description]
```

## Arguments

- `asset-type` — Type: engine | hook | skill | action | formula | algorithm | script
- `name` — Proposed name for the new asset
- `description` — Brief description of what it does (optional but recommended)

## How It Works

1. **Exact Match** — Checks if name already exists in registries
2. **Fuzzy Match** — Jaccard similarity on name tokens (threshold: 0.85)
3. **Semantic Match** — MiniLM embedding cosine similarity on description (threshold: 0.85)
4. **Keyword Search** — Searches across all asset types for related functionality

## MCP-First Execution

Use the live PRISM surfaces instead of placeholder action names:
- `prism_dev:copilot_check_duplication` — primary duplicate check before new assets
- `prism_session:action_search` — capability lookup by intent/domain
- `prism_dev:discover_search` — broader discovery across existing development capabilities

If the duplicate check returns a near-match, stop and inspect the existing asset before creating anything new.
