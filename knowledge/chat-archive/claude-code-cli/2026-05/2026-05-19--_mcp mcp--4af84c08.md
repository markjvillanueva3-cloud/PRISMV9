```bash
node H:/prism/.claude/helpers/sync-h-c-drives.mjs
```

This will:
1. Copy H: → C: for files missing or outdated on C:

## What Gets Synced

- `commands/` — slash commands
- `agents/` — custom agents
- `hooks/` — custom hooks

- `rules/` — rules
- `plans/` — plans

## Why H: is Canonical

H: drive is portable (external drive / network share). C: is machine-specific.
When you switch machines, H: follows you but C: content is lost.

## Options

- `--dry-run` — show what would change without making changes
- `--c-wins` — prefer C: when files differ (use cautiously)
