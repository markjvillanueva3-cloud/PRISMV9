- DXFGeometryParserEngine — legacy POLYLINE support (U-PARSER-POLYLINE)
- open polyline with 3 vertices → 2 line segments, not closed
- closed polyline (group 70 bit 1) — 4 vertices form a closed square (4 segments)
- polyline with bulge on one vertex → arc segment for that span, line for others
- empty polyline (POLYLINE → SEQEND with no VERTEX) — 0 segments, no crash
