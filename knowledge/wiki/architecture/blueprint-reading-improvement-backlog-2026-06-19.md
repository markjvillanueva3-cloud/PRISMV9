   in dense regions — the classic dense-document recall failure. Tile each page into overlapping

   the 3rd model; addresses "dims that were clear but missed in a busy corner."

3. **Scan-quality preprocessing.** The failures concentrate on `scanned document - *.pdf` (raster
   scans). A cheap CPU pre-pass (deskew + denoise + adaptive contrast/binarize via OpenCV/PIL) before
   the VLM recovers low-quality scans the encoder currently can't read. Cheap, high-yield on this corpus.

## P1 — structure + precision

4. **GD&T-aware structured prompting.** Prompt the VLM with the Y14.5 FCF grammar so it emits
   structured feature-control-frames (geometric symbol + tolerance + modifiers + datum refs) instead
