# Neo4j Import — PRISM system-viz graph

> The system-viz graph (~152K nodes, ~185K edges) is exported as Cypher MERGE
> statements at `state/shared/system-viz/graph.cypher` (~22 MB, regenerated by
> `scripts/export-graph-cypher.mjs` inside the 19-stage wiki orchestrator).
> Load it into Neo4j to query the system structure with real graph traversals
> instead of grep.

## What's in the export

- **Nodes:** every L0–L10 + L4a node (L11 filesystem layer skipped by default;
  pass `--full` to `export-graph-cypher.mjs` to include its ~26K nodes too).
  Each node has `:Node` plus a layer label (`:L5`, `:L4`, etc.) and properties
  `id`, `label`, `layer`, `kind`, `subgroup`, `status`, `count`.
- **Relationships:** layer-typed — `PERSONA_USES`, `PAGE_CALLS`,
  `TRANSPORT_TO_DISPATCHER`, `TRANSPORT_TO_AI`, `AI_ROUTES`, `EXPOSES_ACTION`,
  `INVOKES_ENGINE`, `ACTION_INVOKES`, `ENGINE_USES_CORE`,
  `ENGINE_QUERIES_REGISTRY`, `REGISTRY_CONTAINS`, `KNOWLEDGE_RELATES`, and
  `ROUTES` (generic fallback for layer pairs without a named relationship).
- A uniqueness constraint on `:Node(id)` is created first so the MERGEs are fast.

## Import — three options

### Option A — Neo4j Desktop / Community (already running)

```bash
# Neo4j must be running and the `neo4j` database must exist
cypher-shell -u neo4j -p <password> -d neo4j --file state/shared/system-viz/graph.cypher
```

The 22 MB file is ~49K node MERGEs + ~78K edge MERGEs; expect a few minutes on
Community Edition. (If it's slow, raise `dbms.memory.heap.max_size` to 2G+.)

### Option B — Docker (no local install)

```bash
docker run --name prism-neo4j -d \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/prism-viz \
  -v "$PWD/state/shared/system-viz:/import:ro" \
  neo4j:community

# wait ~15s for startup, then:
docker exec -i prism-neo4j cypher-shell -u neo4j -p prism-viz \
  --file /import/graph.cypher

# Browser UI: http://localhost:7474  (neo4j / prism-viz)
```

### Option C — programmatic (neo4j-driver in mcp-server)

```bash
cd mcp-server && npm i neo4j-driver
```

```js
import neo4j from "neo4j-driver";
import { readFileSync } from "node:fs";
const driver = neo4j.driver("bolt://localhost:7687", neo4j.auth.basic("neo4j", "prism-viz"));
const session = driver.session();
const stmts = readFileSync("H:/prism/state/shared/system-viz/graph.cypher", "utf8")
  .split(/;\s*\n/).map(s => s.trim()).filter(s => s && !s.startsWith("//"));
for (const stmt of stmts) await session.run(stmt);
await session.close(); await driver.close();
```

## Query pack

Twelve ready-to-run queries (headline counts, unwired engines, dispatcher
fan-out, blast radius, tier-0 leverage, dead pixels, AI routing, registry
contents, shortest path, degree hubs, cross-layer census) live at
`state/shared/system-viz/graph-queries.cypher`. Copy-paste into cypher-shell or
the Neo4j Browser.

## Refresh cadence

`export-graph-cypher.mjs` runs inside `regen-wiki-from-viz.mjs` on every
post-commit (and the hourly cron), so `graph.cypher` is never more than one
commit stale. Re-import after a refresh — or set up an APOC `apoc.periodic.iterate`
loop against the file if you want continuous sync.
