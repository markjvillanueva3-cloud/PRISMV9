# memory-feedback-feedback-no-delete-assets

The "No Asset Deletion Rule" is a feedback rule that prohibits the deletion or disabling of settings, hooks, skills, scripts, tools, and features without explicit user permission. This rule ensures that users' comprehensive system protections and capabilities are not compromised
