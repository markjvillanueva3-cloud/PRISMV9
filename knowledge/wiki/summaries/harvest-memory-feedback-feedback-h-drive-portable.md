# memory-feedback-feedback-h-drive-portable

The H: drive must be portable between work and home PCs, requiring all fixes to work on both machines. Use SessionStart hooks to dynamically create necessary symlinks and paths, referencing them as `/h/...` or `H:/...`, and test fixes for portability.
