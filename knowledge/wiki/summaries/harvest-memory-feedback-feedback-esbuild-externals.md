# memory-feedback-feedback-esbuild-externals

The PRISM knowledge entry describes a fix for esbuild build failures related to externalizing specific modules (`ws`, `node-opcua`, and `occt-import-js`). These modules must be explicitly marked as external in the esbuild scripts to prevent resolution errors during the build proc
