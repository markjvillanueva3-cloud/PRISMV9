# memory-project-project-prism-forces-naming

PRISM Forces is a patent-free alternative to SolidCAM's iMachining adaptive clearing, using physics-based force prediction and engagement dynamics. It requires renaming all post processor outputs to "PRISM Forces" and updating relevant files and documentation accordingly.
