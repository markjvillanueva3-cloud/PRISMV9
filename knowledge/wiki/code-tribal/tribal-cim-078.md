# Cooling Channel Drilling and Milling

Cimatron programs cooling channel drilling with: gun drilling for straight channels (up to 30×D), helical milling for larger diameters, and 5-axis contour milling for conformal channels. Set peck cycle for gun drills (chip breaking every 3-5×D). Verify channel intersection points for cross-flow connectivity. Program cleaning operations after drilling to remove chips from channel intersections.
