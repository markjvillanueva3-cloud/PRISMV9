# Blade Machining for Turbine Components

PowerMill's blade machining module handles blisks, impellers, and individual blades. Define the hub, shroud, blade surfaces, and splitter blades. The system generates roughing (plunge roughing between blades), semi-finishing, and hub finishing toolpaths. Use barrel cutters for blade finishing — the larger effective radius allows 3-5× larger step-over with the same scallop height.
