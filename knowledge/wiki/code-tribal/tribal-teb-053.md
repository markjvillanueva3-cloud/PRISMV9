# Lead/Lean Angle Control for Ball-End Finishing

Set lead angle 10-15° (forward tilt in feed direction) and lean angle 0-5° (sideways tilt) for 5-axis ball-end finishing. Lead angle moves the contact point off the tool tip where surface speed is zero, improving surface finish by 30-50%. Tebis applies lead/lean relative to the surface normal at each point. Monitor for axis limit violations on trunnion-table machines with limited B-axis range.
