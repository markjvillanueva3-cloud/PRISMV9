# Sobol Sensitivity for Parameter Importance

First-order Si and total-order STi. Finishing: step-over (Si=0.35, STi=0.42), feed (0.25/0.33), speed (0.18/0.25). For iMachining roughing, engagement angle is the dominant parameter — but iMachining controls it automatically. Focus Sobol analysis on finishing operations where parameters are manually selected.
