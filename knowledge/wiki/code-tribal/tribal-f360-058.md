# Multi-Axis Contour Tilt and Side-Tilt Control

In Multi-Axis Contour, set the Tilt angle to 3-8 degrees to position the tool slightly off-normal to the surface. This prevents the tool tip from dragging on the surface (zero-speed center issue on ball nose cutters) and ensures the effective cutting edge is engaged. Use Side Tilt to lean the tool away from adjacent walls when clearance is tight — typically 5-15 degrees is sufficient to avoid holder-to-wall collisions.
