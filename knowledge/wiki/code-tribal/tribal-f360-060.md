# Multi-Axis Flow with Guide Curves for Blade Machining

When machining turbine blades or impeller vanes with Multi-Axis Flow, define guide curves along the leading and trailing edges to control tool direction. Without guide curves, the flow lines may cross each other on highly twisted surfaces, causing erratic tool motion. Add 2-4 guide curves spaced evenly across the blade surface to constrain the flowfield. This ensures the tool moves smoothly from root to tip with consistent engagement.
