# Multi-Setup Alignment with Probing

Master coordinate system across setups. Probe at each setup start. Precision dowels or 3-2-1 for alignment. Include datum locations in setup sheets. When machining both sides, alignment accuracy determines feature relationship quality. SprutCAM setup sheets auto-include WCS data.
