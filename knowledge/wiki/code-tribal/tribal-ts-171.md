# TopSolid Worm Gear Machining — Thread Milling and Turning Approaches

TopSolid machines worm gears using two approaches: (1) CNC turning for simple worm profiles — the worm is essentially a thread with a specific profile (ZA, ZI, ZN, ZK), and (2) 5-axis milling for complex worm profiles that cannot be generated by turning. TopSolid calculates the worm profile from the mating wheel geometry to ensure proper conjugation. For hardened worms, program a ground finish profile using CBN or diamond tools on a precision CNC lathe rather than a dedicated grinding machine.
