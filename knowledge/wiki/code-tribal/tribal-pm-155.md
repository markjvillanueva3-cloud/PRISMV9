# Macro Automation for Standard Sequences

PowerMill macros: record standard rough→semi→finish sequences, parameterize tool sizes and depths, replay for similar parts. Variables, loops, conditionals supported. Store in project-wide Macro folder. Use EDIT MACRO to debug. Macros for: mold base programs, electrode families, standard pockets. Reduces programming time 50-70% for repeat geometry types.
