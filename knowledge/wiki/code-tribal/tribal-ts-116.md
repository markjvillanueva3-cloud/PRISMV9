# Insert Machining with Electrode-Ready Features

TopSolid designs mold inserts with features ready for both CNC machining and electrode EDM. Machinable features (pockets, bores, flat surfaces) are assigned CNC operations, while unmillable features (deep narrow ribs, text, fine detail) are automatically flagged for electrode extraction. The system generates a machining plan that sequences CNC operations first, then creates electrodes for remaining features. This hybrid approach optimizes both cost and accuracy for complex mold cavities.
