# Surface Extension for Clean Tool Exit

Extend machining surfaces 2-5mm beyond part edges for clean tool exit without deceleration marks. Cimatron creates extension surfaces automatically or manually. Tool completes cutting stroke on extension before retract. Critical for visible surfaces on consumer product molds where tool exit marks require extra polishing. Also prevents corner radius deviation at part edges.
