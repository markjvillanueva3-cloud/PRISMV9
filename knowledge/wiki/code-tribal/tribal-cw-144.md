# TBM Report Generation — Tolerance Compliance Documentation

TBM generates tolerance compliance reports showing which features have been programmed to meet their specified tolerances. The report lists each toleranced feature, the assigned machining strategy, expected process capability (Cp/Cpk estimate based on TechDB data), and any features where the programmed strategy may not achieve the tolerance. Review this report before releasing the program — it highlights risk areas that need manual verification or additional operations.
