# Lollipop Cutter for Undercut Features

Lollipop (undercutting) tools access features behind overhanging geometry. In PowerMill, define the lollipop geometry: ball diameter, neck diameter, and neck length. Use '3+2 axis' positioning to orient the tool for undercut access. Verify clearance between the neck and surrounding geometry — the neck is not checked by default in some older PowerMill versions. Set cutting speed based on the ball diameter, not the neck.
