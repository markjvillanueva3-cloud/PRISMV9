# Mold Surface Quality Analysis Before Programming

Cimatron surface analysis: curvature maps, zebra stripes, deviation analysis. Identify tangency breaks, faceting, micro-waviness before machining. Fix in CAD — machining amplifies defects. Pay attention to parting surface continuity — G2 minimum for clean shut-off. Run analysis on imported STEP models before any toolpath generation.
