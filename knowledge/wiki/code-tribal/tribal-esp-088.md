# Batch Processing for Multi-Part Production

ESPRIT's batch processing applies machining templates to multiple parts in a queue. Load CAD files into the batch queue, assign template sets, and let ESPRIT generate all programs overnight. Batch processing supports: automatic feature recognition, template matching, tool assignment, simulation, and G-code generation. Review results the next morning — batch reports flag any parts where templates couldn't be applied (unusual features, tool reach issues).
