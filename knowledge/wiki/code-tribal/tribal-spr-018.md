# Additive Manufacturing with SprutCAM

SprutCAM supports DED (Directed Energy Deposition) additive manufacturing. Define layer height, bead width, and overlap percentage. Use 'Contour + Fill' strategy: contour traces the outline, fill covers interior area. Set 'Interlayer Wait' for cooling between layers. For hybrid additive+subtractive, alternate between deposition and milling operations within the same NC program.
