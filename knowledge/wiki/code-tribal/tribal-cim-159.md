# Cimatron API for ERP/MES Integration

Cimatron API enables external integration: ERP (job import), tool management (sync), PDM (version control), MES (program dispatch). Common workflow: pull job from ERP → create Cimatron project → apply NC Template → post-process → upload to DNC. API also enables batch processing: regenerate all programs overnight after design changes.
