# Hardened Material Rest Machining with Small Tools

After roughing hardened material with a large tool, use Edgecam's rest machining with a smaller ball-nose or bull-nose to clean corners and fillets. Set the 'previous tool' diameter accurately to avoid air cutting. For 55+ HRC, use 4-flute carbide ball-nose with AlTiN or TiSiN coating. Reduce feed to 0.02-0.05 mm/tooth and spindle speed to 12000-20000 RPM (depending on tool diameter). Enable constant chip load in corners to prevent tool overload on small-radius blends.
