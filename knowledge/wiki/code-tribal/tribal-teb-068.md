# Core/Cavity Split Surface Management

Tebis handles core/cavity splits with automatic parting surface generation. Define the parting line, and Tebis creates the parting surface extending to the mold base boundary. Use these surfaces as machining boundaries — separate toolpaths for core side and cavity side. Maintain associativity with the product model so parting surface updates propagate to machining operations.
