# Knowledge-Based Machining Automates Feature-to-Operation Mapping

CATIA Knowledge-Based Machining uses rules to automatically assign machining operations to recognized geometric features. Define rules like: 'If feature is a through-hole with diameter < 20mm and depth < 3xD, apply spot-drill + twist-drill + ream sequence.' Rules are written in EKL (Enterprise Knowledge Language) and stored in knowledge bases. This automation is most effective for parts with standardized features — custom or freeform geometry still requires manual programming.
