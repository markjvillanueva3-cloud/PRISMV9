# Robot Track External Axis Configuration

SprutCAM Robot supports external linear track axes that extend the robot's reach. Define the track length, direction, and mechanical limits. The robot positions along the track for each operation region, then machines within its local reach envelope. Program track repositioning moves between machining zones with 'Safe Height' clearance. This enables machining of large parts (5m+) that exceed the robot's standard reach.
