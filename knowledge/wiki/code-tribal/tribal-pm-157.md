# Volumetric Accuracy Compensation

Import machine's 21-error volumetric error map and PowerMill adjusts toolpath coordinates to pre-compensate. Valuable for large aerospace parts (2m+) where geometric errors compound over travel. Compensation improves accuracy from ±0.03mm to ±0.01mm. Requires periodic machine calibration (laser interferometer or ball-bar) to keep the error map current.
