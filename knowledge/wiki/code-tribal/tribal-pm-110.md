# Morris Screening for Many-Factor Problems

Morris elementary effects: compute μ* and σ per factor. High μ* = important, high σ = interactions/nonlinearity. Screen 10+ factors quickly, then detailed DOE on top 3-4. For PowerMill with many adjustable parameters (speed, feed, DOC, step-over, tolerance, lead/lean, approach/retract type, etc.), Morris identifies which actually matter before expensive factorial experiments.
