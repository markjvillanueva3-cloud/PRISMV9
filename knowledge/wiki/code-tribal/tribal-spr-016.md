# SprutCAM X Feature Recognition

SprutCAM X includes automatic feature recognition that identifies: holes (through/blind/countersink/counterbore), pockets (open/closed), slots, bosses, and chamfers. After recognition, assign machining strategies to feature types — all matching features receive the same strategy. Customize recognition parameters: minimum hole diameter, maximum pocket depth, slot width threshold. Re-run recognition after model changes.
