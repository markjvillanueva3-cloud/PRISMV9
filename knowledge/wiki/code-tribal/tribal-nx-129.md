# Wire EDM Programming in NX

NX's wire EDM module supports 2-axis and 4-axis taper cutting. Define profile geometry, taper angles, and skim cut passes. Set technology parameters: wire type, flushing mode, and power settings per cut (rough, trim1, trim2, skim). For 4-axis dies, specify independent top and bottom profiles — NX interpolates the wire path between them. Add tabs for slug retention on internal cutouts.
