# On-Machine Verification Probing Reduces Setup Iterations

CATIA supports on-machine probing operations within the Manufacturing Program. Insert probing cycles between machining operations to verify critical dimensions without removing the part from the machine. Use probing to check datum features after roughing (before committing to finishing) and to verify bore diameters, pocket depths, and wall positions. If probing detects out-of-tolerance conditions, use the probe results to apply wear offsets automatically, compensating for tool wear and thermal drift.
