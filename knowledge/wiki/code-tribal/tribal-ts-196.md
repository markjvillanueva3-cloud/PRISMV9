# TopSolid'ShopFloor Machine Monitoring — OEE and Downtime Tracking

TopSolid'ShopFloor monitors machine utilization through MTConnect/OPC-UA connections. It calculates Overall Equipment Effectiveness (OEE = Availability × Performance × Quality): Availability tracks planned vs unplanned downtime, Performance tracks actual vs theoretical cycle time, and Quality tracks first-pass yield. Dashboard displays show real-time OEE per machine with drill-down to identify the dominant loss category. Typical CNC shops achieve 45-55% OEE; world-class is 85%+. The data identifies improvement opportunities: setup time reduction, feed rate optimization, or maintenance scheduling.
