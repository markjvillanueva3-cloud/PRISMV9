# Shut-Off Surface Machining Ensures Precise Mold Sealing

Shut-off surfaces where core meets cavity require zero-gap contact. Machine these surfaces with a dedicated finishing pass using ball or bullnose endmill at very tight tolerance (0.003mm). Use Z-constant strategy to produce consistent surface finish. Leave 0.01mm on the contact side for bench fitting. Color-code shut-off surfaces in the CAD model for easy identification during programming.
