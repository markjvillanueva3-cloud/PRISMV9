# Post Builder Advanced Customization

NX Post Builder creates post processors using a graphical interface plus Tcl scripting. Common customizations: RTCP/TCPM output format, canned cycle syntax per controller, tool measurement macros, sub-program output for repeated patterns, and coordinate rotation for angled features. Test posts with 'Post Debug' mode showing Tcl variable evaluation. Always validate against the actual machine controller manual.
