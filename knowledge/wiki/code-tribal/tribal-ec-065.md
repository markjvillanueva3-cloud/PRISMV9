# Feature Creation for Additional Machining

Use Part Modeler to add features needed for machining but absent from the design model: chamfers for deburring, witness flats for clamping, alignment features for second ops, and tapered entry ramps. These manufacturing features stay in the CAM model without modifying the design CAD. Mark them with a distinct color or layer for easy identification during program review.
