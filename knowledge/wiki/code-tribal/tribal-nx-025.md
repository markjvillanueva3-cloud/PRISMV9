# Exporting and Reusing Custom Post Features

NX Post Builder allows you to export custom post features and import them into other post processors. When you develop a working solution (custom cycle, probing routine, sub-program handling), export it as a reusable feature. This prevents re-work when building posts for similar machines and ensures consistency across your post library.
