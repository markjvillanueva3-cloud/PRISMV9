# 5-Axis Blade Machining with Point Milling Strategy

For individual turbine blades, ESPRIT's point milling strategy uses the ball-nose tip to trace the blade profile with precise 5-axis orientation. Set the stepover based on blade surface tolerance (typically 0.005-0.02mm for aerospace). Use 'leading edge priority' to ensure the critical leading and trailing edges are machined with fresh cutting edges. Enable 'smooth axis motion' to limit rotary axis velocity to 15-30 deg/sec for stable cutting.
