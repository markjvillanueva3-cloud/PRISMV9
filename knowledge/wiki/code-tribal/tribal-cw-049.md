# 5-Axis Trimming — Edge Following for Composite and Sheet Parts

5-axis trimming follows part edges while maintaining tool perpendicular to the surface. Used for trimming composite layups, thermoformed sheets, and cast flash. Set the lead/lag angle to tilt the tool slightly in the feed direction to prevent the tool from pulling the material (especially important for composites). Use diamond-coated or PCD tools for composite trimming at high speeds (10,000+ RPM) with minimal feed (0.02-0.05mm/tooth) to prevent delamination.
