# Hotelling T² for Multivariate SPC

Correlated dimensions need multivariate SPC. T² = (x-μ)ᵀ×S⁻¹×(x-μ). MYT decomposition identifies offending dimension(s). Requires n>5p. For complex aerospace parts with 20+ critical dimensions, Hotelling T² prevents the false alarm rate explosion that occurs when running 20 separate X-bar charts (each at 5% → ~64% chance of at least one false alarm).
