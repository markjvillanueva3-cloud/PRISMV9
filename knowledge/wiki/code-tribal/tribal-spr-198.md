# Probing for Turned Part Verification

Probe critical diameters between operations. Verify concentricity after part transfer. Check length after facing. SprutCAM programs probe cycles in turning. Store data for SPC. Use probing to detect bar stock variation before finishing — prevents out-of-tolerance parts.
