# Variable Contour for Drafted Walls

NX Variable Contour 5-axis operation automates programming of complex drafted walls. Select the floor geometry and NX recognizes the drafted walls to generate a 5-axis swarf-style toolpath automatically. This eliminates manual axis definition and can reduce cycle time by 10x compared to 3-axis approaches on tall drafted features.
