# Texture Area Masking Protects EDM Burn Regions

When machining molds with textured surfaces, define texture boundary curves in the CAD model and use them as machining limits. Leave 0.05-0.10mm extra stock on texture areas to be removed by the texture etching process. Use avoidance regions in finishing NCJobs to prevent the tool from entering texture zones. This ensures consistent texture depth after etching.
