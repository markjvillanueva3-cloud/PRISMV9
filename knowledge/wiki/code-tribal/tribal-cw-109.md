# Tool Crib Management — Track Available Tools by Machine

CAMWorks tool crib functionality tracks which tools are physically loaded in each machine's magazine. Constrain programming to available tools to avoid tool changes that require operator intervention. When a required tool is not in the crib, the system alerts the programmer to either substitute an available tool or schedule a tool load. This is critical for lights-out manufacturing where unplanned tool changes halt production. Synchronize the virtual tool crib with the physical machine daily.
