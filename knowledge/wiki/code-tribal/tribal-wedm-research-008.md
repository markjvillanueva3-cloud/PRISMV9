# Deep ensemble learning for EDM surface classification (95% accuracy)

Deep ensemble learning approach classifies EDM surface roughness categories with 95% accuracy. Ensemble combines multiple deep neural network architectures (ResNet, VGG, custom CNNs) with weighted voting. Particularly effective for detecting surface defects: micro-cracks, recast layer anomalies, and white layer variations that correlate with machining parameters.
