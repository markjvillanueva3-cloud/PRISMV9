# Wire EDM No-Core Cutting — Prevent Core Drop Damage

For through-cuts where the slug (core) drops out, CAMWorks Wire EDM supports 'no-core' strategies: (1) glue-stop tabs that leave small bridges to hold the core until manual removal, (2) core-drop detection that pauses the machine and alerts the operator, (3) submerged cutting with core catchers below the workpiece. Set tab width to 0.3-0.5mm for easy manual removal without damaging the cut surface. Place tabs at non-critical locations or corners where they can be filed without affecting functional surfaces.
