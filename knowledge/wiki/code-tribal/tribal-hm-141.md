# Composite CFRP/GFRP Trimming

PCD/diamond compression routers, 200-400 m/min, 0.02-0.05mm fz. 5-axis tool normal. Vacuum fixturing. Zig only for consistent fiber direction. Dust extraction mandatory. hyperMILL programs trim curves with automatic approach/retract. Delamination-free requires sharp tools + controlled feed.
