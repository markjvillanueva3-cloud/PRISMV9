# Batch Automation with NX Journal Macros

NX Journals (VB.NET or Python scripts) automate repetitive CAM tasks: batch import models, apply manufacturing templates, generate toolpaths, run ISV, and post-process. Use Journal Record to capture a manual workflow, then parameterize for batch execution. Common automation: nightly batch regeneration of all programs after design changes, or weekly re-post to updated post processors.
