# VBM IPW Visualization with Section Analysis

Use NX's IPW section analysis to slice through the in-process workpiece at any plane and verify remaining stock thickness. Toggle the IPW display between transparent, solid, and cross-hatch modes to identify uncut islands or excessive stock pockets. Run section analysis after each roughing pass before programming semi-finish to catch areas where the tool failed to reach due to holder interference.
