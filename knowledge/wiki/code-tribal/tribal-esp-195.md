# Gear Deburring and Chamfering Cycles

After gear cutting in ESPRIT, program automatic tooth deburring and chamfering to remove sharp edges that cause noise and premature failure. ESPRIT offers three methods: (1) Rotary deburring with a wire brush or abrasive wheel — synchronized rotation removes burrs from both flanks simultaneously, (2) Single-tooth chamfering with a form tool that matches the tooth profile, (3) 5-axis ball-nose deburring that traces each tooth edge. For automotive production gears, method 1 is fastest (2-5 seconds per gear); for aerospace precision gears, method 3 provides controlled chamfer width (0.1-0.3mm). Configure under Gear → Secondary → Deburr/Chamfer.
