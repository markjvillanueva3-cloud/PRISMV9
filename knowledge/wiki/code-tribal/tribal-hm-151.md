# SPC Control Charts for Production Monitoring

X-bar/R on critical dims after 25 parts. Trends = wear, shifts = fixture, range increase = vibration. MAXX Machining produces more consistent scallop heights than ball-end, reducing surface finish variation — SPC control limits are tighter. Monitor barrel cutter wear pattern separately from conventional tools.
