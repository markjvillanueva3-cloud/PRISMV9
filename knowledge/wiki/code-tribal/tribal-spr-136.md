# Flat Area Detection for Strategy Selection

Detect flat/near-flat areas (threshold 5-10°) for face milling instead of ball-end. 3-5× faster with better Ra. Auto-separates flat from curved regions. Use flat-end for detected areas, ball-end for curved. SprutCAM supports automatic flat area detection and strategy assignment.
