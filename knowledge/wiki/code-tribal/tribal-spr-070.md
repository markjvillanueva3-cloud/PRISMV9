# Surface Extension for Clean Tool Exit

Extend machining surfaces 2-5mm beyond part edges to ensure clean tool exit without deceleration marks. In SprutCAM, create extension surfaces in the 3D model or use 'Boundary Extension' in the operation parameters. The tool completes its cutting stroke on the extension surface before rapid retract. This is critical for visible surfaces on consumer products and mold cavity faces.
