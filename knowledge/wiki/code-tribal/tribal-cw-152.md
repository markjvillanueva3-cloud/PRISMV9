# ShopFloor In-Process Inspection Feedback — Closed-Loop Quality

When CNC machines with probing report measurement data back to ShopFloor, the system displays dimensional results in real-time against tolerance bands. Green/yellow/red status indicators show whether each feature is nominal, approaching limits, or out of specification. This closed-loop feedback enables immediate corrective action (tool offset adjustments) before producing scrap. Configure measurement triggers at 1st piece, every Nth part, and after tool changes.
