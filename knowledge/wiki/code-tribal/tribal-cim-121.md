# AMSAA Reliability Growth for Program Maturity

Track Cimatron program maturity using AMSAA model. Plot cumulative failures vs production hours. Failure rate should follow power law decrease as program matures. If trend stalls: investigate tool vendor change, material batch shift, or machine maintenance. Mature mold programs achieve <0.5% scrap after 50+ cycles. Track separately for rough and finish operations.
