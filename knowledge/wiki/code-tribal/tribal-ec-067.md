# Design Modification Without CAD Round-Trip

Part Modeler enables minor design modifications directly in Edgecam: adding draft angles, filleting sharp edges, splitting surfaces, and extending faces. This avoids the time-consuming round-trip to CAD for simple changes. Common uses: extend a face beyond the part boundary to prevent short tool passes, add split lines for strategy boundaries, and create offset surfaces for stock allowance verification.
