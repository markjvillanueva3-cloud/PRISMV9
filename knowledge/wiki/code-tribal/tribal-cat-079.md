# Data Management and Revision Control for NC Programs

The 3DEXPERIENCE platform provides built-in revision control for Manufacturing Programs, tool catalogs, and NC code. Every change is tracked with author, timestamp, and change description. Use the maturity lifecycle (In Work → Frozen → Released) to control when programs can be modified and when they are approved for production. Set up approval workflows requiring sign-off from the NC programmer, process engineer, and quality engineer before a program reaches 'Released' status.
