# Contour-Driven Parallel Mode for Ruled Surface Finishing

In CATIA Contour-Driven machining, use Parallel Contour mode for finishing ruled or near-ruled surfaces. The tool follows progressively offset copies of a guide contour, producing uniform scallop patterns. Set the Number of Contours based on surface width and desired scallop height. For wide surfaces, specify a maximum distance between contours rather than a count, so CATIA automatically adds passes as the surface widens.
