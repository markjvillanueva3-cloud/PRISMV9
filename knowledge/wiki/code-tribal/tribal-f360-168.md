# Multi-User Tool Library Governance

For teams with 3+ programmers, establish tool library governance rules: read-only access for programmers (they select tools but cannot modify them), edit access for the manufacturing engineer who maintains the library, and a change request process for adding new tools. In Fusion Team, set project-level permissions on the tool library folder. When adding a new tool, require: vendor catalog number, verified speeds/feeds for each material group, holder assembly with collision model, and expected tool life. Review the library quarterly to remove tools that have been discontinued or have poor performance history. This prevents tool library bloat and ensures consistency across all CAM programs.
