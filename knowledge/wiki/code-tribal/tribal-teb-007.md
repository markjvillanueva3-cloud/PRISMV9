# Electrode Design-to-NC Workflow Covers Full EDM Process

Tebis electrode module handles the complete workflow: identify burn areas on the mold, extract electrode shapes, add spark gaps (roughing 0.15-0.25mm, finishing 0.05-0.10mm), create electrode blanks, program machining, and generate EDM setup sheets. Group electrodes by burn position and assign roughing/finishing pairs. The system outputs electrode coordinates relative to the mold datum for direct transfer to the sinker EDM machine.
