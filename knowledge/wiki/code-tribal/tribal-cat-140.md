# Surface Machining Guide Curve Strategy for Flow-Shaped Parts

CATIA Surface Machining supports 'Between Two Guide Curves' strategy for parts with defined flow lines (turbine blades, impeller channels, automotive body panels). Define two boundary curves that represent the desired tool path direction, and CATIA interpolates parallel paths between them. The path density is controlled by 'Number of Passes' or 'Maximum Distance Between Passes'. This strategy produces superior surface quality on ruled or near-ruled surfaces because tool paths follow the surface's natural curvature flow rather than fighting against UV directions.
