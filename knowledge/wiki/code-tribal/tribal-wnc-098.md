# Composite Machining with PCD Tools

For CFRP/GFRP composites in WorkNC, use PCD or diamond-coated tools at 200-500 m/min and 0.05-0.1 mm/tooth. Program climb milling to push fibers against the supporting laminate. Tighten machining tolerance (0.002-0.005 mm) to prevent fiber pullout. Use dust extraction instead of flood coolant. Enable composite-specific M-codes for vacuum systems. Avoid interrupted cuts that cause delamination.
