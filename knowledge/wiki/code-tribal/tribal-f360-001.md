# Adaptive Clearing Optimal Load Controls Tool Engagement

In 3D Adaptive Clearing, the Optimal Load parameter is effectively your stepover — it controls the maximum tool engagement angle. Set it to 25-40% of tool diameter for most materials. Fusion maintains constant chip load by dynamically adjusting the toolpath, so you can run 2-3x deeper axial depths than conventional pocketing without overloading the cutter.
