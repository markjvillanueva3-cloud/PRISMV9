# Automatic Hole Recognition and Template Matching

Use the Hole Recognition feature to automatically detect holes in your model and match them to machining templates. The Hole Template Editor (enhanced 2025) lets you build precise hole signatures using cylinder, cone, and torus segments, and match by color, thread data, or PMI annotations. This automates drilling, tapping, reaming, and boring sequences — saving significant programming time on hole-heavy parts.
