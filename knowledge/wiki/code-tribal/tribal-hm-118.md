# MAXX Machining Roughing with Barrel Cutters

hyperMILL MAXX Machining roughing uses barrel cutters with large effective radius (100-500mm) for 3-5× wider step-over than ball-end mills at the same scallop height. Define barrel geometry: barrel radius, tip fillet, taper angle. Automatic tilt maintains contact zone. Reduces finishing cycle time 60-80%. Verify contact pattern in simulation — incorrect tilt causes gouging.
