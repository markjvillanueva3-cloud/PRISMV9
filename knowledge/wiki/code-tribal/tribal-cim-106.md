# Taguchi Robust Parameter Design

Apply Taguchi L9: speed, feed, step-over (3 levels each). Noise factors: material hardness (±2 HRC), tool wear (new/mid/end). Measure S/N ratio for surface roughness. Taguchi-optimal parameters maximize signal-to-noise — finish least sensitive to noise. These robust parameters outperform 'optimized' parameters that only work under ideal conditions typical in controlled tests.
