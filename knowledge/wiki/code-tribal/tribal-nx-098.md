# NC Code Based Simulation for External Program Validation

NX ISV can import and simulate G-code files from any CAM system — not just NX-generated programs. Load the external NC file through File > Import NC Code, assign the correct machine model and workpiece geometry, and run the simulation. This is invaluable for validating hand-edited programs, legacy code from retired CAM systems, or programs from sister plants. NX parses standard Fanuc, Siemens, and Heidenhain dialects. Custom M-codes require mapping in the VNCK configuration or post definition file.
