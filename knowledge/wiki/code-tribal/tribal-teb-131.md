# Tebis API for External System Integration

Tebis API enables integration with: ERP (job import), tool management (tool data sync), PDM (model version control), and MES (program dispatch). Automate: project creation, model import, template application, NC file export. Common integration: pull job from ERP → create Tebis project → apply NCJob template → post-process → upload to DNC server.
