# Overlap Distance for Steep-Shallow Boundary Blending

In Steep and Shallow finishing, set the Overlap Distance to 0.5-2.0mm to extend each strategy type beyond the threshold boundary. This overlap ensures no unmachined strips remain at the transition zone and produces a smoother blend between the contour and parallel/scallop regions. Larger overlap values (2-3mm) are needed for ball nose tools with diameter under 6mm, where tool deflection at the boundary can leave visible ridges if the overlap is too small.
