# Machining Regions for Selective Toolpath Generation

BobCAD machining regions define specific areas of the part for targeted toolpath generation. Use machining regions to focus operations on critical areas without reprocessing the entire part. For example, define a region around a modified feature and regenerate only that region's toolpaths. Regions can be defined from surface selections, wireframe boundaries, or solid face picks. This is particularly useful for ECO (engineering change order) modifications to existing programs.
