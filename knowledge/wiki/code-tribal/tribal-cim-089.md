# Boundary Management with Boolean Operations

Create boundaries from: surface edges, silhouette projections, user sketches, or automatic steep/shallow detection. Chain with Boolean operations (union, intersection, subtraction). Add 0.5mm extension to prevent tool marks at edges. Store in named sets for reuse across operations. Boundary-based selective machining reduces cycle time by 20-40% when only specific regions need rework.
