# Flat Area Detection for Strategy Selection

Detect flat areas (5-10° threshold) for face milling instead of ball-end. 3-5× faster, better Ra. Auto-separates flat from curved regions. Use flat-end for detected, ball-end for curved. Cimatron supports automatic flat detection and strategy assignment.
