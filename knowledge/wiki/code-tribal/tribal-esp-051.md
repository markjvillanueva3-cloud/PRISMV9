# Wire EDM 2-Axis Profile with Automatic Lead Placement

ESPRIT automatically determines optimal wire lead-in/lead-out positions for 2-axis wire EDM profiles. Place leads on non-critical surfaces or corners where the witness mark won't affect part function. For precision dies, use a tangential lead with 0.5-1mm approach distance. Enable 'automatic start hole positioning' to place EDM start holes in waste material. For multiple profiles, optimize the wire threading sequence to minimize total non-cutting time.
