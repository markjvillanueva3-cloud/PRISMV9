# Adaptive Roughing Maintains Constant Tool Engagement

CATIA's adaptive roughing (available in 3DEXPERIENCE/DELMIA) dynamically adjusts the tool path to maintain a constant radial engagement angle, similar to trochoidal strategies. This allows 2-3x deeper axial cuts and 30-40% higher feedrates compared to conventional zigzag roughing because peak cutting forces are controlled. Set the maximum engagement angle to 40-60 degrees (equivalent to 25-35% radial stepover). Use a full-flute engagement depth of up to 2-3xD.
