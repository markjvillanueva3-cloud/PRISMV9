# Multi-Electrode Set Management for Complex Cavities

Complex cavities may require 20-50 electrodes per cavity. Organize in Cimatron using electrode sets: group by burn area, then by roughing/finishing within each area. Name convention: PART-AREA-TYPE-SEQ (e.g., MOLD1-RIB3-FINISH-01). Generate electrode setup sheets with burn positions, spark gap settings, and depth targets. Track electrode status (new/used/worn) in the tool management system.
