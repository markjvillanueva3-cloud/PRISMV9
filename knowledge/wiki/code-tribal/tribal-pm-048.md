# Port Machining for Cylinder Heads and Manifolds

PowerMill's port machining module programs the internal passages of cylinder heads and manifolds. Define the port centerline curve and cross-section profiles. The system generates 5-axis toolpaths that follow the port interior while maintaining tool access through the port opening. Critical: verify tool length versus port depth — tools must reach the full passage length without holder collision.
