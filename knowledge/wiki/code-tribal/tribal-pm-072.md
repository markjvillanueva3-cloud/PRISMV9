# Toolpath Editing for Manual Corrections

PowerMill allows manual editing of generated toolpaths: insert/delete points, modify point positions, add approach/retract moves, and split/join segments. After editing, regenerate the stock model to reflect changes. Use editing sparingly — modified toolpaths don't update when the model changes. Tag edited toolpaths with notes explaining why manual intervention was needed.
