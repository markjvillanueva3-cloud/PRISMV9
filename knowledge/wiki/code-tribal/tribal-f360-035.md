# Tool Library Organization with Holders and Assemblies

Organize your Fusion tool library with complete tool assemblies — cutter, holder, and stickout modeled accurately. Create separate libraries for each machine (tools that physically live in the carousel) with holder geometry included. Accurate holder models are critical for collision detection in simulation. Export libraries as JSON for backup and sharing across team members.
