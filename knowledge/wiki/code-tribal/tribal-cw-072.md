# Y-Axis Operations — Off-Centerline Milling for Complex Mill-Turn Parts

Y-axis capability on mill-turn machines enables true milling operations off the spindle centerline. CAMWorks programs Y-axis operations as standard milling (pocketing, contouring, drilling) with the part held in the chuck. This eliminates secondary operations on a VMC for features like keyways, flats, and bolt patterns on turned parts. Ensure the Y-axis travel range covers all feature locations — some machines have limited Y travel (±50mm) that constrains feature placement.
