# Verification Probing — Final Part Inspection On-Machine

Program verification probing after the final finishing operation to create an on-machine inspection report. Probe key dimensions (bore diameters, boss locations, face positions) and compare against nominal ± tolerance. Output results to a text file or controller variable for SPC data collection. This provides immediate feedback without moving the part to a CMM. On-machine probing accuracy is typically ±3-5μm with calibrated probes — sufficient for most production tolerances but not for metrology-grade inspection.
