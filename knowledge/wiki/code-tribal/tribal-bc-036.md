# Multi-Surface 5-Axis with Gouge Protection

BobCAD multi-surface 5-axis finishing automatically tilts the tool away from interfering adjacent surfaces while maintaining contact with the target surface. Set minimum tilt angle (5°) and maximum tilt angle (45°). Use 'Smooth tilt transitions' to prevent abrupt axis changes. The Multiaxis Wizard provides guided setup for toolpath types including Parallel Cuts, Cuts Along Curve, Morph Between 2 Curves, Morph Between 2 Surfaces, and Project Curves.
