# GibbsCAM 14 Ribbon UI customization speeds daily workflow with role-based layouts

GibbsCAM 14's ribbon interface supports custom tab layouts and quick-access toolbars. Create role-specific layouts: a 'Turning' layout showing only turning operations and tools, a 'Mill-Turn' layout with both, a 'Wire EDM' layout with EDM-specific tiles. Export layouts as .gcui files for standardization across programming stations. Pin the most-used 8-10 commands to the Quick Access Toolbar (QAT) — operations like 'Rough', 'Finish', 'Simulate', 'Post' should be one click away. This reduces UI navigation overhead by 20-30% for experienced programmers.
