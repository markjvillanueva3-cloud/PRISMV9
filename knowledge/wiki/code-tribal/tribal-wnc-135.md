# WorkNC Dental Nesting — Maximize Restorations per Blank

WorkNC Dental nests multiple restorations in a single disc or block blank to maximize material utilization. The nesting algorithm considers: restoration height (thicker crowns need thicker blanks), sprue connection points (must be on non-critical surfaces), minimum spacing between restorations (0.5-1mm for tool clearance), and blank dimensions (98mm discs are standard for zirconia). For large bridges, the system verifies that the blank has sufficient material in the pontic region. Optimal nesting can fit 15-25 single crowns in one 98mm disc.
