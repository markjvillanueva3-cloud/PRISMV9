# Associative Machining — Automatic Toolpath Update on Design Changes

CAMWorks is fully associative with SOLIDWORKS — when the design model changes, CAMWorks features and toolpaths update automatically. CAD and CAM data are stored in a single file. After a design change, CAMWorks flags affected operations with a yellow warning. Right-click 'Regenerate Toolpath' on flagged operations rather than regenerating everything. For large assemblies, selective regeneration saves significant time compared to full rebuild.
