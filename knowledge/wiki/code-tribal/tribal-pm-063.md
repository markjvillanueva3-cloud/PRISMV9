# Hardened Steel Finishing for Mold and Die

For hardened tool steel (50-62 HRC): ball-end mill with CBN or nano-coated carbide, 100-200 m/min, 0.03-0.06mm feed/tooth, step-over based on target Ra (0.1mm for Ra 0.8μm). Air blast only — coolant causes thermal shock cracking. Use PowerMill's constant scallop finishing for uniform surface quality. Target Ra 0.4-0.8μm directly from machining to minimize polishing time.
