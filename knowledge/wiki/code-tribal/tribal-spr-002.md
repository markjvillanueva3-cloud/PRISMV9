# Machine Setup Wizard for Kinematic Configuration

SprutCAM's Machine Setup Wizard defines the complete kinematic chain: spindle → tool holder → rotary axes → linear axes → table. Import machine models from SprutCAM's library or create custom configurations. Correct kinematic definition is essential for accurate simulation and post-processing. Set axis limits, home positions, and travel ranges to match the physical machine exactly.
