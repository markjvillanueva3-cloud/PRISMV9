# Merchant Shear Angle Analysis

Higher positive rake → higher shear angle → thinner chips → lower forces. Rake 0°→10° reduces force ~15%. Use to validate SprutCAM tool selection: positive rake = better results but weaker edges. Continuous cuts: maximize rake. Interrupted: use stronger geometry. The physics guide tool selection independent of handbook recommendations.
