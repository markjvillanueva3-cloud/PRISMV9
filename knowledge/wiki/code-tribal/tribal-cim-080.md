# Mold Base Machining Templates

Cimatron provides mold base machining templates for standard mold bases (DME, Hasco, Meusburger). Templates include: pocket machining for A/B plates, guide pin holes, return pin holes, sprue bushing bore, and clamping slots. Apply the template matching your base standard, then customize for the specific mold. This standardization saves 4-6 hours on mold base programming.
