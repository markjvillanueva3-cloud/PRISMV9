# Plunge Roughing for Deep Features

Vertical motions, axial forces. For L/D>4, >45 HRC. iMachining handles most deep pockets automatically. Use plunge only when iMachining produces excessive lateral forces on very thin walls. SolidCAM plunge roughing operation available for extreme cases.
