# 5-Axis Swarf Cutting for Ruled Surfaces

For ruled surfaces (draft walls, ribs), use 5-axis swarf cutting where the tool's side (flute length) contacts the surface. Set 'Drive Surface' to the wall, 'Check Surface' to adjacent floors. Limit tool tilt to ±3° from nominal to prevent gouging. Swarf cutting can machine a full wall height in a single pass, dramatically reducing cycle time versus Z-level approaches.
