# Turn Finishing — Single-Pass Profile Following with Spring Cut Option

Turning finishing follows the final contour profile in a single pass. Enable the spring cut option (a second identical pass) for finishing operations on slender shafts (L/D > 5) where tool pressure causes elastic deflection during the first pass. The spring cut removes material left by deflection without adding cutting force. Set finish allowance on the roughing operation to 0.3-0.5mm per side for steel to leave uniform stock for the finishing pass.
