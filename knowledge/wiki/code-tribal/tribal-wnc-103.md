# Smooth Transitions Between Operations Reduce Marks

WorkNC ensures smooth entry/exit between consecutive passes and operations. Use tangential arc entry/exit at 1-3x tool radius. Enable 'Blend transitions' for smooth curves at segment junctions. Ensure transition height stays below finished surface to prevent witness marks. The lead-out from one pass flows into the lead-in of the next for seamless surface quality.
