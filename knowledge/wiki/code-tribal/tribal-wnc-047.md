# Smooth Transitions Between Passes Eliminate Marks

WorkNC generates smooth arc transitions between adjacent cutting passes to prevent witness marks from abrupt direction changes. Enable 'Smooth linking' with tangential arc lead-in/lead-out at 1-3x tool radius. The transition height should remain below the finished surface to prevent marks at transition points. For mirror-quality surfaces, ensure the overlap between adjacent passes is 5-10% of stepover.
