# AFR Machinable Feature Detection — Let CAMWorks Analyze the Solid Model

CAMWorks AFR can identify over 20 types of machinable features including pockets, holes, slots, bosses, and contours directly from native SOLIDWORKS or imported 3D models. Run AFR before manual feature creation — it analyzes the part topology and groups features by setup orientation, saving 60-80% of feature definition time. Review the feature tree after AFR to verify all features were correctly classified before generating operations.
