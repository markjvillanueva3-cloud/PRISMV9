# Additive DED for Repair and Build-Up

SprutCAM DED: contour+fill, 30-50% overlap, 60-80% layer. Interleave machining every 3-5 layers. For worn shaft repair, feature addition, near-net-shape. Robot DED with SprutCAM Robot enables large-scale additive on existing components.
