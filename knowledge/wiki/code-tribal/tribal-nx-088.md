# Shop-Floor Feedback Integration for FBM Refinement

NX's Machining Knowledge Editor allows importing actual cycle times and tool wear data from the shop floor to refine FBM parameters. When an operator reports that a recommended feed rate causes chatter on a specific feature type, update the Machining Knowledge Library entry. The correction propagates to all future programs using that feature-material combination. Track correction frequency per rule to identify systematic issues in the default knowledge base that require global adjustment.
