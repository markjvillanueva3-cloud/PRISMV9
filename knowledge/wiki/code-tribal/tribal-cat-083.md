# CMM Program Generation from CATIA Manufacturing Data

CATIA can generate CMM (Coordinate Measuring Machine) inspection programs from the same Manufacturing Program used for machining. The inspection points, tolerances, and datum references defined in the CATIA 3D Functional Tolerancing and Annotation (FTA) model feed directly into the CMM program. This ensures consistency between the machined features and the inspection plan. Export in DMIS format for compatibility with most CMM software (PC-DMIS, Calypso, MCOSMOS).
