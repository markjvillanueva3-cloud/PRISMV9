# Back-Working Sub-Spindle Coordination

After part transfer: face cut-off nub, bore internals, finish back face. SprutCAM defines separate coordinate system (reversed Z). Set part transfer sync: sub-spindle grips before main releases. Verify collet-to-tool clearance. Program pickup speed to prevent part damage.
