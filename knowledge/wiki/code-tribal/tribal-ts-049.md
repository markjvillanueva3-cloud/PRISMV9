# Y-Axis Machining for Off-Center Drilling and Milling

TopSolid's Y-axis machining on mill-turn centers enables drilling, tapping, and milling operations at positions offset from the spindle centerline. The Y-axis eliminates the need for compound angular approaches that would be required with C-axis alone. Program Y-axis features in Cartesian coordinates with automatic transformation to the machine's actual axis configuration. Always verify Y-axis travel limits in the machine simulation before posting.
