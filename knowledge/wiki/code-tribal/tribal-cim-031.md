# Runner and Gate Machining for Injection Molds

Machine runners with ball-end mill tracing the centerline at graduated depths. For sub-gates, use tapered end mills matching the gate taper angle. Cold runner cross-sections (trapezoidal, round, half-round) each need specific tool and strategy. Cimatron's mold design module provides runner geometry directly — use 'Extract Machining Surfaces' to isolate runner faces for targeted operations.
