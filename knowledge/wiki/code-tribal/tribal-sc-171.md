# iMachining 2D vs 3D Strategy Selection

iMachining 2D: prismatic pockets, profiles, slots. 3D: freeform cavities with varying depth. 2D is simpler and more predictable. Use 2D when geometry allows. 3D adds complexity but handles mold/die cavities. Both maintain constant chip load — the key iMachining benefit.
