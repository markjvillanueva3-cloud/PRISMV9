# Rapid Planning Optimizes Non-Cutting Moves

Edgecam's rapid planning optimizes traverse moves between operations using simultaneous multi-axis rapids instead of sequential retract-move-plunge. Enable machine-aware rapid planning to account for axis travel limits and rapid rates. For multi-operation parts, rapid optimization can save 5-15% of total cycle time. Set the safe retract height to the minimum needed for fixture clearance rather than an arbitrary large value.
