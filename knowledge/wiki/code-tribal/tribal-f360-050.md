# Parallel Finishing Direction Relative to Feed Marks

In Parallel finishing, set the tool direction perpendicular to the primary viewing angle of the part. Feed marks (scallops) run parallel to the tool direction — if the part is viewed from the front, run passes left-right so scallops are horizontal lines, which are less visually apparent. For mold cavity surfaces, orient parallel passes along the draw direction so any remaining witness lines do not interfere with part ejection.
