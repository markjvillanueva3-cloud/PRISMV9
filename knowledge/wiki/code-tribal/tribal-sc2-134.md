# SURFCAM 2023 Automatic Feature Recognition from Solid Models

SURFCAM 2023 includes automatic feature recognition (AFR) that identifies holes, pockets, bosses, and slots from imported STEP/Parasolid models and proposes appropriate operations. Traditional SURFCAM required manual feature identification and geometry selection. AFR accuracy is highest for prismatic features with standard dimensions. Review AFR-generated operations carefully for complex parts — the system may miss fillets-as-features or misclassify shallow pockets as face operations.
