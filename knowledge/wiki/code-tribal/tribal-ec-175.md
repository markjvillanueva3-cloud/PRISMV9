# Barrel Cutter Selection for Large Surface Stepovers

Barrel cutters (lens-shape, taper, general barrel forms) in Edgecam 5-axis finishing achieve 5-10x larger stepovers than ball-nose tools for the same scallop height. A barrel cutter with 250mm effective radius achieves the same scallop height as a ball-nose at 1/5th the stepover. Define barrel tools in Edgecam's tool library with the barrel radius, taper angle, and tip radius. The tool definition drives Edgecam's contact point calculation for 5-axis orientation.
