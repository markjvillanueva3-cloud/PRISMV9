# TopSolid'ShopFloor DNC — Secure Program Distribution

TopSolid'ShopFloor manages NC program distribution to CNC machines via DNC (Direct Numerical Control). Programs are version-controlled — only the latest approved revision can be downloaded. The system maintains an audit log of every program transfer: who requested it, when, to which machine, and which revision. This meets traceability requirements for AS9100 (aerospace), ISO 13485 (medical), and IATF 16949 (automotive). Implement approval workflows: programmer → reviewer → release, with electronic signatures at each stage.
