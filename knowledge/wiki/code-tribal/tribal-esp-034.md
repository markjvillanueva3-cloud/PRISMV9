# 5-Axis Impeller Machining with Hub/Blade/Splitter Control

ESPRIT's impeller cycle machines hub surfaces, blades, and splitter blades in a coordinated sequence. Start with hub roughing using a bull-nose cutter, then switch to blade finishing with a tapered ball-nose. Set the 'blade extension' to 3-5% beyond the blade edge to prevent short strokes. For splitter blades, enable 'secondary blade offset' and use a thinner tool. Always simulate with full holder geometry — splitter blade channels are the most common collision zone.
