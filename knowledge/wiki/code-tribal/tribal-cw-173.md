# Process Variability Sources — Mapping Input Variables to Output Quality

Manufacturing process variability in CNC machining comes from 6 major sources: (1) material hardness variation (±5-10% within a batch), (2) tool wear progression (gradual dimensional shift), (3) thermal drift (0.01-0.05mm/°C on cast iron machines), (4) fixture repeatability (±0.005-0.02mm), (5) tool setting accuracy (±0.002-0.01mm), (6) coolant concentration changes affecting cutting forces. Map these inputs to critical output dimensions using a cause-and-effect matrix. In CAMWorks, account for the dominant sources when setting tolerances and stock allowances.
