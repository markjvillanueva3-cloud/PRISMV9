# Automatic Tool Selection Based on Feature Requirements

WorkNC can automatically select tools from the library based on operation requirements: tool type, minimum diameter (to fit features), minimum length (to reach depth), and material compatibility. The algorithm considers reach, holder clearance, and magazine availability. Review auto-selected tools as the algorithm optimizes for reach, not necessarily for best cutting performance.
