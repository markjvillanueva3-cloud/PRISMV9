# Pattern Machining — Raster/Zigzag for Flat and Gently Curved Surfaces

Pattern (raster) machining moves the tool in parallel lines across the surface. Zigzag mode cuts in both directions for maximum efficiency, while one-way mode ensures consistent climb milling for better finish. Use pattern machining on surfaces with less than 20° curvature variation. Set the cut angle to optimize: 45° diagonal often produces the most uniform finish on rectangular parts by avoiding alignment with surface edges that create visible banding.
