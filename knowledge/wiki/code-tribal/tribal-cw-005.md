# Turned Feature Recognition — Automatic Detection of Lathe Geometry

CAMWorks AFR for turning automatically identifies OD profiles, ID profiles, front face features, and grooves from the revolved solid body. It distinguishes between roughing and finishing profiles and detects threading features from cosmetic thread annotations. For mill-turn parts, run both milling and turning AFR to capture cross-operation features like off-center holes that require C-axis milling on a lathe.
