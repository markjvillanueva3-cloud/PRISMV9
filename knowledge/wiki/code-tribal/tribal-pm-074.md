# PowerMill API for External Integration

PowerMill's COM API enables external integration with: ERP systems (job import), tool management (tool data sync), PDM (model version control), and MES (program dispatch). Use the API to automate: project creation, model import, template application, and NC file export. Common integration: pull job data from ERP → create PowerMill project → apply template → post-process → upload to DNC.
