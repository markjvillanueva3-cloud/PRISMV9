# ProfitTurning Groove Entry with Peck Strategy

For deep grooves (depth > 3x groove width), ProfitTurning uses a peck entry strategy that alternates plunge-retract cycles to break chips and allow coolant to reach the cutting zone. Set the peck depth to 0.5-1x groove tool width and retract 0.5-1mm for chip clearing. For face grooves, add a 0.1mm radial offset per peck to prevent the grooving insert from rubbing on the groove walls during retract.
