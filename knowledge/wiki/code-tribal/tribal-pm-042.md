# Pattern-Based Finishing with User-Defined Curves

Pattern finishing projects a user-defined 2D pattern onto 3D surfaces. Create spiral, radial, or custom curve patterns in PowerMill or import from CAD. The toolpath follows the pattern while maintaining surface contact. Use for: decorative textures, non-standard finishing patterns, and optical surface requirements. Set 'Pattern Projection' to 'Normal to Surface' for even coverage.
