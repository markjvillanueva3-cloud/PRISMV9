# Turbomachinery Splitter Blade Support

NX Turbomachinery Milling handles impellers with up to six splitter blades between the main blades. Define the splitter geometry in the multi-blade setup and NX generates separate roughing and finishing passes for the splitter channels. The system automatically manages the different channel widths between main blades and splitters to select appropriate tool sizes.
