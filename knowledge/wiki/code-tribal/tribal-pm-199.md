# Wire EDM Hybrid for Thin Slots

Export PowerMill geometry to wire EDM for features better suited: thin slots, sharp corners, hardened inserts. Define wire start holes, drill during milling setup. Coordinate WCS. Use each process where it excels. Hybrid reduces total lead time 20-30% on complex mold tools.
