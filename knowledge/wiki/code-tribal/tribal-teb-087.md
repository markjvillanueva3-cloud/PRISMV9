# Boundary Management with Boolean Operations

Create boundaries from: surface edges, silhouette projections, user sketches, or automatic steep/shallow detection. Chain multiple boundaries with Boolean operations (union, intersection, subtraction). Add 0.5mm extension to boundaries to prevent tool marks at edges. Store boundaries in named sets for reuse across operations. Boundary-based selective machining reduces cycle time by 20-40%.
