# Open Pocket Strategy for Parts with Accessible Sides

For pockets with one or more open sides, SURFCAM's open pocket strategy allows the tool to enter from the open side rather than plunging or ramping. This eliminates entry time and enables aggressive first passes. Set the approach distance to 1.5x tool diameter beyond the open edge. Use zigzag pattern parallel to the open side for fastest cycle time. Reduce the last-pass stepover to 40% for consistent wall finish on the closed sides.
