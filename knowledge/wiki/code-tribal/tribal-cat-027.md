# Multi-Axis Helical for Through-Bore and Port Finishing

Use CATIA Multi-Axis Helical machining for angled ports, through-bores, and pipe intersections where the tool axis must follow the bore centerline. Define the helix axis along the bore center curve and set the pitch to achieve the desired stepover. For intersecting ports, split the operation at the intersection point and use separate helical operations for each branch to avoid tool axis discontinuities that cause jerky machine motion.
