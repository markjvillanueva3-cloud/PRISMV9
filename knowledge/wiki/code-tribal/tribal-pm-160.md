# Sensitivity Ranking for Optimization Focus

Vary each parameter ±10%: step-over (35% of Ra variation), feed (25%), speed (20%), DOC (15%), runout (5%). Top 2 account for 60%. For PowerMill finishing, step-over selection is the #1 decision for quality. Feed is #2. Speed and DOC are secondary. Focus optimization effort on step-over and feed — diminishing returns on the rest.
