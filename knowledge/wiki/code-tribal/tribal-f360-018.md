# VS Code Extension for Post Processor Editing

Install the Fusion 360 Post Processor Extension for Visual Studio Code to edit post processor files (.cps). It provides syntax highlighting, function navigation, and the ability to identify specific NC output sections quickly. Posts are written in JavaScript — focus on the onSection(), onLinear(), onCircular(), and onCommand() functions to customize tool change sequences, coolant codes, and axis output.
