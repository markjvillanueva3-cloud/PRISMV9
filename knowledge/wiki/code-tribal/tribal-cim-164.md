# Volumetric Accuracy Compensation for Large Dies

Import machine 21-error map, Cimatron adjusts coordinates. For large dies (1m+) where errors compound. Improves ±0.03mm to ±0.01mm. Requires periodic calibration. Especially valuable for automotive dies where dimensional accuracy over long distances is critical.
