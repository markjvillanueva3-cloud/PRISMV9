# Tool String display shows complete tool stack for quick visual verification

Mastercam's Tool String view in the Operations Manager displays the complete tool stack (spindle, holder, extension, cutter) as a scaled cross-section next to each operation. Use this to quickly verify that tool assemblies are correct before running simulation. A mismatched holder (e.g., CAT50 instead of CAT40) is immediately visible in the Tool String. Enable Tool String display by right-clicking the Operations Manager header and selecting Show Tool String. This 2-second visual check prevents the most common simulation-vs-reality discrepancies.
