# PowerMill Macros for Automated Workflows

PowerMill's macro system records and plays back sequences of operations. Write macros to: auto-generate standard roughing-to-finishing sequences, batch post-process multiple toolpaths, or apply templates to part families. Macros use PowerMill's command language — variables, loops, and conditionals are supported. Store macros in the 'Macro' folder for project-wide access. Use 'EDIT MACRO' to debug.
