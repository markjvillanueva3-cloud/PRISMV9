# iMachining Material Level Calibration

Start at level 4 (moderate) for new materials. If spindle load <30%: increase to 5-6. If vibration: decrease to 3. After 5 parts, the level is calibrated. Document level per material in SolidCAM tool database. Levels are machine-specific — recalibrate when moving programs between machines.
