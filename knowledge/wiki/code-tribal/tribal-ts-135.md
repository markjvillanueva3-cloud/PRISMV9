# TopSolid'Design Fixture Design — CAD and CAM in One Environment

Design custom fixtures directly in TopSolid'Design and immediately use them as collision bodies in TopSolid'Cam. The fixture design references the part geometry, so when the part changes, the fixture updates parametrically. This eliminates the fixture design → export → import → register workflow. For production fixtures, design the fixture, program the fixture machining in TopSolid'Cam, then use the finished fixture model in the part's machining simulation — all in one integrated environment.
