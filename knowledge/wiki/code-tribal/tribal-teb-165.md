# Helical Milling for Hardened Steel Holes

Circular interpolation + Z-feed. One tool for multiple sizes. Lower forces (no chisel edge), no burr, better evacuation. Flat-end 60-70% of hole diameter, pitch 0.3-0.5mm. Superior to drilling in hardened steel where drills wander. Tebis helical operation handles geometry automatically.
