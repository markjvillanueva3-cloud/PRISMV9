# Polishing-Ready Surface Quality from Machining

Achieve Ra 0.4-0.8μm directly from machining to minimize manual polishing. Key factors: (1) step-over based on target Ra using scallop formula, (2) constant scallop mode for uniform quality, (3) sharp tools (< 50% of life), (4) proper lead/lean angles for ball-end, (5) air blast only for hardened steel. This reduces polishing time by 50-70% on mold cavity surfaces, saving 20-40 hours per mold.
