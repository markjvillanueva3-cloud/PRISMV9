# Setup sheet creation in Mastercam documents fixture, tool, and origin information for operators

Mastercam can generate setup sheets that document everything the machine operator needs: fixture orientation and clamping diagram, work coordinate origin location, tool list with holder assemblies, operation sequence with estimated cycle times, and critical dimension callouts. Access Setup Sheet from the Toolpath Manager right-click menu. Customize the template to include your shop logo, machine name, and job number fields. For multi-setup parts, generate one setup sheet per Machine Group. Include photos or screenshots of the fixture setup (use Mastercam's screen capture and paste into the setup sheet). A well-constructed setup sheet reduces setup time by 20–40% and prevents the most common operator errors: wrong tool in wrong position, incorrect work offset, and wrong fixture orientation. Store setup sheets with the NC program files for complete job documentation.
