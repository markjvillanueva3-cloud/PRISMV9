# Electrode Machining Workflow

hyperMILL electrode module: extract geometry from cavity, define blank/holder (EROWA/3R), program rough/finish. Undersizing: roughing 0.3mm, finishing 0.05mm/side. Graphite: no coolant, vacuum extraction. Copper: flood coolant. Program datum pads for CMM. hyperMILL tracks undersizing per electrode type automatically.
