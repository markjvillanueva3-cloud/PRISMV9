# Steep and Shallow Automatic Strategy Assignment

Cimatron automatically detects steep (>65°) and shallow (<65°) regions and assigns Z-level or raster/3D-offset finishing respectively. Set threshold angle. Enable boundary overlap at 1-2mm to eliminate transition witness lines. Use the same ball-end mill for both passes to avoid tool-change marks. This automation reduces programming time by 30-40% for complex cavity finishing.
