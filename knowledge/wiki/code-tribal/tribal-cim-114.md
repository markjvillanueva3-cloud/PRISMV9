# Taylor Tool Life for Economic Cutting Speed

Taylor: VT^n = C. Economic speed V_econ = C / (((1/n)-1) × (Ct/Cm + tc))^n where Ct = tool cost, Cm = machine rate, tc = change time. V_econ typically 70-80% of max productivity speed. For expensive mold tools, use V_econ to maximize tool life and minimize risk of in-cut failure. Longer tool life reduces interruptions on unattended night-shift mold machining.
