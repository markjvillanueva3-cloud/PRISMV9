# Gamma Process for Monotonic Wear Degradation

Tool wear is monotonically increasing — Gamma process prevents physically impossible 'negative wear' that Wiener can produce. RUL = first passage time to threshold with Gamma distribution. Better for Cimatron unattended mold finishing where conservative life prediction prevents expensive failures.
