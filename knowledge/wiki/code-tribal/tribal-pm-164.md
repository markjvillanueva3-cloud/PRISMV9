# BMA for Robust Tool Life Prediction

Weight multiple models (Taylor/Archard/empirical) by posterior probability. P(y|data) = ΣP(y|M_k)P(M_k|data). More robust than single model. For PowerMill when machining diverse materials where no single model fits all conditions.
