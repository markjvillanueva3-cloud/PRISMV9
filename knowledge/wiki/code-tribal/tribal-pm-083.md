# Surface Finish Variance from Tool Wear Progression

Surface finish degrades progressively with tool wear. Fresh tool: Ra 0.4μm → mid-life: Ra 0.6μm → near-replacement: Ra 1.0μm. This 2.5:1 variance means specifying Ra 0.8μm requires starting at 0.4μm. Track Ra vs. tool usage time to build wear-finish curves per tool/material pair. Replace tools when Ra exceeds 70% of the tolerance — this accounts for measurement uncertainty (±0.1μm typical).
