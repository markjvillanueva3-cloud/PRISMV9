# Contour Turning Combines Roughing and Finishing in One Profile

CATIA Contour Turning traces the complete part profile in a single pass, making it ideal for finishing operations. Define the profile as a continuous 2D contour from the start point to the end point. CATIA handles both external and internal profiles, automatically managing clearance moves at shoulders and undercuts. For parts with alternating diameters and faces, contour turning is 20-30% faster than separate longitudinal and facing operations because it eliminates tool change and positioning time.
