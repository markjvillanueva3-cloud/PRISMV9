# Feature Recognition for Hole Automation

PowerMill recognizes holes: through, blind, countersink, counterbore, tapped. Assign drilling strategies in batch. Tolerance 0.01mm. Sort by diameter for tool changes. Canned cycles: G81 through, G83 peck, G84 tapping. Review — filleted pockets occasionally misidentified. Batch processing of 50+ holes saves significant programming time on complex fixture plates.
