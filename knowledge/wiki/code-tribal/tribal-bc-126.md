# Artistic Machining with Relief Model Compositing

BobART supports model compositing: combine multiple relief components (text, logos, borders, textures) into a single design. Each component can be positioned, scaled, rotated, and blended independently. Use 'Add', 'Subtract', 'Merge High', and 'Merge Low' operations to combine reliefs. Save components as STL for reuse across projects. This is particularly powerful for custom woodworking, jewelry, and mold making where multiple design elements are layered.
