# SURFCAM 2023 Operation Manager Replaces Traditional Operation List

The Operation Manager in SURFCAM 2023 provides drag-and-drop reordering, copy/paste of operations with parameter inheritance, and operation grouping by setup. Traditional's flat operation list required manual reordering via move-up/move-down buttons. In 2023, right-click an operation group to apply bulk parameter changes (e.g., change all roughing feeds simultaneously). Use operation templates to standardize recurring setups across part families.
