# Disc Cutter for Slot Machining

Define disc cutters with correct geometry: disc diameter, thickness, bore, tooth count. Use 3+2 positioning per slot. Speed based on outer diameter. Feed per tooth accounts for large tooth count (20-60). Flood coolant for chip evacuation. Disc cutters are preferred for mold runner slots where consistent width is critical — milling with end mills tends to produce tapered slots.
