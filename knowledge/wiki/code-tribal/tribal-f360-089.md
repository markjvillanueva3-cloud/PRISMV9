# Tool Holder Modeling with Accurate Shoulder Geometry

When creating tool assemblies in the Tool Library, model the holder shoulder (the widest part where the collet nut or shrink-fit body flares out) with exact dimensions from the manufacturer datasheet. This shoulder is the most common collision point. Include the pull stud/retention knob length in the overall holder length. For ER collet chucks, the nut diameter is typically 3-5mm larger than the body — model this step explicitly rather than using a smooth taper approximation.
