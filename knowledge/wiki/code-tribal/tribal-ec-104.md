# Titanium Machining with Strict Engagement Control

Titanium (Ti-6Al-4V) in Edgecam requires strict engagement control. Use Waveform with 10-15% radial engagement, 1x diameter axial depth, and consistent chip load of 0.05-0.1mm/tooth. Surface speed: 40-80 m/min carbide, 150-250 m/min ceramic (roughing only). High-pressure coolant (50-70 bar) is essential. Never let the tool dwell — always maintain feed to prevent work hardening. Use climb milling exclusively.
