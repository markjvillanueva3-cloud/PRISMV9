# Knowledge Base Template Parts for Family-of-Parts Programming

For families of similar parts (different sizes, same features), create ESPRIT KB template parts with parametric operations. Define a master program where dimensions, tools, and parameters reference variables rather than fixed values. When a new family member arrives, input the variant dimensions in the KB parameter table — ESPRIT regenerates all operations, recalculates toolpaths, and produces the NC program automatically. This is especially powerful for valve bodies, pipe fittings, bearing housings, and other parametric families. A single template can cover 10-50 size variants, eliminating per-variant programming entirely.
