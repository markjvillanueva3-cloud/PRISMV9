# Thickness Allowance Progressive Strategy

Roughing 0.5mm, semi 0.15mm, finish 0.0mm. Hardened: 0.3→0.15→0.05→0.0mm. Each removes only its layer. Extends tool life 40-60% vs 2-pass. Tebis stock model tracks actual remaining material accurately between operations in the progressive sequence.
