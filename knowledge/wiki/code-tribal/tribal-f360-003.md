# Adaptive Clearing Smoothing Reduces Air Cutting

Enable Smoothing in Adaptive Clearing to reduce unnecessary Z-axis retracts between passes. This keeps the tool closer to the stock and eliminates rapid up-down-up motions that waste cycle time. On deep pockets this alone can cut 10-20% off machining time by minimizing non-cutting travel.
