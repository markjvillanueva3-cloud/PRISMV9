# Feature-Driven Machining Auto-Recognizes Machinable Shapes

TopSolid's automatic feature recognition (AFR) scans imported STEP/IGES models and identifies holes, pockets, facing zones, and contouring regions. Each recognized feature is automatically assigned appropriate machining operations based on machine capability limits. Review the AFR results in the Feature Tree and manually override only where the automatic assignment is suboptimal. This can cut initial programming time from hours to minutes for prismatic parts.
