# Post Processor Customization with Built-In Editor

BobCAD's post processor system includes a built-in editor for customizing NC output. Edit the post to match your controller's format: program header, tool change sequence, coordinate format, and program end. BobCAD uses a template-based system where the post defines output patterns for each toolpath element. Always backup working posts before editing. Test post changes with a simple test program before applying to production parts.
