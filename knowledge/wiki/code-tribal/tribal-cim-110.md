# DOE Factorial Design for Parameter Optimization

2³ factorial DOE: speed, feed, DOC (low/high). Responses: Ra, cycle time, tool wear rate. Analyze main effects and interactions. Speed×feed typically dominates finish, DOC×feed governs tool life. Optimal point is in the design space interior, not at extremes. Cimatron NC Templates generate toolpath variants for each DOE run efficiently.
