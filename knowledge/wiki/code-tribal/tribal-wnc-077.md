# Cutting Data Database Stores Material-Specific Parameters

WorkNC's cutting data database stores speeds, feeds, depths, and stepovers per material type for each tool. When assigning a tool and specifying the workpiece material, the system auto-populates recommended parameters. Maintain these from manufacturer data and shop-floor experience. Create material groups (mild steel, stainless, aluminum, titanium, Inconel) with sub-grades for precise parameter selection.
