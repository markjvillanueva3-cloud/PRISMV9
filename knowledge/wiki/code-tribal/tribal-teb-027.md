# Blank Geometry Definition Matches Raw Material Shape

Define the roughing blank geometry accurately in Tebis — box, cylinder, or imported STL for near-net-shape parts (castings, forgings). For box blanks, set dimensions to the actual raw stock with 1-2mm extra per side. For castings, import the as-cast shape as STL and use it as the stock model. Accurate blank definition eliminates air cuts in the first roughing pass and can save 10-40% of roughing time on near-net-shape parts.
