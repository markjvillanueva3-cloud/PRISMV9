# Spiral Finishing for Flat-Bottomed Pockets

For flat or near-flat pocket floors, spiral finishing produces superior surface quality versus raster. The continuous spiral motion eliminates direction changes that leave witness marks. Set step-over for target scallop height. Use climb milling direction for best finish on aluminum and pre-hardened steel. SprutCAM's spiral auto-computes the center start point and expands outward to the boundary.
