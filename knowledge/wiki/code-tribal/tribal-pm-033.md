# Steep and Shallow Finishing with Automatic Boundary

PowerMill's automatic steep/shallow boundary detection splits finishing into Z-level (steep) and raster/3D-offset (shallow). Set threshold angle to 65-70°. Enable 'Boundary Overlap' at 1-2mm to eliminate the transition witness line. For best results, use the same ball-end mill for both passes to avoid tool-change marks at the boundary.
