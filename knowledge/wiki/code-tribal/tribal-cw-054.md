# 5-Axis Roughing — Plunge and Adaptive Strategies for Deep Cavities

CAMWorks 5-axis roughing offers plunge roughing (drilling-like Z-axis motion), adaptive roughing (constant-engagement lateral motion), and multi-cut roughing (waterline with variable axis). Plunge roughing is preferred for deep cavities with poor tool accessibility — the tool loads axially (strongest direction) rather than radially. Use plunge roughing with insert drills or indexable plunge mills for 3-5x faster stock removal than lateral roughing in deep pockets (L/D > 4).
