# Renewal Theory for iMachining Replacement

C(T) = (Cp + Cf×F(T)) / (T×R(T) + M×F(T)). iMachining extends T (tool life) — optimal replacement interval is longer. But Cf doesn't change. Net effect: fewer replacements per batch. Track cost-per-part including iMachining license amortization.
