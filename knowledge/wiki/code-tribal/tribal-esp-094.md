# Tool Assembly 3D Models for Simulation Accuracy

Import or create 3D models for every tool assembly used in your ESPRIT programs. This includes the cutter profile, holder envelope, collet nut, pull stud, and any extensions. Use manufacturer-provided STEP files when available. For custom tool assemblies, model the critical dimensions (minimum neck diameter, maximum holder diameter, total gauge length) — these determine collision clearance in simulation. A library of 200-300 modeled assemblies covers most shops' needs.
