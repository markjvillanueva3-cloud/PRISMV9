# Die Face Design Tools Prepare Stamping Die Surfaces

For stamping dies, use Tebis die face design to create addendum surfaces, binder wrap, draw beads, and trim lines. The morphing function compensates for springback by over-bending surfaces based on simulation results. Import springback data as a point cloud and use surface morphing to offset the die surface inversely. Typical springback compensation is 0.5-2.0mm depending on material and bend radius.
