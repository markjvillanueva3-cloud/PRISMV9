# Feature Recognition Auto-Detects Machinable Geometry

CATIA Feature Recognition scans the part geometry and automatically identifies machinable features: holes (through, blind, countersunk), pockets (open, closed), slots, steps, and bosses. Each recognized feature carries manufacturing semantics (depth, tolerance, surface finish) that feed into the machining operation assignment. Enable 'Deep Feature Recognition' to detect compound features like counterbored holes and T-slots. Review the recognition results carefully — complex fillets and chamfers may not be recognized correctly.
