# Tool Deflection δ = FL³/3EI Compensation

Cantilever: δ = FL³/(3EI), E=580 GPa (carbide), I=πd⁴/64. For 6mm ball at 40mm overhang, 50N: δ=0.009mm. PowerMill can apply deflection compensation by offsetting tool position. Critical for finishing deep cavities with long-reach tools. Halving overhang reduces deflection 8×. Doubling diameter reduces it 16×. Always prefer shorter, larger tools.
