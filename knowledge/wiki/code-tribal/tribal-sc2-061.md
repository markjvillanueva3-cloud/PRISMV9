# Slug Management with Tab and Bridge Strategies

SURFCAM Wire EDM supports tab (bridge) strategies to prevent slugs from falling during cutting. Program 2-4 tabs per slug, positioned at the widest points of the profile. Tab width should be 0.3-0.5mm — narrow enough to break off easily but wide enough to hold the slug securely during cutting. After all profiles are cut, return to each tab location for a cleanup pass that removes the tab material. Order tabs to minimize wire threading operations.
