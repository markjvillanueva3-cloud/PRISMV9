# Constant Scallop for Freeform, Fixed for Prismatic

Constant scallop on turbine blades, fairings (20-30% shorter). Fixed step-over on brackets, fittings (simpler). NX supports both per operation. Combine in same program for mixed geometry aerospace parts.
