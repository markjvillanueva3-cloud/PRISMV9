# FMEA Integration with NC Operations

Link Process FMEA to Cimatron operations. For each: identify failure modes (tool breakage, dimension drift, surface defects), effects (scrap, rework), assign RPN = Severity × Occurrence × Detection. High-RPN operations: add probing, reduce tool life limits, add redundant finishing. Automotive OEMs require FMEA linkage for APQP (Advanced Product Quality Planning).
