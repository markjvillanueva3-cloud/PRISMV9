# Tolerance Settings by Operation Purpose

Roughing 0.1mm (speed), semi 0.02mm, finishing 0.005-0.01mm (quality). Chord error control. Modern controllers handle high density. For hardened finishing: 0.005mm tolerance + 0.01mm step-over = polishing-ready. Don't over-relax finishing tolerance — it's the primary quality driver.
