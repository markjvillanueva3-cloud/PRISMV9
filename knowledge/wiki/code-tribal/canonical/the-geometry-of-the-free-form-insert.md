## Question

How do I the geometry of the free form insert?

## Answer

the geometry of the free form insert.: On the Tool holder tab, select the New tool holder function from the shortcut menu. → Under Type, select Internal for turning tools for inside machining or External for turning tools for → Specify a Name and optionally a Comment for the tool holder.
