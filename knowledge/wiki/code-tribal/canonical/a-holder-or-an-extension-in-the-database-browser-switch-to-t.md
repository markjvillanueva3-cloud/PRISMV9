## Question

How do I : in the database browser, switch to the holder /?

## Answer

a holder or an extension:: In the database browser, switch to the Holder / Extension tab. → Select the database entry you require and then select New Holder / New Extension. → Give the Holder / Extension in the data view a unique Name and select a Measurement system.
