## Question

How do I : in the browser, switch to the nc tool tab?

## Answer

an NC tool:: In the browser, switch to the NC tool tab. → Choose the database, right-click and select New → NC-Tool from existing tool... . → Select the tool you require in the Select tool dialogue and click OK to confirm.
