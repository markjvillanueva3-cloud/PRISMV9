# Plunge Roughing for Deep Narrow Slots and Ribs

For deep narrow features where radial engagement would cause tool deflection, TopSolid's plunge roughing drives the tool axially into the workpiece in a drilling-like motion, then steps over laterally. This leverages the tool's strongest axis (axial) and minimizes deflection. Set the plunge stepover to 60-75% of cutter diameter and the plunge feed to 50% of drilling feed. Particularly effective for titanium and Inconel ribs with depth-to-width ratios exceeding 4:1.
