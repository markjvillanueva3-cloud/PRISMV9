# Machining Templates Standardize Processes

WorkNC's machining templates capture complete process sequences: operation order, tool assignments, cutting parameters, and linking strategies. Create templates for common part families. Templates can include conditional logic for different feature sizes. Store and share templates across the organization for consistent quality. This can reduce programming time by 60-80% for recurring part types.
