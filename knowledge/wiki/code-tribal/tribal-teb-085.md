# Tebis Viewer for Shop Floor NC Program Review

Tebis Viewer is a free read-only application for the shop floor. Operators can: view 3D models, rotate/zoom/measure, review tool lists, and play back toolpath simulations without a full Tebis license. Install on shop floor PCs near each machine. This replaces paper setup sheets and allows operators to verify details before running programs. Viewer updates when new programs are posted.
