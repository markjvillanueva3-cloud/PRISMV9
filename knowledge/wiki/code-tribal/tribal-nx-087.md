# Template-Driven Automation with Drag-and-Drop Operation Sets

NX supports drag-and-drop deployment of pre-configured operation sets from the Manufacturing Wizard onto part features. Create operation sets that include roughing, semi-finishing, finishing, and inspection in a single template group. The template includes relative tool sizing rules (roughing tool = 60% of pocket width) so it scales to different feature sizes. Drop the template onto the geometry group and NX instantiates all operations with scaled parameters in under 10 seconds.
