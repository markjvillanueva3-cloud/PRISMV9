# Thickness Allowance Strategy

Progressive: roughing 0.5mm, semi-finish 0.15mm, finish 0.0mm. For hardened steel: 0.3→0.15→0.05→0.0mm. Each operation removes only its layer. Extends tool life 40-60% vs 2-pass strategies. PowerMill stock model tracks actual remaining material accurately between operations for optimal rest machining calculations.
