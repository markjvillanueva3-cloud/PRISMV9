# Machine Tool Simulation with Full Kinematic Model

PowerMill's machine tool simulation uses the complete kinematic chain for collision detection. Import the machine model from Autodesk's library or create custom machines. Define: spindle nose, tool holder, rotary table, fixtures, and tailstock. Run simulation at 'Full Machine' mode for 5-axis operations — this catches collisions that ViewMill alone cannot detect (head/table interference).
