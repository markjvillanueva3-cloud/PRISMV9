# Steep and Shallow Combines Two Strategies Automatically

Steep and Shallow finishing creates a single toolpath that intelligently combines Contour passes for steep walls with Parallel or Scallop passes for shallow regions. Set the threshold angle (typically 45-60 degrees) to control where Fusion transitions between strategies. This eliminates the need to manually split finishing into separate contour and parallel operations.
