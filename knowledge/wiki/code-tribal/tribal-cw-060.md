# Sheet Metal Machining — Program Flat Pattern Features Before Bending

For SOLIDWORKS sheet metal parts, machine features in the flat state before bending whenever possible. CAMWorks can work with both the folded and flat pattern configurations. Program hole patterns, tabs, and notches on the flat pattern configuration — these features are fully accessible for 3-axis machining. Only program features that must be added post-bending (mating surfaces, alignment holes) on the folded configuration.
