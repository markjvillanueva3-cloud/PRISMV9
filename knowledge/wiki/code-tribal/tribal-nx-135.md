# Inspection Programming with CMM Integration

NX's CMM Inspection Programming creates inspection paths for CMMs directly from the CAD model. Define measurement points on critical features, set approach vectors, and generate DMIS output. Use GD&T callouts from the model to automatically determine measurement strategy. Integration with Teamcenter links inspection results back to the manufacturing process for traceability.
