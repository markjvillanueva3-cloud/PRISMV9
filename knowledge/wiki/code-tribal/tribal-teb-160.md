# Dimensional Invariant Checks for Process Validation

Validate machining physics using dimensional invariants: cutting power P = Fc × Vc (must equal spindle power draw), specific energy u = P/(MRR), and chip ratio rc = chip_thickness/uncut_thickness. If measured values deviate >20% from predictions, the process has a problem (tool wear, incorrect parameters, fixture compliance). Use these checks as go/no-go validation for new Tebis programs.
