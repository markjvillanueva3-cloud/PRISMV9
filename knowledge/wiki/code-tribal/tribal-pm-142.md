# OEE from PowerMill Manufacturing Data

OEE = Availability × Performance × Quality. Availability: machine uptime/scheduled. Performance: PowerMill estimated vs actual feed rates. Quality: CMM pass/fail linked to program versions. Typical PowerMill cells: 75-85% OEE. Gap analysis between theoretical and actual reveals: slow rapids (Performance), excessive tool changes (Availability), or parameter drift (Quality).
