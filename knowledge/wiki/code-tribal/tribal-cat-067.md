# Catalog Setup for Standardized Tool and Operation Libraries

Set up CATIA Design Catalogs (*.catalog files) for standardized tool libraries and machining operation templates. Use the Catalog Editor to organize items into families with keywords and preview images. Configure catalog search paths in the CATIA settings (Tools → Options → Machining → Output) so all programmers access the same libraries. Version the catalogs using the chapter/revision system so updates propagate without breaking existing Manufacturing Programs that reference the old catalog entries.
