# Boring Cycle with Spring Pass

Finish boring: advance to depth, 0.5s dwell, orient spindle (G76), retract at shifted position to avoid drag mark. For IT6-IT7 precision. Compensate boring bar deflection FL³/3EI in tool offset. SprutCAM programs G76 orient-retract sequence automatically.
