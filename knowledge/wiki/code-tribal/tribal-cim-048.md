# Robust Design for Variable Material Hardness

P20 steel hardness varies ±2 HRC across a single block (28-34 HRC typical range). Design the machining process to be robust against this variation: use Taguchi methods to find feed/speed combinations where surface finish is insensitive to hardness changes. Typically, moderate speeds (120-150 m/min) with consistent chip load (0.08mm/tooth) produce the most stable results across the hardness range.
