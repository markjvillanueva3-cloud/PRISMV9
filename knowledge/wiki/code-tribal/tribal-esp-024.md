# ProfitTurning Chip Breaking for Stringy Materials

Enable ProfitTurning's automatic chip breaking for materials that produce long, stringy chips (austenitic stainless, low-carbon steel, aluminum). The system periodically interrupts the feed to create a momentary break in chip formation. Set the chip break interval based on material: 5-10mm for stainless, 8-15mm for mild steel. This prevents chip wrapping around the workpiece or tool holder that can cause surface damage and tool breakage.
