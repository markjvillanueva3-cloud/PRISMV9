# Geodesic Finishing for Uniform Surface Coverage

Geodesic finishing follows the shortest path along the surface (geodesic curves), producing uniform tool contact patterns regardless of surface parameterization. Unlike raster, geodesic adapts to curvature naturally. Set step-over based on target scallop height. Tebis computes geodesic paths numerically — best for doubly-curved surfaces where raster produces inconsistent scallop height.
