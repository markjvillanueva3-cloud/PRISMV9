# Flowline Finishing for Complex Freeform Surfaces

Flowline finishing follows user-defined flow curves across surfaces. Define start and end boundary curves — Cimatron interpolates intermediate toolpath lines between them. Ideal for surfaces where the tool should follow the natural geometric flow. Step-over measured perpendicular to the flow direction for uniform scallop. Use for automotive exterior surfaces and aerodynamic components.
