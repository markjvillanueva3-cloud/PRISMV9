# Split Line Machining for Multi-Component Molds

TopSolid manages split lines where mold components (sliders, lifters, core pins) meet the main core or cavity. These interfaces require precision-matched machining to prevent flash and misalignment. Program split line surfaces as dedicated finishing operations with matched tool paths that ensure consistent quality across mating components. Use the same tool, strategy, and tolerance for both halves of a split line to minimize mismatch.
