# TopSolid'Cam 7 Automatic Fixture Selection from Catalog

TopSolid'Cam 7 includes a fixture catalog (vises, clamps, step blocks, parallels) that can be placed on the machine table and included in collision checking. Select the workholding type, input the part dimensions, and TopSolid proposes compatible fixtures from the catalog. The fixture components become collision avoidance bodies in the simulation. For production shops, populate the catalog with your actual inventory — brand, model, jaw widths, and clamping ranges. This prevents programming toolpaths that collide with real fixtures.
