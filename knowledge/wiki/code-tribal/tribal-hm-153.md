# Kienzle Force Model for Verification

Fc = kc1.1 × b × h^(1-mc). Verify against spindle rating. If Fc > 50% rated torque, reduce DOC or feed. For MAXX barrel cutters, the wider engagement produces higher total force than ball-end at the same scallop height — verify spindle capacity specifically for barrel cutter operations.
