# Merchant Shear Angle for Chip Formation Analysis

Merchant model: tan(2φ) = 1 - (2τs)/(σn × sin(2(φ+β-α))) where φ = shear angle, β = friction angle, α = rake angle. Higher shear angle = thinner chips = lower forces = better surface finish. Use this to understand why certain tool geometries work better: higher positive rake → higher shear angle → better results. Validates Tebis tool selection for difficult materials.
