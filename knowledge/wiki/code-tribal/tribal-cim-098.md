# Spiral Finishing for Flat Pocket Floors

For flat/near-flat pocket floors, spiral finishing produces superior quality vs raster. Continuous spiral motion eliminates direction changes that leave witness marks. Set step-over for target scallop. Use climb milling direction. Cimatron spiral computes center start point and expands to boundary automatically. Best for visible flat surfaces on consumer product molds.
