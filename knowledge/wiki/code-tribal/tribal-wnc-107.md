# Parametric Machining Adapts to Dimension Changes

WorkNC's parametric machining links operations to model dimensions. When part dimensions change, machining parameters update automatically: Z-levels, tool lengths, stepovers. This ensures programs remain valid across part family variations. Define parameter links using formulas that calculate operation values from geometry dimensions.
