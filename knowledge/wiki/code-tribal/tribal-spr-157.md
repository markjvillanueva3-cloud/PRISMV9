# Tolerance Settings by Operation

Roughing 0.1mm, semi-finish 0.02mm, finishing 0.005-0.01mm. Controls chord error. Tighter = more points = smoother but larger files. Modern controllers handle high density. For hardened steel finishing: 0.005mm with 0.01mm step-over for polish-ready results.
