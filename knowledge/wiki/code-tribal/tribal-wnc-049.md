# Feed Optimization Analyzes Stock for Speed Adjustment

WorkNC's feed optimization module analyzes the instantaneous stock engagement along the entire toolpath and generates a feed-rate profile. Air cuts are accelerated to rapid, light engagement zones run at maximum feed, and heavy engagement zones are slowed to protect the tool. This can reduce cycle time by 15-30% without increasing tool load. Set maximum and minimum feed limits based on the tool manufacturer's recommendations.
