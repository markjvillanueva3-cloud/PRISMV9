# Multi-Cavity Copy with Simulation Verify

Program one cavity, copy to all positions. PowerMill adjusts WCS and rapids per instance. Verify each in simulation — different orientations may need modified approach/retract. For identical cavities: 1/N effort. Critical to verify all instances, not just the first.
