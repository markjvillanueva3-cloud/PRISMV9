# Morph-Between-Curves Finishing for Ruled Surface Regions

Tebis morph finishing interpolates toolpath between two boundary curves, creating a smooth transition across the surface. Ideal for stamping die draw walls, addendum surfaces, and ruled regions. Define the top and bottom boundary curves and the system generates intermediate passes by morphing between them. Control the number of passes or set step-over. The resulting toolpath follows the draw direction, which is the preferred machining direction for die surfaces.
