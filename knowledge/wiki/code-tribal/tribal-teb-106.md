# SPC Control Charts for Critical Mold Dimensions

After establishing stable Tebis programs, implement SPC on critical dimensions. X-bar/R charts from first 25 parts establish control limits. Monitor for: trends (7 consecutive points = tool wear), shifts (fixture or WCS issue), increasing range (vibration onset). Re-qualify the program when any out-of-control signal is detected. SPC evidence is increasingly required by automotive OEMs.
