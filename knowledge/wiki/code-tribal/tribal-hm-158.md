# Sobol Sensitivity for MAXX Parameter Ranking

For MAXX Finishing: tilt angle (Si=0.30, STi=0.40), step-over (0.25/0.35), feed (0.20/0.28), speed (0.15/0.20). Tilt angle dominates — unique to barrel cutters. Tilt×step-over interaction (STi-Si gap) is large. Focus optimization on tilt angle first, then step-over. Speed is less sensitive than in ball-end finishing.
