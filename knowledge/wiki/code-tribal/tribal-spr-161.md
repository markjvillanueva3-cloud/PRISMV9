# Wiener Process for Stochastic Wear

dVB = μdt + σdW. Predict RUL distribution. Update from measurements. More accurate than deterministic Taylor for SprutCAM multi-operation programs. For turning: wear rate varies with diameter (speed changes). For robot machining: force variations increase σ.
