# Boundary Management and Selective Machining

Create boundaries from: surface edges, silhouette projections, user sketches, or automatic shallow/steep detection. Use 'Boundary Inside/Outside' to restrict machining to specific regions. Chain multiple boundaries with Boolean operations (union, intersection, subtraction). Add 0.5mm extension to boundaries to prevent tool marks at edges. Store boundaries in named sets for reuse across operations.
