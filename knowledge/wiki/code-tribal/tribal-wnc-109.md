# Standard Workflows Enforce Process Consistency

WorkNC's workflow system enforces consistent process sequences: stock definition, roughing, verification, semi-finishing, finishing, drilling, simulation, and posting. Mandatory checkpoints prevent skipping steps. This ensures every program follows shop standards regardless of programmer. Workflows can be customized per machine or part type.
