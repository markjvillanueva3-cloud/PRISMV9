# Surface inspection probing generates point cloud for GD&T verification on machine

Mastercam probing can measure a grid of points across a machined surface and compare them to the CAD nominal. This on-machine inspection identifies profile tolerance violations, flatness errors, and surface form deviations without removing the part from the fixture. Set probe point spacing to 2-5 mm for detailed surface maps or 10-20 mm for quick verification. The results can be output as a CSV file for SPC analysis. On-machine surface inspection catches warpage and deflection issues that single-point probing misses.
