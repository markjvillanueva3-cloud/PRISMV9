# Cusp Analysis — Predict Surface Finish Before Cutting

CAMWorks cusp analysis tool calculates and displays the expected surface finish (scallop height and Ra) at any point on the machined surface before cutting. Color-coded display shows areas meeting spec (green) vs. areas exceeding target roughness (red). Use this to identify problem areas that need additional passes, tighter step-over, or a different strategy. Run cusp analysis after generating finishing toolpaths and before committing to production — it costs zero cycle time and prevents rework.
