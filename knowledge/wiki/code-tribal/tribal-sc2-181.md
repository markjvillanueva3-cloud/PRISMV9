# SURFCAM High-Speed Helical Entry for Hardened Pockets

In hardened materials, plunge entry causes catastrophic tool failure. SURFCAM's helical entry ramps the tool into the material at a controlled helix angle (1-3° for >50 HRC). Set the helix diameter to 1.5-2.0x tool diameter and the ramp angle to 1-2° for best results. The helical motion distributes cutting forces across the full circumference of the tool rather than concentrating them on the tip. For blind pockets in hardened steel, always use helical entry — never plunge. Minimum pocket width for helical entry: 2.5x tool diameter.
