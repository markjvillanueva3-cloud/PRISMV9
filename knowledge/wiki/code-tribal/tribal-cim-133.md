# Coffin-Manson Thermal Fatigue for Insert Life

Thermal fatigue in interrupted cutting: Nf = C × (Δε)^(-β) where Δε = α×ΔT, β ≈ 2.0 for carbide. Large temperature swings (dry→flood) accelerate thermal cracking. For interrupted mold operations (island crossing, multiple pockets): commit fully to dry or continuous flood. Intermittent coolant halves insert life. This is the #1 cause of premature insert failure in mold roughing.
