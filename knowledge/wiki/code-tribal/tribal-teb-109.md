# Sensitivity Analysis for Parameter Prioritization

Vary each parameter ±10%, measure impact on surface finish and accuracy. Typical sensitivity ranking: step-over (35% of finish variation), feed rate (25%), cutting speed (20%), DOC (15%), tool runout (5%). Focus optimization on top 2 parameters — they account for 60% of variation. Tebis parameter sweep via NCJob copies generates comparison toolpaths efficiently.
