# NX Turning with FBM for Lathe Features

NX FBM recognizes turning-specific features (grooves, threads, bores, profiles) on rotational parts and generates complete turning operation sequences. The system assigns appropriate insert geometry (CNMG, DNMG, VNMG) and cutting parameters based on the Machining Knowledge Library. Review thread pitch and groove width tolerances in the generated operations before posting.
