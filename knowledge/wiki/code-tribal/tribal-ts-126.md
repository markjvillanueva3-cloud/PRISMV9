# TopSolid'Cam 7 Tool Assembly Builder — 3D Tool and Holder Stacks

Build complete tool assemblies in TopSolid by stacking holder components, extensions, collets, and cutting tools from the integrated catalog. The 3D assembly is used for collision checking during simulation, clearance verification in deep pockets, and automatic tool reach analysis. When a tool cannot reach a surface due to holder interference, TopSolid highlights the collision and suggests longer tools or alternative holders. Import manufacturer tool models (Sandvik, Kennametal) in STEP format and register them in the tool catalog for accurate collision detection.
