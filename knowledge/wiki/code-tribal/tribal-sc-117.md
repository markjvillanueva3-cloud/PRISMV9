# Solid Probe Quality Reporting — Export Measurement Data for Traceability

Configure Solid Probe to output measurement results in a structured format (CSV, XML, or controller variable block) for quality traceability. Each probe result should include: feature ID, nominal value, measured value, deviation, and pass/fail status. For ISO 9001 or AS9100 environments, this in-machine measurement data provides documented evidence of process control between CMM inspections. Store reports with part serial number and date stamp on a network share accessible to the quality department.
