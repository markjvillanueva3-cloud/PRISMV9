# Edgecam Designer Push-Pull Direct Modeling for Fixturing

Use Edgecam Designer's push-pull direct modeling to create fixture components without parametric history. Select a face and drag to extrude, or push to create pockets. Double-click edges to add fillets. This approach is 3-5x faster than parametric CAD for simple fixture plates, clamps, and soft jaws. Export as Parasolid for seamless transfer to the machining environment.
