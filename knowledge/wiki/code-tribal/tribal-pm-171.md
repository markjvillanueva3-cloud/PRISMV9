# Electrode Set Management for Complex Cavities

20-50 electrodes per complex cavity. Organize by burn area, then rough/finish. Name: PART-AREA-TYPE-SEQ. Setup sheets with burn positions, spark gaps, depth targets. Track status. PowerMill manages undersizing automatically. Optimize burn order via TSP for 15-30% EDM time savings.
