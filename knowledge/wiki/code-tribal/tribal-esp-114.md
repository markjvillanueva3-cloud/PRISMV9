# Composite Machining with Diamond Tooling

For CFRP and GFRP composites in ESPRIT, use PCD (polycrystalline diamond) or CVD diamond-coated tools at high speed (200-500 m/min) and low feed (0.02-0.05mm/tooth). Program down-milling (climb) to push fibers against the laminate rather than pulling them up, preventing delamination. Use compression routers (up-down cut geometry) for through-cutting to prevent both top and bottom ply delamination. ESPRIT's 5-axis trimming cycle is optimal for edge trimming composite panels.
