# MTConnect Data Integration for Process Monitoring

Connect NX-programmed machines via MTConnect for real-time process monitoring. Stream: spindle load, axis positions, feed override, coolant flow, and alarm states. Compare actual feed profiles against NX's programmed feeds to identify where the machine decelerates (typically corners and direction changes). Use this data to optimize NX's corner feed limits and motion smoothness settings.
