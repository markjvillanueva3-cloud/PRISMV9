# Robust Hardness Tolerance in Cutting Parameters

P20 varies ±2 HRC across a block (28-34). H13 varies ±1.5 HRC (48-52). Design Cimatron parameters tolerating full range: moderate speeds (120-160 m/min for P20) with consistent chip load produce stable results. Extreme high-speed parameters fail unpredictably at the hard end. Robust parameters sacrifice 10-15% theoretical MRR for process stability.
