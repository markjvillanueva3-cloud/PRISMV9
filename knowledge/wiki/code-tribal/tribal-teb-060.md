# 3+2 Axis Indexed Machining for Multi-Face Parts

3+2 axis (positional 5-axis) locks rotary axes at a fixed angle per operation. Tebis defines the indexed orientation for each face. Use 3+2 when simultaneous 5-axis isn't needed — it provides higher rigidity (locked axes), better accuracy, and simpler post-processing. Create separate operations per indexed angle with appropriate WCS offsets. Tebis auto-generates the rotary axis positioning commands.
