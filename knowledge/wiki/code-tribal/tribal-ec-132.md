# Edgecam Designer Stock Model Creation from Raw Material

Create accurate stock models in Edgecam Designer by starting with standard raw material shapes (round bar, rectangular billet, near-net forging). Use the 'Wrap' command to generate a minimum bounding stock from the finished part with user-defined offsets (typically 2-5mm per side). For castings, import the casting model directly as stock and use Boolean difference to define the machining envelope.
