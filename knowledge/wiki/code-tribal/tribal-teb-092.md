# Collision Checking with Complete Tool Assembly

For deep cavities, set collision detection to include: tool shank, holder body, holder taper, and spindle nose. Use shrink-fit holders for minimum profile. When standard tools can't reach, use extended-length tools with reduced parameters (50% feed at 7:1 L/D). Tebis gouge check verifies the finished surface — run after every finishing operation. Add 0.5mm safety margin to holder collision detection.
