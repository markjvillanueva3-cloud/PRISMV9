# VBM Face Selection for Prismatic Volumes

In Volume Based Machining, select 3D solid faces to define machining volumes instead of manually creating 2D boundaries. NX will compute cut levels and preview the in-process workpiece automatically, eliminating tedious boundary sketching. This works especially well on prismatic parts with stepped features, pockets, and bosses.
