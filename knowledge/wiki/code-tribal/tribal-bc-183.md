# BobART Relief Combination and Boolean Operations

BobART combines multiple relief models using Boolean operations: add (merge highest points), subtract (remove material), intersect, and blend. Use 'Add' to layer decorative elements on a base surface. Use 'Subtract' to create intaglio (recessed) designs. The 'Blend' operation creates smooth transitions between overlapping reliefs using a specified blend radius. For complex compositions (coin designs, medallions), build the relief in layers: background texture first, then border, then main design elements, each added with appropriate blend radii. Save intermediate compositions to prevent rework.
