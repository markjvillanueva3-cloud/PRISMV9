# Thickness Allowance for Progressive Machining

Roughing 0.5mm, semi 0.15mm, finish 0.0mm. Hardened: 0.3→0.15→0.05→0.0mm. Each removes only its layer. 40-60% longer tool life vs 2-pass. Cimatron IPW tracks stock accurately for optimal rest calculation between progressive passes.
