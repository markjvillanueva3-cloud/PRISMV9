# Merchant Shear Angle for Tool Selection

Higher positive rake → higher shear angle → thinner chips → lower forces → better finish. Rake increase from 0° to 10° reduces force ~15%. Use this to validate PowerMill tool selection: positive-rake geometry produces better results but weaker edges for interrupted cuts. For continuous cuts (offset area clear): maximize rake. For interrupted (rest machining): use stronger geometry.
