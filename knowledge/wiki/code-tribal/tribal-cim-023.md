# Die Quoting with Machining Time Estimation

Use Cimatron's Die Quoting module to estimate machining time before committing to a project. The estimator considers: part complexity, material hardness, number of electrodes, surface area, and deepest cavity depth. Calibrate the estimation factors against actual shop data — default values typically underestimate by 15-25% for complex multi-cavity molds.
