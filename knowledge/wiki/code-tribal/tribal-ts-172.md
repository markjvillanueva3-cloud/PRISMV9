# TopSolid Swiss-Type Thread Whirling — Bone Screw Manufacturing

TopSolid programs thread whirling for medical bone screws on Swiss-type machines. Thread whirling uses a ring of cutters rotating around the stationary (or slowly rotating) workpiece, generating the thread profile in a single pass at high speed. TopSolid defines the whirling parameters: ring RPM (typically 3,000-8,000), workpiece RPM (10-100 for pitch synchronization), thread form (buttress, V, ACME), and infeed depth. The process produces Ra < 0.8µm thread finish directly — no polishing required. Critical for Ti-6Al-4V and CoCr medical implants.
