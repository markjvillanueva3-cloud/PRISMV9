# Pareto Front for Quality-Throughput Trade-Off

Build Pareto front: vary step-over (0.1-0.5mm) and feed (0.03-0.10mm/tooth). Plot Ra vs cycle time. Pareto-optimal set = best achievable quality at each cycle time. Select based on job priority: tight-tolerance mold work → quality end, production dies → speed end. The front is tool/material/machine specific — build once per combination, reuse for all similar jobs.
