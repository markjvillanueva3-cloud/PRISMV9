# Gear Machining Cycles in SprutCAM

SprutCAM supports gear machining including hobbing, shaping, and power skiving. Define gear parameters (module, pressure angle, number of teeth, helix angle) and the system generates the tool-workpiece engagement path. For hobbing: set the hob advance rate based on module size. For power skiving: synchronize spindle and tool rotation speeds — even small sync errors cause tooth profile errors.
