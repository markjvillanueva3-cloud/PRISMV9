# Surface Compare for Freeform Deviation Mapping

After machining freeform surfaces, use Surface Inspection to probe a grid of points across the surface and compare them to the CAD model. Set the probe grid spacing to 2-5mm for high-resolution deviation maps on mold surfaces. Fusion generates a color-coded heat map showing point-by-point deviation from nominal. Export the report as a PDF or HTML for quality records. Areas exceeding tolerance can be re-machined with a targeted local finishing pass without re-running the entire operation.
