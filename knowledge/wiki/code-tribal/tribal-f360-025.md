# Simulation Timeline for Cycle Time Estimation

The simulation timeline shows cumulative machining time per operation. Use it to identify which operations consume the most cycle time, then optimize those first — adjust stepover, increase feed rate, or switch to Adaptive Clearing. Compare simulated cycle times against actual run times to calibrate your feed rate overrides and rapid traverse assumptions for future estimates.
