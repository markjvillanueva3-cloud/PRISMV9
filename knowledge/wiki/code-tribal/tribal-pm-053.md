# PowerMill Robot for 6-Axis Robotic Machining

PowerMill Robot programs 6-axis industrial robots for large-scale machining (trimming, drilling, polishing). Define the robot kinematic model, TCP (Tool Center Point), and external axes (track/positioner). Key differences from CNC: lower rigidity requires 30-50% reduced cutting parameters, and singularity zones must be mapped and avoided. Use 'Reachability Analysis' to verify all toolpath points are accessible.
