# Constant Scallop Height Finishing

Tebis constant scallop finishing automatically varies step-over based on local surface curvature to maintain uniform scallop height. Set target scallop (e.g., 0.005mm for polishing-ready). This produces 20-30% shorter cycle times than fixed step-over while maintaining uniform surface quality. Essential for mold surfaces where consistent polish quality is critical across varying curvature regions.
