# Custom Feature Templates — Teach AFR to Recognize Shop-Specific Geometry

When AFR misclassifies or misses proprietary features (e.g., custom O-ring grooves, non-standard keyways), create Interactive Feature Recognition (IFR) templates. Select faces that define the feature, assign a feature type, and save to TechDB. On subsequent parts with similar geometry, AFR will automatically detect and classify the custom feature. This is critical for shops with recurring proprietary part families.
