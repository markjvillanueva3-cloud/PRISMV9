# SOLIDWORKS Configurations — One Model, Multiple CAM Setups

Use SOLIDWORKS configurations to manage multiple machining scenarios for the same part. Create configurations for: different stock forms (bar vs casting vs forging), left-hand vs right-hand variants, and prototype vs production setups. Each configuration can have its own CAMWorks feature tree and operation plan. This is more efficient than separate files because all variants share the base geometry and TechDB knowledge, and design changes propagate to all configurations.
