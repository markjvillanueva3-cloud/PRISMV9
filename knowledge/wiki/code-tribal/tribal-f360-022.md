# GPU-Accelerated Stock Simulation for Fast Verification

Fusion's GPU-based stock simulation (introduced 2025) moves material removal calculations to the graphics card, completing simulations in seconds instead of minutes. Use Stock simulation mode to verify material removal visually — it shows remaining stock as a 3D model you can rotate and inspect. Always run this after generating toolpaths and before posting to catch gouges and missed material.
