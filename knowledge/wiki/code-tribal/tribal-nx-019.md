# Custom Feature Definitions for FBM

Add your own custom geometry configurations to the FBM feature libraries when the out-of-box recognizer doesn't cover your part family. Define the topology pattern once, associate it with a machining process, and NX will recognize and program that feature type on all future parts. This is especially valuable for recurring proprietary features.
