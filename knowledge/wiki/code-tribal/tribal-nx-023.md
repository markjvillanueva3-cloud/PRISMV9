# Post Builder Custom Commands for Shop Enforcement

Add custom warning messages in NX Post Builder to enforce programming standards. For example, trigger a warning if a programmer posts code without a tool-change retract, or if feed rate exceeds a machine-specific limit. Custom commands in the Event Handler can inspect operation data and inject warnings or modified output without altering the core post logic.
