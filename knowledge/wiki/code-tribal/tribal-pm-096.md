# Hertzian Contact Stress for Ball-End Selection

σ_max ∝ (F/R²)^(1/3). Larger ball = lower stress = longer life. Minimum ball diameter = 2×step-over/sin(max_slope). For H13 at 52 HRC: use 6mm ball minimum for step-over ≤0.3mm. This prevents high tip stress that causes premature CBN failure. PowerMill's tool selection should always verify Hertzian stress is within the coating's limit.
