# Operations from Templates for Rapid Programming

After creating and validating a set of operations for a common part family, save them as a Manufacturing Template. When a new part of the same family arrives, create a setup, apply the template, and Fusion generates all operations with the saved settings. The template adapts to new geometry — Adaptive Clearing follows the new pocket shape, contour follows the new profile. The programmer only needs to verify tool selection and adjust depths. This workflow reduces programming time by 60-80% for repeat part families.
