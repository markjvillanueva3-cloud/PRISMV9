# Prismatic Machining Multi-Pocket Recognition and Grouping

CATIA Prismatic Machining can automatically recognize multiple pockets of similar geometry using 'Design Feature Recognition'. Enable Auto Recognition in the Manufacturing Program to scan the part for prismatic features (pockets, slots, holes, bosses). Group similar features using 'Feature Grouping' — this creates a single machining operation applied to all instances, drastically reducing programming time for plate-type parts with dozens of identical pockets. The grouping respects Z-level variations, so pockets at different depths get separate tool path levels automatically.
