# Engraving and Artistic Machining

SprutCAM supports V-bit engraving, image-to-toolpath relief carving, and artistic machining. For V-bit engraving: set 'Flat Area' width for variable-depth text (deeper = wider). For relief carving: import grayscale images where brightness maps to depth. Use ball-end mills with 0.01-0.05mm step-over for photographic reliefs. Enable 'Smooth Path' to prevent faceted artifacts on curved surfaces.
