# Disc Cutter for Runner Slots

Disc cutters produce more consistent slot widths than end mills. Define geometry precisely. 3+2 positioning. Speed on outer diameter. High tooth count (20-60) means very low feed per tooth. Flood coolant. Preferred for mold runner slots where consistent width is critical for plastic flow.
