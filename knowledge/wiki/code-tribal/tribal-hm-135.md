# Steep-Shallow Automatic Strategy Assignment

hyperMILL auto-detects steep (>65°) and shallow (<65°) regions. Z-level for steep, raster/3D-offset for shallow. Overlap 1-2mm at boundaries. Same tool for both passes. Saves 30-40% programming time. hyperMILL's boundary detection is particularly robust on surfaces with varying curvature.
