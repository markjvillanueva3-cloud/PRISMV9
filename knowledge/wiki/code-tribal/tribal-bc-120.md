# Part Alignment Probing for Irregular Stock

For castings and forgings, BobCAD programs multi-point probing to measure datum features and compute best-fit alignment. Measures 6+ points and calculates optimal work offset and rotation (G68). Eliminates 30-60 minute manual indicating. Output computed rotation as coordinate system rotation. BobCAD's Machine Simulation PRO previews the complete probing sequence including probe approach, measurement, and retract moves for safety verification.
