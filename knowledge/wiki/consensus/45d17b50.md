**Quick checklist for a “not compacting” desktop UI**

| # | What to check | Why it matters |
|---|---------------|----------------|
| 1 | **Window size & layout constraints** | Ensure the main window is set to `pack()` (or equivalent) after adding all components. If you’re using a grid/box layout, verify that no component has a fixed minimum size larger than the container. |
| 2 | **Component preferred/minimum sizes** | Some widgets (e.g., text areas, tables) default to large sizes. Override with `setPreferredSize(new Dimension(0,0))` or use `setMinimumSize`. |
| 3 | **Layout manager choice** | A `BorderLayout` will stretch components; consider `GridBagLayout`, `BoxLayout`, or a nested layout that respects preferred sizes. |
| 4 | **Look‑and‑Feel (LAF) changes** | Switching LAF can alter component insets and minimums. Test with the default LAF to see if the issue persists. |
| 5 | **Dynamic content** | If you’re adding components after `pack()`, call `revalidate()`/`repaint()` or re‑call `pack()`. |
| 6 | **Platform differences** | macOS, Windows, and Linux have different default component sizes. Use platform‑independent sizing (e.g., relative to screen size). |

### Quick fix script (Java Swing example)

```java
JFrame frame = new JFrame("Claude Code");
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
frame.setLayout(new BorderLayout());

// Example panel that should compact
JPanel content = new JPanel();
content.setLayout(new BoxLayout(content, BoxLayout.Y_AXIS));
content.add(new JLabel("Hello"));
content.add(new JTextArea(5, 20)); // override size
((JTextArea)content.getComponent(1)).setPreferredSize(new Dimension(0,0));

frame.add(content, BorderLayout.CENTER);
frame.pack();          // <‑‑ crucial
frame.setLocationRelativeTo(null);
frame.setVisible(true);
```

### If you’re using a different framework

- **Qt** – call `layout()->activate()` after adding widgets; set size policies to `QSizePolicy::Preferred` or `Minimum`.
- **Electron/React** – ensure CSS `flex: 1` and no fixed pixel heights on containers.
- **Flutter** – use `Expanded`, `Flexible`, and avoid hard‑coded `SizedBox(height: …)`.
