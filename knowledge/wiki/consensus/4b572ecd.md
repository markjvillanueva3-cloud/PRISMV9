```
**Quick Checklist for Adding Skills / Scripts / Hooks / Slash Commands in PRISM**

| Step | What to do | Why it matters |
|------|------------|----------------|
| 1️⃣ **Define the Skill** | Add a new entry in `handbook-skills-hooks-ms10` (or your skill registry). Example: <br>`skill "mySkill" { description = "Does X"; script = "myscript.js"; }` | The skill must exist before it can be invoked. |
| 2️⃣ **Create the Script** | Place the JS/TS file in `scripts/`. Export a function that receives `(ctx, args)` and returns a Promise. Example: <br>`module.exports = async (ctx, args) => { ctx.reply("Hello!"); };` | Scripts are the executable payload of skills. |
| 3️⃣ **Hook it Up** | In `hypermill-ms12-skills-hooks` (or your hook file), add an event listener that triggers the skill on a specific trigger: <br>`hooks.on('messageCreate', msg => { if (msg.content.startsWith('!mySkill')) runSkill(msg, 'mySkill'); });` | Hooks bind Discord events to skills. |
| 4️⃣ **Register Slash Command** | Use PRISM’s command registration API or the Discord REST endpoint: <br>`client.application.commands.create({ name: 'myskill', description: 'Does X' });` | Without registration, Discord won’t show the slash command. |
| 5️⃣ **Set Permissions** | Ensure the bot has `applications.commands` intent and the role/permissions to use the command in the target guild(s). | Missing intents or permissions block execution. |
| 6️⃣ **Deploy / Reload** | Run `prism deploy` (or your build script) to push changes. If using a dev environment, reload the bot process. | Changes must be live for them to take effect. |

### Common Slash‑Command Issues & Fixes
| Symptom | Likely Cause | Quick Fix |
|---------|--------------|-----------|
| Command not appearing in Discord UI | Not registered or wrong guild ID | Re‑run registration with correct `guildId` (or use global). |
| “Unknown command” error when invoking | Bot lacks `applications.commands` intent | Enable the intent in the bot dashboard and restart. |
| Command works but skill doesn’t run | Hook not firing / script path typo | Verify hook file is loaded (`console.log('hook loaded')`) and script filename matches. |
| Permission denied on command execution | Role missing `Use Application Commands` | Grant role or set command permissions via Discord UI/API. |

### Quick Debugging Script
```js
// In your hook file
hooks.on('interactionCreate', async interaction => {
  if (!interaction.isCommand()) return;
  console.log(`Received slash: ${interaction.commandName}`);
  try {
    await runSkill(interaction, interaction.commandName);
  } catch (e) {
    console.error(e);
    await interaction.reply({ content: 'Error running skill.', flags: 64 });
  }
});
```

Run the bot in debug mode (`node --inspect-brk index.js`) and watch the console for the log statements. If you see “Received slash” but no skill output, the script likely has a runtime error—check its logs.

---

**Bottom line:**  
1. Define the skill → 2. Write the script → 3. Hook it to an event → 4. Register the slash command → 5. Ensure intents/permissions → 6. Deploy.  

Follow the table above and you should get your slash commands working again.
```
