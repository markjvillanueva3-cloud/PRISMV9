/forge-supervised — Forge with Mandatory Scrutiny (U-CK24)

The supervised front-end over /forge-triple — fires the 3-of-3 scrutiny gate BEFORE commit, then writes a close-out record. Adds 0 new logic — composes existing surfaces. Solves the rogue-forge problem where direct /forge-triple calls commit before the Stop hook fires the gate.

Stage 3 — why it's the load-bearing addition

Direct /forge-triple invocations commit immediately. The Stop hook fires the gate AFTER commit; if a finding surfaces, fixing requires a follow-up commit. /forge-supervised moves the gate ALEAD OF the commit so the trio lands in a single PASS-already commit. This removes the "fix-up commit" tax for the common case.
