2. Introduction
This user's guide covers the CAM editing functions. Information on the CAD functions is provided in the
online help for hyperCAD-S (on the Help menu) or in the online help texts for Autodesk Inventor and
SolidWorks.
hyperMILL: integrated CAM Application
The hyperMILL CAM solution requires you to have installed a working version of a CAD application or
the Geometric Engine from hyperMILL, into which it is fully integrated. It is used for generating 2D, 3D,
5-axis and turning NC programs for model and mold construction. hyperMILL is available as an integrated
application for the following CAD systems:
• hyperCAD-S
• hyperCAD
• Autodesk Inventor
• SolidWorks
Note that some of the functions described in this guide are not available in your installation. The range of
functions depends on the licences obtained and the configuration of the software purchased.
hyperMILL SHOP Viewer
The hyperMILL SHOP Viewer allows you to display, analyse and document processed CAD/CAM data.
The software works on the basis of hyperCAD-S and hyperMILL. The following software documentation
explains all the features of hyperMILL. The functions described may not be available or may not be
available to the extent described, in hyperMILL SHOP Viewer.
For further information on the functions of hyperMILL SHOP Viewer , please refer to the corresponding
section in the product documentation for hyperCAD-S.
Supported CAD formats
Supports a wide range of geometry formats (for example, DXF, DWG, IGES, VDA), which enable data
exchange with the majority of CAD construction programs. Data conversion takes place in the background,
while the model is loading.
During conversion, a log window with status information is displayed. The corresponding log file (*.log) can
be opened and viewed later on from within the directory of the associated model file.
Direct interfaces are provided as modules for the following data formats: CATIA V4,
CATIA V5, PTC CREO, Siemens NX, Parasolid and SolidWorks. Please contact your
dealer. For further information, please see the hyperMILL for hyperCAD-S software
documentation
The following formats are supported for saving model data and for CAM editing:

Saving hyperMILL SHOP Viewer data
When data is saved as a SHOP Viewer document ( *.hmc), the following options can be enabled and
included as components in the file in the Setup dialogue: stock data, toolpath entities, postprocessor
configuration, prepared geometry.
*.e3 data for hyperMILL for hyperCAD-S
A *.e3 file must have been stored with a hyperMILL version 2009.2 or newer and with an active hy-
perMILL session in order to ensure that all selections in hyperMILL are restored for hyperCAD-S.
Further information on exchanging data is available in the corresponding CAD manual.

3. User interface
hyperMILL and CAD program
hyperMILL is a CAM module that is fully integrated into the CAD program and is used for generating 2D,
3D, 5-axis, milling and turning programs. Individual machining steps (jobs) are created on the basis of
machining cycles with the open CAD model in the form of one or more work schedules (joblists).
All functions of the hyperMILL toolkit, as well as all input pages, menus and programs that can be opened
with icons can also be accessed using keyboard commands and repeated using <return>.
The functions that are available for the respective CAD platform are outlined below.

Dialogue positioning
In the Modeless dialogue control mode, all input dialogues that are opened via the browser feature a pin
that allows the dialogue to be fixed anywhere on the screen. Message windows always feature this pin,
regardless of which dialogue control mode is set.
 Dialogue is not pinned: The current dialogue window will close when you switch to another dialogue or
to the browser.
 Dialogue is pinned: Pinning allows you to simultaneously display different dialogues for a job (for
example, job, tool and frame definition assigned to each other as well as message windows). When you
select a different job list entry, the display switches to the definitions for the currently selected list entry.
This means that you can quickly check all definitions for a job. The contents of the open message window
refresh immediately when you edit in other dialogue windows.
Define parameters
Input field colours
Black input value: The value is correct.
Red input value: The job can be calculated with this value, however, collisions might occur. Read the warn-
ing in the message window. Change the respective values if necessary and check the job in simulation
after calculating the toolpath.
Input field values
Values can be entered as follows:
• Direct entry of required value into input field.
• Use of a predefined local cycle parameters.
• Definition of user variables.
• Definition using arithmetical expressions.
Local parameters and user variables can be combined in a single expression. You may also enter all
values directly into the input field using the keyboard.
