================================================================================
KEY FINDINGS (3 CRITICAL VULNERABILITIES)
================================================================================

1. ARBITRARY CODE EXECUTION (CVSS 9.8)
   ──────────────────────────────────────
   Endpoint: POST /execute
   Risk: Remote Code Execution (RCE) with no restrictions

   The server accepts raw Python code and executes it directly:

   POST http://localhost:18360/execute
   {"code": "import os; os.system('malware.exe')"}

   Status: EXPLOITABLE via decorators, metaclasses, type(), __subclasses__()
   Impact: Complete system compromise (Fusion 360 process = system access)

   Action Required: REMOVE this endpoint immediately or implement AST sandbox


2. OPEN CORS POLICY (CVSS 8.1)
   ────────────────────────────
   Current Header: Access-Control-Allow-Origin: *
   Risk: Any website can trigger API calls from attacker's page

   Attack: attacker.com embeds <script> to POST /execute → RCE
   Status: ACTIVE, no authentication required
   Impact: Cross-site request forgery (CSRF) to RCE

   Action Required: Restrict to localhost:3000 or remove CORS entirely


3. PATH TRAVERSAL IN EXPORT (CVSS 8.6)
   ───────────────────────────────────
   Endpoint: POST /export
   Risk: Arbitrary file write to any location

   Attack: {"format": "step", "path": "C:\\Windows\\System32\\config\\SAM"}
   Status: EXPLOITABLE, no validation
   Impact: RCE (via startup folder), data corruption, system compromise

   Action Required: Whitelist allowed directories, validate all paths
