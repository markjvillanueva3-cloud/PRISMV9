# Web Legacy Mirror Retirement Plan

## Background

The repository has two frontend directories:

| Directory | Purpose | Status |
|-----------|---------|--------|
| `/web/` | Legacy standalone frontend | **DEPRECATED** |
| `/mcp-server/web/` | Canonical MCP-integrated frontend | **ACTIVE** |

The `/web/` directory was the original standalone React app before MCP integration.
All new development now happens in `/mcp-server/web/`.

## Current Drift Status

As of 2026-04-19:
- Canonical has ~50+ more test files than legacy
- Several shared files have diverged
- Legacy contains some files not in canonical (need migration)

## Retirement Phases

### Phase 1: Zero-Drift CI (CURRENT)
- Script: `scripts/check-web-drift.sh`
- Runs in warning mode during transition
- Reports drift but doesn't fail CI

### Phase 2: Strict Enforcement
- Enable `--strict` mode in CI
- Any drift causes CI failure
- Forces all changes through canonical path

### Phase 3: Legacy Removal
- After 30 days of zero drift
- Delete `/web/` directory entirely
- Update all documentation references
- Remove drift check from CI

## CI Integration

Add to `.github/workflows/ci.yml`:

```yaml
- name: Check web directory drift
  run: ./scripts/check-web-drift.sh
  # Future: ./scripts/check-web-drift.sh --strict
```
