# Physics Web Worker Architecture

**Milestone:** LATHE-PROD-READY-MS0  
**Unit:** U-LPR-WEBWORKER  
**Created:** 2026-04-19

## Overview

Physics preview calculations run in a Web Worker to keep the UI responsive during parameter changes. The frontend preview is for immediate feedback only — **backend calculations are authoritative for release-grade programs**.

## Key Decisions

### 1. Preview vs. Authoritative

| Aspect | Frontend (Worker) | Backend |
|--------|-------------------|---------|
| Purpose | Immediate UI feedback | Program release |
| Accuracy | Simplified models | Full physics |
| Safety checks | None | Full validation |
| Confidence | "preview" / "estimate" | "calculated" |

### 2. Why Web Workers?

- **Non-blocking UI**: Physics calculations don't freeze the interface
- **Debouncing**: 100ms default debounce prevents excessive calculations
- **Parallel**: Multiple calculations can run concurrently

### 3. Simplified Models

The worker uses simplified physics for speed:

- **Cutting force**: Kienzle without temperature/BUE corrections
- **Surface finish**: Ideal geometric Ra without vibration
- **Deflection**: Simple cantilever beam model

These are sufficient for preview feedback but not for production programs.

## Usage

```typescript
import { usePhysicsPreview } from '../hooks/usePhysicsPreview';

function ParameterEditor() {
  const preview = usePhysicsPreview({
    operation: 'cutting_force',
    params: { kc11: 1800, mc: 0.25, ap: 2, f: 0.2 },
  });

  return (
    <div>
      {preview.loading && <Spinner />}
      {preview.result && (
        <PreviewBadge
          value={preview.result.value}
          unit={preview.result.unit}
          confidence={preview.result.confidence}
          warning={preview.result.warning}
        />
      )}
    </div>
  );
}
```

## Available Operations

| Operation | Parameters | Output |
|-----------|------------|--------|
| `cutting_force` | kc11, mc, ap, f | Force in N |
| `surface_finish` | f, r | Ra in µm |
| `cycle_time` | length, f, rpm, passes, rapidTime | Time in s |
| `deflection` | force, length, diameter, E | Deflection in mm |

## Safety

The worker results include:
- `confidence: 'preview'` — explicitly marks as non-authoritative
- `warning` — alerts for values outside normal ranges

**Never use worker results for**:
- Final program parameters
- Safety-critical decisions
- Machine limits validation
