## Executive Summary

Forge-audit surfaced a high-value decoupling: **~9,450 LOC of production-grade context/session/memory engines** coexist with **5,405 LOC of hook scripts that hand-roll the same logic**. Hooks succeed but bypass typed, tested, dispatcher-exposed machinery — creating drift risk and duplicate maintenance surface.

**Audit findings across 4 parallel agents:**

- **CRITICAL** — `compact-counter.mjs:24` references undefined `SAMPLE_RATE` — hook crashes on every PostToolUse once threshold reached.
- **MAJOR** — Non-atomic JSON writes in `per-agent-handoff.mjs:104` and `milestone-tracker.mjs:31`. With 6+ concurrent Claude terminals + Codex, last-writer-wins corrupts state.
- **MAJOR** — 30 context/session/memory engines, **only 1 has a companion test**. SessionHandoffV2Engine, MemoryConsolidationEngine, SessionLifecycleEngine are used by hooks with zero unit coverage.
- **MAJOR** — `SESSION_ARTIFACTS.json` and `post-compact-log.json` are 3-byte empty files despite being referenced by 6+ hooks. Dead inputs pretending to be live.
- **MINOR** — 5 of 6 state files missing `schemaVersion`. Awareness directives stale (2026-04-14/15) but still injected into every session boot.
- **HIGH-VALUE UNWIRED** — ContextChainEngine (410 LOC, has test), ContextWindowMapEngine (199 LOC), SessionEventLogEngine (168 LOC), MemoryPressureMonitorEngine (165 LOC), SessionInsightsLedgerEngine (141 LOC) are production-ready but dispatcher-exposed nowhere.

**Operational constraint (P0 design axiom from user):** at least 6 Claude terminals run concurrently plus 1 Codex chat (primary frontend, opportunistic backend). Any coordination primitive assuming single-writer is wrong. Per-terminal handoff (`HANDOFF-<instance>.md`) is mandatory, not optional.

**Success criteria (Definition of Done):**
1. Zero hook crashes under load.
2. All state writes atomic (tmp+rename) or under FILE_LOCKS discipline.
3. Every hook-used engine has ≥1 companion test.
4. Every state JSON has `schemaVersion` and Zod-validated read path.
5. Every hand-rolled hook logic block duplicating an engine is refactored to call the engine.
6. Compaction survival snapshots readable across 7 concurrent sessions without clobbering.

**Omega target**: 1.0 for all milestones. Total: **7 milestones, 51 units, 14-19 sessions**.

**Added after initial draft (2026-04-16 late):**
- **CPP-MS6** (P0, 6 units) — Concurrent-terminal coordination safety. Wires git-anti-clobber pre/post hooks + node-process janitor + live-terminal roster. Addresses observed failure modes: concurrent `git commit` clobber, leaked hook node processes pinning the PC, stale compaction artifacts poisoning SessionStart.

Formalizes the universal-skills-scripts-hooks roadmap as the quality benchmark; future `/rgs generate` calls emit roadmaps at that tier by default (scope snapshot, artifact tables, coverage deltas, scrutiny findings, leverage-existing, integration-with-prior, anti-patterns, operational-integrity spine).

## CPP-MS6 — Concurrent-Terminal Coordination Safety (P0, 6 units)

**Problem**: 6+ Claude terminals + 1 Codex chat share the same worktree. Today the coordination surface is *advisory* (lock helper scripts that nothing invokes, stale lock files that never expire, node hook processes that leak and choke the host). Concrete failure modes observed in the wild:

1. Two terminals run `git add` / `git commit` at the same second → `.git/index.lock` EEXIST, one side aborts mid-commit, leaves torn state.
2. Background `ps`-polling hooks leak past their declared timeouts; over a 4-hour session ~40 zombie node processes accumulate, pinning the PC.
3. Stale `.compaction-survival-session-*` artifacts from dead terminals are read by live ones on SessionStart, poisoning context.
4. `git-lock.sh` exists but is not wired as a hook — the protection is there on paper, never executes.

**Goal**: convert terminal-coordination from *advisory* to *enforced*. Mutations serialize. Leaked processes are reaped. Dead artifacts are ignored. Live terminals can always tell which session is active on which PID.

### FORGE-TRIPLE for CPP-MS6
- **PROTECTIVE HOOK (pre)**: `git-anti-clobber.mjs` — PreToolUse Bash — detects mutating git subcommand, acquires `state/shared/GIT_LOCK.json` via atomic tmp+rename; DENY with retry message when held by another instance; 180s TTL steal for dead holders; reentrant for same instance.
- **PROTECTIVE HOOK (post)**: `git-anti-clobber-release.mjs` — PostToolUse Bash — releases lock iff `holder === me` (never steals on release).
- **JANITOR HOOK**: `node-process-janitor.mjs` — PostToolUse Bash (async) + UserPromptSubmit — throttled to 30s; kills `.claude/hooks` + `.claude/helpers` node processes older than 45s (well past any declared 10s timeout). Windows via PowerShell Get-CimInstance; Unix via ps+awk+kill.
- **MCP ACTIONS**: `prism_session:terminal_live_roster`, `prism_session:stale_artifact_sweep`
- **SKILLS**: `/terminals-live`, `/coord-status`
