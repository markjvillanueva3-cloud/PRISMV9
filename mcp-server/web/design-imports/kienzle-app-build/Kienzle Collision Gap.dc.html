⚠ THE TWO THINGS THAT BLOCK "PROVABLE"
1. "Probabilistic collision" is the wrong default. A provable system must be conservative — it may cry wolf, but it can never miss. PRISM_PROBABILISTIC_COLLISION optimizes the opposite way. Re-base on conservative bounds; keep probability only for ranking warnings.
2. Discrete sampling misses between steps. Checking poses every N ms lets a tool pass through a clamp between samples. Provable = swept-volume across the whole move (CCD), not point checks. SWEEP_LOFT_ENGINE exists but must be wired as conservative CCD, not visual lofting.
