DATA FLOW DIAGRAM

User Opens Panel
  ↓
PanelCommandCreatedHandler.notify()
  ├─ Load materials (cached if PRISM live)
  ├─ Load machines (NOT cached)
  ├─ Load tools (NOT cached, triggering on diameter change)
  └─ Check PRISM connectivity (prism_live())
       ├─ If live: expand "Select from PRISM Library" group
       └─ If offline: show fallback materials + local Kienzle

User Changes Fields
  ↓
PanelInputChangedHandler.notify()
  ├─ If woc/diameter change: update WOC%
  ├─ If tool diameter change: search tools (API call, 200ms latency)
  │   └─ Populate tool dropdown with 20 results
  ├─ If tool selected: load full tool object
  │   └─ Populate: diameter, flutes, flute length, stickout (missing: coating, radius)
  ├─ If machine selected: load full machine object
  │   └─ Populate: max_rpm, max_power_hp
  └─ Call run_calculation()
       ├─ gather_params() → extract all UI values
       ├─ calculate() → try PRISM, fallback to Kienzle
       ├─ Format results with color coding
       └─ Update all result fields

User Clicks "Apply to CAM Operation"
  ↓
PanelExecuteHandler.notify()
  ├─ apply_to_operation()
  │   ├─ gather_params()
  │   ├─ calculate()
  │   ├─ validate_safety() ← May fail if offline/no API
  │   │   └─ If fail: show violations, DO NOT apply
  │   └─ Write to Fusion operation parameters
  │       ├─ tool_spindleSpeed
  │       ├─ tool_feedCutting
  │       ├─ tool_feedPlunge
  │       └─ tool_feedRamp
  └─ Show confirmation message
