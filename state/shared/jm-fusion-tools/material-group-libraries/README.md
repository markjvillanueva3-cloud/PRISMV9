## What's here
- `*-6groups.csv` -- each JM tool with its original as-run preset PLUS per-GRADE
  presets (1018 / 1045 / 4140-4340 in P; 304-316 / 17-4PH / 2205 in M; Gray /
  Ductile iron in K; 6061-7075 / Brass / Copper in N; Ti-6Al-4V / Inconel in S;
  Hardened tool steel in H) -- ONLY for grades whose ISO group the tool's
  coating+substrate is compatible with. Each grade SFM is scaled from the
  ISO-group base by its canonical machinability rating (4140 ~ -23% vs 1018).
- `by-group/JM-CRIB-<ISO>.csv` — one importable library per material group (all tools).
- `JM-MATERIAL-GROUP-BATCHES.md` — copy-paste cutting-parameter matrix by group × diameter.
- `JM-MATERIAL-CATEGORIZATION.md` — JM stock material → ISO group map.

## Import into Fusion 360 (cloud or local)
1. Manufacture → Manage → Tool Library.
2. Right-click your Cloud (or Local) library → **Import**.
3. Select a `*.csv` (format: `CSV_TOOLS_VERSION_1` — same as JM's existing exports).
4. Each tool carries multiple GRADE presets, each with grade-specific SFM/RPM/feed.
   Fusion AUTO-SELECTS by your setup's stock material via `Filter by Type`
   (steel / stainless steel / cast iron / aluminum / brass / copper / titanium)
   AND `Filter by hardness` (each grade carries its HB range, so 1018 vs 4140 --
   both `steel` -- are told apart by stock hardness). As-run preset stays `all`.

## Provenance / safety
- Geometry + holder collision segments are copied VERBATIM from JM's proven CSVs
  (no unit conversion → no 25.4× scale risk on collision-critical data).
- Cutting presets come from `UltimateSpeedFeedEngine.lookupCuttingData` (Kienzle/Taylor
  CUTTING_PARAMS, balanced). Surface speed/RPM/feed are starting points — verify on the
  machine and adjust for setup rigidity, coolant, and finish.
- Turning/boring presets set CSS surface speed per material and KEEP JM's proven feed/rev
  (turning surface speed is workpiece-diameter driven at the control).
