# Round-6 Agent 2 — Deployment / Hosting Gap

**Verdict:** GAP — the code for a hosted SaaS exists; nothing is deployed. (Reshaped by the desktop-app pivot — see v7.3 §R7.1; the hosted footprint shrinks to a small licensing/funnel backend.)

**What exists:** `Dockerfile` (proper multi-stage, node:22-alpine, non-root, HEALTHCHECK /health, EXPOSE 3000) byte-synced with `mcp-server/Dockerfile` via `.github/workflows/dockerfile-sync.yml`; `docker-compose.yml` (7-service local stack: postgres:16, prism-server, prometheus, qdrant, ollama, grafana — bind-mounts under `data/docker-volumes/`); `deploy/k8s/` (one placeholder file: Namespace/Secret(`change-me-in-production`)/ConfigMap/postgres-StatefulSet/redis/prism-Deployment(3 replicas+HPA)/Ingress — never applied, no Helm); `deploy/{start.sh,prometheus.yml,alerts.yml,grafana-*}`.

**The HTTP server already exists in code:** `mcp-server/src/index.ts` `runHTTP()` (`npm run start:http` → `TRANSPORT=http PORT=3000 HOST=127.0.0.1`) = a real Express app with `/health` (registry-aware), `/metrics` (Prometheus), `/.well-known/mcp.json`, MCP Streamable-HTTP at `POST /mcp`, WebSocket `/ws`, **and a full REST API — `mcp-server/src/routes/index.ts` registers ~70 route modules ("42 endpoints"): `/api/v1/{auth,billing,sfc,cam,cad,quality,schedule,cost,quote,parts,portal,...}`**. Serves `dist/web` when present. Catches: binds 127.0.0.1 unless `PRISM_BIND_HOST=0.0.0.0`; stateless `/mcp` creates fresh transport per request (no session continuity); brief says port 3100, code defaults 3000.

**Auth/multi-tenancy — wired to dispatchers, NOT to a DB:** `AuthEngine.ts` = in-memory Maps (`users`/`sessions`/`tokens` — restart = everyone gone); `AuthEngineV7.ts` claims to replace them but isn't wired into `runHTTP`. Express middleware (`middleware/auth.ts`) + routes (`routes/auth.ts`) are real but hang off the in-memory engine. `MultiTenantEngine.ts` = file-based `state/{tenant_id}/` JSON. **`mcp-server/src/db/schema.sql` exists** (proper PG: `users`, `api_keys`, `materials`, pg_trgm) + `db/connection.ts` (real pg pooling, falls back to in-memory if no `DATABASE_URL`) + `db/migration-runner.ts` + `db/migrations/` — **but AuthEngine never queries it.** `StripeBillingEngine.ts` defaults `testMode:true`, returns mock checkout URLs, no `STRIPE_SECRET_KEY`, webhook sig verify stubbed. Zero real payments today.

**Hosting target: NONE documented.** No `fly.toml`/`render.yaml`/`railway.json`/Vercel/terraform. CI/CD: `.github/workflows/deploy.yml` deploys ONLY `docs/index.html` to GitHub Pages — NOT the server; `web.yml` builds the frontend; `ci.yml` is build+test only; no `docker push`/`kubectl`/`fly`/`render` anywhere.
