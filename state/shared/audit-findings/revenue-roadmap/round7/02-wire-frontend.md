# Round-7 Agent 2 — Frontend Wiring Topology (full detail folded into v7.4 §R8.2)

**Canonical app:** `mcp-server/web/` (React 19 + Vite 6 + react-router-dom 7, **146 pages** in `src/pages/`, lazy-loaded via `src/App.tsx`). Data flow: page → `src/hooks/use*.ts` (48 hooks) → `src/api/*.ts` (90 client modules) → `/api/v1/*`. Backend: `routes/index.ts` mounts ~73 route modules (~50+ `/api/v1/*` families; each handler proxies one dispatcher action) — vastly smaller than the 97-dispatcher / 7,341-action MCP surface. Gold standard page: `CalculatorPage.tsx` (25 call sites). **Thin pages** (call far fewer than they could): `SfcCalculatorPage` (1 of 7 sfc endpoints), `SpeedFeedPage` (2 of 8), `ErpDashboard` (3 of ~230 erp endpoints), `BlueprintQuotePage` (1 call), `ViewerPage` (scenes only — no CAD-import), `usePpg.ts` exports ZERO `use*` hooks (PpgPage wiring is hollow despite a ~60-endpoint `ppg.ts` client) — and ~most of the 146.

**Missing backend endpoints (~8 new route modules, ~25 endpoints):** `POST /api/v1/masterpost/{generate,upload,result/:id,transpile}` (MasterPostUploadPage); `POST /api/v1/sfc/free` (anonymous lead-magnet, no-auth, rate-limited); `routes/gcode.ts` `/gcode/transpile{,/verify,/capability-gate}` (§R5.1 B2); `routes/archive.ts` `/archive/{search,similar-part}` (§R5.1 B3); `routes/quote-to-nc.ts`; `routes/lights-out.ts`; `routes/migrate.ts`; `routes/account.ts` + `routes/auth.ts:/signup`. **Missing api-clients (~12):** `cad.ts` (ViewerPage → `/api/v1/cad/{import,features,analyze}` STEP/STL upload — HIGH), `dfm.ts` (BlueprintQuote/QuoteBuilder — HIGH), `quote.ts`+`quotes.ts` (the 30-endpoint quote router + instant-quote router are unwrapped — HIGH), `threads.ts`, `schedule.ts`, `doc.ts`, then `shopLive.ts`/`userLibrary.ts`/`upload.ts`/`milling.ts`/`print.ts`/`wedm-erp.ts`. (32 route modules lack a frontend client; ~12 revenue-relevant, rest INTERNAL_ONLY: sp/gsd/ralph/manus/dev.)
