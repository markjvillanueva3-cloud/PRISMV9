                   What About Diameter Mode?

                One final thought. A lot of lathes will be set up for g-
                code that runs in diameter mode, where increments on
                the X axis are measured as diameter changes not
                radius changes. Your mill knows nothing of this kind of
                thinking, so the code coming out of it is radius mode
                code. You will have gotten this far and then you'll want
                your profile g-code to be Diameter mode. No worries,
                GWE has a Revision command that can make that
                change for you too:
