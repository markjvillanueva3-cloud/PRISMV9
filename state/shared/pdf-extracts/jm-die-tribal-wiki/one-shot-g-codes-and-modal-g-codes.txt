         What Are G-Code Modes?

         Let's talk about G-Code "Modes." Simply put, a Mode is
         the CNC Controller's way of remembering what you told
         it to do last time. Think of it like muscle memory for
         machines. If you don't specify every little detail, the CNC
         just assumes you want to do it the same way as before.
         It's like the CNC's way of saying, "Been there, done

         What is a One-Shot G-Code?

         Speaking of things which are not modal, we have a
         name for a big category of non-modal behavior which
         are called One-Shot G-Codes. A one-shot g-code is only
         in effect for the block it is used in, and then the mode
         goes back to whatever it was before the block was
         executed. Most of the one-shot g-codes are fairly
         advanced, so we'll save them for a later chapter.
