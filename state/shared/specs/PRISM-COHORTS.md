## How to consume

Stage 2 (batch-compat-scorer.mjs) consumes `PRISM-COHORTS.json` to score every (oldCohort × newCohort) pair on API-shape match + domain alignment + bridge-cost class. Each lego-stacking adapter shim in Stage 3 targets one or more high-leverage (oldCohort, newCohort) pairs from Stage 2's heat-map.

## Re-run

```bash
node H:/prism/scripts/cohort-detector.mjs           # full run
node H:/prism/scripts/cohort-detector.mjs --json    # machine-readable
```
