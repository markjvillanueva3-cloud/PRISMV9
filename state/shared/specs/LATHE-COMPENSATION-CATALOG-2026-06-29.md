# LATHE WIZARD — PRE-EMPTIVE COMPENSATION MASTER PLAN

The proven pattern (UNIT 1 = `stickoutCompensationPlan`): **detect-physics → auto-adjust the CORRECT lever → compensate-residual with opposing geometry → surface-what-changed → never-soften-safety (monotonic — only de-aggress)**. Most physics already exists as ADVISORY-ONLY engines that COMPUTE the number but never WRITE it. Closing those loops is the fast win.

Key naming: AA = auto-adjustment. All engine paths are `H:/prism/mcp-server/src/engines/`.
