## ROOT CAUSE — a four-defect chain, NONE numeric (Glorot init correct, BCE+sigmoid grad checked)
1. **Feature starvation at targets.** `scripts/lib/graph-node-embedding-bridge.mjs` JOINS nodes to a PRE-EXISTING wiki tribal-embed vector by lowercased basename (candidateBasenames/basenameIndex ~L263-333). Ghosts have no wiki page → only **63 of 636** ghost.unwired-engine nodes get a 768-d vector; 573 fall to zero/identical. `node-embeddings-768d.jsonl` = 3789 recs but only 63 `ghost`-prefixed (wiki 1402, eng 1120, vault 799).
2. **Edgeless inference.** `scripts/seed-ghost-gnn-classify.mjs buildGhostSubgraph` returns `edges:[]` (~L195) → GraphSAGE MEAN aggregator agg=0 → the GNN degenerates to `W*features` (a 2-layer MLP). 573 targets on identical zero-features → every target→reference cosine near-identical. **⇒ ANY message-passing aggregator (H2GCN/GPR-GNN/JK) is a structural NO-OP here — do NOT spend F0 budget on heterophily convolutions; that misdiagnoses the bug (2/3 lenses + synthesis independently rejected it).**
3. **No base-rate normalization.** `voteDispatcher` (~L236) accumulates `w = score*confidence` per dispatcher with NO division by reference-class frequency. Uniform cosines → winner = largest reference bucket = **prism_turning** (60/125 high-conf refs) → voteShare identical → confidence pinned ~0.4 → distinctConfidences=1, distinctPredictions=1 → **AUROC 0.5 by Mann-Whitney tie**; macroF1 = F1(turning)/|classes| = 0.667/5 = 0.1333 (matches NN-EVAL.json exactly).
4. **Dead stratified-negative wiring.** `scripts/lib/graphsage-trainer.mjs` `train()` (~L502) unconditionally calls uniform `sampleNegativeEdges` and IGNORES `opt.nodeType`/`opt.negPHard` that the pipeline spreads in (train-pipeline ~L681-684). `sampleStratifiedNegativeEdges` is exported+tested but never called by `train()` → every "stratified" retrain trains on easy uniform cross-type negatives → never learns same-dispatcher separation → deployed checkpoint anti-homophilous (link-pred AUROC 0.096; 768-d candidate 0.388, both <0.5).
- Compounding: `nn-graph-eval.mjs buildHoldout` (~L327) uses a FLAT seededShuffle → holdout inherits the turning skew, prism_calc gets 0 holdout → caps macroF1 even if the vote were fixed.
