### CLEAR-NOT-COMPACT chat flow

1. Operator says `/clear` (instead of `/compact`)
2. Terminal-pin auto-rebinds the slot (terminalWindowId matches)
3. SessionStart hooks fire: awareness-snapshot + build-state + auto-resume
4. Chat reads its per-slot handoff via `per-agent-handoff.mjs read`
5. Chat reads its assigned unit's brief at `state/shared/specs/UNITS/<unit_id>.md`
6. Chat reads its RGS tool plan via `prism_dev:roadmap_tool_plan_query { unit_key: "<MILESTONE>::<unit_id>" }`
7. Chat works. NO recall of prior conversation needed.
