Historical goals by domain

mill — Originally "comprehensive print→validated-program milling pipeline" (collision-safety, multi-machine DB, 95K-tool selection, real-geometry toolpath gen, controller hardening — MILLING-COMPREHENSIVE 11MS/113U). Evolved into MILL-AGI ("AGI-grade cognitive milling": 5 ONNX neural engines + 7 Synergy Laws + closed feedback loop, ~800U/80MS) then collapsed to the integration-first thesis ("STOP CREATING — START INTEGRATING": wire 1,869 engines @30% via facade delegation). The throughline: build the physics core, then wire what exists rather than re-extract. Now the foxtrot/alpha mill galaxy.

lathe / mill-turn — Set out as the "most complex machine type" — full turn+mill multi-channel sync (2-4 ch), sub-spindle transfer, live tooling, Swiss guide-bushing, bar-feeder production loop (MILL-TURN-COMPREHENSIVE 12MS/138U). Evolved toward LATHE-MASTER's ambitious P0 substrate: formal G-code verification (Z3/SMT), local LoRA on JM Die's 5,297 Okuma programs, predictive 60s pre-play twin, live THINC/MTConnect telemetry. Today whiskey owns lathe (physics-first safety: G50/CSS, chuck-jaw).

wedm — The deepest-specced domain from origin: complete print-to-part pipeline (18-stage taxonomy, 12-engine, 15,900 LOC, physics-justified per parameter) → AGI layer (autonomous program-gen, self-optimizing params, digital twin, sensor fusion) → frontend parity (match lathe UX, DXF/photo→program). Evolved into WEDM-CONSOLIDATED master. Most production-complete of any domain. Now mike's galaxy.

cad — Originally CAD-draw + feature-recognition + STEP round-trip + vendor function-index parity (SolidWorks/Inventor/Mastercam). Evolved through CadQuery kernel ambitions and the 6-step studio wizard pattern (Wire EDM wizard became the clone template). Today delta owns cad (75/75 engines wired, electrode/trilobe gen).

cam — The master print-to-CNC spine: CAMX 14-stage MCP dispatcher chain (intake→features→DFM→machine→tool→strategy→S/F→toolpath→collision→post→sim→setup-sheet→cost→package, ~950U), every stage an MCP action so app + agent share one surface. Plus the Fusion 360 and hyperMILL integration product lines (the biggest unbuilt revenue surfaces). Superseded by PRISM-UNIFIED-v2. Now kilo's galaxy.

post-processor — Started as "turn 16+ existing post engines into a paid product" (machine make/model/year/controller→physics-optimized G-code, 4-tier pricing). The flagship "Post-Processor Framework" (Universal Intermediate Representation → 12+ controllers) was one of R14's four named commercial products. Lead-with-value framing (the before/after OptimizationReport). Now echo's galaxy (14-controller AGI surface).

sfc / speed-feed — Born as the physics core: Kienzle/Taylor/Merchant kc1.1 registry enrichment over 18,516 entries + Coolant/Coating registries. Evolved into the all-machine accuracy mandate (every one of 1,941 machine rows hydrates legal selections, validated against published data, honest limited-mode for the rest) + multi-model physics fusion (convergence solver). Now oscar's galaxy (9-axis orchestrator, vendor parity).

quoting — Originally cost-estimation as one of R14's four flagship products. Evolved toward the probabilistic "money shot": DrawingToQuoteMathPipeline producing P10/P50/P90 cost with confidence bands (SCIMATH stakeholder-unanimous). Now charlie's galaxy (print-to-quote + DocuStrata pricing).

business / ERP — Set out as "PRISM as full shop OS" (canonical job/traveler/labor/event spine, role-aware shells, ERP+accounting sync, offline replay — ULTIMATE-SHOP-OS) plus competitor-parity backend (E2/QuickBooks/Xometry/Fictiv) and an Employee/HR/Job-Tracking + Lean/Six-Sigma layer. Evolved into hotel's galaxy (355 engines, prism_business 879 actions). The largest unbuilt-frontend surface (engines exist, dashboards don't).

academy — Course/curriculum/MIT-OCW extraction: ~3,880 atomic skills from 206 MIT courses + 25 CNC/CAM resources, 4 tiers, SCORM export. Evolved into lima's galaxy (pypdf 8,752-page corpus, 3-leg ship contract).

ai-training — The original moat thesis: the Data Flywheel (every recorded job improves recommendations → personal/shop/network/global model tiers + Expert Distillation). Abandoned for lack of a user base; partially revived as the india NN-graph substrate + content/video learning pipeline ("the only post-processor that learns"). Now india's galaxy (GraphSAGE GNN tier-5, ~95 LoRA engines).

system-viz — Grew out of the R5 visual layer (operator-facing UI per intelligence feature) + the reverse-index/master-index awareness need. Evolved into the 548MB live graph that IS the fleet search substrate. Now sierra's galaxy.

infra / cross — The deepest evolutionary arc: from the v17 "Claude Code as autonomous engineering platform" (3-archetype subagents, hooks-as-hard-blocks, Task DAGs, model routing) through the Forge auto-wiring system (artifact lifecycle U0→U6, monotonic quality score), the embedding/semantic-RAG gap, and the persistence gap (PostgreSQL dead-code → in-memory fallback). These ancestors became today's slot fleet, scrutiny-3way gate, duplication-guard, master-index, and wiring-inference cascade.

USEFUL IDEAS WORTH KEEPING

Design ideas/approaches (not full builds) to carry forward into galaxy synthesis:

  • [infra] Wire-don't-rebuild + UTILIZE-BEFORE-CREATE. Facade engines that delegate to existing physics engines; asset-utilization audit table (count × %-wired × gap) as the decision substrate. The ancestor of duplication-guard + master-index — still the operating doctrine. (MILL-AI v4, UNIFIED_v8)
  • [infra] Atomic file-created→awareness-updated transaction. "No single transaction binds creation to registration" is the root cause of ALL duplication. Bind with PostWrite-sync + CAS lockfile + git-checkout rollback (forge-triple→forge-quint). (SCRUTINY-UNIVERSAL-HOOKS)
  • [infra] Dev-tools-first ROI. "1 hour improving dev capability = 10+ hours saved downstream" / "fix dev infrastructure FIRST because ROI compounds across every later session." The explicit doctrine behind today's PRIORITIZE-devtools-backend rule. (PHASE_DA, UNIFIED_v8)
  • [infra] Route deterministic transforms to code, LLM only for judgment. Don't gate on a flaky LLM for what a pure tool decides (deterministic compiler check is the hard block, Codex advisory). The R5 doctrine origin. (AGENTIC-PATTERNS, humble-juggling-cerf)
  • [infra] Hook stack as a feedback control system. PID-controlled blocking aggression (relax when over-blocking, tighten when quality degrades) + Lyapunov stability + Bayesian-updated dedup threshold (the arbitrary 0.85 is PAC-undertrained). (MASTER-AI-SYSTEM-ADDENDUM)
  • [infra] Explicit "Retired Work" / conflict-resolution tables. Kill redundant roadmap units rather than build duplicates (~5,500 LOC retired when Phase-0 absorbed them); authority/precedence ladder for conflicting roadmaps. (MASTER-EXECUTION-PLAN, mill-agent-10)
  • [cross] Product framing — answer the questions machinists actually ask. "I need to machine Inconel 718 on my DMU 50 — what do I do?", "what if I bump Vc 20%?", "I can't get Inconel — substitute?" Intent-engine routing for the Dave persona (20-yr machinist, 10-sec patience). (PHASE_R3, PHASE_R8)
  • [cross] Lead every paid milestone with a demo-able before/after value artifact. The OptimizationReport pattern; physics-backed wiring framed as revenue spine (RFQ→calculator→quote), not cosmetic parity. (PP-REVENUE, CWEDM)
  • [safety] Be better WITHOUT learning data via engineering quality. Cold-start moat: 3,518 materials, physics not lookup, uncertainty quantification — learning is bonus. Should anchor every per-galaxy goal. (DATA_FLYWHEEL)
  • [safety] Fail-loud as a formal contract. Every invariant needs threshold + enforcement + violation-response or it's an ASPIRATION not a CONTRACT. Safety-stability-under-load: |S(x)_loaded − S(x)_isolated| < 0.02. Limited-mode honest behavior beats fake full optimization. (SYSTEM_CONTRACT, CALC-OEM-ACCURACY)
  • [safety] Edge-case routing gate. Detect thin walls <1mm / deep pockets L/D>5 / interrupted cuts / stainless/titanium → conservative S/F or manual review. Phased launch (simple-parts-only MVP, disable risky geometries until validated on 50→200→1000 real parts). (whimsical-hugging-fountain)
  • [cross] Mathematical governance. Every formula declares formula_id/domain/inputs/units/constants/provenance; no inline constants anywhere. Honest formula labels (canonical/prototype/novel); NaN/Inf + FEM-vs-beam ±20% validation gate on custom formulas. (PRISM-UNIFIED-v2, SCIMATH)
  • [cross] Single canonical source per data class. 8 competing materials/ dirs = drift hazard → pick ONE, archive the rest. The lesson the fleet relearned with vendor-catalog-db + resource-roots. (PRISM_DATABASE_AUDIT)
  • [ai-training] Multi-source consensus parameters with provenance.
