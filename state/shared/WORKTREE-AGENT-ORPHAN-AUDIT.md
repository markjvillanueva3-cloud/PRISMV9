## Subtle gotcha for the operator

If you run the equivalent `git rev-list` via `execSync` with a single string
arg (e.g. `execSync('git rev-list X ^main')`), Node spawns a shell which on
Windows interprets `^` as the cmd.exe escape character — the `^main` becomes
literal `main`, and the rev-walk silently reports commits NOT in `main` AS IF
they were unique to the branch. The first run of this audit reported 983
spurious "unique" commits per branch before catching this. Always use
`execFileSync('git', ['rev-list', X, '^main'])` with arg arrays.
