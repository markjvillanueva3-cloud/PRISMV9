4. Изменение функциональности некоторых свойств
Некоторые свойства, в которых ранее не было поддержки множественного выбора
объектов, теперь отображаются, и их можно редактировать на панели свойств, когда
выбрано несколько объектов. Это относится к следующим свойствам:
Для сборки (корневой): Цвет
Для объектов: Область и Объем
Для экрана: Фон с плавным полутоновым переходом, Динамический фон с
плавным полутоновым переходом, Пропорции публикации, Не цвет клиента
публикации
Более того, эти свойства теперь доступны в модуле стилей, ими можно управлять через
профиль стиля (как другими свойствами).

5. Режим отрисовки как (по умолчанию) свойство
документа
Ранее можно было задать режим визуализации только на вкладке ленты Визуализация.
Теперь можно задать режим визуализации как свойство документа (или как свойство
документа по умолчанию) экрана. Это можно сделать в закладке Экран диалогового окна
Свойства документа или Свойства документа по умолчанию.
Важно!
По умолчанию данный параметр скрыт. Чтобы сделать его доступным, необходимо
создать переменную окружающей среды, DS_3DVC_OVERRIDE_RENDER_MODE, и
задать для нее значение 1.
Данный параметр недоступен/неприменим в SOLIDWORKS Sync/Enterprise Sync.
Поэтому документы Composer, созданные в Sync не содержат данный параметр.
После открытия документа в Composer режим отрисовки, определенный в (по
умолчанию) свойствах документа, будет применен при сохранении файла.
Режим отрисовки, указанный в свойствах документа по умолчанию, не будет
использоваться для документов, сохраненных в более ранних версиях Composer
(для таких документов будет сохранен первоначальный режим отрисовки).

6. Поиск объектов по их типу или NetGUID
На панели поиска можно искать объекты по:
их типу (измерения, метки, геометрия и т.д.): используйте свойство Имя класса с
операторами строки.
их netGUID (или GUID): используйте свойство Net GUID с операторами строки и
регулярными выражениями.
Подробнее о фильтрах и операторах фильтрации см. также в разделе Working in
Workshops (Работа в модулях) > Filters Workshops (Модули фильтров) Руководства
пользователя по Composer.
7. Усовершенствованное управление паролями
Добавлено новое поле Подтвердить пароль для повышения уровня безопасности при
защите документа паролем. Это можно сделать на странице Безопасность диалогового
окна Свойства документа или Свойства документа по умолчанию.

8. Полилинии и метки: Улучшение окончаний стрелок
Окончания стрелок полилиний и меток теперь отображаются корректно: линия более не
накладывается на окончание стрелки, даже широкая линия.

9. SOLIDWORKS Composer Sync: Файл журнала в
формате HTML
Файл журнала SOLIDWORKS Composer Sync, который ранее был доступен только в
формате XML, теперь доступен также в формате HTML. Это делает возможным просмотр
файла журнала в браузере Internet Explorer 9 и выше.
По умолчанию файл журнала отображается в формате HTML. Данный параметр можно
изменить на закладке ведения журналов.

Важно! При обновлении с предыдущей версии Composer перед запуском данной новой
версии необходимо удалить все старые файлы журналов из папки SOLIDWORKS
Composer User (обычно имя_пользователя\Documents\SOLIDWORKSComposer\User).
Эта папка определена в настройках приложения, на странице Application Paths (Пути
приложения).
Файлы журнала, которые необходимо удалить, легко определить по именам: это файлы
типа название_приложения.xml и название_приложения.data; можно также удалить
файлы типа seePub.xml и seePub.data, если такие есть в папке User.
10. 	SOLIDWORKS Composer Player: Постоянное хранение
пользовательских настроек
Добавлены новые параметры реестра GUI для хранения пользовательских настроек,
выполненных во время сеанса Composer Player. Они находятся в
HKEY_CURRENT_USER\Software\Dassault
Systemes\SOLIDWORKSComposer\Players\GuiSettings.
Loop.Play: Сохраняет последнее состояние команды Режим циклического
воспроизведения.
Players.Visibility.<ToolbarName>Toolbar: Отображение или скрытие
панели инструментов с именем <ToolbarName>.
Players.Visibility.<ToolbarName>Toolbar.FullScreen: Настройка
полноэкранного режима и хранение его состояния.
Примечания.
Положение самой панели инструментов не сохраняется.
Данные параметры не сохраняются/не используются, т.к. их обработка уже задана
в свойствах ActiveX.
