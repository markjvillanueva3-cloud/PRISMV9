2. 视口缩放系数属性
现在您可以在视口属性中指定视口缩放系数。
正交视图模式中的照相机高度：
透视图模式中的照相机视场：
属性 	描述
照相机高度 	（在正交视图模式时可用。）根据模型指定照相机的高度，这相当于是确定视口
的缩放系数。增加该值会使模型变得更小。
照相机视场 	（在透视图模式时可用。）指定模型的视角范围，这相当于是确定视口的缩放系
数。增加该值会使模型变得更小。您可以输入值或者使用滑块。

4. 某些属性在行为上的变化
当选择多个角色时，许多以前不支持角色多选的属性如今显示在“属性”窗格中并且可以编辑。
这些属性包括：
对于装配（根）：颜色
对于角色：面积和体积
对于视口：背景渐变、背景动态渐变、发布宽高比、发布非工作区颜色
而且，现在可以从“样式工作间”中获得这些属性，并且可以通过样式配置文件管理这些属性
（像其他属性一样）。

5. 渲染模式作为（默认）文档属性
以前，您只能从功能区的“渲染”选项卡中设置渲染模式。现在您可以将渲染模式定义为文档属
性或者默认文档属性。此操作将在“文档属性”或“默认文档属性”对话框的“视口”页面中完
成。
重要信息：
默认情况下将会隐藏该设置。如果您希望此设置可用，则需要创建一个环境变量
DS_3DVC_OVERRIDE_RENDER_MODE，并将其值设置为 1。
该设置在 SOLIDWORKS Sync/Enterprise Sync 中未提供或者不可用。因此，从 Sync 中
生成的 Composer 文档不包含此设置。如果在 Composer 中打开一个文档，当保存文件
时，将会应用在（默认）文档属性中定义的渲染模式。
对于在更早版本的 Composer 中保存的文档，将不会使用在默认文档属性中指定的渲染模
式（这些文档将会保留其原始渲染模式）。

6. 通过其类型或 NetGUID 搜索角色
您现在可以在搜索“窗格”中根据以下条件搜索角色：
类型（测量值、标签、几何图形等）：使用带字符串运算符的“类别名称”属性。
netGUID（或 GUID）：使用带字符串运算符和正则表达式的 Net GUID 属性。
有关过滤器和过滤运算符的更多信息，另请参见
《Composer
用户指南》中的
“在工作间中工作 >
过滤器工作间”。
7. 改进的密码管理
增加了一个新的“确认密码”字段，以便在使用密码保护文档时改进安全性。“文档属性”或
“默认文档属性”对话框的“安全性”页面中提供了此字段。

8. 折线和标签：箭头端点的改进
折线和标签上的箭头端点现在会正确显示：即便是附加线很宽时，附加线也不会与箭头的尖端重叠。
之前 	现在
宽的附加线会与箭头的尖端重叠。 	宽的附加线不再与箭头的尖端重叠。
9. SOLIDWORKS Composer Sync：采用 HTML 格式的日志文件
之前仅以 XML 格式提供 SOLIDWORKS Composer Sync 日志文件，现在还提供了 HTML 格式。
这确保了可以在 Internet Explorer 9 以及更高版本中阅读该日志文件。
默认情况下，日志文件以 HTML 格式显示。您可以在“日志”页面中更改此设置。
重要信息：如果您正在从之前版本的 Composer 进行升级，那么在运行新版本之前，您必须从
SOLIDWORKS Composer 用户文件夹（通常是 user_name\Documents\
SOLIDWORKSComposer\User）中删除之前的所有日志文件。该文件夹在“应用程序路径”页
面上的应用程序首选项中进行定义。
利用文件名称，您将很容易确定要删除的日志文件：它们是 application_name.xml 和
application_name.data 类型的文件；您还可以删除 seePub.xml 和 seePub.data（如果
此“用户”文件夹中有这样的文件）。

10. SOLIDWORKS Composer Player：用户自定义的永久存储器
增加了新的注册表 GUI 设置，用于存储在 Composer Player 会话中执行的自定义。这些设置可
以在 HKEY_CURRENT_USER\Software\Dassault
Systemes\SOLIDWORKSComposer\Players\GuiSettings 中找到。
Loop.Play：存储“循环播放模式”命令的上一个状态。
Players.Visibility.<ToolbarName>Toolbar：显示或隐藏名为 <ToolbarName>
的工具栏。
Players.Visibility.<ToolbarName>Toolbar.FullScreen：自定义全屏模式并
存储其状态。
注意：
将不会存储工具栏自身的位置。
ActiveX 将不会保存/使用这些设置，而是通过其属性来进行处理。
