2. Viewport Zoom Factor Property
You can now specify the zoom factor of the viewport in the viewport properties.
Camera Height in orthogonal view mode:
Camera FOV in perspective view mode:
Property 	Description
Camera
Height
(Available in orthogonal view mode.) Specifies the height of the camera according to
the model, which amounts to determining the zoom factor of the viewport. Increasing
the value makes the model smaller.
Camera
FOV
(Available in perspective view mode.) Specifies the angular extent of the view of the
model, which amounts to determining the zoom factor of the viewport. Increasing the
value makes the model smaller. You can enter a value or use the slider.

4. Change in Behavior for Some Properties
A number of properties, which previously did not support the multi-selection of actors, are now
displayed and editable in the Properties pane when several actors are selected. These
properties are:
For an assembly (root): Color
For actors: Area and Volume
For viewport: Background Gradient, Background Dynamic Gradient, Publication Aspect,
Publication Non Client Color
Moreover, these properties are now available from the Styles workshop, and can be managed
through style profile (like other properties).

5. Render Mode as a (Default) Document Property
Previously, you could only set the render mode from the Render tab in the ribbon. You can now
define the render mode as a document property, or as a default document property, of the
viewport. This is done in the Viewport page of the Document Properties or Default
Document Properties dialog box.
Important:
This setting is hidden by default. If you wish to make it available, you need to create an
environment variable, DS_3DVC_OVERRIDE_RENDER_MODE, and set its value to 1.
This setting is not available/applicable in SOLIDWORKS Sync/Enterprise Sync.
Therefore, Composer documents generated from Sync do not contain this setting. Once
a document is opened in Composer, the render mode defined in the (default) document
properties will be applied when saving the file.
The render mode specified in the default document properties will not be used for
documents saved in earlier versions of Composer (these documents will keep their
original render mode).

6. Search for Actors through their Type or NetGUID
In the Search pane, you can now search for actors according to:
their type ( measurements, labels, geometry, and so on): use the Class name property
with string operators.
their netGUID (or GUID): use the Net GUID property with string operators and regular
expression.
For more information on filters and filtering operators, see also Working in Workshops > Filters
Workshops in the Composer User’s Guide.
7. Improved Password Management
A new Confirm password field has been added for improved safety when securing a document
with a password. This is available in the Security page of the Document Properties or Default
Document Properties dialog box.

is now also available in HTML. This ensures that the log file can be read in Internet Explorer 9

defined in the application preferences, on the Application Paths page.

10. SOLIDWORKS Composer Player: Permanent Storage of
User Customization
New registry GUI settings have been added to store the customization performed during a
Composer Player session. These can be found in
HKEY_CURRENT_USER\Software\Dassault
Systemes\SOLIDWORKSComposer\Players\GuiSettings.
Loop.Play: Stores the last state of the Loop Play Mode command.
Players.Visibility.<ToolbarName>Toolbar: Shows or hides the toolbar named
<ToolbarName>.
Players.Visibility.<ToolbarName>Toolbar.FullScreen: Customizes the full
screen mode and store its state.
Notes:
The position of toolbars itself is not stored.
These settings are not saved/used by the ActiveX, which already handles them through
its properties.

4. Other Requirements
4.1. 	User Assistance Requirements
The browser-based user assistance portal and search engine require the following:
Either of the following:
o 	On Microsoft Windows 7 64-bit: 32-bit versions of both Microsoft Internet
Explorer 9 or 10 and Oracle Java plug-in version 7 (enabled)
o 	On Microsoft Windows 8 64-bit: 32-bit versions of both Microsoft Internet
Explorer 10 and Oracle Java plug-in version 7 (enabled)
o 	On all supported operating systems: 32-bit versions of both Firefox ESR 17 and
Oracle Java plug-in version 7 (enabled)
64-bit Oracle Java Runtime Environment (JRE) 7
Note: Ensure that only one version of JRE is installed.
4.2. 	File Import Requirements
Depending on the file formats you import into SOLIDWORKS Composer, SOLIDWORKS Sync
or SOLIDWORKS Enterprise Sync, different requirements might apply. For example, if you
import SolidWorks® files, you must satisfy the minimum requirements for your version of
SolidWorks (see http://www.solidworks.com/sw/support/SystemRequirements.html).
