4. Modification du comportement de certaines propriétés
Certaines propriétés, qui autrefois ne prenaient pas en charge la sélection de multiples acteurs,
sont désormais modifiables et s'affichent dans le panneau Propriétés lorsque plusieurs acteurs
sont sélectionnés. Ces propriétés sont les suivantes :
Pour un assemblage (racine) : couleur
Pour les acteurs : aire et volume
Pour le viewport : dégradé d'arrière-plan, dégradé dynamique d'arrière-plan, format de la
zone publiée, couleur hors zone de la publication
En outre, ces propriétés sont désormais disponibles dans le Workshop des Styles et peuvent
être gérées via le profil de styles (comme d'autres propriétés).

5. Mode de rendu en tant que propriété de document (par
défaut)
Auparavant, vous pouviez uniquement configurer le mode de rendu à partir de l'onglet Rendu
dans le ruban. Désormais, vous pouvez configurer le mode de rendu en tant que propriété de
document ou propriété de document par défaut du viewport. Pour ce faire, accédez à la page
Viewport dans la boîte de dialogue Propriétés du document ou Propriétés de document par
défaut.
Important :
Ce paramètre est caché par défaut. Si vous souhaitez qu'il soit disponible, vous devez
créer la variable d'environnement DS_3DVC_OVERRIDE_RENDER_MODE et définir sa
valeur à 1.
Ce paramètre n'est pas disponible/applicable dans SOLIDWORKS Sync/Enterprise
Sync. Par conséquent, ce paramètre n'est pas disponible pour les documents Composer
générés à partir de Sync. Lorsqu'un document est ouvert dans Composer, le mode de
rendu défini dans les propriétés de document (par défaut) s'appliquera lors de
l'enregistrement du fichier.
Le mode de rendu spécifié dans les propriétés de document par défaut ne sera pas
utilisé pour les documents enregistrés dans des versions antérieures de Composer (le
mode de rendu d'origine sera alors conservé).

6. Rechercher des acteurs par type ou par NetGUID
Dans le panneau Rechercher, vous pouvez désormais rechercher des acteurs en fonction de :
Leur type (mesures, étiquettes, géométrie, etc.) : utilisez la propriété Classe d'objet
avec des opérateurs de chaîne.
Leur netGUID (ou GUID) : utilisez la propriété Net GUID avec des opérateurs de chaîne
et une expression régulière.
Pour obtenir plus d'informations sur les filtres et les opérateurs de filtrage, reportez-vous à la
section Working in Workshops > Filters Workshops (Utilisation des Workshops > Workshops
Filtres) du Guide d'utilisation de Composer.
7. Gestion améliorée des mots de passe
Un nouveau champ Confirmer le mot de passe a été ajouté pour une sécurité accrue lorsque
vous protégez un document à l'aide d'un mot de passe. Pour y accéder, rendez-vous sur la
page Sécurité dans la boîte de dialogue Propriétés du document ou Propriétés de
document par défaut.

8. Polylignes et étiquettes : amélioration de l'extrémité des
flèches
L'extrémité des flèches sur les polylignes et les étiquettes s'affiche désormais correctement : la
ligne d'attache ne chevauche plus la pointe de la flèche, même lorsque la largeur de la ligne

La ligne d'attache de grande ampleur
chevauche la pointe de la flèche.
La ligne d'attache de grande ampleur ne
chevauche plus la pointe de la flèche.
9. SOLIDWORKS Composer Sync : fichier journal au format
HTML
Le fichier journal SOLIDWORKS Composer Sync, uniquement disponible au format XML
jusqu'à maintenant, est désormais disponible au format HTML. Ainsi, le fichier journal peut être
lu dans Internet Explorer 9 et versions ultérieures.
Par défaut, le fichier journal s'affiche au format HTML. Vous pouvez modifier ce paramètre dans
la page Journal.

Important : si vous effectuez une mise à niveau depuis une version précédente de Composer,
vous devez supprimer tous vos fichiers journaux antérieurs dans le dossier Utilisateur de
SOLIDWORKS Composer (généralement nom_d'utilisateur\Documents\
SOLIDWORKSComposer\User) avant d'exécuter cette nouvelle version. Ce dossier est défini
dans les préférences d'application, dans la page Chemins de l'application.
Vous pouvez facilement identifier les fichiers journaux à supprimer à l'aide de leur nom : ceux-ci
sont du type application_name.xml et application_name.data. Vous pouvez
également supprimer les fichiers seePub.xml et seePub.data si ces derniers sont présents
dans le dossier Utilisateur.
10. SOLIDWORKS Composer Player : mémorisation des
éléments personnalisés par l'utilisateur
De nouveaux paramètres de registre concernant l'interface graphique ont été ajoutés afin
de mémoriser les éléments personnalisés lors d'une session Composer Player. Ceux-ci
sont disponibles sous HKEY_CURRENT_USER\Software\Dassault
Systemes\SOLIDWORKSComposer\Players\GuiSettings.
Loop.Play : enregistre le dernier état de la commande Mode Jouer en Boucle.
Players.Visibility.<NomBarreOutils>Toolbar : affiche ou cache la barre
d'outils nommée <NomBarreOutils>.
Players.Visibility.<NomBarreOutils>Toolbar.FullScreen : permet de
personnaliser le mode plein écran et d'enregistrer son état.
Remarques :
La position des barres d'outils n'est pas enregistrée.
Ces paramètres ne sont pas enregistrés/utilisés par l'ActiveX, qui s'en charge déjà par le
biais de ses propriétés.
