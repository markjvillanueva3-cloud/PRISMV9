4. Modifica del comportamento di alcune proprietà
Determinate proprietà, che in precedenza non supportavano la selezione di più attori, ora sono
visualizzate e modificabili nel pannello Proprietà, quando si selezionano diversi attori. Le
proprietà in questione sono:
Per un assieme (root): Colore
Per gli attori: Area e Volume
Per Viewport: Gradiente sfondo, Gradiente dinamico sfondo, Proporzioni pubblicazione,
Pubblicazione colore non client
Queste proprietà sono inoltre disponibili tramite il workshop Stili e possono essere gestite
attraverso il profilo dello stile, proprio come tutte le altre proprietà.

5. Modalità di rendering come Proprietà (predefinita)
documento
In passato, si poteva impostare la modalità di rendering unicamente nella scheda Rendering
della barra multifunzione. Ora questa modalità può essere definita in quanto proprietà di un
documento, o come proprietà predefinita di un documento, di Viewport, dalla pagina Viewport
della finestra di dialogo Proprietà documento o Proprietà predefinite documento.
Importante:
Questa impostazione è nascosta per impostazione predefinita. Per renderla disponibile,
è necessario creare una variabile di ambiente, DS_3DVC_OVERRIDE_RENDER_MODE, e
impostarne il valore su 1.
Questa impostazione non è disponibile/applicabile per SOLIDWORKS Sync/Enterprise
Sync. Pertanto, non è contenuta nei documenti Composer generati da Sync. Una volta
aperto un documento in Composer, la modalità di rendering definita nelle proprietà
(predefinite) del documento viene applicata quando si salva il file.
La modalità di rendering specificata nelle proprietà predefinite del documento non verrà
utilizzata per i documenti salvati con versioni precedenti di Composer: essi manterranno
invece la modalità di rendering originale.

6. Ricerca degli attori per Tipo o NetGUID
Nel pannello Ricerca è possibile cercare gli attori in base a:
Tipo (es. misure, etichette, geometria): usare la proprietà Nome classe con gli operatori
di stringa.
NetGUID (o GUID): usare la proprietà Net GUID con operatori di stringa ed espressioni
regolari.
Per maggiori informazioni sui filtri e sui relativi operatori, consultare anche Working in
Workshops > Filters Workshops nella Guida per l'utente di Composer.
7. Gestione password migliorata
È stato aggiunto il nuovo campo Conferma password per maggiore sicurezza quando si
protegge un documento con una password. Questo nuovo campo è disponibile nella pagina
Protezione della finestra di dialogo Proprietà documento o Proprietà predefinite
documento.

9. SOLIDWORKS Composer Sync: file di log in formato
HTML
Il file di log di SOLIDWORKS Composer Sync, precedentemente disponibile solo in formato
XML, ora è generato anche in formato HTML, in modo che sia leggibile su Internet Explorer 9 e
versioni successive.
Il file di log viene visualizzato per impostazione predefinita in HTML, ma questa impostazione
può essere modificata nella pagina Accesso.

Importante: se si effettua l'upgrade da una versione precedente di Composer, prima di
avviare la nuova versione, bisogna eliminare tutti i precedenti file di log dalla cartella utente
SOLIDWORKS Composer (generalmente user_name\Documents\
SOLIDWORKSComposer\User). Questa cartella viene definita nelle preferenze
dell'applicazione, alla pagina Percorsi applicazione.
A partire dai loro nomi, sarà facile individuare i file di log da eliminare: si tratta dei tipi
application_name.xml e application_name.data. È possibile eliminare anche
seePub.xml e seePub.data, se presenti nella cartella utente.
10. SOLIDWORKS Composer Player: storage permanente
delle personalizzazioni dell'utente
Sono state aggiunte nuove impostazioni di registro della GUI per archiviare le
personalizzazioni applicate durante una sessione di Composer Player. Sono disponibili
in HKEY_CURRENT_USER\Software\Dassault
Systemes\SOLIDWORKSComposer\Players\GuiSettings.
Loop.Play: archivia l'ultimo stato del comando Modalità Riproduzione a ciclo
continuo.
Players.Visibility.<ToolbarName>Toolbar: mostra o nasconde la barra degli
strumenti denominata <ToolbarName>.
Players.Visibility.<ToolbarName>Toolbar.FullScreen: personalizza la
modalità a tutto schermo e ne archivia lo stato.
Note:
La posizione delle barre degli strumenti non viene archiviata.
Queste impostazioni non sono salvate/usate da ActiveX, che le gestisce già tramite le
proprietà.
