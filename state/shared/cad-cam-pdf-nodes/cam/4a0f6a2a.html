Sub script call on tool report
When generating the tool report, there may be a need to add some additional information that was not
foreseen in the template.
In this case, we can create a supplementary script and call this script when generating the report.

9
Tool report app
After creating the Runtime script, an XML and hms file will be created in your app folder
<AUTOMATION>\Apps
Let’s copy these files and past these files on:
<AUTOMATION>\REPORTS\toolReports\apps
Maybe the folder apps do not exist in your computer.
If this is your case, just create a new folder named as apps.

Before executing the tool Report configuration, it is recommended to delete the Roaming folder
• Open the file explorer and type %appdata%
• Go to Roaming\OPEN MIND\AutomationCenter\<VERSION>
• Delete everything inside this folder (process_apps, process_report_template and
