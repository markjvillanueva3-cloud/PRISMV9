Running the AC in a Server
We can easily run the AC in a server.
The script must be adapted to have no user interaction, otherwise the application will fall.
It is very important to know that the application is just watching a folder and running a script that was
previously defined.
Every action like (Save file, log message, errors) must be manage in the script).
The application will just run what you asked for.
All files can be found on C:\Program Files\OPEN MIND\hyperMILL\#version#\addins\hmAutoColor
PW server configuration (PWserver.exe)
There is one executable file where we can define:
• Watch folder
• Project number (script to be executed)
• Priority
• File type
The watch folder must be a folder accessibly by all clients and server
