Using PW Server with Excel files
Configuration file
Before start, we have some parameters to be defined.
Those parameters can be defined in the file “autoProgramConfig.pcf”
This config file can be found on C:\Program Files\OPEN
MIND\hyperMILL\#version#\addins\hmAutoColor
In this case the version is 29.0
We have 3 parameters to be defined
*EXCEL_FOLDER=c:/temp/defaultExcel.xlsx
*DEFAULT_TEMPLATE=c:/temp/HCS_template.hmc
*DEFAULT_TEMP_START_FILE=c:/temp/start.hmc
The EXCEL file, found in the in-server folder will be copied to the name defined in the parameter
“*EXCEL_FOLDER”.
In the file defined in “*DEFAULT_TEMPLATE” will be copied to the file defined in
“*DEFAULT_TEMP_START_FILE”
hyperCAD-S will be started with “*DEFAULT_TEMP_START_FILE”
In the script the user should read the EXCEL file from “*EXCEL_FOLDER”. It is supposed that a script
name for the process has been defined in it. It has to be called from the start script
In the EXCEL it is supposed to find a model file to be merged in the current model.
The file should be saved to a place defined in the EXCEL file.
The file must be edited as Admin.
