1. Introduction
Many tool suppliers offer 3D models of their tools. You can use the
hyperMILL TOOL Builder to interactive-
ly prepare these models so they can be used for calculation, collision checking and simulation.
3D data import and tool entity creation is handled by running a pre-specified series of steps from a toolbar
in the
hyperMILL TOOL Builder. It is also possible to repeat a command from a previous step. Selected
entities, such as the solids for a holder or axes, for example, are automatically labelled with tags and
saved to an appropriately named layer.
A 	Milling tool: 1 	spindle, 2 	lower spindle coupling, upper holder coupling, 3 	lower holder coupling, up-
per extension coupling, 4 	holder, 5 	extension, 6 	tool.
B 	Turning tool: 7 	insert tool holder, 8 	insert.
The following information refers to creating a tool holder 7 	for turning tools and a holder 4 	and an exten-
sion 5 	for milling tools.
NOTE
Tool holders with a rotationally symmetrical support in the spindle are supported. Tool
holders with a prismatic defined support for a tool turret are not currently supported.
The following insert shapes are supported in combination with the specified tool holders:
• Rhombic insert
• Triangular insert
• W-shape insert
• Round insert
• Rectangular inserts

2. Positional orientation
When tools are assembled, a positional orientation is required.
The Z axis lies coaxially to the main flange and points in the direction of the spindle.
Holder/extension positional orientation
The alignment around the Z axis will allow non-symmetrical entities, such as drill heads and angle heads,
to be supported in the future. If a holder (for example, HSK, CAPTO, KM and KM4X) is also used for turn-
ing on a mill/turn machine, the alignment around the Z axis must be observed. In the case of usual milling
applications with circumferentially rotated bodies, the alignment around the Z axis is only a visual/aesthetic
issue.
BT
The X axis points towards the centre of one of the two slots 1 	. As the BT is symmetrical, the alignment of
the X axis can only be distinguished with other attributes (for example, a screw or another non-symmetrical
entity). Check the alignment of this entity before the 3D data import on the machine tool. The upper cou-
pling should be defined in the flange depth.
SK
The X axis points towards the centre of the flattest slot 2 	– on the same side as the notch 3 	. The upper
coupling should be defined in the flange depth (3.2 mm above the upper side of the flange).
CAT
The X axis points towards the centre of the flattest slot 4 	. The upper coupling should be defined in the
flange depth (3.2 mm above the upper side of the flange).

3. Steps for creating
Turning tool: Creating an insert tool holder
Steps to create an insert tool holder
Overview: open geometry file – define body – define axis – define coupling – define outline profile – define
insert (optional) – generate STL file – export data.
Open geometry file
Icon:
Open a 3D geometry file in the *.step,*.stp,*.iges or *.hmc format.
Define body
Icon:
Specify the geometry of the insert tool holder.
Select Entities. The selected geometric entities 1 	are highlighted in colour and the number of entities is
shown. The data is saved on a designated layer and marked with a tag.
Define axis
Icon:
The geometry of the insert tool holder is recognised automatically based on the coaxial faces of the body
and the program automatically suggests the axis alignment (machine side/workpiece side). A reference co-
ordinate system 1 	is created, whose alignment corresponds to the Z axis of the insert tool holder.
Manually adjust the Direction of the axis if necessary. To do so, select entities or 2 points. The order in
which the points are selected defines the direction 2 	of the axis. Invert the Direction by double-clicking the
axis arrow 2 	or use the Invert command.
The data is saved on a designated layer and marked with a tag.

NOTE

hyperMILL TOOL Builder software. Man-
ual definition in the tool database is not possible. The Rake angle and Inclination angle

Turning tool holder assembly
Assemble tool holder for turning tool. Switch to Assembly mode. Display the toolbars that
are preconfigured for this.
Toolbar
Assembly the 3D data provided by tool manufacturers to form a tool holder for turning tools. Switch to As-
sembly mode. Display the toolbars that are preconfigured for this.
Procedure
The following five basic steps are required to assemble a tool holder for turning tools.
When defining a tool holder for turning tools, select the Geometry → 3D file option beforehand in the OPEN
MIND tool database. In the 3D file row, then select the option.
1. Select model for base body. The Open command is called automatically for this purpose.
See Open.
2. Cancel the Body command. Then show the preconfigured toolbars. To do this, click . The back-
ground colour of the graphics area changes.
3. Load parts that are attached to the base body.
See Merge.
TIP
Select the Group entities option of the Merge command. All imported entities are
combined into a group. This makes it easier to attach a part as a whole to the base
body. Use Save as default to preset the option.
4. Attach the parts to the base body. Assemble the various solids and groups using Mating and Move /
copy.
See Mating.
The base body is fixed automatically by loading a first additional part.
5. If you choose, simplify the tool holder so that it specifies the actually existing tool holder with sufficient
accuracy.
See Direct modelling.
CAUTION
Collisions may occur if the outer shape of the tool holder model does not match the
tool holder that is really used.
6.
Switch back to the normal mode for defining a tool holder and complete the definition of
the tool.

4. Options
Open the hyperMILL TOOL Builder options dialogue to define display and precision options.
File → Options
Mesh tolerance: Specify precision for reading in the geometry data in the *.step, *.stp, *.iges or *.hmc for-
mats.
Assembly mode: Display toolbars for assembling tool holders for turning tools.
Tool holder
Profile tolerance: Specify precision for the outline profile of the insert tool holder.
Holder
Profile tolerance: Specify precision for the rotational profile of the holder.
Colours
Define the colours for the Axis, Machine / workpiece indicators, Profile, Body mesh, Insert mesh and Rota-
tional shape. To do so, select the entity in the Value column and click the button to open the colour selec-
tion dialogue and define the desired colours. This can also be adjusted directly for each entity in the corre-
sponding row (red, green, blue).
Display the background of the graphics area in a different colour for the Assembly mode. To do this, select
the Assembly - bottom colour and Assembly - top colour options.
Use Save settings to save your changes.
