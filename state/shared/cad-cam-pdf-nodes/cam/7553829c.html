Requirements and set up exchange folder
NOTE
The following notes apply to the tool database from version 2021.1.
When importing external tool data into the
hyperMILL tool database, synchronization is performed by a local
Windows service. The following requirements must be met for the service to work without problems:
1. Service, tool database and exchange folder must be on one Computer.
2. A
hyperMILL installation is mandatory because the tool database uses
hyperCAD-S functions to create tool
geometries.
3. The exchange folder must be provided with full access rights for the service.
4. A
hyperMILL license must be available during the setup of the service. If the setup is complete, the licence is
no longer required.
To give the exchange folder the necessary access rights, proceed as follows:
1. Switch to the exchange folder.
2. Right click and choose Properties → Security.
