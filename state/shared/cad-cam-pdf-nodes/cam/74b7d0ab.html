1. Introduction
The VIRTUAL Machining simulation solution allows machining operations to be reliably evaluated, checked
and optimised before the machine run thanks to a virtual mapping of the actual processes. The central
component is the VIRTUAL Machining Center software with simulation and analysis options for the NC
code following the postprocessor run. The Optimizer module automatically calculates the best solution
for multi-axis machining from various possible tool inclinations. The CONNECTED Machining module
connects the CAM workstation and machine tool to allow a bidirectional exchange of information between
the generation and execution of programs.
VIRTUAL Machining Center
VIRTUAL Machining Center delivers maximum processing safety. Actual machining operations, including
linking movements, are mapped virtually and can be simulated after the postprocessor run completely on
the basis of the NC code. The simulation on the virtual machine also takes into account the holder, fixtures
and clamps in addition to workpiece and tool. Axes can be moved manually, axis limitations are indicated
and limit switch traversals are detected automatically. Each machining operation is checked before any
movement on the machine. Machining steps can be simulated individually. Collisions can be detected and
therefore avoided.
Numerous analysis functions allow machining situations to be thoroughly checked. The best-fit function
automatically calculates the optimal placement of the part for the available workspace. This can prevent
time-consuming adjustments of the machine setup. Axis diagrams show the traversing movements of the
individual axes in detail. Unusual movements can be identified quickly and can be corrected before the
program is transferred to the machine.
VIRTUAL Machining Optimizer
The VIRTUAL Machining Optimizer module provides support for multi-axis machining. Optimization algo-
rithms calculate the technically best tool positions that allow efficient traverse movements during machin-
ing. All selected tool positions are checked for possible collisions, thus guaranteeing a safe machine
run. Programming errors are avoided. This means there is no need to make subsequent changes to the
machining programs on the machine.
CONNECTED Machining
The CONNECTED Machining module allows networking and synchronisation with the machine via a
bidirectional data exchange with the controller. Data can be sent to the machine and executed there, and
data can also be received from the machine. The actual machining is available in the simulation in ‘real
time’.
Before the machine run, machining and machine configurations, such as zero-point definitions, tool data
and machine configuration parameters, are read from the controller and checked against the program data
in
hyperMILL. The machine run will only start if the data matches and the collision check has been carried
out successfully. The NC programs are loaded directly into the memory of the controller. This stops the
programs from being mixed up and protects them against unauthorised access.
This software documentation provides information on how to use the VIRTUAL Machining Center and
CONNECTED Machining software.

3. Operating modes
Use the main navigation toolbar to switch between the various operating modes: Project administration,
Program run (simulation), Machine configuration, VIRTUAL Machining Center configuration and Analysis.
Project administration operating mode
In large NC programs, load one of several available main programs. If the project only
contains one main program, this main program is loaded automatically.
Program run (simulation) operating mode
Simulate the VNC program file or NC program file. Show the control elements for regulating
the speed, the block display and the coordinate values. Control how the tool, part, stock
and clamp are displayed.
Machine configuration operating mode
Control the display of the machine elements. Position the machine axes manually (manual
control). View the axis limits of the machine.
VIRTUAL Machining Center configuration operating mode
Display changes to the NC file, set the minimum feedrate for the rapid, show the toolpaths
for linking jobs, display the tool reference point and coordinate systems of the machine in
use.
Analysis operating mode
Perform a graphical analysis of the movement paths of the machine axes, define break-
points and conditions for breakpoints, display breakpoints as a list and display breakpoint
coordinates.

Best Fit - determine real part position
More complex part shapes, alternative manufacturing processes (casting, 3D printing,
forged stock) and smaller allowances make manually aligning the part very time-con-
suming. The
hyperMILL Best Fit alignment eliminates the need for time-consuming
manual alignment measures. Positioning is automatic and based on the internal origin
shift captured using the 3D Point Probing cycle. Probing takes place both in the CAM
programming and on the machine, so that the position deviation between the virtual and
the real situation can be determined and corrected. The Best Fit real part position is
adjusted in the VIRTUAL Machining Center and is checked for collisions. An attempt is
made to comply with all machine limits with the help of the NC optimizer.

The following applies to the terms used in the collision check message:
