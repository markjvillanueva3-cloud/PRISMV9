Modifying the tool report template
We have a very nice solution in hyperMILL to generate tool reports.
This application is Automation Center based.
That means, the AC is running behind.
In this documentation we are going to explain how to customize a new template.

-- 1 of 10 --

2
Path definitions
• The Addins path in the settings we will call in this document <ADDINS>
• The Automation Center path in the settings we will call in this document <AUTOMATION>

-- 2 of 10 --

3
• The new name of the report we will call <REPORT_NAME>
• The language of the report we will call <LANGUAGE>

-- 3 of 10 --

4
Copy folder
Copy the folder OM_REPORT_2
We can find this folder on:
• <ADDINS>\hmAutoColor\SYSTEM_PROCESS\Reports\ToolReports
Past folder
Past the folder OM_REPORT_2 on:
• <AUTOMATION>\REPORTS\toolReports\report_templates\
Maybe the folder report_templates does not exist in your computer.
If this is your case, just create a new folder named as report_templates.

-- 4 of 10 --

5
Rename the template folder
Rename the template folder as your <REPORT_NAME>
After that, a new folder will appear to be selected in the Tool report configuration

-- 5 of 10 --

6
Rename files
• The file Template_OM_REPORT_2.xlsx must be renamed to
Template_<REPORT_NAME>.<LANGUAGE>.xlsx
• The file ToolReport_OM_REPORT_2.xlsx must be renamed to
ToolReport _<REPORT_NAME>.xlsx
• The file OM_REPORT_2_JL.jpg must be renamed to
<REPORT_NAME>_JL.jpg

-- 6 of 10 --

7
Modifying the template
• Open the file (Template_<REPORT_NAME>.<LANGUAGE>.xlsx)
• Customize the template as do you wish

-- 7 of 10 --

8
Modifying the Header definition
• Open the file (ToolReport _<REPORT_NAME>.xlsx)
• Go to Header tab
• Only existing parameters from column “B” can be used
• Rows must not be changed
• Cell address can be specified in columns “C”

-- 8 of 10 --

9
Modifying the tool definition
• Open the file (ToolReport _<REPORT_NAME>.xlsx)
• Go to Tool Part Definition tab
• Only existing parameters from column “B” can be used
• Rows must not be changed
• Cell address can be specified in columns “C”

-- 9 of 10 --

10
Final step
• Start the report configuration and run the report
