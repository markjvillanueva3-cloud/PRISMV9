1. Introduction
The
hyperMILL VIRTUAL Machining simulation solution allows machining operations to be reliably evalu-
ated, checked and optimised before the machine run thanks to a virtual mapping of the actual processes.
The central component is the
hyperMILL VIRTUAL Machining Center software with simulation and analysis
options for the NC code following the postprocessor run. The Optimizer module automatically calculates
the best solution for multi-axis machining from various possible tool inclinations. The CONNECTED Ma-
chining module connects the CAM workstation and machine tool to allow a bidirectional exchange of
information between the generation and execution of programs.
hyperMILL VIRTUAL Machining Center
hyperMILL VIRTUAL Machining Center delivers maximum processing safety. Actual machining operations,
including linking movements, are mapped virtually and can be simulated after the postprocessor run
completely on the basis of the NC code. The simulation on the virtual machine also takes into account the
holder, fixtures and clamps in addition to workpiece and tool. Axes can be moved manually, axis limitations
are indicated and limit switch traversals are detected automatically. Each machining operation is checked
before any movement on the machine. Machining steps can be simulated individually. Collisions can be
detected and therefore avoided.
Numerous analysis functions allow machining situations to be thoroughly checked. The best-fit function
automatically calculates the optimal placement of the part for the available workspace. This can prevent
time-consuming adjustments of the machine setup. Axis diagrams show the traversing movements of the
individual axes in detail. Unusual movements can be identified quickly and can be corrected before the
program is transferred to the machine.
hyperMILL VIRTUAL Machining Optimizer
The
hyperMILL VIRTUAL Machining Optimizer module provides support for multi-axis machining. Optimi-
sation algorithms calculate the technically best tool positions that allow efficient traverse movements
during machining. All selected tool positions are checked for possible collisions, thus guaranteeing a safe
machine run. Programming errors are avoided. This means there is no need to make subsequent changes
to the machining programs on the machine.
hyperMILL CONNECTED Machining
The
hyperMILL CONNECTED Machining module allows networking and synchronisation with the machine
via a bidirectional data exchange with the controller. Data can be sent to the machine and executed there,
and data can also be received from the machine. The actual machining is available in the simulation in
‘real time’.
Before the machine run, machining and machine configurations, such as zero-point definitions, tool data
and machine configuration parameters, are read from the controller and checked against the program data
in
hyperMILL. The machine run will only start if the data matches and the collision check has been carried
out successfully. The NC programs are loaded directly into the memory of the controller. This stops the
programs from being mixed up and protects them against unauthorised access.
This software documentation provides information on how to use the
hyperMILL VIRTUAL Machining
Center and
hyperMILL CONNECTED Machining software.

3. Operating modes
Use the main navigation toolbar to switch between the various operating modes: Project administration,
Program run (simulation), Machine configuration, VIRTUAL Machining Center configuration and Analysis.
Project administration operating mode
In large NC programs, load one of several available main programs. If the project only
contains one main program, this main program is loaded automatically.
Program run (simulation) operating mode
Simulate the VNC program file or NC program file. Show the control elements for regulating
the speed, the block display and the coordinate values. Control how the tool, part, stock
and clamp are displayed.
Machine configuration operating mode
Control the display of the machine elements. Position the machine axes manually (manual
control). View the axis limits of the machine.
hyperMILL VIRTUAL Machining Center configuration operating mode
Display changes to the NC file, set the minimum feedrate for the rapid, show the toolpaths
for linking jobs, display the tool reference point and coordinate systems of the machine in
use.
Analysis operating mode
Perform a graphical analysis of the movement paths of the machine axes, define break-
points and conditions for breakpoints, display breakpoints as a list and display breakpoint
coordinates.

Best Fit - determine real part position
NOTICE
More complex part shapes, alternative manufacturing processes (casting, 3D printing,
forged stock) and smaller allowances make manually aligning the part very time-con-
suming. The
hyperMILL Best Fit alignment eliminates the need for time-consuming
manual alignment measures. Positioning is automatic and based on the internal origin
shift captured using the 3D Point Probing cycle. Probing takes place both in the CAM
programming and on the machine, so that the position deviation between the virtual and
the real situation can be determined and corrected. The Best Fit real part position is
adjusted in the
hyperMILL VIRTUAL Machining Center and is checked for collisions. An
attempt is made to comply with all machine limits with the help of the NC optimiser.

Collision check options
Use the following options to control the collision check.
NOTE
The tolerance values/limit values for the still permissible contact of the tool with the
part/stock must be in reasonable proportion to the size of the tool used. OPEN MIND
recommends defining these values no larger than half the tool diameter.
Check tool against model: Checks the tool against the model.
Check holder/shaft/core against model: Holder, shank and tool core are checked against the model.
Always check G0: The rapid traverse check is activated by default. If the Check tool against model function

Synchronising data and performing consistency checks
A consistency check must be performed before an NC program is used.
For this purpose, the current data is loaded from the machine and a check is made to see whether the data
in the NC program matches the real data on the machine.
Update Heidenhain CNC: Transfer data from the machine.
If the values in the Origin table, Tool table or Machine configuration areas
do not match, the corresponding areas are graphically highlighted by col-
oured buttons. A distinction is made between Error 1 	and Warning 2 	.
Error 1 	: The NC program is not approved and cannot be loaded onto the
machine until the errors are fixed. The following error message is output:
Consistency check with error(s).
Warning 2 	: A check should be carried out. The NC program can be ap-
proved and loaded onto the machine. The following warning message is
output:
Consistency check with warning(s). Continue?
If the question is answered with Yes, the NC program is loaded onto the
machine and the following message is output:
Upload to CNC succeeded.
