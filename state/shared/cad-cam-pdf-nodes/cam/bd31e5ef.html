1. HMC Batch Converter
Mit diesem lizenzfreien Batch-Konvertierungs-Tool können Sie mehrere und verschiedene CAD-Dateien
gleichzeitig in HMC konvertieren.
1.1. Wichtig
Die OPEN MIND Technologies AG übernimmt keine Gewähr für die Ergebnisse der Konvertierung. Wichti
ge Dateien müssen manuell bezüglich des -Imports geprüft werden, z. B. indem Sie sie manuell konvertie
ren. Öffnen Sie dazu die CAD-Datei in .
Sobald die Datei gespeichert ist, wird sie in HMC konvertiert. Da wir unsere Produkte ständig weiterentwi
ckeln, behalten wir uns das Recht vor, die Anwendung in zukünftigen Versionen zu ändern.
1.2. System-Voraussetzungen
Die Installation von lizenzierten Softwareversionen von und auf dem System muss sichergestellt sein.
Zudem muss eine aktive Lizenz der Software, deren Dateiformat konvertiert werden soll, vorhanden sein.
1.3. Quick start
Für den schnellen Start können Sie im Video sehen, wie Sie den Batch Converter schnell und einfach nut
zen können.
Klicken Sie auf die Pinnadel, um ein Video zum Thema zu sehen.

2. So konvertieren Sie Dateien in HMC
Der Batch Converter ist ein einfach zu verwendendes Konvertierungswerkzeug. Gehen Sie wie folgt vor:
1. Starten Sie den Batch Converter, siehe Abschnitt 3, „Den HMC Batch Converter starten“
2. Überprüfen Sie ggf. die allgemeinen Einstellungen (z. B. HMC-Ausgabeordner), siehe Abschnitt 3.2,
„Nehmen Sie allgemeine Einstellungen vor“
3. Wählen Sie Ordner aus, die zu konvertierende Dateien enthalten, siehe Abschnitt 3.3, „Auswahl von
Dateien und Ordnern“
4. Starten Sie die Konvertierung, siehe Abschnitt 4, „Dateikonvertierung starten“
5. Beenden Sie die Konvertierung, siehe Abschnitt 5, „Das Programm beenden“
6. Optional: XML-Datei bearbeiten, siehe Abschnitt 6, „XML-Datei konfigurieren (optional)“

3. Den HMC Batch Converter starten
Der Batch Converter wird automatisch im separaten Unterordner
BatchConverter des -Installationsordners
installiert.
• Gehen Sie in das Batch-Converter-Unterverzeichnis und doppelklicken Sie
hmcBatchConverter.exe.
Der Batch Converter wird gestartet, das Batch-Converter-Fenster wird geöffnet.
3.1. Beschreibung des Batch-Converter-Fensters
Das Fenster zum Batch Converter ist ein übersichtliches Dialogfenster. Sehen Sie alle relevanten Kompo
nenten auf einen Blick.
1. Titelleiste: Zeigt das Dialogfeld des Batch Converters
2. Abschnitt General Settings: Auswahl des Ordners
hmc.exe (falls erforderlich) der aktuellen Version und
eines Ausgabeordners zum Speichern der konvertierten HMC-Dateien.

werden. Die Standardwerte werden automatisch festgelegt.

Sie aus irgendeinem Grund zu einer anderen hmc.exe wechseln müssen, wählen Sie den entsprech
enden Pfad aus, indem Sie auf diese Schaltfläche drücken und den gewünschten Pfad auswählen.

2. Output HMC folder:
Wenn Sie möchten, dass die HMC-Ausgabedateien im selben Ordner wie das Eingabemodell gespei
chert werden, wählen Sie Input Model folder = HMC Output.
Wenn Sie möchten, dass die HMC-Ausgabedateien in einem separaten Ordner gespeichert werden,
wählen Sie Separate HMC Output folder. Die zusätzliche Schaltfläche HMC output folder auswählen
wird angezeigt. Wählen Sie diese Schaltfläche und den angegebenen Ordner.
3.3. Auswahl von Dateien und Ordnern
Der Datei- und Ordnerauswahlbereich bietet mehrere Suchoptionen. Die folgende Suchroutine wird emp
fohlen:
1. Drücken Sie auf Scan folder(s): Wählen Sie Laufwerk und Ordner aus dem Ordner-Browserdialog für
zu konvertierende Dateien.
Bei Bedarf kann der Dateifilter aktiviert werden, indem das Kontrollkästchen Enable File Filters akti
viert wird.
Aktivieren Sie ggf. das Kontrollkästchen Scan and list from subfolder(s), bevor Sie auf Scan folder (s)
klicken. Das Programm durchsucht alle Unterverzeichnisse.
2.	
File formats auswählen und ggf. weitere Dateifilter auswählen: Aktivieren oder deaktivieren Sie die
Dateiformate in der Liste, die Sie konvertieren möchten. Filter können außerdem je nach Dateigröße,
Dateidatum oder Dateiname eingestellt werden.
Derzeit verfügbare Dateitypen sind:
hyperCAD (e2, e3, GKD), CATIA V4, V5, DXF-DWG, IGES,
Inventor, Parasolid-Modell, PointFiles, PTC Creo-Modelldatei, Siemens NX-Modell Datei, Solidworks
model-Datei, STEP-Datei, STL-Datei, JT-Modelldatei.
Das Verhalten der Suchergebnisse im Dateiauswahlbereich ist wie folgt:
Enable File filters aktiviert: Dateitypen werden in Abhängigkeit von den geladenen Dateier
weiterungen und davon, was der Benutzer von Hand gewählt hat,
geprüft. Ein Filterwechsel wird nur auf die Liste angewendet,
nachdem Sie auf die Schaltfläche Apply filter geklickt haben.
Durch Drücken der Schaltfläche Refresh Folder (s)/File (s) wer
den die überprüften Laufwerke/Ordner zurückgesetzt, da sie je
nach den bereits geladenen Dateierweiterungen erneut aktuali
siert werden.
Enable File filters nicht aktiviert: Alle Dateiformate werden automatisch geprüft. Dateien aus
Unterordnern werden auch geladen oder gefiltert. Diese Bedin
gung wird automatisch auch nach dem Drücken der Schaltfläche
Clear selected Folder(s)/Files(s) durchgeführt.
Ohne Setzen des File Filters werden alle CAD-Dateiformate, die sich in dem ausgewählten Laufwerk
oder Ordner befinden, durch Drücken von Scan folder(s) aufgelistet.
Werden zuvor im File filters CAD-Dateiformate ab- oder anselektiert, werden nur die ausgewählten
CAD-Elemente beim Scannen des Laufwerks oder des Ordners durch Ausführen von Scan folder(s)
berücksichtigt und aufgeführt..

4. Dateikonvertierung starten
Nachdem Sie alle relevanten Dateien ausgewählt haben, können Sie die Dateikonvertierung einfach durch
Drücken von starten Start conversion to HMC.
Vor dem Start muss die Installation von lizenzierten Versionen von ,und sichergestellt sein.
• Drücken Sie Start conversion to HMC.
ANMERKUNG
Je nach Dateigröße und Dateikomplexität kann der Konvertierungsvorgang pro Datei
einige Minuten dauern.
Die Dateien werden jetzt konvertiert. Die konvertierte Datei wird als * .HMC-Datei gespeichert.
ANMERKUNG
Die resultierende HMC einer e2-Datei wird als * _e2.HMC gespeichert.
• Im Statusfenster können der Konvertierungsstatus und das Ergebnis beobachtet werden.
• Um die Konvertierung anzuhalten, drücken Sie Pause.

6. XML-Datei konfigurieren (optional)
Die Datei hmcBatchConverter.xml enthält einige relevante Einstellungen zum Verhalten des Tools und zur
Dateiauswahl, die vom Benutzer bearbeitet werden können. Im Allgemeinen muss diese Datei nicht impli
zit bearbeitet werden. Bearbeiten Sie hmcBatchConverter.XML, wenn Sie die folgenden relevanten Ver
zeichnisse und Daten dort anpassen möchten:
1. <Label>
hyperCAD-S Path</Label>, Z.B.. C:\Program Files\OPENMIND\hyperCAD-S\[Version]
\hmc.exe
2. <Label>Sleep time unit for multi threading (in seconds) </Label>, z. B. .2 Sekunden
3. <Label>Time interval for CAD memory size check, no size change isconsidered hanging CAD (in
minutes)<Label>, z. B. 2 Minuten
4. <Label>LOG files older than this amount of days are deleted when theapplication starts </Label>, z.
B. 15 Tage
5. <Label>Quit automatically
hyperCAD-S after EACH SINGLE conversionis finished [TRUE/FALSE] </
Label>:TRUE (Standardeinstelling): wird nach dem Konvertieren jeder Datei beendet und zum Kon
vertieren der nächsten Datei neu gestartet (pro: sicherer; alle Dateien werden konvertiert, auch wenn
eine Datei einen Fehler verursacht, contra: zeitaufwendig), nicht konvertierte Dateien befinden sich im
Ordner ‚j ', siehe unten. FALSE: wird nach der Konvertierung jeder Datei nicht beendet (pro: viel
schneller, contra: Wenn eine Datei einen Fehler verursacht, wird der Konvertierungsprozess nicht
beendet, die Dateikonvertierung wird nicht fortgesetzt).
6. <Label>Remember last folder selected by user[TRUE/FALSE]</Label>:TRUE: Der letzte Ordner wird
gespeichert. FALSE: Der letzte Ordner wird nicht gespeichert. Der Ordner ist leer.
7. <Label>Overwrite existing hmc [TRUE/FALSE]</Label>: TRUE: Vorhandene hmc-Datei wird über
schrieben, die Datei wird erneut konvertiert, FALSE: Vorhandene hmc-Datei im Ordner „h“ wird nicht
überschrieben, die Datei wird nicht erneut konvertiert.
8. <Label>hmc Output Path</Label>standardmäßig ist es leer; Wenden Sie sich für besondere Einstel
lungen an OPENMIND.
9. <Label>JS Output Path </Label>standardmäßig ist es leer; Wenden Sie sich für besondere Einstellun
gen an OPENMIND
10. <Label>LOG Output Path</Label>standardmäßig ist es leer; Wenden Sie sich für besondere Einstel
lungen an OPENMIND
11. <Label>not converted models folder </Label>standardmäßig ist es leer; Wenden Sie sich für besonde
re Einstellungen an OPENMIND
12. <File-Type>: Jeder Dateityp wird durch seinen speziellen XML-Abschnitt <FILE-TYPE> definiert, der
die folgenden drei Eigenschaften enthält:
TPYE_NAME Name of the file type, e.g. POINT files
TYPE_EXTENSIONS Alle verfügbaren Dateierweiterungen für diesen Dateityp, z. PT ASC XYZ TXT
für POINT-Dateien
TYPE_ACTIVE Zeigt den aktiven Status der Datei an. Hier sind keine Änderungen erforderlich
• Wenn Sie einen vollständigen FILE TYPE-Abschnitt löschen, wird der gelöschte FILE TYPE im
Dateiauswahlbereich angezeigt und nicht mehr geladen und gefiltert.

7. Fehlerbehebung
Der Batch Converter sollte zuverlässig funktionieren. Wenn dennoch Probleme auftreten, überprüfen Sie
Folgendes:
Die Konvertierung der e3-Datei funktioniert nicht.:
Laden Sie die e3-Datei in und speichern Sie die Datei als HMC-Datei.
Es gibt immer noch Probleme beim Laden von e3-Dateien:
Wenn beim Laden einer e3-Datei in Probleme auftreten, muss Folgendes geprüft werden:
1. Prüfen Sie Ihre Installation: Ist Thinkdesign installiert?
2. Prüfen Sie Ihre Lizenz: Ist eine Lizenz für Thinkdesign verfügbar?
3. Prüfen Sie Ihre Registration:“... \ OPENMIND \
hyperCAD-S \ [VERSION] \ bin \ converters \ tdhcbrid
ge.dll” ist nicht registriert Lösung: Führen Sie den Befehl "CMD" aus und fügen Sie regsvr32 ein "... \
OPEN MIND \
hyperCAD-S \ [VERSION] \ bin \ converters \ tdhcbridge.dll ". Bitte verwenden Sie den
neuesten -Installationspfad.
4. Überprüfen Sie die Registrierung auf den alten Namen des Pakets:„Tdesign.exe“ verschwindet nach
einigen Sekunden im Task-Manager, während e3 mit geladen wird. Lösung: Innerhalb des Registrie
rungsschlüssels löschen: HKEY_CURRENT_USER \ Software \ think3 \ thinkdesign \ 2009.3 \ Options
\ the key: ”BUNDLENAME ”.
5. Prüfen Sie die e3-Datei:
Kann die e3-Datei manuell geöffnet werden?
Fehlen externe Komponenten? Siehe Symbol im Modellbaum, löschen oder laden und speichern.
Sind Komponenten mit „Lichtdarstellung“ markiert? Aktivieren Sie "Vollbild".
Tritt beim Öffnen der e3-Datei eine Fehlermeldung auf? Versuchen Sie es zu lösen. Erstellen Sie den
Modellbaum neu.
Sind korrupte Entitäten im Modell? Prüfen Sie mit dem Befehl "Modellqualität".
Kopieren Sie alle Elemente in eine neue leere E3-Datei.
6. Ein Doppelklick auf die e3-Datei startet nicht :
Die Verknüpfung zwischen der e3-Datei und dem Programm fehlt. Prüfen Sie im Explorer im Kontext
menü der e3-Datei: "Öffnen mit" und wählen Sie im Installationsordner von die exe-Datei aus und akti
vieren Sie "permanent".
7. Gibt es noch Probleme??
Senden Sie die e3-Datei an das OPEN MIND-Supportteam.
