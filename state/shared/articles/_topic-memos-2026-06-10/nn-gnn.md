### Key techniques / claims (the actual ideas, terse bullets)
- **GraphSAGE link-prediction as a 5th wiring-inference tier.** 2-layer, mean aggregator, `concat(self, agg)`, ReLU hidden + **linear output** (ReLU on the final layer traps embeddings in the positive orthant → AUROC collapses to ~0.5), L2-normalized. Inference = `sigmoid(z_u · z_v)`. Pure JavaScript, no torch (`scripts/lib/graphsage-model.mjs`).
- **Edgeless-subgraph embedding to avoid label leakage** — unwired ghosts are graph-isolated, so the honest signal is the model's learned transform of symbolic features, not message passing; embedding the proposed-wire neighborhood would leak the cascade's own guesses.
- **Heterophily is the root failure.** Engine↔dispatcher edges connect *different* node types, so vanilla neighbor-blending destroys signal → link-pred AUROC sits at **0.096 (sub-random anti-correlation)**. The lever is **H2GCN** (Zhu 2020): ego/neighbor **separation** (`z = [ego ‖ agg(N1) ‖ … ‖ agg(NH)]`, never blended) + exactly-k-hop disjoint neighborhoods.
- **Multi-seed before any AUROC claim.** Single-seed lifts are noise traps — a simple-config single seed showed +0.118 while seed7 was −0.049. Only multi-seed at deploy-realistic config (768-d, 4000 nodes, 3 seeds) is trustworthy. H2GCN hops=2 gives robust +0.067; **hops=3 is the settled optimum at +0.138** but ceilings ~0.64, still below the 0.78 gate.
- **Post-hoc calibration is a measured dead end** (Murphy decomposition): reliability/miscalibration is only 0.0197 of the 0.179 Brier — the residual is *refinement* loss, which no monotone recalibration removes.
- **Selective deployment is the honest win.** At the production gate `minConf=0.7`, the tier abstains on 68% and defers to the LLM tier; on the **emitted set**: Brier 0.041 / macro-F1 1.0 / AUROC 0.808 (global) — **DEPLOY-READY-SELECTIVE** (El-Yaniv & Wiener risk@coverage), robust across all τ≥0.7.
- **Embedding degeneracy/collapse** — live 543-node embeddings have meanCosine 0.861 (random ≈ 0), centroidNorm 0.928 (~93% of every vector points one shared way); edge-predict scores saturate at sigmoid(1.0)=0.7311. A same-feature GPU re-embed is therefore wasted; the fix is sharper (H2GCN) features.
- **Int8 quantization for node-embedding storage** — `q[i] = round(v[i]*127)` clamped, ~4× disk savings, error ≤ 1/127 (below 768-d cosine noise floor).
