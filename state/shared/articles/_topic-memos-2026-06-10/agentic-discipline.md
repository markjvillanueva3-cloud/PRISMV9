### Key techniques / claims (terse)
- **The "I don't know" license** is half-config (CLAUDE.md honesty rules) + half-habit (reward "I haven't verified this" with patience, not frustration). A correct "I don't know" beats a confident guess.
- **Verify-before-claim AND verify-before-use**: read its def / grep it / check the manifest before asserting a symbol exists; cite `file:line` as the proof of that verification.
- **Never claim ABSENCE without an exhaustive search** — Glob the full tree + master-graph + wiki/memory + Ollama content-search before "no X exists."
- **Fail loud** (R12): "migration completed" is a lie if 30 records were skipped; "tests pass" is a lie if any `.skip`. Surface uncertainty, don't hide it.
- **Maker ≠ checker**: a *fresh, independent* model/agent verifies output against a rubric — kills self-preferential bias (Anthropic harness article; Addy Osmani; rody L4).
- **Stop hook runs the test suite** as the load-bearing "done" gate (rody article #2 keystone).
- **CLAUDE.md must stay short** (rody: >50 lines and Claude skims; Mnilax/PRISM: past ~200 lines compliance collapses) — doctrine lives as a *pointer index*, detail in memories/wiki.
- **Facts vs judgments labeled separately**; healthy dimensions get one sentence (no padding).
